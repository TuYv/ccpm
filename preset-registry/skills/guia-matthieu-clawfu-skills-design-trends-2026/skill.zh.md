# 2026 年设计趋势

> 将 2026 年占主导地位的 10 种平面设计美学应用于任何创意项目——基于 Kittl × Savee 的趋势报告，并有 Adobe、Figma 和 Pinterest 的平台数据作为支持。

## 何时使用此 Skill

- **为设计师或 AI 图像生成器撰写简报**——将模糊的“做得现代一些”转化为精确的风格词汇
- **创建品牌形象或进行视觉焕新**——选择与你的受众和定位相匹配的美学风格
- **制作情绪板**——结合趋势与意图，而不只是堆砌截图
- **设计社交媒体或营销素材**——使用当下正在各平台流行的视觉语言
- **提案创意方向**——用数据信号支持你的选择，而不只是依靠品味

## 方法论基础

**来源**：Kittl × Savee——《2026 年设计趋势报告》（2026 年 1 月）

**核心原则**：2026 年的设计处于两股力量的交汇点：手工创作的视觉元素正在回归（Adobe 报告显示，手绘元素的搜索量增长了 30% 以上），与此同时，AI 正在加速探索过程（根据 Figma 2024 年的数据，60% 的设计师会在早期概念阶段使用 AI）。2026 年最出色的作品存在于两者之间——凌乱与精准相遇，怀旧与未来交融，混乱与刻意并存。

**为何重要**：趋势并非装饰，而是文化信号。选择正确的视觉语言，能让你与受众已有的感受产生连接。选择错误，则会让你被忽视或显得过时。此 Skill 为你提供词汇、数据和决策框架，帮助你有意识地做出选择。

## 2026 年十大趋势

### #1 — 稚拙设计
**标语**：“当杂乱胜过完美”

**视觉基因**：摇晃的线条、不均匀的填色、潦草的线稿、儿童般的插画、手绘的温暖感、笑脸形状、刻意为之的颤抖笔触。

**配色方案**：明亮的原色、蜡笔般的色调、米白色或再生纸背景。

**字体设计**：手写字体、不齐整的基线、马克笔或蜡笔质感。

**文化信号**：在经历多年由 AI 塑造的平滑完美之后，人们渴望看到作品由人类创作的证据。稚拙设计并非缺乏技巧，而是在了解规则的基础上，自信地打破规则。

**最适合**：
| 受众 | 有效的原因 |
|----------|-------------|
| 儿童产品 | 有趣、可信且富有吸引力 |
| 食品饮料／手工艺品牌 | 亲切、真诚且富有手工质感 |
| 时尚与街头服饰 | 表现力强且引领潮流 |
| 创意机构／初创企业 | 个性驱动，反传统企业风格 |
| 健康与身心疗愈 | 温暖，可弱化临床感 |

**AI 提示词关键词**：`naive illustration, childlike drawing, wobbly linework, hand-drawn imperfect, crayon texture, uneven fills, sketchy warmth, doodle art`

**适合搭配**：童趣核心（增强趣味性）、字体拼贴（增添活力）

**避免搭配**：监控设计、蓝图设计（与原始质朴感相矛盾）

**参考图片**：`docs/kittl-2026-trends/01-naive-design.png`

### #2 — 字体拼贴
**标语**：“以高冲击力字体设计构成画面”

**视觉基因**：在同一版式中混合多种字体、字号和样式。文字相互重叠、文本块旋转排布，并呈现剪纸美学。仅通过字体设计便实现视觉极繁主义。

**配色方案**：高对比度——以黑白为基础，搭配 1-2 种醒目的强调色。或者使用完整的霓虹色谱。

**字体设计**：每个构图使用 3 种以上字体。衬线体 + 无衬线体 + 展示字体。运用多种可变字重。文字本身就是视觉主体。

**文化信号**：平台原生创意与 DIY 小志怀旧风格相遇。Z 世代认为这种风格新鲜而真实。大胆、兼收并蓄，并有意打破规则。

**最适合**：
| 受众 | 有效原因 |
|----------|-------------|
| 音乐 / 活动 / 音乐节 | 瞬间营造活力与氛围 |
| 时尚品牌 | 引领潮流，富有编辑设计感 |
| 社交媒体内容 | 抓人眼球，贴合平台原生风格 |
| 杂志 / 编辑设计 | 大胆尝试版式布局 |
| 面向年轻人的品牌 | 深谙文化语境，奉行极繁主义 |

**AI 提示词关键词**：`type collage, mixed typography, overlapping text, typographic composition, zine layout, cut-paper lettering, bold type mix, maximalist typography`

**适合搭配**：朋克垃圾风（增添叛逆感）、稚拙设计（增添温暖感）

**避免搭配**：颗粒模糊风（与易读性冲突）

**参考图像**：`docs/kittl-2026-trends/02-type-collage.png`

### #3 — 蓝图设计
**标语**：“将过度解释化为美学”

**视觉基因**：技术制图语言——箭头、尺寸标注、爆炸图、部件标签、网格背景、示意线条、注释标注。将一双运动鞋拆解成 47 个部件。把拉面绘制得如同机器一般。

**配色方案**：经典蓝图配色（蓝底白线），或反转配色（奶油色/白底深色线条）。单色为主，搭配一种强调色。

**字体排印**：等宽字体、技术风格、小型大写字母、类似 DIN 的字体。将标签和注释作为设计元素。

**文化信号**：让普通产品显得经过精心设计与考量。对细节的极致追求本身就是炫耀资本。以诙谐的过度解释创造视觉幽默。

**最适合**：
| 受众 | 有效原因 |
|----------|-------------|
| 科技 / SaaS 产品 | 传达精准与匠心 |
| 运动鞋 / 街头服饰文化 | 痴迷细节的受众对此青睐有加 |
| 食品与饮料（精工制作） | “拆解原料” |
| 产品发布 | 让任何产品都显得经过深思熟虑 |
| 具有设计鉴赏力的消费者 | 巧妙、细节丰富，值得细细品味 |

**AI 提示词关键词**：`blueprint design, technical drawing, exploded view diagram, schematic illustration, annotated product, engineering diagram style, labeled parts, grid background, measurement lines`

**适合搭配**：监控设计（同样注重精准）、信号图形（增添活力）

**避免搭配**：稚拙设计（精准度与之相反）、颗粒模糊风（与清晰度相矛盾）

**参考图像**：`docs/kittl-2026-trends/03-blueprint-design.png`

### #4 — 小物设计
**标语**：“以物件彰显身份”

**视觉基因**：将日常物件（贝壳、纽扣、硬币、水果、水晶）排列成整齐的网格或博物馆风格的平铺陈列。兼具静物摄影与剪贴簿风格。俯拍摄影、柔和阴影、中性背景。

**配色方案**：柔和的自然色——奶油色、石色、腮红色、鼠尾草绿。由物件提供色彩。温暖且富有触感。

**字体排印**：简约优雅的衬线字体或纤细的无衬线字体。退居物件之后。

**文化信号**：体现当代文化对策展式整理的痴迷——Pinterest 收藏板、“我的包里有什么”帖子、搁架造型。通过收藏的物件表达身份。

**最适合**：
| 受众 | 有效原因 |
|----------|-------------|
| 生活方式品牌 | 兼具个人感与向往感 |
| 时尚与配饰 | 构建产品策展叙事 |
| 健康与美容 | 以触感呈现成分故事 |
| 编辑设计 / 杂志 | 精致高级的平铺美学 |
| 电子商务 | 将产品置于情境中的造型展示 |

**AI 提示词关键词**：`trinket design, curated flat lay, museum display arrangement, object collection grid, still life curation, knolling photography, tactile objects, overhead arrangement`

**适合搭配**：颗粒模糊（增添梦幻感）、稚拙设计（增添温暖感）

**避免搭配**：朋克垃圾风（与整洁感相冲突）、信号图形（过于混乱）

**参考图像**：`docs/kittl-2026-trends/04-trinket-design.png`

### #5 — 朋克垃圾风
**标语**：“通过艺术表达叛逆之声”

**视觉基因**：撕裂的纸张纹理、复印机噪点、极具攻击性的字体、喷漆痕迹、贴纸、胶带和破损边缘。粗粝、喧闹、刻意凌乱。以不加修饰作为一种态度表达。

**配色方案**：高对比度——以黑白为基础，搭配霓虹强调色（亮粉色、电光黄、红色）。所有元素均覆以脏污纹理。

**字体排印**：做旧、印章、模板喷字、剪贴式勒索信风格。打字机字体。带有愤怒情绪的手写体。

**文化信号**：对 AI 式平滑完美的直接反击。设计师为算法注入灵魂。这并非对机器的愤怒，而是一次重新转向粗粝感、意外感和人类印记的方向修正。

**最适合**：
| 受众 | 有效原因 |
|----------|-------------|
| 音乐／地下文化 | 真实的叛逆美学 |
| 街头服饰／滑板品牌 | 反主流文化公信力 |
| 独立／另类品牌 | 反企业化定位 |
| 青年行动主义／小志 | DIY 精神，制作门槛低 |
| 精酿啤酒／纹身工作室 | 粗粝、毫不掩饰的个性 |

**AI 提示词关键词**：`punk grunge design, torn paper collage, xerox texture, distressed typography, spray paint marks, sticker bomb, ripped edges, raw gritty aesthetic, anti-design`

**适合搭配**：字体拼贴（增强能量感）、稚拙设计（营造更柔和的叛逆感）

**避免搭配**：Frutiger Aero（风格极性相反）、小物件设计（与混乱感相冲突）

**参考图像**：`docs/kittl-2026-trends/05-punk-grunge.webp`

### #6 — 未来中世纪
**标语**：“像身处 1426 年——也像身处 2026 年那样设计”

**视觉基因**：哥特式拱门、华丽边框、泥金装饰手抄本细节、纹章符号——与数字故障效果、霓虹强调色和未来主义叠加元素相结合。巴洛克式极繁主义与赛博朋克交汇。

**配色方案**：深邃的宝石色调（勃艮第红、宝蓝色、金色），搭配明亮的霓虹高光色（青色、洋红色）。使用深色背景。

**字体排印**：以哥特体／黑体字为主。搭配纤细的无衬线字体或等宽字体形成对比。使用装饰性首字母。

**文化信号**：突破极简主义，以讲述更丰富的故事。Pinterest 和 Adobe 均证实，中世纪字体的搜索量正在激增。熟悉的历史加上全新的数字化变化，形成了独特的心理吸引力。

**最适合**：
| 受众 | 有效原因 |
|----------|-------------|
| 游戏／奇幻品牌 | 美学风格天然契合 |
| 高端／奢侈品牌 | 华丽装饰＝更高的感知价值 |
| 音乐（金属、暗黑电子） | 与流派原生视觉语言契合 |
| 时尚（暗黑、前卫） | 具有编辑大片般的戏剧张力 |
| 精酿／手工烈酒 | 传统传承＋现代感 |

**AI 提示词关键词**：`future medieval, gothic digital art, illuminated manuscript modern, blackletter neon, heraldic cyberpunk, ornate border glitch, dark baroque futuristic, medieval meets digital`

**适合搭配**：扭曲肖像（增强戏剧感）、监控设计（增添暗黑科技层次）

**避免搭配**：童趣核心（调性不符）、稚拙设计（过于轻快）

**参考图像**：`docs/kittl-2026-trends/06-future-medieval.png`

### #7 — 扭曲肖像
**标语**：“表达你最大胆的精神状态”

**视觉基因**：面部被拉伸、故障化、液化、碎片化或分层。扭曲的五官、双重曝光、扫描线效果、像素位移。具有人性，却又诡异异常。

**配色方案**：不限——可以是情绪化的单色、高饱和霓虹色，也可以是带有故障风点缀的自然色调。扭曲本身就是色彩叙事。

**字体排印**：与整体风格相匹配的扭曲处理——弯曲的基线、故障化字形、拉伸字体。

**文化信号**：摆脱“精致但可预测”。在 AI 生成的图库人像盛行的时代，这种风格富有表现力、人情味与颠覆性。随着 AR 滤镜和 VR 虚拟形象日益普及，扭曲将静态艺术与沉浸式空间连接起来。

**最适合**：
| 受众 | 奏效原因 |
|----------|-------------|
| 音乐 / 专辑封面 | 充满情感与表现力的叙事 |
| 时尚 / 美妆品牌 | 颠覆性的先锋气质 |
| 心理健康 / 身心健康 | 将内在状态视觉化 |
| 艺术 / 画廊 / 文化 | 概念深度 |
| 科技 / AI 品牌 | 人类与数字相遇的隐喻 |

**AI 提示词关键词**：`distorted portrait, glitch face, liquified features, double exposure portrait, fragmented face, pixel displacement, warped portrait photography, scan line distortion`

**适合搭配**：朋克垃圾风（强化粗粝感）、颗粒模糊（增添梦幻质感）

**避免搭配**：蓝图设计（氛围完全相反）、饰品设计（主题冲突）

**参考图像**：`docs/kittl-2026-trends/07-distorted-portrait.png`

### #8 — 监控设计
**标语**：“当精准影像开始发声”

**视觉基因**：闭路电视画面、生物识别 HUD、识别框、十字准星、系统日志、单色叠加层、时间戳结构。提取自安防系统的 UI 元素。严谨的网格、实用主义字体排印。

**配色方案**：高对比度的极简配色——黑色、白色、绿色（夜视）、红色（警报）。单色基调搭配数据叠加层强调色。

**字体排印**：等宽字体（Courier、JetBrains Mono）、全大写系统文本、时间戳、坐标、状态标签。

**文化信号**：一种受控的反乌托邦美学，传达监视、精确与数据流动。它将概念上的锐利感与围绕身份、可见性和控制的文化相关性融为一体。

**最适合**：
| 受众 | 奏效原因 |
|----------|-------------|
| 科技 / 网络安全品牌 | 原生视觉语言 |
| 音乐（电子、工业） | 暗黑且富有氛围感 |
| 时尚（机能服、实用主义） | 功能性美学 |
| 数据 / 分析产品 | 传递精准感 |
| 电影 / 媒体（惊悚、科幻） | 营造氛围基调 |

**AI 提示词关键词**：`surveillance design, CCTV aesthetic, biometric HUD overlay, security camera feed, system log typography, crosshair targeting, night vision green, dystopian data interface`

**适合搭配**：蓝图设计（同样强调精准）、未来中世纪（深色分层）

**避免搭配**：稚拙设计（氛围相反）、童趣核心（调性冲突）

**参考图片**：`docs/kittl-2026-trends/08-surveillance-design.webp`

### #9 — 颗粒模糊
**标语**：『创造梦幻、感性的图形』

**视觉基因**：带有颗粒/噪点叠加效果的柔焦处理。失焦摄影或渐变。胶片颗粒纹理。柔和或粉彩色调相互晕染。具有电影感的模拟影像温度。

**配色方案**：低饱和粉彩、柔和大地色或氛围感深色——全部带有可见的颗粒/噪点。温暖的模拟胶片色彩。

**字体设计**：柔和、优雅，通常略带透明感或融入模糊效果之中。衬线体或细无衬线体。

**文化信号**：受众已经厌倦了极度锐利的『完美』图像。接纳不完美能够增添温度、深度和真实感。整体呈现出电影般、梦幻且情感充沛的感觉。

**最适合**：
| 受众 | 奏效原因 |
|----------|-------------|
| 音乐 / 专辑封面 | 由氛围驱动，富有情感 |
| 美妆 / 护肤品牌 | 柔和、令人向往、富有触感 |
| 健康 / 冥想 | 平静、富有氛围 |
| 时尚（编辑风格） | 梦幻、富有电影感 |
| 酒店 / 旅行 | 浪漫、令人向往 |

**AI 提示词关键词**：`grainy blur design, soft focus noise texture, film grain overlay, dreamy blurred gradient, analog photography aesthetic, cinematic grain, muted pastel blur, out-of-focus noise`

**适合搭配**：饰品设计（增加纹理）、扭曲肖像（增加情感）

**避免搭配**：蓝图设计（与精准感矛盾）、监控设计（温度感相反）

**参考图片**：`docs/kittl-2026-trends/09-grainy-blur-main.webp`、`09-grainy-blur-noise.webp`、`09-grainy-blur-floral.webp`

### #10 — 信号图形
**标语**：『源自 90 年代电视和 Y2K 的动感视觉』

**视觉基因**：动画形状、相互碰撞/变形的物体、爆炸性色彩。3D 与扁平图形混合。超高饱和度、卡通化、张扬。早期 CGI 的活力、爆炸形状、频道标识动画和过载色彩。

**配色方案**：饱和度拉满——霓虹绿、电光蓝、亮粉色、铬银色。随处可见的渐变。闪亮、光滑的表面。

**字体设计**：粗体、3D 挤出效果、铬金属或渐变填充。活泼、超大，令人无法忽视。

**文化信号**：90 年代/Y2K 怀旧风与当今令人过度刺激的社交信息流相遇。其设计旨在动起来、打断注意力，并在嘈杂环境中脱颖而出。娱乐性优先于含蓄表达。

**最适合**：
| 受众 | 奏效原因 |
|----------|-------------|
| 音乐 / 播客 | 张扬、吸引注意力 |
| 服装 / 周边商品 | 大胆的图形 T 恤和印花 |
| 游戏 / 电子竞技 | 与其原生活力水平相契合 |
| 数字营销活动 | 让人停止滚动的社交内容 |
| Z 世代 / 青年品牌 | 既怀旧又新鲜 |

**AI 提示词关键词**：`signal graphics, Y2K design, 90s TV ident, exploding shapes, hyper-saturated 3D, chrome text, early CGI aesthetic, neon color overload, kinetic graphics`

**适合搭配**：字体拼贴（极繁主义组合）、朋克垃圾风（叛逆能量）

**避免搭配**：饰品设计（能量感相反）、颗粒模糊（与锐利感冲突）

**参考图像**：`docs/kittl-2026-trends/10-signal-graphics.webp`

## 示例

### 示例 1：精品咖啡品牌识别

**背景**：一家新创精品咖啡烘焙商，目标受众是重视真实性的 25-35 岁都市人群。

**输入**：
> 我正在推出一个名为「Grounds」的精品咖啡品牌。我们的受众是注重产地和制作过程的都市千禧一代。我们希望呈现手工质感，但不要显得矫饰。哪些 2026 年趋势适合我们？

**输出**：

**主要趋势：蓝图设计（#3）**
你的受众喜欢制作过程和产地故事。蓝图设计让你能够将咖啡之旅解构为视觉识别元素——咖啡豆结构、烘焙温度曲线、冲煮比例。它传递出「我们痴迷于工艺」的信号，同时又不会显得自命不凡。

**辅助趋势：稚拙设计（#1）**
用手绘的温暖感来平衡技术上的精确性。比如线条略带摇晃感的咖啡植物插画，以及手写的产地名称。这一组合表达了「知识深厚，但平易近人」。

**避免**：朋克垃圾摇滚风（对于晨间仪式而言过于激进）、未来中世纪风（情感基调不符）、信号图形（对于需要沉静体验的产品而言过于喧闹）。

**包装 AI 提示词**：
```
Specialty coffee bag design, blueprint technical drawing of coffee bean cross-section
with labeled parts and measurement annotations on cream background, hand-drawn naive
illustration of coffee plant in corner, monospaced typography for origin details,
warm artisanal feel with engineering precision, product packaging mockup
```

**情绪板方向**：
- 色彩：奶油色基底 + 深棕色 + 一种强调色（陶土色或鼠尾草绿）
- 字体：技术标签使用 DIN 或 Space Mono + 手写品牌名称
- 纹理：浅色网格纸背景、细微的铅笔痕迹
- 构图：以带标注的产品图解作为主视觉图形

**有效原因**：蓝图设计 + 稚拙设计是源报告中并不存在的趋势组合——它通过综合创新创造出原创效果，同时又紧跟趋势。

### 示例 2：电子音乐节社交媒体宣传活动

**背景**：一个夏季电子音乐节希望打造能在拥挤的音乐内容信息流中脱颖而出的社交媒体内容。

**输入**：
> 为「SIGNAL」音乐节社交媒体宣传活动提供设计方向。电子音乐，受众年龄 18-30 岁，需要主导 Instagram 和 TikTok。

**输出**：

**主要趋势：信号图形（#10）**——这个名字几乎已经写好了设计简报。Y2K 能量、超高饱和度的 3D 形状、爆炸般的色彩。你的受众正是在这种风格中成长起来的。它既怀旧，又面向未来。

**辅助风格：扭曲肖像（#7）** — 以扭曲肖像形式呈现艺人官宣，能够立即激发好奇心。为艺人阵容照片添加故障效果。让人们停止滚动，试图弄清楚这是谁。

**第三层：监控设计（#8）** — 将音乐节倒计时内容设计成系统日志和闭路电视风格的画面。以“检测到信号”作为反复使用的文案框架。

**用于社交媒体帖子的 AI 提示词**：

艺人官宣：
```
Electronic music DJ portrait with pixel displacement and scan-line distortion,
neon magenta and electric cyan color scheme, fragmented face with glitch effects,
dark background with surveillance grid overlay, hyper-saturated Y2K aesthetic,
square format for Instagram
```

活动倒计时：
```
Surveillance camera interface design showing countdown timer, green night vision
aesthetic with CCTV timestamp, "SIGNAL DETECTED" text in monospaced font,
crosshair overlay, dark dystopian data interface, Instagram story format 9:16
```

通用宣传活动素材：
```
Exploding 3D chrome shapes on black background, hyper-saturated neon colors,
90s TV ident energy, signal graphics style, kinetic explosive composition,
bold 3D extruded text, Y2K nostalgia meets futuristic, widescreen 16:9
```

**这种组合为何有效**：这三种趋势拥有相同的能量水平（高），并且面向一致的受众（年轻的数字原住民）。这种组合能够创造出鲜明独特的音乐节形象，其他活动无法仅靠模仿其中一种趋势来复制。

### 示例 3：健康应用品牌焕新

**背景**：一款冥想/健康应用需要焕新视觉形象，从“千篇一律的平静”美学中脱颖而出。

**输入**：
> 每款健康应用看起来都一样——柔和的渐变、纤细的字体、过多的留白。我们如何在保持平静感的同时实现差异化？

**输出**：

**主要风格：颗粒模糊（#9）** — 仍然平静，但以模拟媒介的温暖取代数字媒介的冷漠。胶片颗粒增添了质感和人情味。柔焦营造出氛围，同时避免呈现“图库素材式冥想”的观感。

**辅助风格：小物件设计（#4）** — 不使用千篇一律的自然照片，而是精心挑选富有意义的物件：一块光滑的石头、一只茶杯、一根蜡烛、一本日记。精心陈列的平铺构图让人感觉既个性化，又令人向往。

**避免使用**：稚拙设计（对该品类来说过于活泼）、朋克垃圾摇滚风（整体氛围完全不符）、信号图形（感官过载与产品用途相矛盾）。

**与竞争对手相比有何不同**：
大多数健康应用都采用鲜明、整洁的渐变（约 2020 年的 Headspace/Calm 美学）。颗粒模糊带来了可触摸般的温暖质感——感觉就像透过一扇略微起雾的窗户观看。小物件设计通过物品而非千篇一律的插图来增添个性。

**风格指南用语**：
```
We are: Warm, textured, intentionally imperfect
We are NOT: Clinical, sharp, digitally sterile
Our references: Grainy Blur (atmosphere) + Trinket Design (curation)
Our anti-references: Frutiger Aero (too tech), Blueprint (too analytical)
```

## 技能边界（边界识别）

### 此技能擅长：
- 为特定受众选择并组合视觉美学
- 生成采用流行风格的精准 AI 提示词
- 以文化逻辑为依据构建情绪板和风格指南
- 通过选择不那么显而易见的趋势组合，与竞争对手形成差异化

### 此技能不适用于：
- **预测哪些趋势会长久持续** → 趋势是信号，而非保证。请结合你的受众进行验证。
- **替代受过专业训练的平面设计师** → 此技能提供方向，而非可用于生产的文件。
- **非视觉类品牌决策** → 如需制定传播信息或定位，请使用 `brand-strategy` 或 `positioning` 技能。
- **高度本地化或小众的亚文化** → 这 10 种趋势是主流信号。亚文化的变化更快，方式也有所不同。

### 质量检查点

在接受输出结果之前，请确认：
- [ ] 推荐的趋势确实符合目标受众，而不只是“看起来很酷”
- [ ] 文化信号说明符合品牌定位逻辑
- [ ] AI 提示词足够具体，能够生成一致的结果
- [ ] 趋势组合不会造成调性冲突（查看“避免组合”指南）
- [ ] 该方向能够与竞争对手形成差异，而不只是追随他们正在使用的相同趋势

## 迭代指南

> “第一轮选择趋势。第二轮让它成为你的专属方向。”

### 推荐的迭代模式

| 轮次 | 重点 | 要提出的问题 |
|------|-------|------------------|
| **第 1 轮** | 趋势选择 | “这一趋势是否符合我的受众已经会产生共鸣的内容？” |
| **第 2 轮** | 组合 | “主要趋势与辅助趋势的组合是否创造出了原创效果？” |
| **第 3 轮** | 具体程度 | “AI 提示词／情绪板描述是否足够精确，可以用来向他人传达需求？” |
| **第 4 轮** | 差异化 | “竞争对手是否也会得出相同的组合？如果会，就进一步突破。” |

### 实用的后续提示词

- “这感觉太笼统了。请为 [audience] 尝试一种不那么显而易见的趋势组合。”
- “我的竞争对手已经在使用 [trend]。有什么与其相近但有所不同的选择？”
- “向我展示这一趋势将如何应用于 [specific deliverable: packaging / social / web header]。”
- “创建 3 种变体——一种稳妥、一种大胆、一种实验性。”
- “[specific designer or brand you admire] 会如何运用这一趋势？”
