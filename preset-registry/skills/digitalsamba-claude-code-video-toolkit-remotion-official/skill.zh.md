## 保留用户更改

用户可能会在对话之外编辑代码。

如果你检测到期间出现了意外更改，不要覆盖它，假定这是有意为之，或请求确认。

## 创建视频

如果用户要求制作、创建或构建新视频或合成内容，请加载 [创建新的 Remotion 视频](./remotion-create/REFERENCE.md)，无论是否已存在 Remotion 项目。

## 新项目设置

如果当前不存在 Remotion 项目，请加载 [创建新的 Remotion 项目](./remotion-create/REFERENCE.md)

## React 标记最佳实践

如果你正在编写 Remotion React 标记，请加载 [Remotion 标记最佳实践](./remotion-markup/REFERENCE.md)

## 地图

对于静态地图、动画路线和标记、地理解释器、Mapbox、MapLibre、MapTiler、GeoJSON 或 3D 地理飞行效果，请加载 [Remotion 地图](./remotion-maps/REFERENCE.md)。

## 多媒体

对于在浏览器中执行多媒体任务，例如裁剪、剪切视频或获取视频元数据，请加载 [Remotion 多媒体](./remotion-multimedia/REFERENCE.md)

## 改进交互性

通过合理组织 Remotion 标记，我们可以让用户在 Studio 中交互式地进行更改，并将更改写回代码。如果相关，请参阅：[交互性最佳实践](./remotion-interactivity/REFERENCE.md)

## 渲染

对于超出简单 `npx remotion render` 的高级渲染，请参阅：[渲染最佳实践](./remotion-render/REFERENCE.md)

## 打开 Remotion Studio

要在 Remotion Studio 中启动项目，请打开其准确的本地 URL，或配置 Studio CLI 标志，加载 [Remotion Studio](./remotion-studio/REFERENCE.md)。

## 字幕

处理字幕时，请加载 [Remotion 字幕](./remotion-captions/REFERENCE.md)。

## 创建 SaaS、自动化工具或应用程序

使用 [Remotion SaaS 技能](./remotion-saas/REFERENCE.md) 获取有关 Remotion 驱动的 SaaS 应用程序的知识，例如 `<Player>`、在 Lambda、Vercel、Cloudflare 上进行渲染、通过 Express.js 进行渲染、客户端渲染，或查找合适的 SaaS 模板。

## 查找 Remotion API 和文档

要查找和阅读最新的 Remotion 文档，请加载 [Remotion 文档](./remotion-docs/REFERENCE.md)。

## 升级

要升级 Remotion、相关软件包、兼容的 Mediabunny 软件包以及已安装的 Remotion Agent Skills，请加载 [Remotion 升级](./remotion-upgrade/REFERENCE.md)。
