# TikTok 广告规划

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。此插件未声明第一方 NotFair TikTok MCP 变更操作接口；仅基于经过验证的来源材料进行规划和审核。

## 让最初几秒可测试

在撰写创意内容之前，先明确转化事件、衡量负责人、落地页和已获批准的优惠方案。围绕鲜明的首秒钩子、产品演示或证据、原生格式的制作方向、CTA，以及适合各版位安全裁切的构图来构思创意。核实创作者权利、音乐授权、用户证言以及价格/效果声明；将证据未知的内容标记为 `needs_substantiation`。

采用一小组真正不同的钩子或形式。每个方案都应包含受众假设、创意变量、主要指标、护栏指标、预期曝光量、审核日期，以及会导致该方案被淘汰的结果。若没有指定的下游衡量指标，不要将观看量或 CTR 视为转化成功。

## 交接给操作人员

向人工操作人员提供准确的上线简报：目标、以账户币种表示的预算、定向逻辑、排除条件、需要在当前平台 UI 中验证的事件/像素要求、所需的创意文件以及状态。若没有当前已验证的来源，不得虚构 TikTok 设置、资格条件、最低预算或发布确认。
