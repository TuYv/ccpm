# 专家秘诀

> 运用 Russell Brunson 的框架，围绕专业知识打造一场大众运动——包括魅力领袖定位、新机会型产品、打破信念的故事，以及完美网络研讨会结构。

## 何时使用此技能

- **将自己定位为专家**，通过在线知识变现
- **基于专业知识创建在线课程或教练辅导项目**
- **设计网络研讨会**，将参与者转化为购买者
- **建立社群**，赋予其身份认同、共同事业和集结口号
- **使用顿悟之桥公式创作起源故事**
- **使用价值堆叠幻灯片技巧包装产品**

## 方法论基础

| 方面 | 详细信息 |
|--------|---------|
| **来源** | Russell Brunson — *《专家秘诀》*（2017） |
| **核心原则** | 每一场大众运动都有三个要素：一位魅力领袖、一个新机会（而非改进方案），以及一项面向未来的事业 |
| **关键洞察** | 人们不想修补已有的问题——他们想要一种实现愿望的新载体 |

## Claude 做什么与你决定什么

| Claude 做什么 | 你决定什么 |
|-------------|------------|
| 针对你的细分领域构建专家秘诀框架 | 你的个人故事和真实表达风格 |
| 确定你的魅力角色类型 | 将哪方面的专业知识变现 |
| 起草顿悟之桥故事和信念破除内容 | 最终的创意方向和语气 |

| 创建包含三个秘密的完美网络研讨会大纲 | 面向哪个受众群体 |

## 说明

### 第 1 部分：创建你的大众运动

三个必备要素：

**1. 魅力领袖**——选择你的类型：
- **领袖**——以身作则，展示成功（最适合已经取得成果的人）
- **冒险家**——带领追随者踏上一段旅程（最适合与受众一同探索的人）
- **记者**——成为专家与受众之间的桥梁（最适合经验尚浅但充满热情的人）

**2. 新机会**——设计一种载体转换，而不是改进型产品：
- 确定受众想要的结果
- 确定他们当前使用的载体（他们现在正在做什么）
- 创建你的机会转换方案（使用具有专属性名称的新载体）
- 关键：“重点不是少吃，而是根据你自己的新陈代谢方式正确饮食”

**3. 面向未来的事业**——团结你的社群：
- 创建集结口号／标语
- 为你的社群命名（例如，“漏斗黑客”）
- 撰写一份“我是___”的身份宣言
- 为进步设计里程碑奖励

### 第 2 部分：打破错误信念

找出**关键多米诺骨牌**——那个能让购买成为必然的唯一信念：

> “如果我能让人们相信，**[新机会]**是实现**[期望结果]**的关键，并且只能通过**[我的框架]**获得，那么其他所有异议都会变得无关紧要。”

然后使用顿悟之桥故事打破三种错误信念模式：

| 信念类型 | 它是什么 | 故事结构 |
|-------------|------------|-----------------|
| **载体** | “这种方法行不通” | 背景故事 → 障碍 → 顿悟 → 转变 |
| **内在** | “我做不到” | 使用相同结构，重点聚焦于自我怀疑 |
| **外在** | “我的客观条件不允许我这样做” | 使用相同结构，重点聚焦于外部障碍 |

### 第 3 部分：构建完美的网络研讨会

| 环节 | 时长 | 内容 |
|---------|----------|---------|
| **开场** | 5-10 分钟 | 以承诺作为钩子，建立可信度，预告产品方案 |
| **秘密 #1** | 15-20 分钟 | 唯一关键点——打破对载体的错误信念 |
| **秘密 #2** | 15-20 分钟 | 隐藏的好处——打破内在错误信念 |
| **秘密 #3** | 15-20 分钟 | 新机会——打破外在错误信念 |
| **价值堆叠与成交** | 20-30 分钟 | 展示价值堆叠幻灯片、试探性成交、制造紧迫感、CTA |

全程使用**试探性成交**：“你能看出为什么这很重要吗？”→“你能看出这如何能对你奏效吗？”→ 连续回答“是”的模式会让最终购买显得自然而然。

### 第 4 部分：构建价值堆叠幻灯片

1. 定义核心产品方案
2. 添加针对每个错误信念的赠品
3. 添加快速行动赠品
4. 为每个组成部分赋予价值（总价值应为价格的 10 倍）
5. 在构建完整价值后揭示实际价格

### 第 5 部分：设计价值阶梯

以多个价格档位将专业知识产品化：

| 层级 | 形式 | 交付方式 |
|-------|--------|-------------|
| 免费 | 内容、获客赠品 | 自己完成 |
| $7-27 | 图书 | 自己完成 |
| $97-997 | 在线课程 | 自己完成 |
| $997-2,997 | 团体辅导 | 陪你一起完成 |
| $10K+ | 大师班 / 一对一 | 为你完成 |

**验证检查点：**在构建更高层级的产品方案之前，确认你已经从较低层级获得客户证言和案例研究。

## 示例

### 示例：健身教练

- **领袖类型：**冒险家（“我曾经超重 50 磅，尝试过所有方法，直到我发现……”）
- **新机会：**“代谢重置法”（而不是“改善你的饮食”）
- **社群：**“重置勇士”
- **大多米诺骨牌：**优化激素 → 持久减重 → 只能通过代谢重置实现
- **价值堆叠：**12 周计划（价值 $1,997）+ 激素指南（$297）+ 膳食模板（$197）+ 社群（$497）+ 启动通话（$297）= 价值 $3,285 → 价格：$497

有关填空式模板（顿悟之桥脚本、完美网络研讨会规划器、价值堆叠幻灯片构建器、大多米诺骨牌陈述），请参阅 [TEMPLATES.md](TEMPLATES.md)。

## 技能边界

### 此技能擅长的方面
- 使用 Brunson 经过验证的框架构建专家定位
- 设计能够避开“改进”陷阱的新机会型产品方案
- 为网络研讨会和发布活动创建打破信念的故事序列
- 使用具有说服力的价值架构构建价值堆叠幻灯片产品方案

### 此技能无法做到的方面
- 验证市场需求（请先使用 `mom-test` 或 `customer-discovery`）
- 撰写最终销售文案（请使用 `copywriting-schwartz` 或 `landing-page-copy`）
- 处理网络研讨会的技术设置或平台选择
- 保证转化率——框架的质量取决于输入的质量
