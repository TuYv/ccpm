# Markdown 转 EPUB 转换技能

本技能可将 markdown 文档转换为专业的 EPUB 电子书文件。非常适合将研究文档、博客文章、文章或聊天对话摘要转换为便携、与设备无关的电子书格式。

## 概述

该技能接受多种形式的 markdown 内容，并生成格式规范的 EPUB3 文件，可在所有主流电子书阅读器上正常使用，包括：
- Apple Books
- Amazon Kindle（通过 Kindle for Mac/Windows/iOS/Android）
- Google Play Books
- Kobo 及其他 EPUB 阅读器
- 任何标准 EPUB 阅读器

## 输入格式

### 选项 1：原始 Markdown 文本
直接在消息中提供 markdown 内容：

```
Convert this markdown to EPUB:
# My Book Title
## Chapter 1
This is chapter one content...
```

### 选项 2：文件路径
提供待转换的 markdown 文件的路径。

## 工作原理

1. **Markdown 解析**：分析你的 markdown，并自动：
   - 将 H1 标题（`#`）视为章节边界
   - 将 H2 标题（`##`）视为章节内的小节标题
   - 保留格式（粗体、斜体、链接、列表、代码块）

2. **结构生成**：创建规范的 EPUB 结构：
   - 根据章节自动生成目录
   - 导航文档（EPUB3 标准）
   - 元数据（标题、语言等）

3. **文件创建**：生成有效、可随时下载使用的 EPUB3 文件

## 获得最佳效果的技巧

1. **使用规范的 Markdown 结构**：当 markdown 遵循标准约定（H1 用于标题，H2 用于小节）时，该技能效果最佳

2. **清晰的章节分隔**：使用 H1 标题清晰地标记章节划分

3. **具有描述性的标题**：标题会成为目录，因此请使其清晰且具有描述性

4. **内容组织**：将内容按逻辑放置在各标题之间

5. **支持的格式**：坚持使用基本的 markdown 格式，以在所有阅读器上获得最佳兼容性

## 故障排除

**EPUB 无法打开**：请确保你的 markdown 格式正确。检查链接中的括号是否配对以及语法是否正确。

**目录为空**：请确保你的 markdown 中包含用于定义章节的 H1 标题。

**格式显示不同**：EPUB 阅读器会应用自身的字体和样式。这是正常且符合预期的行为。
