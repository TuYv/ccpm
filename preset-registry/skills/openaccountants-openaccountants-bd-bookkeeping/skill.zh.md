# 孟加拉国簿记与记录 — 技能 v1.0

> **仅供一般参考。** 本技能是用于 AI 辅助工作流程的一般税务/会计参考资料。尚未针对任何特定个人的事实、文件、选择、截止日期、居民身份、申报状态或当地程序进行审核。在未经相关司法管辖区的合格专业人士审核的情况下，请勿依赖本技能进行申报、缴税、修正申报或采取任何税务立场。

## 第 1 节 — 快速参考

| 字段 | 值 |
|---|---|
| 国家 | 孟加拉国 |
| 货币 | BDT (৳) |
| 税务机关 | 国家税务局（NBR）；电子申报网站为 etaxnbr.gov.bd |
| 核心记录 | 收入/收款、费用、银行对账单、发票、资产登记册 |
| IT 出口商必须保存 | 每笔境外收款的银行**汇款/结汇证明**（也是获得出口现金奖励的必要条件） |
| 保存期限 | 保存足以支持纳税申报的记录（通常为 6 年——请核实） |
| 质量等级 | 已经研究核实——有待孟加拉国执业人士最终确认 |
| 技能版本 | 1.0 |

## 第 2 节 — 应保存的资料（第 1 级）
- **收入：**客户发票、平台对账单（Upwork/Fiverr）、银行入账记录。对于出口商，**银行汇款/外币结汇证明**至关重要——它可以证明出口收入以及任何 ICT 现金奖励（参见 bd-it-freelancer-tax）。
- **费用：**供应商账单、租金/公用事业费用收据、设备（用于资产登记册/折旧）、软件/订阅。
- **银行：**所有账户（BDT 和外币账户）的全年对账单。
- **税务：**以往的电子申报表、TDS 证明（用于税款抵免）、营业执照、TIN。

## 第 3 节 — 发票与 VAT 记录
- 个体经营者开具的发票应注明 TIN（如已登记 VAT，还应注明 BIN）。已登记 VAT 的企业应保存规定的 VAT 记录/Mushak 表格，并可在适用情况下使用 NBR 的电子 VAT 系统（EFD/SDC）（参见 bangladesh-vat）。

## 第 4 节 — 示例
一名自由职业者保存以下资料：每月平台对账单、每笔汇款对应的银行结汇证明、简单的费用表（笔记本电脑、互联网、软件），以及年终银行对账单——这些资料足以支持电子申报并申请出口奖励。

## 第 10 节 — 禁止事项
- 绝不允许 IT 出口商丢弃汇款/结汇证明。
- 绝不在未分别记录的情况下混合国内收入和出口收入。
- 绝不在未核实现行规则的情况下说明记录保存期限。
