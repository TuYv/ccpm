# 域名头脑风暴助手

本技能通过生成创意选项并检查实际可注册的域名，帮助你为项目找到完美的域名。

## 何时使用本技能

- 启动新项目或公司
- 发布产品或服务
- 创建个人品牌或作品集网站
- 为现有项目重塑品牌
- 为副业项目注册域名
- 首选域名被占用时寻找可用的替代方案

## 本技能的功能

1. **理解你的项目**：分析你正在构建什么以及面向谁
2. **生成创意名称**：创建相关且令人难忘的域名选项
3. **检查可用性**：验证哪些域名在多个 TLD（顶级域）中确实可用
4. **多种后缀**：推荐 .com、.io、.dev、.ai、.app 等
5. **提供备选方案**：首选被占用时提供变体选项
6. **品牌洞察**：解释为什么某些名称效果好

## 域名命名技巧

### 好域名的标准

✓ **简短**：15 个字符以内最理想
✓ **易记**：容易回想和拼写
✓ **可读出**：能在对话中说出口
✓ **有描述性**：暗示你的业务内容
✓ **可品牌化**：足够独特，能脱颖而出
✓ **不含连字符**：口头分享更方便

### TLD 指南

- **.com**：通用、可信，非常适合商业用途
- **.io**：科技初创公司、开发者工具
- **.dev**：面向开发者的产品
- **.ai**：AI/ML 产品
- **.app**：移动或网页应用
- **.co**：.com 的替代选择
- **.xyz**：现代、创意项目
- **.design**：创意/设计机构
- **.tech**：科技公司

## 示例工作流程

### 初创公司上线
1. 描述你的创业想法
2. 获取覆盖多个 TLD 的 10-15 个域名建议
3. 查看可用性和价格
4. 选出最中意的前 3 个
5. 立即注册

### 个人品牌
1. 提供你的姓名和职业
2. 获取各种变体（firstname.com、firstnamelastname.dev 等）
3. 同时检查社交媒体账号名的可用性
4. 在各平台注册一致的品牌

### 产品命名
1. 描述产品和目标市场
2. 获取有创意、可品牌化的名称
3. 检查商标冲突
4. 核实域名和社交媒体账号的可用性
5. 用目标受众测试这些名称

## 成功技巧

1. **行动要快**：好域名很快就会被抢注
2. **注册变体**：同时注册 .com 和 .io 以保护品牌
3. **避免数字**：口头交流时不易说清
4. **检查社交媒体**：确保 @username 也可用
5. **大声念出来**：测试是否容易发音
6. **检查商标**：确保没有法律纠纷
7. **着眼长远**：5 年后它是否依然合适？

## 价格参考

推荐域名时，我会注明：
- 标准域名：约 $10-15/年
- 高级 TLD（.io、.ai）：约 $30-50/年
- 已被占用的域名：若有标价则按市场价
- 优质域名：数百至数千美元
