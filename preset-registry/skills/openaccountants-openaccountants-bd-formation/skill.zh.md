# 孟加拉国企业设立 — 技能 v1.0

> **仅供一般参考。** 本技能是用于 AI 辅助工作流程的一般税务/会计参考资料。其内容尚未针对任何特定个人的事实情况、文件、选择、截止日期、居民身份、申报状态或当地程序进行审查。在未经相关司法管辖区合格专业人士审查的情况下，请勿依赖本技能进行申报、缴款、修正申报或采取税务立场。

## 第 1 节 — 快速参考

| 字段 | 值 |
|---|---|
| 个人经营形式 | 独资企业（营业执照 + TIN） |
| 多所有者经营形式 | 合伙企业（根据《合伙企业法》注册） |
| 公司 | 通过 RJSC（股份公司注册局）注册的私人有限公司 |
| 核心登记 | **TIN**（NBR，etaxnbr.gov.bd）+ **营业执照**（市政公司 / 市政府 / 联合教区） |
| VAT | 超过 VAT 起征门槛时，向 NBR 注册 **BIN**（企业识别号） |
| 电子商务 | 在线卖家需取得 DBID（数字企业识别码） |
| 质量等级 | 已经研究核实 — 等待孟加拉国执业人士最终确认 |
| 技能版本 | 1.0 |

### 保守默认值
| 不明确事项 | 默认处理 |
|---|---|
| 经营形式未知 | 个人自由职业者采用独资企业形式 |
| VAT 注册 | 超过门槛后必须注册；低于门槛时可自愿注册 |
| 申报人状态 | 建议取得 TIN 并提交年度 e-Return（避免较高的 TDS） |

## 第 2 节 — 个人自由职业者的办理步骤（第 1 级）
1. **取得 TIN**：使用 NID 在 NBR（etaxnbr.gov.bd）办理，将自己登记为纳税人。
2. **取得营业执照**：以企业名称/经营活动向当地主管机关（市政公司 / 市政府 / 联合教区）申请。
3. **开立企业银行账户**（接收出口汇款 / 取得结汇证明时需要）。
4. **VAT（BIN）：**如果营业额超过 VAT 注册门槛，请向 NBR 注册（参见 bangladesh-vat）。
5. **电子商务：**如果在线销售，请取得 **DBID**。
6. **提交年度 e-Return**，以保持申报人身份（较低的 TDS，并可使用相关服务）。

## 第 3 节 — 独资企业、合伙企业与公司对比
| 因素 | 独资企业 | 合伙企业 | 私人有限公司（RJSC） |
|---|---|---|---|
| 设立 | 营业执照 + TIN | 合伙协议 | RJSC 公司注册 |
| 责任 | 个人承担 | 共同承担 | 有限责任 |
| 报告 | 仅提交纳税申报表 | 提交纳税申报表 | 向 RJSC 提交财务报表 + 审计 |
| 最适合 | 个人自由职业者 | 合伙人 | 业务扩张/引入投资者 |

## 第 10 节 — 禁止事项
- 对于已登记的经营活动，绝对不得省略办理营业执照。
- 超过门槛后，绝对不得遗漏 VAT（BIN）注册。
- 在未核实 NBR/当地现行规则的情况下，绝对不得说明具体门槛。
