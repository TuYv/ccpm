# 孟加拉国社会保障与养老金 — 技能 v1.0

> **仅供一般参考。** 本技能是用于 AI 辅助工作流程的一般税务/会计参考资料。其内容尚未针对任何特定个人的事实、文件、选择、截止日期、居留身份、申报状态或当地程序进行审核。在未经相关司法管辖区合格专业人士审核的情况下，请勿依赖本技能进行申报、缴税、修正申报或采取任何税务立场。

## 第 1 节 — 快速参考

| 计划 | 适用对象 | 性质 |
|---|---|---|
| 全民养老金计划（Sarbojanin Pension，自 2023 年起） | 18–50 岁公民，包括自雇人士 | **自愿性**缴费养老金 |
| — Surokkha | 自雇人士 / 自由职业者 / 专业人士 | 自愿按月缴费 |
| — Progoti | 私营部门雇员 | 雇员 + 雇主 |
| — Probash | 非居民孟加拉国人 | 自愿 |
| — Samata | 低收入者（低于某一门槛） | 部分缴费由政府资助 |
| 公积金 / 离职酬金 | 部分私营部门雇员 | 基于雇主计划 |

## 第 2 节 — 要点（第 1 级）
- 孟加拉国**不存在广泛适用于自雇人士的强制性社会保障缴费**。独立自由职业者通常**无需**缴纳社会保障费用 — 其主要义务是缴纳所得税（出口商另请参阅 bd-it-freelancer-tax）。应明确说明这一点。
- **全民养老金计划**（于 2023 年推出）属于**自愿性**计划：自雇人士可以加入 **Surokkha** 计划，并按月缴费以积累养老金；**Samata** 计划则为低收入者提供政府配套缴费。请核实当前的缴费档次和政府配套缴费金额。
- **雇员**可能通过其雇主享有**公积金**和**离职酬金**；孟加拉国并不存在许多国家所采用的全民性国家社会保险工资税。

## 第 3 节 — 示例
一名独立自由职业者：**没有**强制性社会保障缴费；只需缴纳所得税。其可以选择加入全民养老金计划下的 **Surokkha**，自愿缴费以积累养老金（该缴费也可能符合投资税收抵免条件 — 请核实）。

## 第 10 节 — 禁止事项
- 绝不要告知独立自由职业者其必须缴纳强制性社会保障费用（通常无需缴纳）— 应指出可自愿参加养老金计划。
- 在未核实当前 NPA 规则的情况下，绝不要说明养老金缴费档次 / 政府配套缴费金额。

## 免责声明
仅供参考；不构成建议。请向国家养老金管理局 / 雇主核实全民养老金计划的缴费档次以及公积金/离职酬金规则。所有输出均须由合格的孟加拉国执业人士审核并最终确认。维护于 [openaccountants.com](https://openaccountants.com)。
