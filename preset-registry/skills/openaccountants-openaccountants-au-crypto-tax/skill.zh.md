# 澳大利亚加密资产税务——资本利得税与所得税技能 v1.0

> **仅供一般参考。** 本技能是用于 AI 辅助工作流程的一般税务/会计参考资料。尚未针对任何特定个人的事实、文件、税务选择、截止日期、居民身份、申报状态或当地程序进行审查。在未经相关司法管辖区的合格专业人士审核的情况下，请勿依赖本技能进行申报、缴税、修正申报或采取税务立场。

## 第 1 节——快速参考

| 字段 | 值 |

| 国家 | 澳大利亚（澳大利亚联邦） |
| 税种 | 所得税——加密货币/数字资产 |

### 核心原则

ATO 将加密货币（包括 Bitcoin、Ethereum、稳定币、NFT 和 DeFi 代币）视为**资本利得税资产（CGT 资产）**，而非外国货币。每次处置都会触发一项 CGT 事项。

### 个人边际税率（2024-25）

| 应税收入（AUD） | 税率 |
|---|---|
| 0 -- 18,200 | 0% |
| 18,201 -- 45,000 | 16% |
| 45,001 -- 135,000 | 30% |
| 135,001 -- 190,000 | 37% |
| 190,001+ | 45% |

### 关键门槛

| 项目 | 值 |
|---|---|
| 个人使用资产豁免 | 取得成本 < $10,000 |
| CGT 折扣（持有满 12 个月或以上） | 个人和信托为 50% |
| CGT 折扣——公司 | 不适用 |
| 资本损失结转 | 无限期（仅可抵扣未来的资本利得） |

### 保守默认处理

| 不明确事项 | 默认处理 |
|---|---|
| 取得日期未知 | 不适用 50% 折扣 |
| 成本基础未知 | $0（最大利得）——获取相关记录 |
| 不确定是个人使用还是投资 | 按投资处理（适用 CGT） |
| 不确定是交易还是投资 | 按投资者处理（适用 CGT，而非普通收入） |
| DeFi 事项——性质未知 | 按处置处理（CGT 事项） |

## 第 2 节——分类规则

### 2.1 CGT 事项（处置）

在进行以下行为时，会发生 CGT 事项：

| 事项 | 是否触发 CGT？ |
|---|---|
| 将加密资产出售换取 AUD（或法定货币） | 是 |
| 用一种加密资产交易另一种加密资产（例如 BTC → ETH） | 是——按市场价值处置 BTC |
| 使用加密资产购买商品/服务 | 是——按市场价值处置 |
| 将加密资产赠与他人 | 是——按赠与时的市场价值计算 |
| 将加密资产发送至交易所以供出售 | 否（转入自己的钱包不属于处置） |
| 在自己的钱包之间转账 | 否——实益所有权相同 |
| 加密资产丢失/被盗（无私钥） | 可能构成 CGT 事项——必须证明无法找回 |

### 2.2 成本基础计算

| 要素 | 是否计入成本基础 |
|---|---|
| 以 AUD 计价的购买价格 | 是 |
| 取得时的交易所费用/佣金 | 是 |
| 取得交易产生的 Gas 费 | 是 |
| 处置时的交易所费用/佣金 | 减少资本处置收入（或在兑换交易中计入新资产的成本基础） |
| 钱包转账费用（自己的钱包之间） | 计入该资产的成本基础 |
| 投资组合跟踪工具的订阅费用 | 计入（第三项要素——所有权成本） |

**相同资产的认定方法：** 先进先出法（FIFO）、后进先出法（LIFO）或个别认定法——必须保持一致并留存记录。ATO 不强制要求采用特定方法，但要求前后一致。

### 2.3 50% 资本利得税折扣

符合以下条件时可以享受：
- 资产持有时间至少为 12 个月（从取得到处置）
- 纳税人为个人或信托（公司不适用；养老金基金适用 1/3 的折扣）
- 发生资本利得税事件时，纳税人为澳大利亚税务居民

### 2.4 个人用途资产豁免

| 条件 | 必须全部满足 |
|---|---|
| 为个人用途而取得（例如用于购买商品） | 是 |
| 取得成本 < $10,000 | 是 |
| 在取得后的短期内使用 | 是 |
| 并非作为投资持有 | 是 |
| 并非为兑换/交易目的而持有 | 是 |

如果任何一次取得成本 ≥ $10,000，则个人用途资产豁免不适用。如果加密货币存放在交易所或被长期持有，ATO 会将其视为投资，而非个人用途资产。

### 2.5 交易与投资的区别

| 因素 | 投资者（资本利得税） | 交易者（经营收入） |
|---|---|---|
| 交易量 | 低到中等 | 高频、系统化 |
| 持有期限 | 数周/数月/数年 | 数分钟/数小时/数天 |
| 目的 | 长期增值 | 从短期价格波动中获利 |
| 组织方式 | 非经常性 / 兼职 | 以经营方式开展，投入大量时间 |
| 投入资本 | 个人储蓄 | 大量营运资金 |
| 税务处理 | 资本利得（可享受 50% 折扣） | 普通收入（无资本利得税折扣，不受资本亏损限制） |
| 亏损 | 仅限资本亏损 | 经营亏损（可抵扣所有收入） |

### 2.6 质押奖励

| 税务处理 | 详情 |
|---|---|
| 分类 | 按收到时的市场价值计为普通收入 |
| 确认时间 | 在收到或取得奖励控制权的收入年度计入应税收入 |
| 未来资本利得税的成本基础 | 收到当日的市场价值成为成本基础 |
| 资本利得税折扣的持有期限 | 从收到之日起计算 |

### 2.7 空投

| 类型 | 税务处理 |
|---|---|
| 无需执行任何操作的空投 | 收到时按市场价值计为普通收入（如果存在已确立的市场价值） |
| 需要执行操作的空投（例如发起领取交易） | 领取时计为普通收入 |
| 无价值/无市场的代币空投 | 收入为 $0；成本基础 = $0 |
| 后续处置 | 资本利得税事件——成本基础为收到时的价值 |

### 2.8 DeFi 特定事件

| DeFi 操作 | 税务处理 |
|---|---|
| 封装（例如 ETH → WETH） | ATO 观点：可能构成处置（资本利得税事件）。保守处理方式：按市场价值视为处置 |
| 解封装（WETH → ETH） | 处置 WETH，取得 ETH |
| 提供流动性（LP tokens） | 处置已存入的代币；按合计市场价值取得 LP token |
| 移除流动性 | 处置 LP token；取得底层代币 |
| 收益耕作奖励 | 收到时按市场价值计为普通收入 |
| 以加密货币为抵押进行借贷（抵押品） | 不构成处置（受益所有权未发生变化）。但是，如果被清算——则构成资本利得税事件 |
| 跨链桥交易（跨链） | 保守处理方式：视为处置 + 取得 |
| 代币迁移/硬分叉 | 以 $0 成本基础取得新代币；在处置之前不计入应税收入 |

### 2.9 NFT

与其他加密资产采用相同方式处理。购买 = 取得（CGT 资产）。出售 = 处置（CGT 事件）。如果从事 NFT 创作业务，则创建并出售 NFT 所得属于普通收入；否则按 CGT 处理。

## 第 3 节——交易模式库

### 3.1 交易所模式——Coinbase

| 模式 | 税务处理 | 备注 |
|---|---|---|
| BUY [CRYPTO] | 取得 | 成本基础 = 澳元金额 + 手续费 |
| SELL [CRYPTO] | 处置（CGT 事件） | 收益 = 收到的澳元金额 |
| CONVERT [CRYPTO A] TO [CRYPTO B] | 处置 A + 取得 B | 按转换时的市场价值计算 |
| COINBASE EARN / LEARN REWARD | 普通收入 | 按收到时的市场价值计算 |
| STAKING REWARD | 普通收入 | 按收到时的市场价值计算 |
| SEND / RECEIVE (own wallet) | 不属于 CGT 事件 | 转账——无收益/损失 |
| WITHDRAWAL TO BANK | 不属于 CGT 事件 | 法定货币转账（已完成出售） |

### 3.2 交易所模式——Swyftx

| 模式 | 税务处理 | 备注 |
|---|---|---|
| BUY ORDER | 取得 | 成本基础 = 等值澳元金额 + 点差/手续费 |
| SELL ORDER | 处置（CGT 事件） | 收益 = 记入账户的澳元金额 |
| SWAP [A] FOR [B] | 处置 A + 取得 B | 按执行时的市场价值计算 |
| STAKING REWARD | 普通收入 | 按收到时的市场价值计算 |
| DEPOSIT AUD | 不征税 | 法定货币存入 |
| WITHDRAWAL AUD | 不征税 | 法定货币提取 |

### 3.3 交易所模式——CoinSpot

| 模式 | 税务处理 | 备注 |
|---|---|---|
| MARKET BUY | 取得 | 成本 = 支付的澳元金额 + 0.1% 手续费 |
| MARKET SELL | 处置（CGT 事件） | 收益 = 收到的澳元金额（扣除 0.1% 手续费后） |
| SWAP | 处置 + 取得 | 两个 CGT 事件 |
| AFFILIATE PAYMENT | 普通收入 | |
| REFERRAL REWARD | 普通收入 | 按收到时的市场价值计算 |
| AIRDROP | 普通收入（如果价值 > $0） | |
| SEND TO EXTERNAL WALLET | 不属于 CGT 事件 | 自有钱包之间的转账 |

### 3.4 链上模式

| 模式 | 税务处理 | 备注 |
|---|---|---|
| UNISWAP / SUSHISWAP SWAP | 处置 + 取得 | 按市场价值计算的两个 CGT 事件 |
| LP DEPOSIT (ADD LIQUIDITY) | 处置代币，取得 LP 代币 | |
| LP WITHDRAWAL (REMOVE LIQUIDITY) | 处置 LP 代币，取得代币 | |
| CLAIM REWARDS | 普通收入 | 按领取时的市场价值计算 |
| BRIDGE [TOKEN] TO [CHAIN] | 保守处理：处置 + 取得 | |
| MINT NFT | 取得 | 成本基础 = 铸造价格 + Gas 费 |
| APPROVE / REVOKE (no transfer) | 不属于 CGT 事件 | Gas 费计入下一笔相关交易的成本 |

## 第 4 节——计算方法

### 第 1 步：识别所有 CGT 事件
列出该财政年度内的每项处置（出售、兑换、消费、赠与、DeFi 事件）。

### 第 2 步：计算每个事件的收益/损失
资本收益款项 − 成本基础 = 资本利得（或资本损失）。

### 第 3 步：应用 50% 折扣（如符合条件）
对于持有资产 ≥ 12 个月的每项利得：净资本利得 = 利得 × 50%。

### 第 4 步：抵扣资本损失
在应用 50% 折扣之前，使用本年度和以前年度的资本损失抵扣资本利得总额。

**正确顺序：** 总收益 − 资本损失 = 净收益。然后对剩余的符合条件的收益应用 50% 折扣。

### 第 5 步：加上普通收入
质押奖励 + 空投 + 挖矿收入应申报为其他收入（不计入 CGT 附表）。

### 第 6 步：在纳税申报表中申报
- 资本收益：第 18 项（资本收益）
- 普通加密资产收入：第 24 项（其他收入）

## 第 5 节——记录保存要求

ATO 要求为每笔交易保存以下记录：

| 记录 | 是否必需 |
|---|---|
| 取得日期 | 是 |
| 处置日期 | 是 |
| 交易时以 AUD 计价的金额 | 是 |
| 交易目的 | 是 |
| 交易所/钱包记录 | 是 |
| 交易对手详细信息（如适用） | 是 |
| 使用的汇率（换算为 AUD） | 是 |
| 代理商/交易所费用 | 是 |

保存期限：自申报相关收益/损失的纳税申报表提交之日起 5 年。对于仍在持有的资产：记录必须保存至最终处置后 5 年。

## 第 6 节——边缘案例

### 6.1 硬分叉

通过硬分叉获得的代币（例如，从比特币分叉获得的比特币现金）的成本基础为 $0。收到时不计收入。后续处置时触发 CGT 事件，成本基础 = $0。

### 6.2 丢失或被盗的加密资产

如果能够证明加密资产已经丢失（例如，私钥丢失且无法恢复，或因诈骗/黑客攻击而损失且无法追回），则可以申报资本损失。纳税人必须证明该损失是永久性的。ATO 可能会要求提供证据。

### 6.3 挖矿

| 情形 | 处理方式 |
|---|---|
| 业余矿工（小规模） | 挖得的代币以 $0 成本基础取得；处置时适用 CGT |
| 商业矿工（规模较大） | 挖得时按市场价值计入普通收入；可能适用交易存货规则 |

### 6.4 作为服务报酬收到的加密资产

应按收到时以 AUD 计价的市场价值作为普通收入（PSI 或营业收入）课税。未来计算 CGT 时的成本基础 = 该市场价值。

### 6.5 保证金交易/期货

加密资产衍生品和保证金交易产生的利润与损失通常按收入账户处理（普通收入/损失），除非其明显属于一次性投机行为。

## 第 7 节——禁止事项

- 切勿对长期存放在交易所的加密资产申请个人使用资产豁免
- 未核实持有期达到 12 个月以上时，切勿应用 50% CGT 折扣
- 切勿对公司或非居民应用 50% CGT 折扣
- 切勿用资本损失抵扣普通收入（只能抵扣资本收益）
- 切勿在总收益之前应用资本损失（先应用损失，然后再应用折扣）
- 切勿将加密资产之间的互换视为非应税事件而忽略——每次互换都是一次处置
- 切勿假定 DeFi 事件不应税——保守做法是将其视为处置
- 切勿遗漏质押/空投收入——收到时即构成普通收入
- 切勿将税务计算结果表述为确定结果——始终标注为估算值
