# 紫牛营销——脱颖而出，否则就会被忽视

> 运用赛斯·高汀的紫牛方法论，创造非凡的产品和体验，使其通过口碑传播

## 何时使用此技能

- **发布新产品**，需要它在拥挤的市场中脱颖而出
- **让你的品牌形成差异化**，摆脱与竞争对手千篇一律的局面
- **摆脱商品化处境**，不再只能依靠价格竞争
- **在广告预算有限的情况下规划营销策略**
- 当“足够好”不再奏效时，**找到你的非凡切入点**
- **瞄准早期采用者**，让他们帮助传播口碑
- **构思产品创新**，让客户愿意主动谈论

## 方法论基础

| 方面 | 详情 |
|--------|---------|
| **来源** | 《紫牛：从默默无闻到与众不同》（2003 年） |

## 此技能的作用

此技能可以帮助你摆脱平庸的陷阱。你无需试图通过投放更多广告来胜过竞争对手，而是要创造出值得人们谈论的事物——一头紫牛。

你将学会：

1. **识别非凡之处**——在你的产品中找到紫牛，或创造一头紫牛
2. **避开安全的中间地带**——走向非凡事物所在的边缘
3. **找到你的传播者**——瞄准传播创意的人，而非大众
4. **为口碑传播而设计**——让你的非凡事物易于分享
5. **摆脱对广告的依赖**——让产品自己营销自己

最终成果：打造出非凡到足以让客户主动为你营销的产品或服务。

## 说明

### 紫牛概念

```
┌─────────────────────────────────────────────────────────────┐
│              THE PURPLE COW PRINCIPLE                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Brown Cow, Brown Cow, Brown Cow... PURPLE COW!             │
│                                                             │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌───────────┐   │
│  │  Average  │ │  Average  │ │  Average  │ │REMARKABLE │   │
│  │ (Ignored) │ │ (Ignored) │ │ (Ignored) │ │ (Noticed) │   │
│  └───────────┘ └───────────┘ └───────────┘ └───────────┘   │
│                                                             │
│  The old P's: Product, Price, Place, Promotion, Packaging  │
│  The new P:   PURPLE COW (Remarkable)                       │
│                                                             │
│  "If you're remarkable, it's likely that some people won't  │
│   like you. Avoiding criticism is not a goal worth having." │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**核心真相**：传统广告已经失效。消费者会忽略广告、跳过商业宣传，并饱受信息过载之苦。脱颖而出的唯一方式就是做到非凡——值得人们谈论。

---

### 第 1 步：理解“非凡”的真正含义

非凡 = 值得人们谈论

**非凡并不意味着：**
- 为了怪异而怪异
- 令人震惊或冒犯他人
- 成为最便宜的选择
- 拥有最多的功能
- 毫无目的地追求“与众不同”

**非凡意味着：**
- 以出人意料的方式解决真实问题
- 让客户惊喜到主动向他人推荐
- 在真正重要的人群（你的目标受众）中脱颖而出
- 创造值得分享的体验

**非凡测试：**

| 问题 | 如果是 | 如果不是 |
|----------|--------|-------|
| 会有人把它介绍给朋友吗？ | ✓ 具有非凡潜力 | 无人关注 |
| 陌生人会停下来询问它吗？ | ✓ 具有非凡潜力 | 无人关注 |
| 它会让人发出“哇！”或“咦，有点意思”的感叹吗？ | ✓ 具有非凡潜力 | 无人关注 |
| 它值得拍照分享吗？ | ✓ 具有非凡潜力 | 无人关注 |
| 如果它消失了，你的客户会想念它吗？ | ✓ 非凡 | 普通商品 |

---

### 第 2 步：走向极端

**危险地带**：安全的中间地带是产品走向死亡的地方。“足够好”就意味着无人关注。

```
    THE EDGE SPECTRUM

    ←── EDGE ─────────── MIDDLE ─────────── EDGE ──→

    Remarkable         Safe/Invisible        Remarkable
    (Risky)            (Competing on price)  (Risky)

    "In a world of too many choices, the safest thing is to be risky."
```

**找到你的极端定位：**

| 维度 | 安全的中间地带（无人关注） | 极端选项（非凡） |
|-----------|------------------------|---------------------------|
| **价格** | 有竞争力 | 免费，或者贵 10 倍 |
| **功能** | 行业标准 | 极致简洁，或者极其全面 |
| **设计** | 专业且符合预期 | 极具辨识度 |
| **服务** | 尚可 | 极度个性化，或者完全自助 |
| **速度** | 当日完成 | 即时完成，或者值得等待 |
| **受众** | 所有人 | 对你的产品痴迷的微型细分群体 |
| **个性** | 中立的企业风格 | 大胆、立场鲜明、人性化 |

**极端练习：**
针对每个维度，问自己：“如果我们走向极端，会发生什么？”

---

### 第 3 步：找到你的“喷嚏传播者”

**采用曲线误区**：大多数公司面向大众进行营销。等到大众开始关注时，你已经沦为同质化商品。

```
    INNOVATION ADOPTION CURVE

    ┌────────────────────────────────────────────────────────┐
    │                                                        │
    │      █                                                 │
    │     ███                                                │
    │    █████      ████████████████████████                 │
    │   ███████    ████████████████████████████████          │
    │  █████████  ██████████████████████████████████████     │
    │                                                        │
    │  INNOVATORS  EARLY     EARLY      LATE      LAGGARDS   │
    │    (2.5%)   ADOPTERS  MAJORITY  MAJORITY    (16%)      │
    │             (13.5%)    (34%)     (34%)                 │
    │                                                        │
    │  ←─── TARGET THESE ───→                                │
    │  (They spread ideas)                                   │
    └────────────────────────────────────────────────────────┘
```

**喷嚏传播者**：像传播病毒一样传播你的创意的人。

| 喷嚏传播者类型 | 特征 | 策略 |
|--------------|-----------------|----------|
| **广泛型喷嚏传播者** | 什么都告诉所有人，传播量大，但每次分享的影响力较低 | 让分享毫无阻力，为他们提供内容 |
| **强力型喷嚏传播者** | 选择性强、可信度高，推荐次数较少，但影响更大 | 创造配得上他们声誉的事物 |

**寻找喷嚏传播者：**
1. 谁会主动寻找你所在品类中的新事物？
2. 其他人会向谁征求推荐？
3. 谁拥有平台或受众？
4. 谁对你的领域抱有“御宅式兴趣”（痴迷般的兴趣）？

---

### 第 4 步：找到御宅族

**御宅式兴趣**（日语）：对某个特定事物抱有痴迷且全身心投入的兴趣。

对你的品类抱有御宅式兴趣的人：
- 深切关注其他人忽略的细节
- 投入远超常人的时间和金钱
- 能够影响该细分领域中的其他人
- 主动寻找非凡之处
- 只要非凡之处达到预期，就能包容瑕疵

**你的任务**：找到对你的品类抱有御宅式兴趣的人，然后给他们一些值得痴迷的东西。

**御宅式兴趣的示例：**
- 音响发烧友（高保真音响设备）
- 球鞋爱好者（稀有鞋款）
- 咖啡鉴赏家（单一产地咖啡豆）
- 机械键盘爱好者
- 精酿啤酒发烧友

**问题**：谁会痴迷于你销售的东西？什么会让他们兴奋到疯狂？

---

### 第 5 步：为口碑传播而设计

你的非凡之处必须满足以下要求：

| 要求 | 检验问题 |
|-------------|---------------|
| **易于解释** | 别人能用一句话描述它吗？ |
| **可见** | 其他人能看到、使用或体验它吗？ |
| **值得承担社交风险** | 推荐它值得拿自己的声誉冒险吗？ |
| **便于分享** | 是否存在自然而然的分享时机？ |
| **令人难忘** | 他们明天还会记得它吗？下周呢？ |

**口碑传播设计检查清单：**
- [ ] 任何人都能复述的一句话宣传语
- [ ] 值得拍照或截图的视觉元素
- [ ] 讲起来有趣的故事钩子
- [ ] 自带让人提及的理由（惊喜、愉悦、身份感）
- [ ] 不设置分享障碍（名称复杂、难以找到等）

---

### 第 6 步：紫牛创造流程

```
    1. IDENTIFY           2. EDGE              3. SNEEZERS
    What could be    →    Go extreme in    →   Who will
    remarkable?           that dimension       spread this?
         │                     │                    │
         ▼                     ▼                    ▼
    4. DESIGN            5. TEST              6. RELEASE
    Make it easy    →    Does it pass    →   Let the
    to spread            the tests?           sneezers work
```

**流程详情：**

**1. 识别**：你的产品/服务在哪个方面可以做到引人注目？
- 审视你所做的一切
- 找出你可以做到最出色的那一件事
- 找到对传播者最重要的维度

**2. 突破极限**：在该维度上做到极致
- 不是好 10%，而是好 10 倍，或者截然不同
- 接受你会让一部分人疏远
- 加倍投入，不要瞻前顾后

**3. 传播者**：瞄准那些会主动传播的人
- 初期忽略大众市场
- 将资源集中在创新者和早期采用者身上
- 给他们谈论的理由

**4. 设计**：让它易于传播
- 一句话宣传语
- 视觉化/可分享的元素
- 消除阻力

**5. 测试**：它是否通过了引人注目性测试？
- 他们会把它告诉朋友吗？
- 他们会想念它吗？
- 它真的值得人们议论吗？

**6. 发布**：让口碑发挥作用
- 从传播者群体开始投放
- 不要过度营销
- 倾听反馈并持续迭代

## 示例

### 示例 1：Mailchimp 的早期增长

**情境**：身处竞争激烈的电子邮件营销软件市场（Constant Contact、AWeber 等）。

**紫牛分析：**

**引人注目之处：**
- 为小规模邮件列表提供免费套餐（颠覆性定价）
- 有趣、不拘一格的品牌语调（而非企业腔）
- 黑猩猩吉祥物和动画（鲜明的视觉特色）
- “向朋友发送营销活动”功能（内置病毒式传播机制）

**他们选择突破的维度：**
| 维度 | 竞争对手 | Mailchimp |
|-----------|-------------|-----------|
| 价格 | 仅提供付费服务 | 订阅者不超过 2,000 人时免费 |
| 语调 | 企业化、严肃 | 有趣、古怪、人性化 |
| 视觉 | 专业/乏味 | 古灵精怪的黑猩猩、活泼的设计 |
| 复杂度 | 功能繁多 | 简单、专注 |

**传播者是谁：**
- 博主和小型内容创作者
- 初创公司创始人
- 向客户推荐工具的网页设计师

**它为何能够传播：**
- 免费试用 = 零门槛
- 有趣的品牌 = 乐于谈论
- “Powered by Mailchimp”页脚 = 提高曝光度
- 营销活动结束后的击掌动画 = 值得分享的时刻

**结果**：从挑战者成长为市场领导者，最终被 Intuit 以 120 亿美元收购。

### 示例 2：RXBAR 的透明包装

**情境**：蛋白棒市场由配料表令人费解、借健康概念进行营销的品牌主导。

**紫牛分析：**

**引人注目之处：**
- 直接在包装正面列出配料
- “No B.S.”宣传语
- 简洁、醒目的字体排版
- 在一个充斥欺骗的品类中做到彻底透明

**他们选择的极致方向：**
| 维度 | 竞争对手 | RXBAR |
|-----------|-------------|-------|
| 包装 | 营销宣称 | 将配料表作为设计 |
| 传播信息 | “健康” | “3 个蛋清、6 颗杏仁、4 颗腰果……” |
| 复杂度 | 30 多种配料 | 5-6 种真正的食物 |
| 定位 | 健康品牌 | 诚信品牌 |

**谁是传播者：**
- CrossFit 社群（对洁净饮食有御宅级热情的人群）
- 厌倦了补充剂胡扯的健身意见领袖
- 仔细阅读每个标签的 Whole Foods 顾客

**它为何能够传播：**
- 在货架上一眼可见 = 立即形成差异化
- 容易解释 = “它只是把配料直接列在包装正面”
- CrossFit 社群 = 联系紧密且具有影响力的传播者
- 符合价值观 = 值得花费社交资本去推荐

**结果**：营收在 5 年内从 200 万美元增长到 1.6 亿美元，随后被 Kellogg's 以 6 亿美元收购。

### 示例 3：服务型企业的紫牛

**情境**：一家希望从数十家同类公司中脱颖而出的本地会计师事务所。

**传统做法（无法引人注目）：**
- 使用图库照片的专业网站
- 传达“值得信赖、经验丰富、可靠”的信息
- 有竞争力的定价
- 通用的服务项目

**紫牛做法：**

| 极致方向选项 | 非凡之处 |
|-------------|---------------------|
| **彻底透明** | 在线公布所有价格，保证在 24 小时内提供报价 |
| **极致细分** | “OnlyFans 创作者专属会计师”（真实存在的业务） |
| **极致服务** | 48 小时内完成纳税申报，否则免费 |
| **鲜明个性** | “真正会回复电子邮件的会计师事务所” |
| **专业聚焦** | 只服务餐厅，熟悉每一项可抵扣费用 |

**实施示例（细分策略）：**

**目标**：Shopify 上的电商卖家

**非凡要素：**
- 直接集成 Shopify（自动提取数据）
- 针对电商的税务优化检查清单
- “Shopify 店铺财务健康报告”（免费的潜在客户诱饵）
- 面向 Shopify 卖家的 Slack 社群
- 包含真实营收数据的案例研究

**传播者**：Shopify 播客主播、电商 Facebook 群组管理员、Shopify 应用开发者

**它为何能够传播：**
- 容易解释：“他们只为 Shopify 店铺提供服务”
- 专业能力清晰可见：专门面向电商的内容
- 值得推荐：通过专业知识帮助客户省钱
- 自然契机：社群中报税季的相关讨论
