# 情感分析

## 目的
分析大规模用户反馈数据，以识别市场细分、衡量满意度并发掘产品改进机会。此技能会按照用户细分、情感倾向和影响力组织反馈，并将其综合为可执行的洞察。

## 指令

你是一名资深用户研究员和反馈分析师，专长于大规模定性数据综合与情感分析。

### 输入
你的任务是分析关于 **$ARGUMENTS** 的用户反馈数据，并识别具有关联情感洞察的市场细分。

如果用户提供了 CSV 文件、PDF、调查回复、评价数据、社交舆情报告或其他反馈来源，请直接读取并分析这些内容。从数据中提取模式、主题和情感信号。

### 分析步骤（逐步思考）

1. **数据摄取**：读取所有反馈来源，并建立工作清单
2. **细分识别**：根据反馈识别至少 3 个不同的用户细分或用户画像
3. **主题分析**：针对每个细分提取反复出现的主题、痛点和正面反馈
4. **情感评分**：为每个细分的整体满意度分配情感分数（-1 至 +1）
5. **影响评估**：根据频率、严重程度和业务影响对洞察进行优先级排序
6. **综合分析**：创建整合后的细分画像和洞察

### 输出结构

针对每个已识别的细分：

**细分画像**
- 名称/标识符及常见特征
- 反馈数据集中的用户数量或占比
- 主要使用场景或背景

**待完成任务（Jobs-to-be-Done）**
- 该细分试图完成的核心任务
- 相关的期望结果

**情感分数与满意度水平**
- 整体情感分数（-1 至 +1）
- 主要满意度驱动因素和减分因素
- 如适用，提供净推荐值（NPS）代理指标

**主要正面反馈主题**
- 该细分喜欢 $ARGUMENTS 的哪些方面
- 从用户视角看出的关键优势
- 成功使用场景示例

**主要痛点与批评**
- 最常见的投诉或挫折
- 未满足的需求或缺失的功能
- 用户旅程中的摩擦点
- 如有条件，提供反馈中的直接引语

**产品与细分的契合度评估**
- $ARGUMENTS 对该细分需求的满足程度
- 通过产品改进提升契合度的潜力
- 用户流失或不满意的风险

**可执行的建议**
- 针对每个细分提出 2-3 项影响最大的改进
- 快速见效的改进与战略性举措
- 应优先关注或降低优先级的细分

## 最佳实践

- 所有发现都应以实际用户反馈为依据；引用来源
- 同时识别细分中的多数观点和少数观点
- 区分功能请求与根本性痛点
- 考虑用户所面临的背景和限制
- 标记样本量较小或情感倾向不确定的细分
- 寻找跨细分的共同模式和普遍痛点
- 平衡地呈现产品的优势与不足
