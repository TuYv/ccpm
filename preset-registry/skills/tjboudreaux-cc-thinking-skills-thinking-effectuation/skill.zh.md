# 效果逻辑

在奈特不确定性（Knightian uncertainty）下，从可用的手段和可承受的损失出发——而不是从固定目标和预测回报出发。通过可控的行动和真实的承诺来开辟路径。

## 何时使用

- 市场、技术或问题足够新颖，以致结果概率不可信赖。
- 手段比目标更清晰：身份、技能、资产和人脉先于固定目标而存在。
- 一个小行动就能换来信息或伙伴承诺，而不会带来毁灭性风险。
- 计划不断失效，因为环境变化快于预测。

## 何时不使用

- 路径是可预测的：已知的市场、可测算的单位经济模型、成熟的行动手册 → 使用因果规划。
- 一步走错就会导致毁灭或不可逆 → 先去风险；不要把可承受损失的步骤当作无代价的。
- 目标已经固定，资源是唯一的不确定性 → 按目标制定计划。
- 需求已确定的常规执行 → 直接行动；不要重新盘点手段。

## 流程

1. **只盘点手段。** 列出你是谁（技能、约束、价值观）、你知道什么（领域、工具、数据）、你认识谁（可触及的伙伴、用户、资源）。拒绝把“理想计划需要什么”作为输入。
2. **设定可承受损失上限。** 明确你能损失并仍能继续的最大时间、金钱、声誉和机会成本。如果拟议步骤超出任何一项上限，就把步骤改小或停止。
3. **选择一个可控的下一步行动。** 优先选择能带来 (a) 他人的真实承诺或 (b) 有区分度信息的最小行动。在损失上限内行动；不要优化预期回报。
4. **寻求承诺，而非意见。** 分享基于现有手段的可行方案。任何投入资源、渠道或工作的人都成为共创者，并可能重塑目标。将不含承诺的反馈视为无约束力而弃置。
5. **利用偶然性。** 把意外当作新手段：招聘失败、竞争对手的动作、路线图之外的需求。问“这如何扩大控制？”而不是“我们如何恢复旧计划？”
6. **更新手段与目标，然后停止或循环。** 将新手段和新承诺纳入盘点；重述浮现中的目标。在以下情况停止：可行路径已足够可控可以执行、损失上限耗尽而毫无进展，或不确定性收敛为可预测的计划（此时转向因果规划）。

## 输出

输出一份效果逻辑简报：

- `means`: 当前实际可用的身份 / 知识 / 人脉
- `affordable_loss`: 硬性上限（时间、金钱、声誉、机会）
- `next_action`: 上限之内的一个可控步骤
- `commitments_sought_or_won`: 谁必须押上切身利益，以及如果他们投入了，什么发生了变化
- `contingencies_used`: 被转化为手段的意外事件（或无）
- `emerging_goal`: 由手段和承诺塑造的当前目标（可能与最初的愿望不同）
- `stop_or_loop`: 继续使用效果逻辑、转向因果规划，或停止

## 验证

- **证伪手段优先的主张：** 如果简报从固定目标出发再回填资源，就从手段重写或放弃效果逻辑。
- **损失上限检查：** 每个建议的行动都必须落在声明的可承受损失之内；否则就缩小或停止。
- **承诺测试：** 仅依赖预测或未承诺的兴趣的进展无效——要求至少一个真实承诺或一次低成本的信息增益。
- **过度应用防护：** 如果存在可靠的预测和已知的行动手册，不要强行使用效果逻辑；按因果方式规划。
- **停止：** 在完成一轮“手段 → 损失上限 → 行动 → 承诺”循环并做出明确的停止/循环决策后停止；不要在效果逻辑的标签下无限探索。
