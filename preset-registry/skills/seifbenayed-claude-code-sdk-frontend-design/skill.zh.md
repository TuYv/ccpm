这个技能指导创建独特的、生产级的前端界面，避免千篇一律的“AI 垃圾风”审美。实现真正可用的代码，并对美学细节和创意选择给予非同寻常的关注。

用户提供前端需求：需要构建的组件、页面、应用程序或界面。他们可能会附带关于目的、受众或技术约束的背景信息。

## 设计思考

在编写代码之前，先理解上下文，并确定一个大胆的美学方向：
- **目的**：这个界面解决什么问题？谁在使用它？
- **基调**：选择一个极致方向：冷峻的极简、极繁主义的混乱、复古未来主义、有机/自然、奢华/精致、俏皮/玩具风、编辑/杂志风、粗野主义/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等。可选的风格如此之多。将这些作为灵感来源，但要设计出真正忠于美学方向的作品。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：是什么让它令人难以忘怀？别人会记住的是哪一点？

**至关重要**：选择一个清晰的概念方向并精准地执行它。大胆的极繁主义和精致的极简主义都可行——关键在于有意为之，而非力度大小。

然后实现满足以下条件的可运行代码（HTML/CSS/JS、React、Vue 等）：
- 生产级且功能完备
- 视觉上引人注目且令人难忘
- 具有连贯性和清晰的美学观点
- 每个细节都经过精心打磨

## 前端美学指南

重点关注：
- **排版**：选择美观、独特且有趣的字体。避免 Arial 和 Inter 这类通用字体；转而选择能提升前端美学的独特选择；出人意料、富有个性的字体选择。将一款独特的展示字体与一款精致的正文字体搭配使用。
- **色彩与主题**：坚持一种连贯的美学风格。使用 CSS 变量保持一致性。以主导色搭配锐利的强调色，胜过胆怯的、均匀分布的配色方案。
- **动效**：使用动画来实现效果和微交互。在 HTML 中优先采用纯 CSS 方案。在 React 中可用时使用 Motion 库。聚焦于高影响力的时刻：一次精心编排的页面加载配合交错显示（animation-delay）带来的愉悦感，胜过零散的微交互。运用滚动触发和令人惊喜的悬停状态。
- **空间构图**：出人意料的布局。不对称。重叠。对角线流动。打破网格的元素。大面积留白或可控的密度。
- **背景与视觉细节**：营造氛围和深度感，而不是默认使用纯色。添加与整体美学相匹配的情境效果和纹理。运用创意形式，如渐变网格、噪点纹理、几何图案、分层透明、戏剧化的阴影、装饰性边框、自定义光标和颗粒叠加。

绝不使用千篇一律的 AI 生成美学，例如被过度使用的字体（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（尤其是白底紫色渐变）、可预测的布局和组件模式，以及缺乏情境特色的流水线式设计。

进行创意解读，做出感觉真正为该情境量身定制的出人意料的选择。任何设计都不应雷同。在明暗主题、不同字体、不同美学之间进行变化。绝不要在不同生成轮次中趋同于常见的选择（例如 Space Grotesk）。

**重要**：让实现复杂度与美学愿景相匹配。极繁主义设计需要精雕细琢的代码，包含大量动画和效果。极简主义或精致的设计则需要克制、精准，以及对间距、排版和微妙细节的细致关注。优雅源于对愿景的出色执行。
