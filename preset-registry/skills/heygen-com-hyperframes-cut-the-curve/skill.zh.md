# 切断曲线 —— 技术目录

五种 SEAM 技术，一个原则：**在速度峰值处切断，在切点两侧匹配方向和速度
**——再加上场景内的两种技术（§6 入场、§7 滑动）。
seam LAW —— 向量法则、current、ledger、Seam Gate —— 位于
`motion-doctrine`；请先阅读。此技能说明参数与机制。
所有 GSAP 代码模板（worker + registry）：`examples/gsap-implementation.md`。

## 目录

| #   | 技术                  | 范围                          | 轴                | 用途                                                |
| --- | -------------------------- | ------------------------------ | ------------------- | ------------------------------------------------------ |
| 1   | **Zoom-Through**（前进） | 场景内文本替换                 | Z，朝向观看者      | 在同一思路中继续深入                                 |
| 2   | **Inverse Zoom-Through**   | 入场 / 回报节拍                 | Z，远离观看者      | 更大的事物落地                                     |
| 3   | **Cut the Curve**          | 场景之间                       | X / Y               | 默认边界，影片的 current                            |
| 4   | **Waterfall Cut**          | 文本到文本的 seam               | X，逐词            | 大字号文本节拍之间的逐词交接                       |
| 5   | **Rack-Focus Blur-Cut**    | 同一表面的状态切换              | X / Y / Z           | 你希望被看见的那一次切换——DSLR 拉焦式的华丽效果      |
| 6   | **Waterfall Entry**        | 场景内 ARRIVAL（无 seam）       | Y，从下方          | 标题卡、段落开场、列表引入                          |
| 7   | **Nudge Curve**            | 场景内组滑动（无 seam）         | X / Y               | 重新定位已编排的组，为其他内容腾出空间               |

## Z 方向是一个符号

仅有“同一轴”还不足以确定 Z——切换两侧的 d(scale)/dt 符号必须匹配：

| Z 向量       | 退出缩放          | 入场缩放          | 变体              |
| -------------- | ------------------- | -------------------- | -------------------- |
| Push（前进） | 增长 `1 → 1.2`   | 增长 `0.75 → 1`   | zoom-through         |
| Pull（后退） | 缩小 `1 → 0.8` | 缩小 `1.25 → 1`   | inverse zoom-through |

禁止的镜像：后退式退出接上从小变大的入场（pull 翻转为 push——
这是最常见的一种，因为从小变大是默认的元素入场方式），以及前进式退出
接上从超大尺寸回缩。这会约束传入场景自身在 seam 窗口（切换 + 约 0.5 秒）中的入场：
保持传入画面已完成编排，或让其入场方式与符号匹配。按照 Seam Gate 规则 7
逐项验证。

## 模糊逻辑（所有 Z 变体）

| 主体                                       | 峰值模糊   | 原因                                                            |
| --------------------------------------------- | ----------- | -------------------------------------------------------------- |
| 文本尺度（标题、词组）             | **10px**    | 20px 会使字形变成拖影；切换读起来像故障，而不是速度感 |
| 全画幅表面（窗口、卡片、截图） | **18–20px** | 大表面使用较轻的模糊，会读起来像渲染卡顿      |

在交换帧的两侧使用相同的峰值模糊。模糊 **WRAPPER**，绝不要模糊子元素。

## 1. 穿越式缩放（前进）

Z 轴速度匹配切换；**绝不能同时显示两段文本。** 所有内容都在放大：退出文本加速向镜头靠近，在峰值模糊处进行硬切换，进入文本继续放大并进入焦平面。仅适用于标题和短语。总时长 ≈ 0.4 秒。

| 阶段       | 缩放     | 模糊     | 不透明度             | 缓动                                       | 时长   |
| ---------- | -------- | -------- | -------------------- | ------------------------------------------ | ------ |
| 退出       | 1 → 1.2  | 0 → 10px | 1 → 0.15             | power3.in（不透明度使用单独的 `none` 补间） | 0.2s   |
| 切换（`tl.set`） | in: 0.75 | 10px     | out: 0 / in: 0.15    | —                                          | —      |
| 进入       | 0.75 → 1 | 10 → 0px | 0.15 → 1             | expo.out                                   | 0.5s   |

退出不透明度 MUST 使用单独的线性补间 — `power3.in` 会让不透明度过长时间保持接近 1。

进入时所有属性共享 `expo.out`。

## 2. 逆向穿越式缩放（后退）

向后拉远的镜像效果：退出元素后退；进入元素以超大尺寸到达（仿佛刚刚位于镜头之后），然后收缩回焦平面。所有内容都在缩小。应将时长投入到 ARRIVAL/回报节拍 — 回报台词、巨大的回复、停留的结束状态 — 而不是普通边界。总时长 ≈ 0.7 秒（退出占 30%，进入占 70%）。

| 阶段       | 缩放       | 模糊     | 不透明度             | 缓动                                       | 时长    |
| ---------- | ---------- | -------- | -------------------- | ------------------------------------------ | ------- |
| 退出       | 1 → 0.8    | 0 → 10px | 1 → 0.15             | power3.in（不透明度使用单独的 `none` 补间） | ~0.2s   |
| 切换（`tl.set`） | in: 1.25 | 10px     | out: 0 / in: 0.15    | —                                          | —       |
| 进入       | 1.25 → 1   | 10 → 0px | 0.15 → 1             | expo.out                                   | ~0.5s   |

模糊值为 10px 文本缩放；仅当两侧都是全出血表面时才使用 18–20px。

**符号纪律：** 进入场景必须以一个完整构图的画面形式位于收缩中的 wrapper 内 — 不得在接缝窗口中从小尺寸放大进入。分阶段进入应在收缩稳定后开始，或从 ≥1 的尺寸开始并进行收缩。

## 3. 切断曲线（默认场景边界）

X/Y 轴速度匹配切换 — 这是所有场景间边界的默认方式，使用影片当前的方向，而不是强调色。退出英雄元素沿一个方向加速，切换在运动中段落点，进入英雄元素沿 SAME 方向继续运动并减速。总时长 ≈ 0.6 秒；方向为 LEFT / RIGHT / UP / DOWN（默认为 LEFT）。

**部分移动：** 约占画面的 12%（1920 下约为 230px）— 绝不能完全移出屏幕。

| 方向       | 退出           | 进入起点 → 终点 |
| ---------- | -------------- | --------------- |
| 向左       | `x: 0 → −230`  | `x: +230 → 0`   |
| 向右       | `x: 0 → +230`  | `x: −230 → 0`   |
| 向上       | `y: 0 → −230`  | `y: +230 → 0`   |
| 向下       | `y: 0 → +230`  | `y: −230 → 0`   |

Mechanics:

- **镜像缓动：**退出使用 `power4.in` + 进入使用 `power4.out`，距离和持续时间相同 —
  这是一个 `power4.inOut` 的两个半段，因此在切点处速度完全匹配。
- **淡出技巧：**退出不透明度在运动行程的约 25–30% 处完成（淡出约 0.18–0.3s
  对比运动的 0.3–0.34s）；进入在路径中段以约 0.35 的不透明度点燃。让最后一个淡出元素恰好在切点消失 —
  如果出现没有任何内容移动的间隙，观感会像死气沉沉的空白。
- 退出 0.2–0.4s；进入 ≥ 退出。可选模糊 8–10px。
- **舞台底色：**`#root` 必须是不透明的
  （`background: var(--canvas-deep, var(--canvas, #000))`）— 否则中间窗口会打开一个总不透明度 < 1 的窗口，导致白色闪现（参见 `seam-craft`）。

`push-slide` 存在，但违反了部分行程和运动中阶段的要求；优先使用 cut-the-curve。

## 4. Waterfall Cut（逐词 cut-the-curve）

以 WORD 粒度执行 cut-the-curve — 这是文本到文本接缝中最强的向左切换方式。
离场单词沿各自的曲线加速退出；入场单词在运动中段级联进入 — 形成一股视线可以沿着穿过接缝移动的波浪。

**范围：**由 worker 在一个多节拍 comp 内编写（堆叠的全画幅 `.beat` 图层），
不是 registry/injector 类型 — 它补间的是单词 span，而不是 clip wrapper。文本节拍块的前后边界仍使用普通 registry transition。不会计入 2–3 个 transition 的预算。

| 参数                 | 值                          | 原因                                         |
| -------------------- | --------------------------- | -------------------------------------------- |
| 移动距离             | ±230px（约占画面 12%）      | 部分行程 + 速度 > 全画幅推移                 |
| 退出                 | 0.34s `power4.in`           | 加速度本身就是切换                             |
| 退出淡出             | 0.18s，与 x 同时开始        | 约在行程的 25–30% 处消失 — 不产生拖影          |
| 退出交错             | +0.022s，按阅读顺序          | 逐行剥离，而不是整块滑动                       |
| 进入                 | 0.3s `power4.out`            | 复合运动的后半段 — 速度匹配                    |
| 进入起始不透明度     | 0.35                        | 路径中段点燃；二元的 0→1 会产生突兀跳变         |
| 进入间隔             | 0.05s × 0.84 衰减            | 加速级联，最终形成完整构图                     |

规则：

- 每条链只使用一个方向，顺势而行。反向缩放仅作为链条的 ARRIVAL 节拍。
- 在构建时将所有单词预先设置为 `x: +230, opacity: 0` — 仅使用
  `immediateRender: false` 会让尚未启动的单词在静止状态下仍然可见。
- 较短的第一个节拍可以整行退出：其淡出应在切点前约 0.02s 结束，这样它在下一个单词点燃时仍处于拖掠状态 — 不产生死寂间隙。
- 仅使用变换/不透明度（可安全 seek）；使用不透明的舞台底色。

## 5. Rack-Focus Blur-Cut（可见切换）

这是唯一一种切换可被**看到**的变体：失焦模糊 SPIKE 隐藏单帧硬切换 — 仿佛手持 DSLR 的拉焦。作为同一视觉主题内同一表面的状态切换的偶发点缀使用；绝不作为默认边界。

与其他变体的区别：离场内容在切点前保持**完全不透明**（由模糊隐藏切换 — 不提前淡出）；使用 `power2.in` / `power2.out` 缓动（柔和的光学效果，而非动量）。

规则：

- 仅在叙事节拍处触发，约每 8 秒最多一次；绝不要在字幕中途或停顿期间触发。
- 在模糊峰值处（≥6px；峰值 8–12px，最大 ≤16–18px）切换——在上升途中切换会暴露切换点。
- 轻微缩放（约 1.06 的镜头呼吸感）能让它呈现为光学效果。
- 两侧方向一致——向量规律仍然成立。进入时长 ≥ 退出时长。
- 模糊包装器；绝不要在同一个元素的单个 tween 中同时使用模糊和透明度（无头合成存在 bug）；绝不要直接模糊 `<video>`（请将其包裹起来）。

## 6. 瀑布式进入（场景内抵达，不是接缝）

交错的抵达级联：单词/元素从下方快速甩入（保持一个一致的方向），每个元素都在前一个元素稳定下来之前开始——形成一阵加速的波浪，最终定格为构成完整的布局。标题卡、段落开场、列表/功能介绍。接缝的同类效果见 §4；不要混用两者的规则：

|               | §6 进入（抵达）                            | §4 瀑布式切换（接缝）                                   |
| ------------- | --------------------------------------------- | --------------------------------------------------------- |
| 透明度       | 在进入时通过 `tl.set` 实现二值 0→1——绝不淡入 | 在路径中段 0.35 处点燃——淡入本身就是速度技巧 |
| 默认轴       | Y，从下方进入                                 | X，沿当前方向运动                                     |
| 退出侧       | 无                                          | 单词通过镜像的 power4.in 加速退出                      |

编排：

- **重叠，不要排队**——下一个元素应在前一个元素稳定前后 ±2 帧内开始；级联过程中间隔逐渐缩短；最后一个元素要瞬间定格。
- **速度随权重变化**——重要/锚点元素移动距离更远、持续时间更长；轻量单词/标点则快速紧凑地进入：

| 参数 | 锚点/重要元素 | 普通单词 | 轻量/标点 |
| --------- | ------------ | ----------- | --------- |
| Y 偏移  | 60–80px      | 40–50px     | 30–48px           |
| 时长  | 0.16–0.20s   | 0.13–0.16s  | 0.10–0.13s        |
| 重叠   | 0–2f 间隔     | 1f 重叠  | 1–2f 重叠      |

- 使用 `power4.out` 缓动（需要额外的快速定格时使用 expo.out）；进入时绝不使用 `.inOut`。
- 每个级联只使用一个方向。
- 将最终单词拆分成片段以延长高潮；片段移动得更远。
- 稳定后，整体通常会滑动以便为下一个节拍腾出空间——这属于 §7。

## 7. 推移曲线（场景内整体滑动，不是接缝）

对已构成的整体（单词行、卡片堆叠、列表）进行慢-快-慢的重新定位，以展示内容或腾出空间。没有任何单一的内置缓动能产生这种效果——`power4.inOut` 会猛烈地停下。将同一个属性串联成三个 tween：

| 阶段     | 缓动            | 距离 | 时间 | 感受                                     |
| --------- | ----------- | -------- | ---- | ---------------------------------------- |
| 1 加速进入 | `power3.in`     | ~10%     | ~20% | 几乎不动——让运动被感知到，但没有冲击 |
| 2 爆发   | `none`（线性） | ~65%     | ~18% | 约为平均 px/帧的 2 倍——有目的地移动        |
| 3 尾段    | `power4.out`    | ~25%     | ~62% | 逐渐衰减、缓慢爬行至静止——消除猛烈停止感 |
|

- 尾段在时间上应 ≥ 入场阶段的 3×。如果仍然有冲击感：延长尾段的时间（而不是距离），或使用 `power5.out`。
- 阶段 2 保持线性，缓动会削弱爆发对比。
- 在阶段 2 期间展示新内容，爆发会遮蔽其出现。
- 垂直方向使用相同的比例；按比例缩放距离，保持时间比例。

## 反模式

| 不要这样做                                                                  | 应该这样做                                                                         |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 穿越缩放期间同时显示两段文本                                                | 在模糊峰值处硬切，一次只显示一段文本                                               |
| 对文本大小的主体使用 20px 模糊                                               | 文本使用 10px；仅全画面使用 18–20px                                               |
| 反向缩放退出 → 从小尺寸增长的进入（或推入 → 超大尺寸回缩）                    | 匹配缩放速度的符号；在切点±0.1s 处进行验证                                           |
| 在 Z 衔接包装器的补间动画下使用传入合成自身的放大进入                          | 以组合完成的状态到达；在衔接稳定后安排阶段进入，或匹配该符号                           |
| 替换时模糊/不透明度不匹配                                                     | 在切点帧使用完全相同的值                                                               |
| 温和的进入缓动（`power2.out`）                                                | 镜像退出效果：`power4.out` / `expo.out`                                             |
| 完全移出屏幕的退出/进入                                                       | 部分位移（约 12%）+ 提前淡出                                                          |
| 在切点任一侧使用 `.inOut` 缓动                                                | 镜像的 `power4.in` / `power4.out`                                                    |
| 单独的元素在切点之前很久就开始淡出                                             | 淡出应在切点前约 0.02s 结束，或使用逐词级联                                               |
| 瀑布式级联使用相等的间隔                                                       | 每个单词将间隔缩小 ×0.84                                                               |
| 对正文使用穿越缩放                                                             | 仅用于标题和短语                                                                       |
| 场景切换不使用切断曲线                                                         | 这是默认边界                                                                           |
| 连续的边界使用相反方向                                                         | 每次只使用一个方向；将预留向量用于表达含义                                               |
| 中间窗口切换时 `#root` 背后未绘制                                               | 使用不透明的舞台底色                                                                   |
| 排队进入（每个元素都等待前一个元素稳定）                                       | 重叠 ±1–2 帧，级联是波浪，而不是队列                                                   |
| 每个级联元素使用相同的偏移量/持续时间                                          | 根据权重变化：锚点移动更远，标点则快速吸附                                             |
| §6 到达效果使用渐变不透明度淡入                                                | 通过 `tl.set` 实现二值 0→1，淡入会与吸附效果冲突（衔接处使用淡出，而到达效果不使用）       |
| 对整体滑动使用单一缓动（`power4.inOut`、`slow()`）                             | 使用 §7 的三阶段链                                                                        |
| 将尾段缩短到小于入场阶段的 3×                                                 | 延长尾段的时间，而不是距离                                                               |
