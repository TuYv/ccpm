# 切割曲线——技巧目录

五种 SEAM 技巧，一个原则：**在速度峰值处切换，并使切换两侧的方向与速度相匹配**——外加两种场景内技巧（§6 入场、§7 滑动）。
接缝法则——向量法则、流向、账本、接缝门——位于
`motion-doctrine` 中；请先阅读它。本技能说明参数与机制。
所有 GSAP 代码模板（工作器 + 注册表）：`examples/gsap-implementation.md`。

## 目录

| #   | 技巧                       | 范围                           | 轴                  | 用途                                                   |
| --- | -------------------------- | ------------------------------ | ------------------- | ------------------------------------------------------ |
| 1   | **穿透缩放**（向前）       | 场景内文本切换                 | Z，朝向观看者       | 沿着同一思路继续深入                                   |
| 2   | **反向穿透缩放**           | 入场 / 收效节拍                | Z，远离观看者       | 更重要的内容落定                                       |
| 3   | **切割曲线**               | 场景之间                       | X / Y               | 默认边界，影片的流向                                   |
| 4   | **瀑布式切换**             | 文本到文本的接缝               | X，逐词             | 大字文本节拍之间的词级交接                             |
| 5   | **变焦模糊切换**           | 同一表面上的状态切换           | X / Y / Z           | 你希望观众看见的那一次切换——DSLR 拉焦式华彩效果       |
| 6   | **瀑布式入场**             | 场景内入场（无接缝）           | Y，从下方进入       | 标题卡、段落开场、列表引入                             |
| 7   | **微移曲线**               | 场景内群组滑动（无接缝）       | X / Y               | 重新定位已编排的群组以腾出空间                         |

## Z 方向有正负号

在 Z 轴上，仅仅“同轴”还不够——切换前后的 d(scale)/dt 符号必须匹配：

| Z 向量         | 退出缩放            | 进入缩放             | 变体                 |
| -------------- | ------------------- | -------------------- | -------------------- |
| 推进（向前）   | 放大 `1 → 1.2`      | 放大 `0.75 → 1`      | 穿透缩放             |
| 后拉（向后）   | 缩小 `1 → 0.8`      | 缩小 `1.25 → 1`      | 反向穿透缩放         |

禁止使用镜像组合：后退式退出后接从小到大的进入（后拉翻转为推进——
这是最常见的一种，因为从小到大是默认的元素入场方式），以及推进式退出
后接超大尺寸回缩。这一约束适用于接缝窗口期间（切换 + 约 0.5 秒）进入场景自身的入场动画，
而不仅仅是包装器补间动画：保持进入帧的构图不动，或让其入场动画与符号匹配。
按照接缝门规则 7 逐项验证。

## 模糊逻辑（所有 Z 轴变体）

| 主体                                          | 峰值模糊    | 原因                                                           |
| --------------------------------------------- | ----------- | -------------------------------------------------------------- |
| 文本缩放（标题、词组）                        | **10px**    | 20px 会涂抹字形——切换看起来像故障，而不是速度                 |
| 全帧表面（窗口、卡片、截图）                  | **18–20px** | 在大面积表面上使用较轻的模糊，会看起来像渲染卡顿               |

在切换帧处，两侧使用相同的峰值模糊。模糊应施加于包装器，绝不能施加于子元素。

## 1. 穿透式缩放（前进）

沿 Z 轴进行速度匹配剪切；**绝不能让两段文本同时可见。** 一切都在放大：出场文本朝镜头加速，在模糊达到峰值时通过硬切隐藏切换，入场文本继续放大并进入焦平面。仅适用于标题和短语。总时长 ≈ 0.4s。

| 阶段           | 缩放     | 模糊      | 不透明度          | 缓动                                       | 时长     |
| -------------- | -------- | --------- | ----------------- | ------------------------------------------ | -------- |
| 出场           | 1 → 1.2  | 0 → 10px  | 1 → 0.15          | power3.in（不透明度：单独的 `none` 补间）  | 0.2s     |
| 切换（`tl.set`） | 入场：0.75 | 10px      | 出场：0 / 入场：0.15 | —                                          | —        |
| 入场           | 0.75 → 1 | 10 → 0px  | 0.15 → 1          | expo.out                                   | 0.5s     |

出场不透明度必须使用独立的线性补间——`power3.in` 会让不透明度在接近 1 的状态维持过久。
入场时，所有属性共用 `expo.out`。

## 2. 反向穿透式缩放（后退）

后拉式镜像效果：出场元素向后退去；入场元素以超大尺寸到达（仿佛刚好位于镜头后方），然后回缩至焦平面。一切都在缩小。用于到达/揭晓节拍——揭晓文案、巨型回复、持续停留的结束状态——绝不要用于普通边界。总时长 ≈ 0.7s（30% 出场 / 70% 入场）。

| 阶段           | 缩放     | 模糊      | 不透明度          | 缓动                                       | 时长     |
| -------------- | -------- | --------- | ----------------- | ------------------------------------------ | -------- |
| 出场           | 1 → 0.8  | 0 → 10px  | 1 → 0.15          | power3.in（不透明度：单独的 `none` 补间）  | ~0.2s    |
| 切换（`tl.set`） | 入场：1.25 | 10px      | 出场：0 / 入场：0.15 | —                                          | —        |
| 入场           | 1.25 → 1 | 10 → 0px  | 0.15 → 1          | expo.out                                   | ~0.5s    |

文本尺度下的模糊值为 10px；仅当两侧都是满出血画面时才使用 18–20px。

**方向纪律：** 入场场景应作为一个完整构图画面置于正在回缩的包装器内到达——在接缝窗口中不要使用从小尺寸放大的入场效果。分阶段入场应在回缩稳定后发生，或从 ≥1 开始并向内回缩。

## 3. 沿曲线切换（默认场景边界）

沿 X/Y 轴进行速度匹配剪切——这是所有场景间边界的默认方式，应融入影片当前的运动流，而不是作为强调效果。出场主体朝一个方向加速，在运动途中落下切点，入场主体沿相同方向继续运动并减速。总时长 ≈ 0.6s；方向为左 / 右 / 上 / 下（默认为左）。

**局部位移：** 约为画面的 12%（在 1920 下约为 230px）——绝不要完整移出屏幕。

| 方向     | 出场          | 入场起点 → 终点 |
| -------- | ------------- | ----------------- |
| 向左     | `x: 0 → −230` | `x: +230 → 0`     |
| 向右     | `x: 0 → +230` | `x: −230 → 0`     |
| 向上     | `y: 0 → −230` | `y: +230 → 0`     |
| 向下     | `y: 0 → +230` | `y: −230 → 0`     |

机制：

- **镜像缓动：**退出使用 `power4.in`，进入使用 `power4.out`，距离和持续时间相同——
  两者分别构成一个 `power4.inOut` 的前后两半，因此切换点处的速度完全匹配。
- **淡出技巧：**退出元素在完成约 25–30% 的位移时便完成不透明度变化（淡出约 0.18–0.3 秒，
  而运动为 0.3–0.34 秒）；进入元素在路径中途以约 0.35 的不透明度亮起。应让最后一个淡出
  元素恰好在切换点消失——如果出现所有内容都不动的空隙，观感上就会像一段冷场。
- 退出 0.2–0.4 秒；进入时长 ≥ 退出时长。可选使用 8–10px 模糊。
- **舞台底色：**`#root` 必须不透明
  （`background: var(--canvas-deep, var(--canvas, #000))`）——否则，中间窗口处的切换会产生一个
  总不透明度 < 1 的窗口，导致白色闪烁（参见 `seam-craft`）。

`push-slide` 虽然存在，但它违反了局部位移和运动中途切换的要求；优先使用曲线中切。

## 4. 瀑布式切换（逐词曲线中切）

在单词粒度上执行曲线中切——这是文本到文本接缝中最有力的向左切换方式。
传出单词沿各自的曲线加速退出；传入单词则在运动途中级联进入——形成一道让视线
跨越接缝跟随移动的波浪。

**适用范围：**由 worker 在一个多节拍合成中创作（堆叠的全帧 `.beat` 图层），
而不是注册表/注入器类型——它补间的是单词 span，而不是剪辑包装器。文本节拍区块的
进入和退出边界仍使用常规注册表转场。不计入 2–3 个转场的预算。

| 参数                | 值                    | 原因                                        |
| ------------------- | --------------------- | ------------------------------------------- |
| 位移                | ±230px（约为画面的 12%） | 局部位移 + 速度 > 全画面推移                |
| 退出                | 0.34 秒 `power4.in`    | 加速本身就是切换                            |
| 退出淡出            | 0.18 秒，与 x 同时开始 | 单词在约 25–30% 位移处消失——不会拖影        |
| 退出错开            | +0.022 秒，按阅读顺序  | 让文本行逐层剥离，而不是整块滑动            |
| 进入                | 0.3 秒 `power4.out`    | 复合运动的后半段——速度匹配                  |
| 进入起始不透明度    | 0.35                  | 路径中途亮起；二元式 0→1 会突兀跳变         |
| 进入间隔            | 0.05 秒 × 0.84 衰减   | 加速级联，最终稳定地完成构图                |

规则：

- 每条链只使用一个方向，顺势而行。反向缩放仅用于该链的到达节拍。
- 构建时将所有单词预设为 `x: +230, opacity: 0`——仅使用 `immediateRender: false`
  会使尚未开始运动的单词在静止位置可见。
- 较短的第一个节拍可以整行退出：其淡出应在切换点前约 0.02 秒结束，使它在后续单词
  亮起时仍处于疾驰状态——避免出现空档。
- 仅使用变换/不透明度（可安全跳转）；同样需要不透明的舞台底色。

## 5. 焦点切换模糊剪切（可见的切换）

这是唯一一种让切换本身可见的变体：一次失焦模糊尖峰掩盖单帧硬切——模拟手持
数码单反相机的焦点拉移。仅偶尔用于同一视觉主题内、同一表面的状态切换，以增添效果；
绝不能作为默认边界转场。

与其他方式的区别：传出内容在切换前始终保持完全不透明（由模糊来掩盖交换——不提前淡出）；
缓动使用 `power2.in` / `power2.out`（柔和的光学效果，而非动量感）。

规则：

- 仅在叙事节拍点触发，约每 8 秒不超过一次；绝不在字幕中途或停留期间触发。
- 在模糊达到峰值时切换（≥6px；峰值 8–12px，最大不超过 16–18px）——在模糊增强途中交换会暴露剪切点。
- 轻微的缩放（约 1.06，模拟镜头呼吸效应）能让它看起来像光学效果。
- 两侧方向保持一致——矢量法则依然成立。入场时长 ≥ 出场时长。
- 对包装容器应用模糊；绝不要在同一元素的一次补间中同时使用模糊和不透明度（无头模式下的合成错误）；绝不要直接模糊 `<video>`（应将其包装起来）。

## 6. 瀑布式入场（场景内到达——不是接缝）

交错的入场级联：文字/元素从下方快速进入（保持同一方向），
每个元素都在前一个元素稳定之前开始运动——形成一道不断加速的波浪，最终收束为
完整的布局。适用于标题卡、段落开场、列表/功能介绍。对应的接缝效果见
§4；不要混用两者的规则：

|               | §6 入场（到达）                                  | §4 瀑布式剪切（接缝）                                       |
| ------------- | --------------------------------------------- | --------------------------------------------------------- |
| 不透明度      | 通过入场时的 `tl.set` 从 0→1 二元切换——绝不淡入 | 在路径中点以 0.35 点亮——淡入本身就是速度技巧             |
| 默认轴        | Y，从下方进入                                  | X，顺势流动                                               |
| 出场侧        | 无                                              | 文字通过镜像的 power4.in 加速退出                         |

编排：

- **重叠，不要排队**——下一个元素应在前一个元素稳定前后 ±2 帧内开始；
  级联过程中的间隔逐渐缩短；最后一个元素迅速归位。
- **速度随视觉重量变化**——较重的元素/锚点元素移动得更远、持续时间更长；
  较轻的文字/标点则快速紧凑地进入：

| 参数      | 锚点/较重元素 | 普通文字    | 较轻元素/标点 |
| --------- | ------------ | ----------- | ----------------- |
| Y 偏移量  | 60–80px      | 40–50px     | 30–48px           |
| 持续时间  | 0.16–0.20s   | 0.13–0.16s  | 0.10–0.13s        |
| 重叠      | 0–2f 间隔    | 重叠 1f     | 重叠 1–2f         |

- 缓动使用 `power4.out`（需要更强的利落感时使用 expo.out）；入场绝不要使用 `.inOut`。
- 每次级联只使用一个方向。
- 将最后一个单词拆分成碎片以延长高潮；碎片移动得更远。
- 稳定后，整个组通常会滑动，为下一个节拍腾出空间——这就是 §7。

## 7. 微移曲线（场景内组滑动——不是接缝）

通过慢—快—慢的方式重新定位已编排好的组（文字行、卡片堆、列表），以
展示内容或腾出空间。没有任何单个内置缓动能实现这种效果——`power4.inOut`
会突兀地停下。在同一属性上串联三个补间：

| 阶段       | 缓动            | 距离 | 时间 | 感受                                     |
| --------- | --------------- | -------- | ---- | ---------------------------------------- |
| 1 加速进入 | `power3.in`     | ~10%     | ~20% | 几乎不动——让运动被感知，但没有顿挫       |
| 2 爆发     | `none`（线性） | ~65%     | ~18% | 约为平均 px/frame 的 2 倍——目的明确      |
| 3 收尾     | `power4.out`    | ~25%     | ~62% | 逐渐衰减并缓慢归位——消除突兀的停止感     |

规则：

- 拖尾时长至少是渐入时长的 3 倍。如果仍有生硬冲击感：延长拖尾的时间（而非
  距离），或使用 `power5.out`。
- 阶段 2 保持线性——添加缓动会削弱爆发对比。
- 在阶段 2 期间揭示新内容——爆发会掩盖其出现。
- 垂直方向使用相同比例；按比例缩放距离，保持时间比例不变。

## 反模式

| 不要                                                                       | 应该                                                                              |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 穿透缩放期间同时显示两段文本                                               | 在模糊峰值处硬切，每次只显示一段文本                                              |
| 对文本缩放主体使用 20px 模糊                                               | 文本使用 10px；仅全画面使用 18–20px                                               |
| 反向缩放退出 → 从小放大进入（或推进 → 从过大状态回缩）                    | 匹配缩放速度的方向；在切点±0.1s 处验证                                            |
| 在 Z 接缝包装器补间下，让传入合成执行自身的放大入场                        | 以完整构图抵达；在接缝稳定后再安排入场，或匹配方向                                |
| 切换时模糊/不透明度不匹配                                                  | 在切换帧使用相同的值                                                              |
| 柔和的进入缓动（`power2.out`）                                             | 镜像退出：`power4.out` / `expo.out`                                                |
| 完全移出/移入屏幕                                                          | 部分位移（约 12%）+ 提前淡出                                                       |
| 在切点任一侧使用 `.inOut` 缓动                                             | 镜像的 `power4.in` / `power4.out`                                                  |
| 单个元素在切换前很久就开始淡出                                             | 淡出在切换前约 0.02s 结束，或使用逐词级联                                         |
| 瀑布式级联中的间隔相等                                                     | 每个词的间隔按 ×0.84 递减                                                         |
| 对正文文本使用穿透缩放                                                     | 仅用于标题和短语                                                                  |
| 场景切换不使用切割曲线                                                     | 它是默认边界                                                                      |
| 连续边界采用相反方向                                                       | 保持同一股流向；将保留向量用于表达含义                                            |
| 窗口中途切换时，背后的 `#root` 未绘制                                      | 使用不透明的舞台底色                                                              |
| 入场排队执行（每个都等待前一个稳定）                                       | 重叠 ±1–2 帧——级联是波浪，而不是队列                                              |
| 每个级联元素使用相同的偏移和持续时间                                       | 根据视觉权重变化：锚点移动得更远，标点快速弹入                                    |
| §6 入场使用渐进式不透明度淡入                                              | 通过 `tl.set` 进行二元 0→1 切换——淡入会削弱突现感（接缝切换会淡出；入场不会）     |
| 对群组滑动使用单一缓动（`power4.inOut`、`slow()`）                         | 使用 §7 的三阶段链                                                               |
| 微移拖尾短于渐入的 3 倍                                                    | 延长拖尾的时间，而非距离                                                          |
