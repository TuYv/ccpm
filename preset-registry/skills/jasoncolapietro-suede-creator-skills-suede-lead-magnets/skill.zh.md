# Suede 潜在客户磁铁系统

Suede 将潜在客户磁铁设计为有用、权利清晰的资产，通过诚实的价值交换，以及一条可衡量的产品价值实现路径。应根据受众需求和潜在客户资质，而不是为了最大化原始邮箱获取量，来选择格式、深度、门槛、交付方式和后续跟进。

## 规划前

**首先检查产品营销背景：**
如果存在 `.agents/product-marketing.md`（或 `.claude/product-marketing.md`，或者在较旧设置中使用的旧版 `product-marketing-context.md` 文件名），请在提问前阅读。使用其中的背景信息，只询问尚未涵盖或与此任务具体相关的信息。

收集以下背景信息（如未提供则询问）：

### 1. 业务背景
- 公司是做什么的？
- 理想客户是谁？
- 你的产品解决什么问题？

### 2. 当前潜在客户生成情况
- 你目前如何获取潜在客户？
- 你有哪些潜在客户磁铁或优惠？
- 目前通过邮箱获取的转化率是多少？
- 受众平时在哪里上网？
- 潜在客户在购买前最常提出的问题是什么？

### 3. 内容资产
- 现有的哪些内容可以重新利用？（博客文章、指南、数据）
- 你可以将哪些专业知识打包？
- 你们内部使用哪些模板或工具？

### 4. 目标
- 主要目标：扩大邮箱列表、提升潜在客户质量，还是进行产品教育？
- 目标受众处于哪个阶段：认知、考虑，还是决策？
- 时间安排和资源限制是什么？

## 潜在客户磁铁原则

### 1. 解决具体问题
- 针对一个明确的痛点，而不是宽泛的主题
- “如何撰写能获得回复的冷邮件” > “营销指南”

### 2. 匹配买家阶段
- 认知阶段的潜在客户需要教育
- 考虑阶段的潜在客户需要比较和评估
- 决策阶段的潜在客户需要实施帮助

### 3. 高感知价值，低时间投入
- 看起来应该值得付费
- 应在 30 分钟内消费完毕（理想情况下不超过 10 分钟）
- 提供即时、可执行的收获

### 4. 通向产品的自然路径
- 解决你的产品同样能够解决的问题
- 让人意识到你的产品可以填补的空缺
- 展示你在该领域的专业能力

### 5. 易于消费
- 使用一种清晰的格式（不要混合电子书 + 视频 + 电子表格）
- 能够在移动设备上使用
- 无需特殊软件

### 默认拒绝制作的内容
无论简报如何要求，本技能都不会制作以下命名俗套内容：
- 没有人能读完的 40 页《[Category] 终极指南》。
- 复述其所门控博客文章的“10 个技巧”PDF。
- 清单中的每一项都是“考虑 X”，而不是可作出决定的行动。
- 只有标题的空白模板。

## 潜在客户磁铁类型

| 类型 | 最适合 | 工作量 | 创建时间 |
|------|----------|--------|----------------|
| 清单 | 快速见效、流程步骤 | 低 | 1-2 小时 |
| 速查表 | 参考资料、捷径 | 低 | 2-4 小时 |
| 模板（文档/电子表格/Notion） | 可重复的流程、工作流 | 低-中 | 2-8 小时 |
| 示例库 | 灵感、示例 | 中 | 4-8 小时 |
| 电子书/指南 | 深度教育、建立权威 | 高 | 1-3 周 |
| 迷你课程（电子邮件） | 教育 + 培育 | 中 | 1-2 周 |
| 迷你课程（视频） | 教育 + 个性化表达 | 高 | 2-4 周 |
| 测验/评估 | 细分、互动 | 中 | 1-2 周 |
| 网络研讨会 | 权威、实时互动 | 中 | 准备 1 周 |
| 资源库 | 持续价值、回访 | 高 | 持续进行 |
| 免费试用/社区访问权限 | 产品体验 | 不定 | 不定 |

**有关各格式的详细创建指南**：参见 [references/format-guide.md](references/format-guide.md)

## 将引流诱饵匹配到买家阶段

### 认知阶段
目标：教育受众了解问题。吸引尚不了解你的人。

| 格式 | 示例 |
|--------|---------|
| 清单 | “10 项网站审计清单” |
| 速查表 | “初学者 SEO 速查表” |
| 电子书/指南 | “电子邮件营销完整指南” |
| 测验 | “你属于哪种类型的营销人员？” |

### 考虑阶段
目标：帮助评估解决方案。建立信任并展示专业能力。

| 格式 | 示例 |
|--------|---------|
| 对比模板 | “CRM 对比表格” |
| 评估 | “营销成熟度评估” |
| 案例研究合集 | “5 家将销售管道增长至 3 倍的公司” |
| 网络研讨会 | “如何选择合适的分析工具” |

### 决策阶段
目标：帮助实施。消除购买阻力。

| 格式 | 示例 |
|--------|---------|
| 模板 | “可直接使用的销售邮件模板” |
| 免费试用 | “14 天免费试用” |
| 实施指南 | “迁移清单：30 分钟完成切换” |
| ROI 计算器 | “计算你的节省金额”（转到 `suede-free-tools`） |

## 门控策略

### 门控选项

| 方法 | 使用时机 | 权衡 |
|----------|-------------|-----------|
| **完全门控** | 高价值内容、漏斗底部 | 最大化信息收集，触达范围较低 |
| **部分门控** | 预览版 + 完整版 | 平衡触达范围与信息收集 |
| **不设门控 + 可选填写** | 漏斗顶部教育内容 | 最大化触达范围，信息收集较少 |
| **内容升级** | 博客文章 + 额外内容 | 上下文相关，意向较高 |

### 要求填写哪些信息

- **仅邮箱** — 转化率最高，阻力最小
- **邮箱 + 姓名** — 支持个性化，阻力略有增加
- **邮箱 + 公司/职位** — 更好地筛选潜在客户，阻力更大
- **多字段** — 仅适用于高价值产品（网络研讨会、演示）

经验法则：只询问所需的最少信息。每增加一个字段，转化率就会降低 5-10%。

### 如何表达交换条件

- 明确展示价值：“免费获取完整的 25 页指南”
- 展示预览：目录、第一页、示例结果
- 添加社会证明：“已有 5,000 多名营销人员下载”
- 降低风险：“无垃圾邮件。随时可以退订。”

**有关表单优化**：转到 `suede-site-alchemy`。  
**有关弹窗实现**：转到 `suede-site-alchemy`。

## 落地页与交付

### 落地页结构

1. **标题** — 清晰说明收益：他们将获得什么，以及为什么这很重要
2. **预览/样机** — 展示引流诱饵的视觉内容（封面、截图、示例页面）
3. **内容概览** — 以 3-5 个项目符号列出关键收获
4. **社会证明** — 下载数量、客户评价、品牌徽标
5. **表单** — 字段尽量精简，CTA 按钮清晰
6. **常见问题** — 消除疑虑（真的免费吗？是什么格式？）

**有关落地页优化**：转到 `suede-site-alchemy`。

### 交付方式

| 方式 | 优点 | 缺点 |
|------|------|------|
| **即时下载** | 立即获得满足感 | 无法验证邮箱 |
| **通过电子邮件交付** | 验证邮箱，开始建立关系 | 存在轻微延迟 |
| **感谢页面 + 电子邮件** | 兼具两者优势——即时访问 + 邮件副本 | 稍微复杂一些 |
| **滴灌式交付** | 培养习惯，多次触达 | 仅适用于课程/系列内容 |

### 感谢页面优化

不要浪费感谢页面。在访客完成转化后：
- 确认交付（“查看你的收件箱”）
- 提供下一步行动（预约演示、开始试用、加入社区）
- 鼓励社交分享（预先写好的推文/帖子）
- 推荐相关内容

## 推广与分发

### 博客 CTA 与内容升级

- 创建与具体文章相关的内容升级（例如，为教程文章提供额外的检查清单）
- 内容升级的转化效果比通用的侧边栏 CTA 高出 2-5 倍

### 离站意图与弹窗

- 在检测到离站意图或达到特定滚动深度时触发
- 让弹窗优惠与页面内容相匹配
- 将弹窗的实现交由 `suede-site-alchemy` 处理。

### 社交媒体

- 将社交策略和帖子制作交由 `suede-social` 处理。

### 付费推广

- 使用 Facebook/Instagram 潜在客户广告推广漏斗顶部的引流磁铁
- 使用 Google Ads 推广高意向引流磁铁（模板、工具）
- 使用 LinkedIn 推广 B2B 引流磁铁
- 使用引流磁铁广告重新定位博客访客
- 使用 `suede-ads` 制定广告活动策略

### 合作伙伴联合推广

- 将合作伙伴交叉推广、嘉宾网络研讨会和捆绑资源集合交由 `suede-co-marketing` 处理。

## 衡量成功

### 关键指标

| 指标 | 它能告诉你什么 | 基准 |
|--------|-------------------|-----------|
| **落地页转化率** | 优惠的吸引力 | 20-40%（暖流量），5-15%（冷流量） |
| **每条潜在客户成本** | 获客效率 | 因渠道和行业而异 |
| **潜在客户到客户的转化率** | 潜在客户质量 | 1-5%（B2B），差异很大 |
| **电子邮件互动率** | 内容相关性 | 30-50% 打开率，2-5% 点击率 |
| **转化所需时间** | 培育效果 | 按引流磁铁来源进行追踪 |

基准数据仅为用于校准的行业区间——绝不要将其断言为该资产预期达到或已经实现的结果。

**如需了解按格式和行业划分的详细基准数据**：请参阅 [references/benchmarks.md](references/benchmarks.md)

### A/B 测试思路

- **标题**：以利益为重点 vs. 以好奇心为驱动
- **格式**：针对同一主题的检查清单 vs. 指南
- **门槛程度**：完全门控 vs. 部分预览
- **表单字段**：仅需电子邮件 vs. 电子邮件 + 姓名
- **CTA 文案**：“免费下载指南” vs. “获取你的副本”
- **交付方式**：即时下载 vs. 通过电子邮件交付

### 潜在客户质量信号

当以下 4 项中至少有 3 项成立时，引流磁铁通过质量检查：
- 电子邮件互动率高于平均水平
- 潜在客户以预期的比率进入试用/演示阶段
- 交付后的退订率较低
- 潜在客户的人口统计特征符合 ICP

## 输出格式

创建引流磁铁策略时，请提供：

### 1. 引流磁铁建议
- 格式和主题
- 目标买家阶段
- 为什么此格式适合该受众
- 预计创建工作量

### 2. 内容大纲
- 关键章节/组成部分
- 长度和范围
- 它的独特之处或价值所在
- 引流磁铁中嵌入的每项第三方资产（库存图片、引用的数据或图表、借用的模板、其他产品的截图），逐项列出其名称及许可证；如果许可证不明确，则说明这一缺口。未解决的缺口会阻止该资产的制作。

### 3. 门控与捕获计划
- 门控哪些内容以及如何门控
- 表单字段
- 落地页结构

### 4. 分发计划
- 推广渠道
- 内容升级机会
- 付费放大（如适用）

### 5. 衡量计划
- KPI 和目标
- 首先进行 A/B 测试的内容

## 边界

- 没有证据时，不要声称转化、需求、原创性或受众匹配度。
- 未经明确授权，不要发布资产、创建表单、收集联系人、启动活动或更改同意设置。
- 不要对用户因法律、安全、账户或支持原因而必须免费提供的材料设置门控。
- 不要替用户决定所捕获数据的隐私、许可、合规或保留政策。

## 路由

- 使用 `suede-free-tools` 处理计算器、评分器、测验和生成器。
- 使用 `suede-copy` 处理资产和落地页文案，使用 `suede-emails` 处理捕获后的培育邮件。
- 使用 `suede-content-strategy` 进行主题选择，使用 `suede-analytics` 进行衡量。
- 使用 `suede-ads` 或 `suede-social` 进行分发，使用 `suede-co-marketing` 进行合作伙伴推广。
- 使用 `suede-site-alchemy` 实现落地页、表单和弹窗。
- 使用 `suede-ab-testing` 设计和评估 A/B 测试创意中的测试。
