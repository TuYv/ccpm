### 1.2 暴力形式（11,340/2006法第7条）

| 形式 | 定义 | 示例 |
|-------|-----------|----------|
| **身体** (I) | 损害身体完整性或健康 | 拍打、拳击、推搡、烧伤、掐脖 |
| **心理** (II) | 情绪伤害、降低自尊、控制 | 羞辱、威胁、隔离、Gaslighting、操纵 |
| **性** (III) | 强迫对方目睹/维持/参与性行为的行为 | 婚内强奸、阻止避孕使用、强迫堕胎 |
| **财产** (IV) | 扣押、盗窃、毁坏物品/工作工具 | 扣押证件、毁坏手机、控制财务 |
| **名誉** (V) | 诽谤、毁谤或侮辱 | 公开指控通奸、泄露隐私、辱骂 |

### 1.3 紧急保护性措施

#### 针对施害者（Art. 22）

| 措施 | 描述 |
|--------|-----------|
| **I** | 停止持有/携带武器 |
| **II** | 强制离开住宅 |
| **III-a** | 禁止接近（由法官确定最小距离） |
| **III-b** | 禁止通过任何方式联系 |
| **III-c** | 禁止进入特定场所 |
| **IV** | 限制或暂停未成年子女探视 |
| **V** | 临时抚养费 |
| **par. 5** | **电子监控**（脚环）— 15,125/2025 法案 |

| 措施 | 描述 |
|--------|-----------|
| **I** | 转介至保护计划 |
| **II** | 施害者离开后返回住所 |
| **III** | 将受害人转移，不损害其权利 |
| **IV** | 分居 |

#### 财产保护（Art. 24）

| 措施 | 描述 |
|--------|-----------|
| **I** | 返还施害者扣押的财物 |
| **II** | 禁止出售/出租共同财产 |
| **III** | 暂停授权行为 |
| **IV** | 临时保证金 |

### 1.4 服务流程 — 家庭暴力受害人

```
VITIMA em situacao de violencia
│
├─→ EMERGENCIA (risco imediato de vida)
│   └─→ Ligar 190 (PM) ou 180 (Central da Mulher)
│       └─→ Flagrante + afastamento imediato do agressor
│           └─→ Delegacia (B.O.) + DEAM se disponivel
│               └─→ Medida protetiva em ate 48h (Art. 12-C)
│
├─→ URGENCIA (violencia recorrente)
│   └─→ Delegacia (B.O.) ou DEAM
│       └─→ Solicitar medidas protetivas
│           └─→ Juiz decide em ate 48h (inaudita altera pars)
│               └─→ Monitoramento eletronico se necessario
│
├─→ ORIENTACAO (quer saber direitos)
│   └─→ CRAM (Centro de Referencia da Mulher)
│       └─→ Defensoria Publica / OAB / advogado particular
│           └─→ Avaliacao do caso + estrategia juridica
│
└─→ SINAL VERMELHO (Lei 14.188/2021)
    └─→ Desenhar X vermelho na mao
        └─→ Mostrar em farmacia/hospital participante
            └─→ Estabelecimento aciona autoridades
```

### 5.4 狡猾性作为加重情节

狡猾性可作为：
- **普通加重情节**（CP第61条II款“c”）——以背信、埋伏、**伪装**或其他妨碍受害人辩护的方式实施的犯罪
- **杀人的加重情节**（CP第121条第2款IV项）——背信、埋伏、**伪装**或其他使受害人防御受阻的方式
- **诈骗罪的加重情节**（CP第171条第1款）——针对老年人的情形

### 6.1 Sistema Trifásico (Art. 68 CP)

```
FASE 1: Pena-base (Art. 59 CP — circunstancias judiciais)
  → Culpabilidade, antecedentes, conduta social, personalidade,
    motivos, circunstancias, consequencias, comportamento vitima
  → Resultado: entre o minimo e maximo legal

FASE 2: Circunstancias agravantes e atenuantes
  → Agravantes (Arts. 61-62) e Atenuantes (Arts. 65-66)
  → NAO pode ultrapassar os limites legais (Sumula 231 STJ)

FASE 3: Causas de aumento e diminuicao
  → Majorantes e minorantes (partes especial e geral)
  → PODE ultrapassar os limites legais
```

## 10 模块 — 案件刑事分析完整流程

在收到刑事案件进行分析时，请始终执行以下10个步骤：

## 第1步 — 事实定性

- 罪名类型（是什么犯罪？）
- 法律依据（CP/特别法的哪一条？）
- 分类：故意/过失，未遂/既遂，一般/特殊/凶恶

## 第2步 — 相关主体

- 主体行为人（谁实施了？）
- 受害主体（谁遭受？）
- 他们之间关系（家庭、职业、陌生人）
- 被害人弱势性

## 第3步 — 物证与责任人

- 物证（鉴定书、警情记录、照片、病历）
- 责任人证据（证人、监控、认罪、电子数据）
- 是否有足够线索支持起诉？

## 第4步 — 情节分析

- 可适用的加重与减轻情节
- 刑期加重/减轻原因
- 犯罪竞合（实质竞合、形式竞合、持续犯罪）

## 第5步 — 刑期初步核算

- 基准刑期估算（第一阶段）
- 加重/减轻（第二阶段）
- 加重/减轻事由（第三阶段）
- 预期起始执行制度

## 第6步 — 程序性问题

- 管辖权（刑事法庭、陪审团、青少年法庭、家庭暴力）
- 刑事诉讼性质（公诉有条件、公诉无条件、附带私诉）
- 现行犯逮捕？预防性？临时？
- 可适用的保全措施

## 第7步 — 可供主张

- 辩方：哪些主张可行？
- 检方：哪些论点更强？
- 相关判例

## 第8步 — 风险与情景

- 乐观情景（无罪、降格）
- 基准情景（有缓解情节的定罪）
- 悲观情景（判处法定最高刑）

- 与检察机关谈判

**情况复杂**：当所谓受害人伪造攻击以获取利益（监护权、不动产、赡养费）时。

**注意事项：**
- 在家庭暴力中，受害人的陈述具有特殊分量（该类犯罪具有隐蔽性）
- 主张虚假需提供**充分证据**（仅否认不足）
- 若指控无根据，存在二次伤害受害者的风险
- 若虚假得到证明：第339条《刑法》（诬告罪）—2-8年有期徒刑

**可证明虚假的证据：**
- IML鉴定为阴性 / 与指控不一致
- 矛盾的消息（WhatsApp、SMS）
- 安全监控录像
- 现场证人
- 已证实的不在场证明（定位、卡记录、监控）
- 双方之间的财产诉讼历史

### 15.1 执行中的利益

| 利益 | 时间要求 | 主观要求 |
|-----------|-------------------|-------------------|
| **进展（普通）** | 16%（初犯） / 20%（累犯） | 良好行为 |
| **进展（暴力）** | 25%（初犯） / 30%（累犯） | 良好行为 |
| **进展（非致死重罪）** | 40% / 50% / 60% | 良好行为 |
| **进展（致死重罪）** | 50% / 60% / 70% | 良好行为 |
| **有条件释放** | 1/3（初犯） / 1/2（累犯） | 良好行为 + 赔偿损失 |
| **有条件释放（重罪）** | 2/3 + 非特定累犯 | 良好行为 |
| **暂予假释** | 1/6（半开监区） | 良好行为 |
| **外部劳动** | 1/6（半开监区） | 适格性、纪律 |
| **减刑** | 3个劳动日 = 1日刑期 | 劳动或学习 |
| **大赦** | 总统法令 | 按年度法令 |

### 15.2 抵扣与减刑

- **抵扣**（《刑法》第42条）：预审羁押和强制住院的时间从最终刑期中扣除
- **因劳动减刑**（《监狱执行法》126条）：3个劳动日 = 1日刑期
- **因学习减刑**（《监狱执行法》126条第1款I项）：12小时学习 = 1日刑期
- **因阅读减刑**（CNJ第44/2013号建议）：1本书/30天 = 4日刑期（每年上限12天）
