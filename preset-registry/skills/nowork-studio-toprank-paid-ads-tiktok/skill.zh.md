# TikTok 广告规划

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。此插件未声明第一方 NotFair TikTok MCP 变更操作接口；只能依据经过验证的来源材料进行规划和审核。

## 让最初几秒可测试

在撰写创意内容之前，先明确转化事件、衡量负责人、目标页面和已获批准的优惠方案。围绕鲜明的首秒钩子、产品演示或证明、原生格式制作方向、CTA，以及适合各版位安全裁切的构图来构建创意概念。核实创作者权利、音乐许可、用户证言，以及价格/效果声明；将证明情况未知的内容标记为 `needs_substantiation`。

采用一小组真正不同的钩子或形式。每个方案都应包括受众假设、创意变量、主要指标、护栏指标、预期曝光量、审核日期，以及会导致该创意方案被淘汰的结果。若没有指定的下游衡量指标，不要将观看量或 CTR 视为转化成果。

## 移交给操作人员

向人工操作人员提供准确的投放简报：目标、以账户币种计价的预算、定向逻辑、排除项、需要在当前平台 UI 中验证的事件/像素要求、所需创意文件和状态。如果没有当前已验证的来源，不要虚构 TikTok 设置、资格要求、最低预算或发布确认。
