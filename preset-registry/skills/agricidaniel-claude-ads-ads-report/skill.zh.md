# 渲染付费媒体报告

1. 仅接受经过验证且带版本的报告包，绝不接受零散的工作代理文本。
2. 确认运行完整性、证据覆盖范围、隐私级别、品牌选项、目标受众和输出格式。
3. 使用相同的规范数据和确定性模板渲染所有格式。
4. 保留调查结果、置信度、证据引用、矛盾之处、缺失的输入、行动项、负责人和衡量周期。
5. 先执行结构检查，再对 HTML 和 PDF 执行视觉与布局检查。
6. 以原子方式写入运行目录，并更新其清单。

不得包含凭据、客户名单、私有路径、原始研究资料、内部代理记录或宣传文案，除非操作人员已明确启用品牌内容。绝不能在执行摘要中隐瞒运行结果不完整或证据不足的状态。
