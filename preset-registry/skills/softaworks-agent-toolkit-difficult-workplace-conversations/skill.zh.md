# 困难对话技能

一个结构化框架，用于应对职场中具有挑战性的对话，包括冲突、绩效问题、敏感反馈以及情绪激烈的讨论。

## 何时使用本技能

- 为与同事进行一场具有挑战性的对话做准备
- 处理团队成员的绩效问题
- 向同级或上级传达难以开口的反馈
- 化解团队成员之间的冲突
- 讨论敏感话题（薪酬、晋升、解雇）
- 应对情绪化或防御性的反应
- 在困难讨论之后进行跟进

## 核心框架：准备—传达—跟进

困难对话的成败取决于三个阶段：

### 阶段 1：准备（之前）

**目的：** 为一场富有成效的对话做好铺垫

1. **厘清问题**
   - 具体发生了什么？（仅限可观察到的事实）
   - 造成了什么影响？（对你、团队、工作）
   - 你希望有什么改变？

2. **审视自己的情绪**
   - 我现在的感受是什么？为什么？
   - 我是否足够冷静，可以进行这场对话？
   - 这场对话中什么可能会触发我的情绪？

3. **考虑对方的视角**
   - 对方可能如何看待这个情况？
   - 对方可能面临哪些约束或压力？
   - 对方在乎什么，是我可以认可的？

4. **明确你的目标**
   - 我想要什么样的结果？
   - 可接受的最低结果是什么？
   - 我愿意在哪些方面做出妥协？

### 阶段 2：传达（期间）

**目的：** 有效地进行这场对话

1. **以中立的方式开场**
   - 从事实出发，而非评判
   - 表达想要理解的意图，而非指责
   - 营造心理安全感

2. **表达你的视角**
   - 描述行为，而非品性
   - 关注影响，而非动机
   - 使用“我”开头的表述，而不是“你总是……”

3. **积极倾听**
   - 提出澄清性问题
   - 认可对方的观点
   - 寻找共同的利益点

4. **寻求解决方案**
   - 提出具体的行动
   - 就后续步骤达成一致
   - 设定检查跟进的时间表

### 阶段 3：跟进（之后）

**目的：** 确保问题得到持久解决

1. **记录达成的共识**
   - 达成了哪些共识？
   - 谁在什么时间之前做什么？
   - 如何衡量成效？

2. **检查进展**
   - 按承诺进行跟进
   - 认可对方的改进
   - 及时处理仍存在的问题

3. **维护关系**
   - 将问题与人区分开
   - 随着时间推移重建信任
   - 留意故态复萌

## 关键原则

### 将影响与动机区分开

**发生了什么：** 可观察到的行为
**我的感受：** 你的情绪反应
**我的臆测：** 对方的动机（往往是错的）

让对话聚焦于行为和影响，而非臆测的动机。

### SBI 模型

**情境：** 这件事是在何时何地发生的？
**行为：** 对方具体做了什么/说了什么？
**影响：** 对你、团队或工作造成了什么影响？

### 管理情绪

| 如果你有这种感受 | 在行动之前 |
| ----------- | ------------- |
| 愤怒 | 等待 24 小时，可以写下来但不要发送 |
| 受伤 | 先找中立的一方谈一谈 |
| 焦虑 | 提前演练这场对话 |
| 防御 | 找出自己应承担的部分 |

### 何时升级处理

在以下情况下应升级处理：

- 安全面临风险
- 涉及法律问题
- 多次对话均未奏效
- 权力关系阻碍问题解决
- 你需要留存书面记录

## 对话类型

### 绩效反馈

- 以具体事例开场
- 与期望/标准建立关联
- 聚焦于未来的改进
- 提供支持和资源

### 冲突调解

- 先分别听取双方的陈述
- 识别背后的深层利益
- 寻找双赢的解决方案
- 记录达成的共识

### 敏感话题

- 选择私密、中立的场合
- 留出消化处理的时间
- 直接但富有同理心
- 尊重保密原则

### 接受反馈

- 感谢对方给出反馈
- 提出澄清性问题
- 不要立刻辩解
- 回应之前先反思

## 示例场景

### 场景 1：处理错过截止日期的问题

```markdown
**Issue:** Team member missed 3 deadlines in past month
**Impact:** Project delayed, others blocked
**Goal:** Understand root cause, agree on prevention plan

**Opening:** "I wanted to check in about the recent deliverables. I've noticed
the last three have come in past deadline, and I'd like to understand what's
happening and how we can address it together."
```

### 场景 2：同级冲突

```markdown
**Issue:** Colleague publicly criticized your work in meeting
**Impact:** Embarrassed, trust damaged
**Goal:** Address behavior, rebuild working relationship

**Opening:** "I'd like to talk about what happened in yesterday's standup.
When you said my code 'missed obvious issues,' I felt called out in front
of the team. I'd like to understand your concerns and find a better way
to handle code quality feedback."
```

### 场景 3：向经理申请加薪

```markdown
**Issue:** Feel underpaid relative to market/contribution
**Impact:** Demotivation, considering leaving
**Goal:** Discuss compensation, get timeline or adjustment

**Opening:** "I'd like to discuss my compensation. I've been here two years,
taken on the payments project leadership, and want to make sure my salary
reflects my contributions and the current market."
```

## 需要避免的反模式

### 在准备阶段

- **逐字编写台词**——那样会显得机械生硬；要准备主题要点，而非逐字稿
- **罗列“罪证”**——这不是一场审判；要寻求理解，而不是争个输赢
- **拖延太久**——问题会越积越多；应及时处理

### 在传达阶段

- **以“你总是……”开头**——会立刻触发对方的防御心理
- **把重点埋在后面**——要直奔主题；不要过度软化措辞
- **提出诱导性问题**——“难道你不觉得……”并不算提问

### 在跟进阶段

- **忘记跟进**——没有后续跟进，一切都不会改变
- **耿耿于怀**——问题解决了，就意味着关系可以照常继续
- **过度记录**——并非所有事情都需要留下书面记录

## 成功指标

一场成功的困难对话：

- 双方都感到被倾听
- 就具体行动达成一致
- 关系得到维护或改善
- 问题不再复发（或已有明确的升级处理路径）
- 事后任何一方都不会感到措手不及
