---
name: handoff
description: Write or update a handoff document so the next agent with fresh context can continue this work.
---
编写或更新一份交接文档，以便下一个带着全新上下文的智能体能够继续这项工作。

步骤：
1. 检查项目中是否已存在 HANDOFF.md
2. 如果存在，先阅读它以了解之前的上下文，然后再进行更新
3. 创建或更新该文档，包含以下内容：
   - **目标**：我们想要完成的事情
   - **当前进度**：到目前为止已完成的工作
   - **有效的做法**：取得成功的方法
   - **无效的做法**：失败的方法（避免重复尝试）
   - **后续步骤**：用于继续推进的明确行动项

将其保存为项目根目录下的 HANDOFF.md，并告知用户该文件路径，以便他们仅凭这个路径就能开启一段全新的对话。
