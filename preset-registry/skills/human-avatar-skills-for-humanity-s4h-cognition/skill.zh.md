# 认知

运用认知科学来理解并改善思维本身的运作方式——注意力、心智模型、元认知和认知负荷。诊断所需的认知工作类型，并将其路由到正确的工具。

## 哪个工具适用

| 你需要…… | 工具 |
|---|---|
| 了解是什么在占用或消耗注意力，以及如何保护注意力 | cognition-attention |
| 揭示并审查驱动感知和决策的心智模型 | cognition-mental-models |
| 运用对思考本身的思考来监控理解程度并校准信心 | cognition-metacognition |
| 管理工作记忆的限制——分块、外部化、降低复杂度 | cognition-cognitive-load |

## 路由决策

**框架检查：** 路由前确认具体的认知情境。用一句话说明你识别出的内容——所涉及的思考者或系统、认知挑战，以及用户希望改进或理解什么——然后使用 `AskUserQuestion`：
- **问题：**“我的理解是：[用一句话概述具体的认知挑战，以及你希望理解或改变的内容]。对吗？”
- **标题：**“框架”
- **选项：**
  - **是——继续**——框架正确
  - **调整**——有一个要素不准确；用户会先予以纠正，然后你再继续
  - **重新界定**——实际情境与你的理解不同；继续前纳入用户的纠正

- **“我无法集中注意力” / “注意力总是被拉走” / “如何保护我的深度工作时间”** → cognition-attention（梳理注意力经济，识别威胁和防御措施）
- **“我总是以同一种方式看待这件事” / “我看待这件事的方式中包含哪些假设” / “我正在使用什么心智模型”** → cognition-mental-models（揭示驱动感知的隐性表征）
- **“我不知道自己不知道什么” / “我应该有多大把握” / “我真的理解了吗”** → cognition-metacognition（运用对思考本身的思考来校准和监控）
- **“需要同时记住的东西太多了” / “复杂性让我不堪重负” / “如何简化这件事”** → cognition-cognitive-load（应用斯威勒的认知负荷理论来管理工作记忆限制）
- **不明确** → cognition-metacognition；大多数认知困难都可追溯到不知道自己理解什么、又不理解什么

## 确认方向

诊断出适用的工具后，使用 `AskUserQuestion` 工具确认方向。动态构造问题，将你的诊断包含在内：

- **问题：**“我的判断是：**[诊断出的工具]**——[用一句话说明它为何适用]。你希望如何继续？”
- **标题：**“方向”
- **选项：**
  - **是，运行该工具**——立即使用已提供的上下文执行诊断出的技能
  - **显示所有选项**——列出此类别中的每项技能，并为每项提供一句话说明
  - **快速版本**——如果此情境存在更轻量的替代方案，则运行该方案
  - **重新诊断**——重新审视情境描述，得出不同的判断

根据他们的选择继续。

## 注意力

*描绘个人或情境中的注意力经济——什么会吸引注意力、什么会消耗注意力，以及如何保护注意力。*

注意力是有限且具有方向性的。占据注意力的事物并非随机出现，而是遵循可预测的规律：显著性、新颖性、情绪强度和个人相关性都会争夺这种支撑其他一切认知活动的资源。此技能描绘特定个人或情境中完整的注意力图景：哪些事物正在主动争夺注意力、存在哪些合理需求、哪些噪声可以消除，以及哪些结构性条件会保护或破坏持续注意力。输出结果是一份按优先级排序的认知带宽防御计划。

**输出：** 注意力威胁图、当前的消耗来源、结构性保护措施，以及用于重新夺回专注力的优先事项列表。

## 心智模型

*揭示并审查驱动感知与决策的内部表征。*

每一种感知和每一个决策都要经过心智模型——即对世界某一部分如何运作的简化内部表征。危险在于，模型会变得难以察觉：它们在我们毫无意识的情况下，塑造我们会注意到什么、如何解读证据，以及能够设想哪些选项。此技能以 Philip Johnson-Laird 的模型理论为基础，将隐性的内容显性化。它识别情境中正在起作用的模型，检验其准确性和完整性，并揭示那些在未被察觉的情况下影响判断的缺口与扭曲。

**输出：** 已识别的活跃模型、准确性审查（每个模型正确和错误之处）、缺口与盲点，以及建议的模型更新或替代方案。

## 元认知

*将对思维的思考作为一种实用工具——监控理解程度、校准信心，并知道自己不知道什么。*

元认知——理解并调节自身的认知过程——是杠杆效应最高的认知技能，因为它统领着其他所有认知技能。John Flavell 在 20 世纪 70 年代将其发展为一门正式学科，它涵盖：知道自己知道什么和不知道什么（元认知知识）、监控自己是否真正理解某件事（元认知监控），以及在尚未理解时调整方法（元认知控制）。此技能将这三个维度应用于思维质量至关重要的具体情境。

**输出：** 知识、监控和控制各维度的元认知状态——包括具体缺口、过度自信警报和建议的调整措施。

## 认知负荷

*管理工作记忆的限制——通过组块化、外部卸载和减少不必要的复杂性，为重要事务释放认知容量。*

George Miller 于 1956 年证实，工作记忆大约能容纳七个项目（上下浮动两个）。John Sweller 的认知负荷理论对此作了进一步细化：并非所有负荷都是相同的。内在负荷是材料本身固有的；外在负荷源于糟糕的设计；相关负荷用于构建图式。目标是最大限度地减少外在负荷，通过组块化管理内在负荷，并运用外部卸载策略，使有效工作记忆超越其生物学限制。

**输出：** 认知负荷类型细分（内在负荷 / 外在负荷 / 相关负荷）、分块建议、认知卸载策略，以及适用情况下重新设计的信息结构。
