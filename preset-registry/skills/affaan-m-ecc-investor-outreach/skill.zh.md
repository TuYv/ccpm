# 投资人联络

撰写简短、个性化且便于采取行动的投资人沟通内容。

## 何时启用

- 给投资人撰写陌生开发邮件
- 起草熟人引荐请求
- 在会议后或未收到回复时发送跟进消息
- 在流程推进期间撰写投资人更新
- 根据基金投资理念或合伙人匹配度定制联络内容

## 核心规则

1. 对每一条主动发出的消息进行个性化处理。
2. 让请求尽可能易于回应。
3. 用事实证明，而不是用形容词修饰。
4. 保持简洁。
5. 绝不发送可以套用于任何投资人的通用文案。

## 陌生开发邮件结构

1. 主题行：简短且具体
2. 开场：为什么特别联系这位投资人
3. 推介：公司做什么、为什么是现在、哪些证明最重要
4. 请求：一个具体的下一步行动
5. 落款：姓名、职务，以及必要时附上一项可信度背书

## 个性化信息来源

引用以下一项或多项：
- 相关的被投公司
- 公开的投资理念、演讲、帖子或文章
- 共同联系人
- 与投资人关注方向明确匹配的市场或产品

如果缺少此类背景信息，请向用户询问，或说明该草稿是一个等待个性化处理的模板。

## 跟进节奏

默认：
- 第 0 天：首次主动联络
- 第 4-5 天：简短跟进，并提供一个新的数据点
- 第 10-12 天：最后一次跟进，并明确结束本轮沟通

此后不要继续催促，除非用户希望采用更长的联络序列。

## 熟人引荐请求

尽量方便引荐人：
- 说明为什么这次引荐是合适的
- 附上可直接转发的简介
- 将可转发简介控制在 100 字以内

## 会后更新

包括：
- 讨论过的具体事项
- 承诺提供的答案或最新进展
- 如有，提供一个新的证明点
- 下一步行动

## 质量检查

交付前确认：
- 消息已个性化
- 请求明确
- 没有空话或乞求式措辞
- 证明点具体
- 字数保持精简
