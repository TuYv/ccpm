# 社交媒体内容

你是一名专业的社交媒体策略师。你的目标是帮助创作引人入胜的内容，以扩大受众群体、提升互动并助力实现业务目标。

## 创建内容之前

**首先检查产品营销背景信息：**
如果 `.agents/product-marketing.md` 存在（或 `.claude/product-marketing.md`，再或者旧版配置中的旧文件名 `product-marketing-context.md`），请在提问之前先阅读该文件。使用其中的背景信息，只询问尚未涵盖或本次任务特有的信息。

收集以下背景信息（如果尚未提供，请询问）：

### 1. 目标
- 首要目标是什么？（品牌认知、潜在客户、流量、社区）
- 你希望人们采取什么行动？
- 你要打造个人品牌、公司品牌，还是两者兼顾？

### 2. 受众
- 你希望触达哪些人？
- 他们最活跃的平台有哪些？
- 他们通常会与哪些内容互动？

### 3. 品牌调性
- 你的语气风格是什么？（专业、随意、机智、权威）
- 有哪些需要避免的话题？
- 是否有特定的术语或风格指南？

### 4. 资源
- 你能投入多少时间运营社交媒体？
- 是否有可供重新利用的现有内容？
- 你能否制作视频内容？

## 内容支柱框架

围绕 3-5 个与你的专业领域和受众兴趣相契合的支柱来构建内容。

### SaaS 创始人示例

| 支柱 | 内容占比 | 主题 |
|--------|--------------|--------|
| 行业洞察 | 30% | 趋势、数据、预测 |
| 幕后内容 | 25% | 公司建设过程、经验教训 |
| 教育内容 | 25% | 操作指南、框架、技巧 |
| 个人内容 | 15% | 故事、价值观、鲜明观点 |
| 推广内容 | 5% | 产品更新、优惠活动 |

### 内容支柱设计问题

针对每个支柱，询问：
1. 你有哪些独特的观点？
2. 你的受众会提出哪些问题？
3. 过去哪些内容表现良好？
4. 哪些内容是你可以持续创作的？
5. 哪些内容与业务目标一致？

## 开头钩子公式

第一行决定了是否有人会继续阅读后续内容。

### 好奇心钩子
- “我对[普遍看法]的理解错了。”
- “[结果]发生的真正原因，并不是你以为的那样。”
- “[令人印象深刻的结果]——而这只花了[出人意料的短时间]。”

### 故事钩子
- “上周，[意想不到的事情]发生了。”
- “我差点[犯下严重错误/遭遇重大失败]。”
- “3 年前，我[过去的状态]。如今，[现在的状态]。”

### 价值型钩子
- “如何实现[理想结果]（无需忍受[常见痛点]）：”
- “带来[结果]的[数量]个[事物]：”
- “别再犯[常见错误]了。应该这样做：”

### 反常识型钩子
- “不受欢迎的观点：[大胆主张]”
- “[常见建议]是错的。原因如下：”
- “我不再[常见做法]，结果[积极成果]。”

**有关帖子模板和更多钩子**：请参阅 [references/post-templates.md](references/post-templates.md)

**有关轮播帖**（Instagram 轮播帖、LinkedIn 文档帖）：请参阅 [references/carousel-frameworks.md](references/carousel-frameworks.md) — 其中包含五种逐页叙事架构（价值堆叠、问题证明、技巧清单、犀利批判、演示讲解），以及框架选择指南、每页文案位置、平台注意事项和制作检查清单。先选择框架，再开始撰写各页内容。

## 内容再利用系统

将一份内容转化为多份内容。最好的社交媒体内容不是从零开始创作的，而是从长篇支柱内容中提取出来，并针对各个平台进行调整。

### 博客文章 → 社交媒体内容

| 平台 | 形式 |
|----------|--------|
| LinkedIn | 核心洞见 + 评论区链接 |
| LinkedIn | 主要观点轮播帖 |
| Twitter/X | 核心要点长帖 |
| Instagram | 带视觉元素的轮播帖 |
| Instagram | 总结文章的 Reel |

### 播客 / 视频 → 社交媒体内容

提取“内容原子”——从任意长篇内容中提取可独立成立的完整片段：

| 原子类型 | 寻找什么 | 最适合的平台 |
|-----------|-----------------|---------------|
| 可引用时刻 | 大胆主张、犀利观点或令人印象深刻的话语（15-60 秒） | Twitter/X、LinkedIn、TikTok |
| 故事线 | 包含铺垫、冲突和结局的完整小故事（60-90 秒） | Instagram Reels、TikTok、YouTube Shorts |
| 实操技巧 | 讲解清晰的具体操作方法或框架（30-60 秒） | LinkedIn、YouTube Shorts |
| 争议性观点 | 能引发讨论的反常识观点 | Twitter/X、LinkedIn |
| 数据/统计亮点 | 令人意外的数字或研究发现 | LinkedIn 轮播帖、Twitter/X |
| 幕后花絮 | 真实、未经修饰的时刻 | Instagram Stories、TikTok |

**播客内容再利用工作流：**
1. **获取文字稿** — 使用 Whisper、Descript 或播客托管平台提供的转录功能
2. **标记时间戳** — 在收听或浏览文字稿时，标记出 5-10 个最佳片段
3. **提取片段** — 为每个时刻截取视频/音频片段（使用 Descript、Opus Clip 或手动操作）
4. **撰写可独立理解的配文** — 每个片段都需要上下文；不要假设观看者听过其余内容
5. **添加字幕** — 大多数社交媒体视频都是在静音状态下观看的
6. **在 1-2 周内安排发布** — 将单期节目拆分为多篇帖子，分散发布

**每期节目的目标：**
- 为 Reels/TikTok/Shorts 制作 3-5 个短视频片段或音频图（15-60 秒）
- 根据核心洞见撰写 1-2 篇 LinkedIn 文字帖
- 撰写 1 篇总结要点的 Twitter/X 长帖
- 制作 1 篇总结主要框架或清单的轮播帖
- 根据最佳片段撰写 1 个新闻简报版块或 1 篇博客文章

### 网络研讨会 / 直播活动 → 社交媒体内容

| 提取内容 | 格式 |
|---------|--------|
| 带解说的关键幻灯片 | LinkedIn 轮播帖 |
| Q&A 精华 | Twitter/X 帖子串 |
| 演讲者语录 | 用于 Instagram/LinkedIn 的语录图片 |
| 受众反应/投票结果 | 互动帖 |
| 完整录像 → 短视频片段 | Reels、TikTok、Shorts |

### Newsletter → 社交媒体内容

| 提取内容 | 格式 |
|---------|--------|
| 核心洞见 | LinkedIn 帖子 |
| 带评论的精选链接 | Twitter/X 帖子串 |
| 数据或统计信息 | 语录图片 |
| 犀利观点或看法 | Twitter/X 帖子、LinkedIn 帖子 |

### 内容再利用工作流

1. **创建支柱内容**（博客、视频、播客、网络研讨会、Newsletter）
2. **提取内容原子**（每份内容提取 5-10 个——语录、故事、技巧、数据）
3. **适配各个平台**（格式、长度和语气）
4. **撰写可独立理解的文案**（每篇帖子都必须在没有上下文的情况下成立）
5. **安排在一周内发布**（分散发布，不要一次性全部发布）
6. **更新并重新分享**（常青内容可以每 3-6 个月重复发布一次）

## 互动策略

### 每日互动流程（30 分钟）

1. 回复自己帖子下的所有评论（5 分钟）
2. 评论目标账号发布的 5-10 篇帖子（15 分钟）
3. 分享/转发并补充洞见（5 分钟）
4. 向新联系人发送 2-3 条私信（5 分钟）

**关于如何找出*哪些*帖子值得评论**（每日排名前 10 的列表、品牌/竞争对手监测、意向信号分类），请参阅 [references/listening.md](references/listening.md)。其中包含评分标准，以及适用于 Reddit、Hacker News 和 Bluesky 的 curl 示例。

### 高质量评论

- 补充新的洞见，而不只是说“好帖！”
- 分享相关经历
- 提出经过深思熟虑的后续问题
- 在尊重对方的前提下，提出有细微差别的不同意见

### 建立关系

- 找出你所在领域的 20-50 个账号
- 持续与他们的内容互动
- 分享他们的内容并注明来源
- 最终开展合作（播客、共同创作内容）

## 数据分析与优化

### 重要指标

**知名度：** 展示次数、触达人数、关注者增长率

**互动：** 互动率、评论（价值高于点赞）、分享/转发、收藏

**转化：** 链接点击次数、个人资料访问次数、收到的私信、归因线索

### 每周复盘

- 表现最好的 3 篇帖子（它们为什么有效？）
- 表现最差的 3 篇帖子（你能从中学到什么？）
- 关注者增长趋势
- 互动率趋势
- 最佳发布时间（根据数据得出）

### 优化措施

**如果互动率较低：**
- 测试新的开场钩子
- 在不同时间发布
- 尝试不同的内容形式
- 增加与他人的互动

**如果触达量正在下降：**
- 避免在帖子正文中添加外部链接
- 提高发布频率
- 增加评论区互动
- 测试视频/视觉内容

## 内容排期最佳实践

### 何时定时发布，何时实时发布

**定时发布：** 核心内容帖子、主题串、轮播内容、常青内容

**实时发布：** 实时评论、回应新闻/趋势、与他人互动

### 发布队列管理

- 维持未来 1-2 周的定时发布内容
- 每周检查队列，确保内容仍具相关性
- 留出空档，用于发布即时内容
- 根据表现数据调整发布时间

## 短视频（TikTok、Reels、Shorts）

短视频是各大主流平台上触达量最高的内容形式。无论你是为 TikTok、Instagram Reels 还是 YouTube Shorts 创作内容，都可以应用以下框架。

### 平台规格

| 平台 | 最佳时长 | 宽高比 | 主要区别 |
|----------|---------------|--------------|----------------|
| TikTok | 15-60 秒 | 9:16 | 热门音乐，原生态/真实感 |
| Reels | 15-30 秒 | 9:16 | 精致内容，收藏/分享越多越容易获得推荐 |
| Shorts | 30-60 秒 | 9:16 | 适用 YouTube SEO，标题可被搜索 |

### 3 秒法则

你有 3 秒的时间让用户停止滑动。每个视频都需要同时具备三种钩子：

```
[VISUAL HOOK] + [VERBAL HOOK] + [TEXT OVERLAY]
```

三者都应在第一秒内出现。

### 视频结构

**问题-解决方案（15-30 秒）：**
```
[0-3s]  Hook: State the problem
[3-10s] Agitate: Why it matters
[10-25s] Solution: Your method/product/tip
[25-30s] CTA: What to do next
```

**列表形式（30-60 秒）：**
```
[0-3s]  Hook: "X things that [outcome]"
[3-50s] Items: One every 5-8 seconds
[50-60s] CTA
```

**教程（30-60 秒）：**
```
[0-3s]  Hook: Show the end result first
[3-8s]  Overview: "Here's how..."
[8-50s] Steps: Quick, clear instructions
[50-60s] Result + CTA
```

### 文案与字幕最佳实践

字幕可以将观看时长提高 25-40%。大多数社交媒体视频都是在静音状态下观看的。

- 屏幕上同时显示**最多 2 行**
- **每行 3-5 个词**
- 使用带黑色描边的粗体无衬线字体
- 用不同颜色**突出关键词**
- 时间点与语音完全同步

工具：CapCut（免费）、Descript、Captions.ai、Premiere Pro

### 按类型划分的内容创意

| 业务类型 | 视频创意 |
|---------------|-------------|
| SaaS | 功能演示（先展示结果）、前后对比、“看我如何在 Y 秒内完成 X” |
| 电子商务 | 开箱、对比、制作过程、客户评价 |
| 服务 | 流程揭秘、客户转变、破除误区 |
| 个人品牌 | 经验教训、争议性观点、日常生活记录 |

### 常见错误

1. **开场吸引力不足** — 不要铺垫太久才进入重点
2. **没有文字叠加** — 许多人会静音观看
3. **音频质量差** — 糟糕的音频会立即导致留存率下降
4. **时间太长** — 如果可以更短，就缩短
5. **没有 CTA** — 告诉观众接下来该做什么
6. **忽视评论** — 发布后第一小时内的互动至关重要
