# 付费广告创意

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。根据实际情况，将平台执行工作分派至 `/notfair:google-ads-copy`、`/notfair:google-ads-assets`、`/notfair:meta-ads-creative`、`/notfair:paid-ads-x` 或 `/notfair:paid-ads-linkedin`。

## 基于明确的证据开展工作

从经过验证的来源入手：表现优异的广告、搜索词、客户研究、已获批准的落地页声明、销售通话、经授权使用的评论，或有文档记录的优惠方案。确保每项承诺与其目标落地页一致。不得捏造客户证言、评分、价格、结果、供应情况、所有权或产品证明。

## 制作创意方案集

交付三个彼此不同的 `ready_for_review` 概念卡片。每张卡片包含：

- 概念 ID 和假设：受众 × 动机 × 角度 × 形式 × 一个变量；
- 证据来源和声明台账，将缺乏支持的声明标记为 `needs_substantiation`；
- 钩子、核心信息、CTA、目标页面和版位适配；
- 视觉/制作简报，包括所需权利或缺失的素材；
- 成功指标、护栏指标、归因窗口、观察窗口和失败条件。

不要制作仅在表面上有所不同的同一创意变体。每次只测试一个策略变量：钩子、证据、形式、角度、受众或目标页面。在建议更新创意之前，应结合完整窗口内的频次、链接 CTR、CPM 和投放环境来诊断素材疲劳。

## 发布边界

发布前，应通过经过验证的来源核实当前平台的规格和政策。简报或生成的图像不能证明某项声明已获许可，也不能证明平台已接受该素材。对于没有经过验证的 NotFair 变更操作接口的平台，应输出可供操作人员直接执行的简报和清晰的交接说明，而不是承诺上传。
