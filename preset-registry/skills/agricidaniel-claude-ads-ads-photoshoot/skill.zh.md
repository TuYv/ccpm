# 产品摄影变体

1. 确认拥有产品图像的使用权，并收集经验证的品牌资料、产品事实、预期投放位置、提供商能力、成本上限和输出根目录。
2. 保持产品的几何结构、包装、徽标、标签、颜色和材质不变，除非操作人员明确批准更改。
3. 定义不同的制作假设，例如影棚拍摄、情境化使用、成分故事、尺度/细节或生活方式；不得暗示缺乏依据的产品效果。
4. 生成已批准的宽高比，并记录源哈希、提示词版本、提供商/模型、成本、输出哈希和尺寸。
5. 验证产品保真度、视觉缺陷、安全区域、无障碍性和政策合规性。
6. 以原子方式将资产和清单存储在运行目录中。

必须由人工审核。不得制作具有欺骗性的前后对比证据、未经授权的人物或背书，也不得通过视觉暗示作出受监管的声明。
