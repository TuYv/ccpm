### 1.1 离婚

#### 非司法协议离婚（Lei 11.441/2007）

| 要件 | 说明 |
|-----------|---------|
| **达成共识** | 双方同意离婚及相关条款 |
| **无未成年人/丧失民事能力子女** | 如有此类子女，必须走司法途径 |
| **公证书** | 在公证处起草 |
| **律师** | 为必需（可由双方共同聘请同一律师） |
| **时限** | 即时（自EC 66/2010后不再要求分居期限） |
| **平均费用** | R$ 1.500 至 R$ 4.000（公证费 + 律师费） |
| **财产分割** | 可包含在同一份公证书中 |

#### 司法离婚（Art. 731-734 CPC）

| 类型 | 说明 |
|------------|-----------|
| **协商离婚** | 双方达成一致——由法官予以确认（Art. 731 CPC） |
| **争议离婚** | 无协议——由法官裁定（Art. 693 CPC） |
| **管辖** | 子女监护权住所地或夫妻最后共同住所以及居住地（Art. 53, I CPC） |

#### 财产制度（Art. 1.639-1.688 CC）

| 制度 | 特征 | 分割比例 |
|--------|---------------|--------|
| **部分共同财产制**（默认） | 婚姻存续期间取得的财产为共同财产 | 可分割财产的50% |
| **完全共同财产制** | 所有财产共同所有（Art. 1.668 所列例外除外） | 全部财产50% |
| **完全分离制** | 无任何财产共同所有 | 无分割份额 |
| **法定分离制** | 由法律规定（Art. 1.641 CC） | STF Súmula 377：增值财产可分割 |
| **终局分离财产制** | 婚姻中期间财产分别持有，解除时进行并入分配 | 取得增值部分的50% |

#### STF Súmula 377 — 法定分离制
在法定财产分离制下，婚姻存续期间取得的财产可进行共有。

**实践适用：** 70岁以上婚姻（Art. 1.641, II CC）——即使适用法定分离制，配偶对婚姻关系存续期间取得的财产仍有份额分割权。

### 1.2 抚养费

#### 法律依据
- **Art. 1.694-1.710 CC** — 亲属、配偶及同居伴侣之间的抚养费
- **Lei 5.478/1968** — 抚养费法（特别程序）
- **Art. 528-533 CPC** — 抚养费执行（拘禁、查封、工资扣划）

#### 抚养费类型

| 类型 | 说明 |
|------|-----------|
| **临时性** | 在抚养费诉讼中先行裁定（Art. 4 Lei 5.478） |
| **临时措施性** | 在紧急救济中裁定（Art. 300 CPC） |
| **最终性** | 在判决书中裁定 |
| **补偿性** | 为平衡财产失衡（STJ — REsp 1.954.279） |
| **孕期抚养** | 用于孕妇（Lei 11.804/2008） |
| **过渡性** | 为前配偶临时提供重返社会生计保障 |

#### 抚养费执行（Art. 528-533 CPC）

| 路径 | 程序 | 时效 |
|-----|-------------|-------|
| **民事拘禁** | Art. 528, par. 3 — 拘禁期限1-3个月 | 3次给付期限（STJ Súmula 309） |
| **查封** | 按确定金额执行 | 每次给付权利每2年时效 |
| **工资扣减** | Art. 529 CPC — 向雇主下达扣款令 | 扣除净收入的最高50% |
| **SISBAJUD** | 查封账户 | 立即执行 |
| **抗议信控** | Art. 528, par. 1 — 对票据进行抗议信控 | 无上限 |

#### 需要与可能性二元判断（Art. 1.694, par. 1 CC）
- **受抚养人需求：** 生活费、医疗、教育、住房成本
- **供养人能力：** 收入、财产、生活水平
- **比例原则：** 法院在二者之间取得平衡

#### 裁量参数（判例法）

| 情况 | 常用参数 |
|----------|----------------|
| 1名子女（CLT） | 净收入30% |
| 2名子女（CLT） | 33%-40% |
| 3名及以上子女（CLT） | 40%-50% |
| 个体工商户/非正式就业 | 最低工资比例（1-3个SM） |
| 前配偶抚养费 | 收入的20%-33%（临时） |

### 1.3 同性伴侣关系（事实婚姻）（Art. 1.723-1.727 Cc）

| 方面 | 说明 |
|---------|---------|
| **要件** | 公开、持续、长期共同生活，具有建立家庭的目的 |
| **财产制度** | 共同财产制（除非另有协议相反—Art. 1.725 CC） |
| **确认方式** | 可为司法确认、非司法确认（公证书）或死后确认 |
| **继承权** | 同居伴侣与子女和父母共同继承（Art. 1.790 CC — 已被STF在RE 878.694中宣告违宪） |
| **居住权** | 有（类比婚姻制度—STJ） |
| **解除关系** | 与离婚模式一致（Art. 7, par. 2 Lei 9.278/96） |

### 1.4 亲子关系确认调查

| 方面 | 说明 |
|---------|---------|
| **法律依据** | Lei 8.560/1992 + Art. 1.606-1.617 CC |
| **诉讼请求** | 亲子关系调查与抚养费并行 |
| **管辖** | 未成年人住所地（Art. 53, II CPC） |
| **DNA** | 首要鉴定证据，但拒绝会产生推定（Súmula 301 STJ） |
| **不受时效影响** | Art. 27 ECA — 该诉讼不受时效约束 |
| **否认诉讼** | Art. 1.601 CC — 丈夫可对父系血统提起否认 |
| **社会血缘** | STF Tema 622 — 社会血缘父系关系不排除生物学父系关系 |

### 4.1 离婚财产分割

#### 可共同分割财产 vs 不可共同分割财产（共同财产制）

| 共同分割（50%份额） | 不共同分割（个人财产） |
|------------------------|----------------------------------|
| 婚姻期间购买的不动产 | 婚前财产（Art. 1.659, I CC） |
| 婚姻关系存续期间购置的车辆 | 继承和受赠财产（Art. 1.659, I CC） |
| 以劳动收入形成的投资 | 个人财产的代位财产（Art. 1.659, II CC） |
| 共同账户余额 | 标记为不可共同分割的财产（Art. 1.659, III CC） |
| 婚姻期间累计的 FGTS（STJ） | 个人使用物、书籍、职业工具（Art. 1.659, V CC） |
| 私人养老金（STJ—有争议） | 个人劳动收益（Art. 1.659, VI CC）—有争议 |

#### 财产评估

| 方法 | 使用时机 |
|--------|-------------|
| 鉴定评估（Art. 464 CPC） | 不动产、企业、高价值财产 |
| 当事人协议 | 和解离婚——当事人自行确定价值 |
| 市场评估（经纪人/评估师） | 居住用不动产、车辆 |
| 资产负债表评估 | 社会股权、企业持股 |

### 4.2 死亡财产继承与分割

#### 非司法遗产清算（Art. 610, par. 1 CPC + Lei 11.441/2007）

| 要件 | 说明 |
|-----------|---------|
| 所有继承人均为成年人且有行为能力 | 必要 |
| 就财产分配达成共识 | 全体同意 |
| 无遗嘱 | 一般规则（例外：CNJ 35/2007号决议，Art. 12-A 允许已确认遗嘱） |
| 公证书 | 公证处——任何司法辖区 |
| 律师 | 必要 |
| 时限 | 继承开场起 60 天（Art. 611 CPC）——逾期按 ITCMD 罚款 |

#### 司法遗产清算（Art. 610-673 CPC）

| 程序类型 | 适用情形 |
|------------|--------|
| **简易遗产清单**（Art. 659 CPC） | 继承人具备能力 + 达成协议 |
| **一般遗产清单**（Art. 664 CPC） | 财产不超过 1,000 个最低工资单位 |
| **传统遗产清算**（Art. 610 CPC） | 继承人有丧失能力、存在争议、遗嘱情况 |

#### 继承权顺序（Art. 1.829 CC）

| 顺序 | 继承人 | 备注 |
|-------|-----------|-----------|
| 第一顺位 | 子女 + 配偶 | 配偶与子女共同继承（Art. 1.832 CC） |
| 第二顺位 | 直系上辈 + 配偶 | 配偶与父母竞争时可得 1/3（Art. 1.837 CC） |
| 第三顺位 | 生存配偶（单独） | 继承全部 |
| 第四顺位 | 四级以内旁系亲属 | 兄弟、侄子侄女、叔叔阿姨、表亲 |

#### 生存配偶权利

| 财产制度 | 是否与子女共继 | 依据 |
|----------------|--------------------------|------|
| 共同财产制 | 是，在死者的个人财产中参与分配 | Art. 1.829, I CC |
| 共同所有制 | 否 | Art. 1.829, I CC |
| 法定分居财产制 | 否（有争议——STF Súmula 377） | Art. 1.829, I CC |
| 约定分居财产制 | 是，在全部财产中参与 | STJ — REsp 1.382.170 |

#### 同居伴侣（稳定伴侣关系）
- **STF RE 878.694（主题498）：** 判定同居伴侣在继承目的下与配偶等同
- Art. 1.790 CC 被宣告违宪——适用 Art. 1.829 CC

### 4.3 遗嘱

| 类型 | 法律依据 | 要求 |
|------|-----------|-----------|

| **密封遗嘱** | Art. 1.868 CC | 由遗嘱人书写，经过公证员认可 |

### 5.1 监护类型（Art. 1.583-1.590 CC + Lei 13.058/2014）

| 类型 | 说明 | 法律依据 |
|------|-----------|------|
| **共同监护** | 默认规则——双方均行使监护权，即使未达成一致 | Art. 1.584, par. 2 CC |
| **单方监护** | 一方父母行使监护权，另一方享有探视权 | Art. 1.583, par. 1 CC |
| **轮换监护** | 孩子定期在双方居住地交替居住 | 司法解释（法律未明文规定） |
| **“巢式监护”** | 孩子固定居住，由父母轮流照料 | 巴西极少见 |

### 5.2 共同监护（Lei 13.058/2014）

| 事项 | 说明 |
|---------|---------|
| **一般规则** | 即使无协议也仍为默认规则（Art. 1.584, par. 2 CC） |
| **例外情形** | 仅在一方父母表示不愿承担监护或无力承担时不适用 |
| **主要住所** | 孩子有主要居住地，但与双方共同生活 |
| **共同生活时间** | 均衡分配，不要求严格 50/50 |
| **重大决定** | 双方共同决定健康、教育、休闲 |
| **抚养费** | 共同监护不排除抚养费（STJ — REsp 1.629.994） |

### 5.3 探视安排（Art. 1.589 CC）

| 事项 | 说明 |
|---------|---------|
| **享有权利者** | 父母方与孩子本人（以未成年人利益为先） |
| **祖父母** | 享有探视权（Art. 1.589, par. unico CC — Lei 12.398/2011） |
| **确定方式** | 法院裁定或协议 |
| **违反义务** | 依法执行并追回未成年人（Art. 461 CPC）+ 罚款 |
| **监督探视** | 存在风险时应安排监护下的探视 |

### 5.4 父母绑架（也称亲子疏离行为）（Lei 12.318/2010）

#### 定义（Art. 2）
由一方父母（或祖父母/监护人）对孩子的心理形成施加干预，以损害其与另一方父母的关系。

#### 亲权异化形式（第2条，单一段落）

| # | 形式 |
|---|-------|
| I | 攻击并抹黑育有一方父母 |
| II | 困难化父母权的行使 |
| III | 困难化子女与一方父母的接触 |
| IV | 困难化行使共同生活/探视权 |
| V | 隐瞒相关个人信息（学校、健康） |
| VI | 对另一方父母提起虚假指控以阻碍共同生活 |
| VII | 搬迁住所以困难化共同生活 |

#### 制裁（第6条）

| 制裁 | 严重程度 |
|--------|-----------|
| 警告 | 轻度 |
| 扩大共同生活/探视制度 | 中度 |
| 罚款 | 中度 |
| 心理辅导 | 中度 |
| 更改监护安排 | 严重 |
| 暂停父母权 | 极其严重 |

## 案件完整法分析流程（12阶段）

对于任何复杂法律案件，请按以下12个阶段执行：

## 阶段 1 — 法律框架确定

- 法律领域（哪个模块？）
- 主要法律依据（哪部法律、条文、段落？）
- 主管权限（哪个法庭/庭次/法院？）

## 阶段 2 — 涉事当事人

- 当事人身份识别（原告/被告/第三人）
- 当事人关系（亲属关系、合同关系、非合同关系）
- 脆弱性（未成年人、老年人、消费者、经济弱势）

## 阶段 3 — 相关事实

- 事件时间线
- 已有/必要的文件
- 可用证人和证据

## 阶段 4 — 法律依据分析

- 适用的法条
- 相关判例（STJ、STF、各级上诉法院）
- 相关学说（在相关时）

## 阶段 5 — 实体法分析

- 客户权利是否有充分依据？
- 是否存在可行的法律抗辩？
- 现有证据力量如何？

## 阶段 6 — 诉讼风险

- 时效/除斥期间
- 诉讼资格与利益
- 领域/地域管辖
- 期间消灭（诉讼行为丧失）

## 阶段 7 — 结果预估

- 乐观情景
- 基准情景（最可能）
- 悲观情景

## 阶段 8 — 费用预估

- 司法费用
- 律师费（合同费与败诉后承担费）
- 鉴定费及附带成本
- 司法救助（若适用 — CPC第98条）

## 阶段 9 — 诉讼策略

- 非诉程序（调解、和解、仲裁）
- 司法程序（程序类型、诉讼请求、紧急救济）
- 可提起的上诉

## 阶段 10 — 关键期限

- 权利时效
- 诉讼程序期限
- 上诉期限
- 判决执行期限

## 阶段 11 — 紧急措施

- 先行紧急保护（CPC第300条）
- 证据性救济（CPC第311条）
- 保护令（若适用）
- 特定保全措施
