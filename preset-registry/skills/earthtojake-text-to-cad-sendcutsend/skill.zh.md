# SendCutSend

来源：维护于 [earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad)。
使用已安装的本地 skill 文件作为运行时事实来源；仓库链接仅用于来源追溯和发布审查。

使用此 skill 为 DXF 和 STEP/STP 文件生成保守且有证据支持的 SendCutSend 预检报告。

将 SendCutSend 的订购指南、目录 JSON 和规格 JSON 视为证据源，而不是稳定 API。字段名称、类型和覆盖范围可能有所不同。不要将缺失、无法解析、`N/A` 或相互冲突的源数据转化为通过或失败。直接从官方 URL 获取源文件，仅使用本地检查代码测量特定文件事实；根据明确的比较结果编写最终报告。

## 几何检查

使用当前项目的 Python 环境运行本地几何检查代码。如果 `$cad` skill 可用，优先使用它进行 STEP/STP/DXF 几何检查、测量和验证工作流，然后再补充仍然缺失的、SendCutSend 特有的定向测量。使用 `build123d.import_step` 检查 STEP/STP，并在需要几何事实时直接使用 `ezdxf` 包（`import ezdxf`；它会与 build123d 一起安装）检查 DXF。不存在 `build123d.ezdxf`。不要使用原始文本解析或其他几何后端获取几何事实。

## CAD 查看器交接

完成会创建或修改 `.dxf`、`.step` 或 `.stp` 上传候选文件的 SendCutSend 工作后，如果安装了 `$cad-viewer` skill，必须始终将明确的文件路径交给 `$cad-viewer`。如果 CAD Viewer 尚未运行，`$cad-viewer` 必须启动它，并返回相关已创建或已更新文件的链接；如果 `$cad-viewer` 不可用或启动失败，应报告该情况，而不是默默省略交接。

## 工作流

1. 收集订购意图。
   - 激光板材切割和二维板材轮廓优先使用 DXF。
   - CNC 铣削和三维模型上传工作流优先使用 STEP/STP。
   - 记录文件类型、预期工艺、材料/SKU、厚度、数量、服务、表面处理和硬件。
   - 如果订购上下文缺失或存在歧义，检查足够的源数据以提供具体选项，然后要求用户确认，再编写准备就绪结论。包括候选 SKU/材料/厚度/服务及相关源链接；如果规格 JSON 中提供了 `photo_url` 图片和 `learn_more_url` 链接，也一并包括。
2. 阅读 `references/official-sources.md`，直接获取官方源，然后检查返回的文档。以防御性方式规范化源事实：解析数字字符串、尺寸字符串、`N/A`、缺失字段、混合类型以及缺失的服务数组，并将它们明确记录为备注。
3. 使用 `$cad`（如果可用）检查确切的上传文件，并使用定向 Python/`build123d` 检查仍然缺失的事实。不要只检查源生成器、CAD 模型或生成器控制台摘要。
   - DXF：根据所选服务，测量单位、边界、图层、实体类型、开放/重复几何、不支持的注释、候选孔/圆、线条统计、折弯线候选项、折弯到切割边的距离、折弯相邻切割几何、局部法兰深度，以及退化的零面积轮廓等必要内容。
   - STEP/STP：根据所选服务，测量可解析性、单位提示、实体/曲面信号、包围盒、壳体/实体信号、有效性、可获取时的板材厚度、适用折弯时的圆柱形折弯面半径，以及相关限制。
   - 保持每个检查辅助工具仅输出事实。它可以报告测量结果、解析错误和限制，但不得输出通过/失败/准备就绪状态。
4. 根据证据质量选择源记录。
   - 仅使用完全匹配的 SKU 作为权威目录/规格连接键。
   - 如果只提供了材料和厚度，则仅在候选匹配唯一且足够精确时选择材料；否则列出带有源记录链接/图片的候选项，并要求用户选择。
   - 使用目录 JSON 确认可订购性：库存、切割工艺、可用服务、尺寸限制、硬件和表面处理。
   - 使用规格 JSON 获取工程值：公差、孔、连接桥、折弯、攻丝、沉头、硬件插入、表面处理和材料属性。
   - 使用订购指南了解通俗易懂的工作流和一般文件格式规则。

## 比较

仅比较可信的证据对。

- 确定某项检查是否适用。
- 引用源字段路径或指南章节。
- 引用测得的文件事实。
- 仅当源要求和测得的文件事实均可用且可信时才进行比较。
- 如果缺少所需测量结果或测量存在风险，请针对该特定几何事实编写一个小型、定向的 `build123d`/`ezdxf` 检查器。
- 暂时将每项已测得的上传风险、可制造性问题或引用的要求违反视为错误。不要推断任何其他 SendCutSend UI 分类。
- 对于 DXF 单位，应结合检查 `$INSUNITS`、头部范围、测得的边界以及上下文顺序。如果 `$INSUNITS` 缺失、不受支持，或不是 SendCutSend 指南所期望的 DXF 单位代码（`1` 英寸或 `4` 毫米）之一，请报告单位/缩放错误，并建议在进行尺寸、法兰或材料特定的比较之前重新导出或确认单位。不要静默地重新缩放几何体，也不要使用不确定的缩放比例来发出材料特定的通过/失败检查。
- 对于带有折弯线的 2D 文件，沿每条折弯线局部检查法兰长度。在每个跨度或采样点处，测量折弯两侧最近的切割边缘/自由边缘，包括会中断折弯跨度或形成局部自由边缘的缺口、槽、间隙、分割凸耳和切口。将最小局部法兰深度与所选 SKU 的 `bending_specs.min_flange_length_before_bend` 和 `bending_specs.min_flange_length_after_bend` 进行比较。除非引用的源为该服务提供了孔到折弯或特征到折弯的规则，否则不要将法兰长度限制应用于普通的封闭孔或内部切口；应根据引用规则的要求，分别报告这些部位的中心线到折弯线或边缘到折弯线的测量结果。除非剩余的局部法兰仍满足法兰长度最小值，否则不要将折弯附近的切割几何体仅视为角部避空。如果任何局部法兰深度低于 SKU 最小值，请报告 `❌ fail`。当导出的几何体存在局部切口、中断的折弯、分割的折弯段、避空、凸耳或不受支持的区域时，不要依赖源级别的汇总值。
- 按物理原因分别记录折弯问题。不要将折弯附近的几何体合并为笼统的法兰失败。对于最小法兰/接触长度错误、折弯线或模具区域几何体交叉、附近自由边缘或切口导致的折弯接触/支撑不足、未跨越折弯区域的折弯线、分割/共轴折弯段，以及接触或穿过折弯线的切割几何体，应分别报告独立的行。如果 SendCutSend 源未公开确切的模具区域/接触阈值，请将测得的文件事实引用为直接文件检查结果，并明确标记该比较受源信息限制。
- 对于 STEP/STP 折弯零件，如果模型包含钣金折弯几何体或预期服务包括折弯，请检查折弯半径。尽可能使用 `$cad`/`build123d`/OCP 提取圆柱面或环面折弯面及其半径，对重复的折弯半径进行分组，并将其与所选 SKU 的 `bending_specs.effective_bend_radius` 或 `bending_specs.bend_radius` 进行比较。如果所选材料/SKU 未知，请报告测得的折弯半径集合，并在给出就绪性结论之前询问材料/厚度。如果测得的半径与所选 SKU 的模具半径冲突，请报告折弯半径不匹配错误。

带有限状态标签的报告：

- `✅ pass`：测得的文件事实满足所引用的当前要求。
- `❌ fail`：测得的上传风险、可制造性问题，或直接测得的违反所引用当前要求的情况。
- `❓ need more info`：缺少上下文、缺少源文件证据、几何尺寸未测量、源文件之间存在冲突，或工具存在限制。

## 诊断图像

当通过视觉方式更容易理解问题时，如果具备图像生成或图像编辑能力，应主动生成简洁的诊断图。使用生成或编辑的图像来添加标注、图例以及修改前后的说明。出现 `❌ fail`、空间关系不明确的几何问题，或需要解释几何修改前后差异时，无需等待用户要求即可执行。如果图像生成工具不可用，应在报告中说明这一限制，并描述预期的图示内容。

生成图像前，执行布局预检：

- 选择解释修复方案所需的最少标注。
- 估计标签是否会挤占几何图形、彼此重叠或超出画布。如果可能出现拥挤，应在生成前标记这一点，并改用带侧边图例的编号标记、更大的画布或单独的细节视图。
- 将较长的测量值和规则文本放在图例中，不要直接叠加在密集的几何图形上。
- 包含测得的失败距离、引用的最小值，以及建议的移动距离或间隙目标。

生成图像后，在交付前检查渲染结果。如果标签重叠、被裁切、难以阅读或遮挡几何图形，应重新生成或修改诊断图后再进行报告。

## DXF 审查

对于激光板材切割，应从刷新的源文件和测得的 DXF 几何事实开始。

检查以下内容：

- 单个可上传的 DXF 文件，且模型几何以 1:1 比例表示
- 单位和零件整体尺寸；将缺失、不受支持或异常的 `$INSUNITS` 视为比例错误，直到用户确认单位
- 在服务要求闭合轮廓的情况下，检查闭合的切割轮廓
- 退化或零面积的闭合轮廓、两点闭合多段线，以及奇数阶切割端点
- 重复或重叠的切割几何
- 不受支持的注释、文本、尺寸标注、图像、构造线或隐藏的说明图层
- 订购指南和上传流程中规定的图层、颜色及线稿约定
- 折弯线实体、折弯线段长度、分割式/共轴折弯、每条折弯线两侧的局部法兰深度、距离最近的非折弯切割边或切口的距离、折弯线跨度覆盖范围、不足的折弯接触/支撑、模具区域或折弯邻近切割几何的交叉，以及在折弯属于范围内时切割几何与折弯线接触或交叉的情况
- 仅当源文件事实和测得的文件事实都支持比较时，才检查最小孔径、槽宽、腹板宽度、内部几何、零件密度、排样和间距
- 在提出要求时，检查折弯、攻丝、沉头、五金件、表面处理或去毛刺等辅助服务的要求

## STEP 审查

对于 CNC routing 或 3D model upload，应从刷新后的源文件和经过测量的 STEP 几何事实开始。

检查以下内容：

- STEP/STP 文件是否可读，以及是否为实体，而不是松散曲线或曲面
- 单位、比例、边界框、厚度和特征尺寸
- 当弯折属于检查范围时，钣金弯曲半径；将测得的圆柱形弯曲面半径与所选 SKU 的 `bending_specs.effective_bend_radius` 或 `bending_specs.bend_radius` 进行比较
- 仅当文件检查能够测量相关事实时，检查尖锐内角、小孔/槽、薄壁、孤岛、深腔、刀具可达性和公差
- 几何图形是否更适合作为板材轮廓，并使用 DXF 进行激光切割
- 材料、厚度、表面处理和二次服务兼容性

## 报告

包含文件路径、假定服务、材料/订单上下文、检查过的源文件及访问日期、检查到的几何事实、按实际影响排序的发现，以及具体的下一步修改。在发现表中，加入 `Rule source` 列，其中包含指向源 URL 的 Markdown 链接，以及该行所使用的具体 JSON 字段路径或指南章节。如果某一行仅基于直接文件检查且没有外部规则，请写明 `Direct file inspection`；不要将来源留空。除非所有必需且有引用的检查都已通过，或已明确标注为不属于所选服务，否则不要将文件称为 "SendCutSend ready"。

当结构化报告会有所帮助时，使用 `references/report-template.md`。
