# SendCutSend

来源：由 [earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad) 维护。
请以已安装的本地技能文件作为运行时事实依据；该仓库链接仅用于来源追溯和版本审查。

使用此技能为 DXF 和 STEP/STP 文件生成保守且有证据支持的 SendCutSend 预检报告。

将 SendCutSend 的订购指南、目录 JSON 和规格 JSON 视为证据源，而非稳定的 API。字段名称、类型和覆盖范围可能会有所变化。不要将缺失、无法解析、`N/A` 或相互冲突的源数据判定为通过或失败。请直接从官方 URL 获取来源，并仅使用本地检查代码测量特定的文件事实；最终报告应基于明确的比较来编写。

## 几何检查

使用当前项目的 Python 环境执行本地几何检查代码。如果 `$cad` 技能可用，请优先使用它进行 STEP/STP/DXF 几何检查、测量和验证工作流，然后再补充仍然缺失的 SendCutSend 专项测量。当需要获取几何事实时，使用 `build123d.import_step` 检查 STEP/STP，并使用 `build123d.ezdxf` 检查 DXF。不要使用原始文本解析或其他几何后端来获取几何事实。

## CAD Viewer 交接

完成会创建或修改 `.dxf`、`.step` 或 `.stp` 上传候选文件的 SendCutSend 工作后，如果已安装 `$cad-viewer`，则必须始终将明确的文件路径交给 `$cad-viewer`。如果 CAD Viewer 尚未运行，`$cad-viewer` 必须将其启动，并返回相关新建或更新文件的链接；如果 `$cad-viewer` 不可用或启动失败，请报告该情况，而不是无提示地省略交接。

## 工作流

1. 收集订单意图。
   - 对于激光板材切割和二维板材轮廓，优先使用 DXF。
   - 对于 CNC 铣削和三维模型上传工作流，优先使用 STEP/STP。
   - 记录文件类型、预期工艺、材料/SKU、厚度、数量、服务、表面处理和五金件。
   - 如果订单上下文缺失或含糊，请检查足够的源数据以提供具体选项，然后要求用户确认，之后再编写就绪结论。请包含候选 SKU/材料/厚度/服务及相关来源链接；如果规格 JSON 中提供了 `photo_url` 图片和 `learn_more_url` 链接，也请一并包含。
2. 阅读 `references/official-sources.md`，直接获取官方来源，然后检查返回的文档。以防御性方式规范化来源事实：将数值字符串、尺寸字符串、`N/A`、缺失字段、混合类型和缺失的服务数组解析为明确的备注。
3. 在可用时使用 `$cad` 检查实际的上传文件，并使用针对性的 Python/`build123d` 获取任何缺失的事实。不要只检查源生成器、CAD 模型或生成器控制台摘要。
   - DXF：根据所选服务的需要，测量单位、边界、图层、实体类型、开放/重复几何体、不受支持的注释、候选孔/圆、线条统计、候选折弯线、折弯线到切割线的距离、与折弯相邻的切割几何体、局部翼缘深度和退化的零面积轮廓。
   - STEP/STP：根据所选服务的需要，测量可解析性、单位提示、实体/曲面信号、边界框、壳体/主体信号、有效性、可获取时的板材厚度、涉及折弯时的圆柱形折弯面半径，以及相关限制。
   - 每个检查辅助程序都应仅报告事实。它可以报告测量结果、解析错误和限制，但不得输出通过/失败/就绪状态。
4. 根据证据质量选择来源记录。
   - 仅使用完全匹配的 SKU 作为目录与规格关联的权威依据。
   - 如果仅提供了材料和厚度，只有在候选匹配足够唯一且精确时，才使用选定的材料；否则，请列出候选项以及来源记录中的链接/图片，并要求用户选择。
   - 使用目录 JSON 获取可订购性信息：库存、切割工艺、可用服务、尺寸限制、五金件和表面处理。
   - 使用规格 JSON 获取工程数值：公差、孔、连接桥、折弯、攻丝、沉头孔、五金件压装、表面处理和材料属性。
   - 使用订购指南获取通俗易懂的工作流程和通用文件格式规则。

## 比较

仅比较可信的证据对。

- 确定检查是否适用。
- 引用来源字段路径或指南章节。
- 引用实测文件事实。
- 仅当来源要求和实测文件事实均可获得且可信时才进行比较。
- 如果所需测量缺失或存在风险，请针对该特定几何事实编写一个小型、专用的 `build123d`/`ezdxf` 检查器。
- 目前，将每项实测上传风险、可制造性问题或违反所引用要求的情况均视为错误。不要推断任何其他 SendCutSend UI 分类。
- 对于 DXF 单位，应结合检查 `$INSUNITS`、标头范围、实测边界和订单上下文。如果 `$INSUNITS` 缺失、不受支持，或不是 SendCutSend 指南预期的 DXF 单位代码之一（`1` 表示英寸，`4` 表示毫米），请报告单位/比例错误，并建议在进行尺寸、法兰或材料特定的比较之前重新导出或确认单位。不要静默缩放几何图形，也不要使用不确定的比例来做出材料特定的通过/失败判定。
- 对于包含折弯线的 2D 文件，应沿每条折弯线局部检查法兰长度。在每个跨度或采样点测量每条折弯线两侧最近的切割边/自由边，包括会中断折弯跨度或形成局部自由边的缺口、槽、间隙、分离式凸片和切口。将最小局部法兰深度与所选 SKU 的 `bending_specs.min_flange_length_before_bend` 和 `bending_specs.min_flange_length_after_bend` 进行比较。除非引用的来源针对该服务给出了孔到折弯或特征到折弯的规则，否则不要将法兰长度限制应用于普通封闭孔或内部切口；应按引用规则的要求，使用中心线到折弯或边缘到折弯的测量值单独报告这些特征。不要仅仅因为折弯附近存在相邻的切割几何图形，就将其视为转角避空；除非剩余的局部法兰仍满足法兰长度最小值。如果任何局部法兰深度低于 SKU 最小值，请报告 `❌ fail`。当导出的几何图形中存在局部切口、中断的折弯、分离的折弯段、避空、凸片或无支撑区域时，不要依赖来源层级的汇总值。
- 按物理原因分别记录折弯相关发现。不要将折弯附近的几何问题归并为笼统的法兰失败。应分别报告以下各项：最小法兰/接触长度错误、与折弯线或模具区域相交的几何图形、因附近自由边或切口导致的折弯接触/支撑不足、未跨越折弯区域的折弯线、分离式/共轴折弯段，以及接触或穿过折弯线的切割几何图形。如果 SendCutSend 来源未提供确切的模具区域/接触阈值，请将实测文件事实引用为直接文件检查，并明确标记该比较受来源信息限制。
- 对于 STEP/STP 折弯零件，当模型包含钣金折弯几何图形或预期服务包含折弯时，应检查折弯半径。尽可能使用 `$cad`/`build123d`/OCP 提取圆柱形或环面形折弯面及其半径，对重复的折弯半径进行分组，并将其与所选 SKU 的 `bending_specs.effective_bend_radius` 或 `bending_specs.bend_radius` 进行比较。如果所选材料/SKU 未知，请报告实测折弯半径集合，并在做出就绪性判定之前要求提供材料/厚度。如果实测半径与所选 SKU 的工装半径冲突，请报告折弯半径不匹配错误。

使用克制的状态标签进行报告：

- `✅ pass`：测得的文件事实符合所引用的现行要求。
- `❌ fail`：存在测得的上传风险、可制造性问题，或直接违反所引用现行要求的测量结果。
- `❓ need more info`：缺少上下文、缺少来源证据、几何结构未经测量、来源相互冲突或存在工具限制。

## 诊断图像

当使用视觉方式能更容易理解发现的问题，并且具备图像生成或图像编辑能力时，应主动制作简洁的诊断图。使用生成或编辑的图像来提供标注、图例和修改前后对比说明。只要存在 `❌ fail`、空间关系不明确的几何问题，或几何修改需要修改前后对比说明，就应这样做，无需等待用户提出请求。如果图像生成工具不可用，请在报告中说明此限制，并描述原计划制作的图示。

生成图像之前，先执行布局预检：

- 选择能够说明修复方法的最少标注集合。
- 评估标签是否会挤占几何图形、相互重叠或超出画布。如果可能出现拥挤，请在生成前指出，并改用编号标记加侧边图例、更大的画布或单独的细节视图。
- 将较长的测量值和规则文本放在图例中，不要直接置于密集的几何图形之上。
- 包括测得的不合格距离、所引用的最小值，以及建议的移动量或间隙目标值。

生成图像后，在交付之前检查渲染结果。如果标签相互重叠、被裁切、难以阅读或遮挡几何图形，请重新生成或修改图示，然后再进行报告。

## DXF 审查

对于激光板材切割，应从已刷新的来源和测得的 DXF 几何事实开始。

检查以下事项：

- 是否为包含按 1:1 比例绘制的模型几何图形、可上传的单个 DXF 文件
- 单位和零件整体尺寸；在用户确认单位之前，将缺失、不受支持或非预期的 `$INSUNITS` 视为比例错误
- 在服务要求封闭轮廓时，切割轮廓是否封闭
- 退化或面积为零的封闭轮廓、仅含两个点的封闭多段线，以及度数为奇数的切割端点
- 重复或重叠的切割几何图形
- 不受支持的注释、文本、尺寸标注、图像、构造线或隐藏的说明图层
- 订购指南和上传工作流程规定的图层、颜色及线条约定
- 当涉及折弯时，检查折弯线实体、折弯线段长度、分段或共轴折弯、每条折弯线两侧的局部法兰深度、到最近非折弯切割边缘或开孔的距离、折弯线跨度覆盖范围、折弯接触或支撑不足、模具区域或折弯相邻切割几何图形的交叉，以及切割几何图形与折弯线接触或交叉的情况
- 仅当来源事实和测得的文件事实都支持比较时，才检查最小孔、槽、腹板宽度、内部几何图形、零件密度、排样和间距
- 在用户提出要求时，检查折弯、攻丝、沉头孔、五金件、表面处理或去毛刺等二次加工服务要求

## STEP 审查

对于 CNC 铣削或 3D 模型上传，应从已刷新的来源和实测的 STEP 几何事实入手。

检查以下内容：

- STEP/STP 文件是否可读，以及是否包含实体而非松散的曲线或曲面
- 单位、比例、边界框、厚度和特征尺寸
- 当涉及折弯时，检查钣金折弯半径；将实测的圆柱形折弯面半径与所选 SKU 的 `bending_specs.effective_bend_radius` 或 `bending_specs.bend_radius` 进行比较
- 仅当文件检查能够测量相关事实时，检查尖锐内角、小孔/槽、薄壁、孤岛、深腔、刀具可达性和公差
- 几何形状是否表示更适合以 DXF 格式进行激光切割的钣金轮廓
- 材料、厚度、表面处理和二次加工服务的兼容性

## 报告

包括文件路径、假定的服务、材料/订单上下文、已检查的源文件及访问日期、已检查的几何事实、按实际影响排序的发现，以及具体的后续修改建议。在发现表中，加入一个 `Rule source` 列，其中包含指向来源 URL 的 Markdown 链接，以及该行所使用的具体 JSON 字段路径或指南章节。如果某一行仅基于直接文件检查且没有外部规则，请注明 `Direct file inspection`；不要将来源留空。除非每项引用的必需检查均已通过，或已明确不在所选服务的适用范围内，否则不要将文件称为“SendCutSend 就绪”。

当结构化报告有帮助时，使用 `references/report-template.md`。
