# 内容引擎

将一个创意转化为适合各平台的优质内容，而不是在所有平台发布完全相同的内容。

## 何时启用

- 撰写 X 帖子或帖子串
- 起草 LinkedIn 帖子或发布动态
- 编写短视频或 YouTube 讲解视频脚本
- 将文章、播客、演示或文档改编为社交媒体内容
- 围绕产品发布、里程碑或主题制定轻量级内容计划

## 首要问题

明确以下事项：
- 来源素材：要基于什么进行改编
- 受众：开发者、投资者、客户、运营人员还是普通受众
- 平台：X、LinkedIn、TikTok、YouTube、新闻简报或多平台
- 目标：提升认知、促进转化、招聘、树立权威、支持发布或提高互动

## 核心规则

1. 针对平台进行调整。不要在不同平台交叉发布相同文案。
2. 钩子比摘要更重要。
3. 每篇帖子都应传达一个清晰的观点。
4. 使用具体信息，而不是口号。
5. 让行动请求简短明确。

## 平台指南

### X
- 快速切入主题
- 每篇帖子或帖子串中的每条推文只表达一个观点
- 除非必要，否则不要在正文中放置链接
- 避免滥用话题标签

### LinkedIn
- 使用有力的首句
- 采用短段落
- 更明确地阐述经验、成果和要点

### TikTok / 短视频
- 前 3 秒必须能打断用户的注意惯性
- 围绕画面编写脚本，而不只是旁白
- 一次演示、一个主张、一个行动号召

### YouTube
- 尽早展示结果
- 按章节组织内容
- 每 20-30 秒更新一次画面

### 新闻简报
- 提供一个清晰的视角，而不是堆砌互不相关的内容
- 让章节标题便于快速浏览
- 确保开篇段落真正发挥作用

## 内容改编流程

默认流程：
1. 核心素材：文章、视频、演示、备忘录或发布文档
2. 提取 3-7 个独立观点
3. 编写适合各平台的不同版本
4. 减少不同输出之间的重复
5. 让行动号召与平台意图保持一致

## 交付内容

当用户要求提供一套推广活动方案时，返回：
- 核心角度
- 各平台专属草稿
- 可选的发布顺序
- 可选的行动号召版本
- 发布前仍需补充的任何信息

## 质量检查

交付前确认：
- 每份草稿都符合其平台的原生表达习惯
- 钩子有力且具体
- 不使用泛泛的炒作语言
- 除非用户要求，否则不同平台之间不重复使用相同文案
- 行动号召与内容和受众相匹配
