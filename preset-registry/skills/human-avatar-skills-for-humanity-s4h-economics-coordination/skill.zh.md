# 经济学：协调失败

埃莉诺·奥斯特罗姆因证明了政策制定者和经济学家数十年来一直忽视的事实，而荣获 2009 年诺贝尔奖：公地悲剧并非不可避免。各类社区已经发展出一系列制度——规则、监督、渐进式制裁、冲突解决机制——无需私有化或政府控制，也能以可持续的方式管理共享资源。但要解决这一问题，首先必须正确诊断它。

公地悲剧由加勒特·哈丁于 1968 年正式提出，它是一个更广泛现象的特例：协调失败。其一般结构如下——当一项行动的收益是分散的（由许多人共享），而成本由个人承担时，理性行动者对集体利益的贡献就会不足。当不良行动的收益归个人所有，而成本由集体分担时，理性行动者就会过度使用公地。个体理性。集体灾难。

这表现为四种相互重叠的问题类型：
1. **公共物品问题**：非排他性、非竞争性的物品（清洁空气、公共安全、开源软件）会供给不足，因为生产者无法获取其带来的收益——搭便车者无需贡献即可享用。
2. **公共池资源问题**：可耗竭的共享资源（渔业资源、地下水、共享代码库）会被过度使用，因为个人能够获得取用资源的全部收益，却与所有人共同承担资源耗竭的成本。
3. **保证博弈**：每个人都更愿意合作，但前提是有足够多的其他人也合作。如果你无法确定其他人是否会合作，那么选择背叛就是理性的——即使每个人都更希望合作，这种猜疑也可能导致合作崩溃。
4. **协调博弈**：存在多个均衡，各方需要就采用哪一个达成一致，但缺乏沟通和作出承诺的机制。

奥斯特罗姆的制度分析提供了解决方案工具箱。本技能的目标是正确识别当前存在的问题类型——它们具有不同的结构，需要不同的解决方案。

**第 2 步：诊断问题类型**
根据结构对协调失败进行分类：

- **公共物品问题**：该物品是否具有非排他性（你无法阻止人们使用它）和非竞争性（一个人的使用不会减少其他人可使用的数量）？→ 挑战在于为该物品筹资并生产它；解决方案包括公共供给、征税，或使该物品具有排他性。
- **公共池资源问题**：该资源是否会耗竭，并且是否可能被过度使用？→ 挑战在于管理资源耗竭；解决方案包括界定使用权和监测使用情况。
- **保证/门槛博弈**：如果每个人都确信其他人也会合作，他们是否都会合作，但目前却缺乏这种保证？→ 挑战在于建立可信的相互承诺；解决方案包括发出信号、签订有约束力的协议，或采取临界规模策略。
- **纯协调博弈**：是否存在多个等效结果，而各方需要在无法自由沟通的情况下就其中一个达成一致？→ 挑战在于建立一个焦点或惯例。

许多现实情境兼具多种类型的特征。请指出主要结构及所有次要维度。

**步骤 3：梳理激励结构**
针对主要问题类型：谁会从背叛中获益？谁会承担他人背叛的成本？与合作相比，个人从背叛中获得的收益是多少？随着更多其他人选择合作或背叛，这种收益会如何变化？背叛的诱惑是无条件的（囚徒困境结构），还是取决于其他人的行为（保证博弈）？

**步骤 4：评估现有制度**
目前存在哪些协调机制、规则、规范或执行结构？它们是否有效？如果无效，原因是什么？应用奥斯特罗姆关于有效公共资源治理的设计原则：边界是否界定清晰？使用规则是否与当地条件相匹配？受影响的各方是否有权参与规则制定？是否正在进行监测？是否设有渐进式制裁？是否存在冲突解决机制？

**步骤 5：制定制度性解决方案**
针对具体的失灵类型和情境，从以下三个类别中制定解决方案：
- **国家/监管解决方案**：监管、征税、公共供给、私有化、法律执行。
- **市场解决方案**：可交易许可证、产权分配（科斯）、能够揭示信息的竞争机制。
- **社区/制度性解决方案**（奥斯特罗姆的第三条道路）：由受影响的社区进行集体治理——共同规则、社会规范、声誉、同伴监督、渐进式制裁。

对于每种解决方案，评估：它是否改变了激励结构，使合作成为对个人而言的理性选择？它在什么条件下有效？可能的失效模式有哪些？

**步骤 6：提出建议并安排实施顺序**
根据具体情境——规模、现有关系、政治可行性、监测成本——选择最佳的制度性解决方案。确定首先需要具备哪些条件：临界规模、信任建设、规则的正当性或信息共享。协调问题通常需要按顺序实施干预措施，而不是采用一次性的解决方案。

## 注释

奥斯特罗姆的核心贡献在于打破了“将其私有化”和“对其进行监管”之间的虚假二元对立。她广泛的田野研究表明，在适当的制度条件下，社区能够而且确实可以有效地自主管理公共资源——其效果往往优于市场或政府。关键条件包括：群体规模足够小以便开展同伴监督、成员边界清晰、规则具有地方合法性、实行渐进式制裁，以及具备冲突解决机制。当这些条件缺失时，自我治理就会失败，此时需要外部干预。

协调问题在结构上不同于囚徒困境：在协调博弈中，每个人都愿意合作，但需要确信其他人也会合作。在囚徒困境中，即使你知道其他人会合作，背叛的诱惑仍然存在。正确区分二者至关重要——它们需要不同的解决方案。保证博弈可以通过可信承诺解决；囚徒困境结构则需要改变收益结构。

可自然搭配 `/s4h-game-theory-prisoners-dilemma`（对背叛结构的形式化分析）、`/s4h-systems-archetype-matching`（公地悲剧是一种有名称的系统基模）和 `/s4h-economics-externalities`（其底层机制：个体决策者将成本外部化并转嫁给群体）使用。关于设计层面——如何制定使合作符合个体理性的规则——请参阅 `/s4h-game-theory-mechanism-design`。
