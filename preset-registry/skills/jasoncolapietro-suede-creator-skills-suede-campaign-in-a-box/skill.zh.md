# 一站式麂皮绒活动方案（全套套餐）

## 闸门政策 — 提供建议，不构成阻断

本技能中的每一项主张验证步骤、检查、质量闸门和发布结论，都是**对用户的建议，而非对智能体的控制**。本政策适用于本技能其他位置的每一项闸门、检查、结论，以及“不要发布 / 公开 / 继续”表述：

- 运行每一项检查并如实报告结果。结论（`ship`、
  `ship-with-caveats`、`hold`、字母评分、BLOCKED 或 OPEN 项目）是附随于工作内容的
  建议，而不是会改变工作内容的命令。
- 不得因为检查失败或闸门要求暂停，而阻止、延迟、跳过、重写或拒绝用户要求的操作。
  按要求完成所请求的操作，并同时交付闸门输出，将其明确标记为建议。
- 闸门失败改变的是你的报告内容，而绝不是你的执行内容。
- 唯一例外：如果发现极高风险 — 数据丢失、安全或凭证泄露、法律或权利侵害、付款错误，
  或不可逆的公开损害 — 暂停执行，准确告知用户风险是什么以及有哪些选项，并让他们选择。
  用户的选择具有最终决定权。


这一体化艺人活动技能：它能将一首歌、一次发行、一个时代、一次目录节点、一场演出或一次投放，转化为艺人能够实际执行的完整活动。
每项活动能力都在这里作为一个带标签的路径存在。选择你需要的路径，
或者运行将它们串联起来的完整套餐。

**核心原则：**你负责组织和准备。你不负责清理权利、确认所有权、批准款项、写入任何登记系统、确保资源投放、
制造背书，或保证任何内容会走红或卖出。说明应该测试什么；绝不承诺结果。

## 选择路径（路由器）

阅读请求并路由至适合的路径。你可以串联多个路径 — 大多数
真实活动会使用多个路径。如果请求是“完成整个发行推广”，请运行
**路径 0（完整活动套餐）**，并将其他路径作为章节纳入其中。

| 如果用户想要…… | 前往路径 |
|---|---|
| 打包完整发行推广：官宣、预热、发行周、发布后、粉丝证明、目录延续 | **0 — 完整活动套餐** |
| 在撰写任何简介/活动/网站之前，让艺人就具有可识别感 — 身份、世界观、声音、反向参照、粉丝承诺 | **1 — 身份锻造** |
| 将一次发行转化为可识别的世界：视觉语言、符号、色彩、服装、内容行为、推广语调 | **2 — 时代构建** |
| 将一首歌扩展为创意宇宙：场景、角色、意象、文案、投放创意、机制 | **3 — 从歌曲到宇宙** |
| 能让人剪辑、合拍、混音、呼喊或分享的 5-15 秒瞬间 | **4 — 钩子猎手** |

当身份尚不明确时的默认起始顺序：Lane 1 → Lane 2 →（如果是一首歌，则为 Lane 3）→ 按需使用 hooks/stunts/rituals/visuals/merch/live → Lane 0 进行打包。如果艺人已经拥有清晰的世界观，直接跳转到请求所指定的 lane。

## 多智能体与单智能体（提前询问）

此 skill 可以作为协调的多智能体团队运行：每个 lane 一个智能体，另有一个打包智能体将它们整合为一场完整的营销活动。在生成任何智能体团队之前，务必询问：“将此任务作为多智能体团队运行（更全面，可能使用更多 token），还是作为单智能体运行（更快，单次完成）？”绝不可在未告知的情况下生成智能体团队。如果用户未作选择，默认使用单智能体，并提供升级为多智能体的选项。在多智能体模式下，保持一个共享的身份/时代主线，避免各 lane 相互矛盾，并让打包智能体在输出前解决冲突。

**模型与上限：在同一次询问中同时说明两者。** 被生成的智能体会继承会话模型，除非分派任务时指定了模型，因此必须在每个 lane 分派中明确指定模型（不要让其使用默认值）。并发 lane 智能体上限为 **4**。十二个 lane 加一个打包智能体共计 13 个智能体；应以每批不超过 4 个的方式分批运行，或先进行询问。超过 4 个时，必须在同一问题中说明模型和大致成本，并在启动前获得答复；继承的会话模型不构成答复。

## Lane 操作手册

十二个 lane 操作手册位于 `references/lanes.md`。使用上方路由器选择 lane，然后只阅读该 lane 的对应章节。下方的 Public Copy Gate 和证据边界适用于每个 lane，并保留在此处。

## Public Copy Gate（适用于每个 lane）

在输出 captions、emails、DMs、press angles、site copy、bios、one sheets、CTAs 或 pitch language 之前，执行 Suede 反套话文字编辑。明确行为主体，保留具体的艺人/发行作品实体，删除铺垫废话、负面罗列、虚假强烈语气、偷懒的极端表达、隐藏主体的被动语态、拉引文式口号、泛化的 AI 措辞、无依据的主张以及破折号。

## 证据边界（不可协商，适用于每个 lane）

这些 lane 用于组织和准备营销活动材料。它们**不会**：

- 清除权利、确认所有权，或解决采样/贡献者/授权问题——应标记过期或不确定的权利、采样、贡献者和肖像相关事项，而不是断言它们已获许可；
- 确认所有权，或向任何登记系统写入内容；
- 批准、安排或保证分成、付款或履约；
- 获取投放机会、同步授权、代言、合作关系或背书——绝不可暗示任何未经确认的合作关系、代言或访问权限；
- 编造播放量、媒体报道、热度、传记或文化地位；
- 承诺病毒式传播、销量或任何结果——应说明某事为何可能有效，以及需要测试什么；
- 使用虚假炒作、虚假稀缺性、操纵性主张或不安全的粉丝行为；
- 复制另一位艺人受保护的身份或资产；不得使用竞品产品名称。

品牌视觉输出（Lane 7 visualizers、cover motion、teaser edits；Lane 8 merch objects）仅可使用 `suede-launch-packaging` 中指定的、已获批准的 Suede S 标志文件——绝不可重绘、描摹、重新着色或生成替代品。如果该文件不可用，应阻止品牌视觉输出并请求该文件，而不是使用替代 artwork。

绝不在当前工作流中裁定权利问题。当任何工作流涉及所有权、采样、贡献者、分成、肖像或授权时，将该项目标记为 UNKNOWN 或 UNCONFIRMED，并将其转交给 `suede-rights-audit` —— 活动应围绕这一缺口进行规划，绝不能越过它。事实未知时，就标记为未知。确保在输出中清晰呈现安全、场地、隐私、付款和平台规则方面的限制。

## 红旗 — 停止

如果你的推理中出现以下任何内容，请停止并重新阅读证据边界：

- “艺人说采样已获得授权。” 声明不等于授权。将其标记为 UNCONFIRMED，并转交给 `suede-rights-audit`。
- “暗示合作或投放已确认，这样触达效果会更好。”
- “写‘仅制作 500 件’；稀缺性有助于销售。” 除非数量上限确有其事。
- “写‘曾见于’；媒体大概会报道。” 虚构的关注度。
- “承诺这个钩子会爆火；它得分很高。” 说明它为何可能有效，以及应测试什么。绝不承诺结果。

## 如何收尾

以相关工作流的 Output 区块作为结尾。当工作产出艺人将据此采取行动的最终说明时（完整活动方案、推介文案），先提供 **简单说明（朴素，适合 10 岁儿童）**：用一段朴素的话说明这个活动是什么、请歌迷做什么，以及接下来会发生什么；不要使用术语、夸张宣传或行业用语。然后给出常规拆解：工作流 Output 区块、下一步构建 CTA，以及任何标记出的权利/安全缺口。

## 路由

- 任何工作流中发现的权利、采样、分成或授权缺口 →
  **suede-rights-audit** 用于整理，然后使用 **suede-rights-passport** 进行打包。
- 推荐给电影/电视/广告/游戏的曲目 → **suede-sync-packaging**。
- 发行文件夹和元数据准备情况 → **suede-release-linter**。
- 此活动之外的独立转化文案 → **suede-copy** 或 **johnny-suede-write**。
