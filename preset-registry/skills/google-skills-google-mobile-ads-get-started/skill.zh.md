# Google Mobile Ads SDK - 安装

## 工作流程

1.  **确定用户的平台**：确认项目是 Android、iOS 还是 Unity。如果不明确，请在继续之前询问。

2. **阅读平台指南**以了解实现细节：
    - Android：`references/android-get-started.md`
    - iOS：`references/ios-get-started.md`
    - Unity：`references/unity-get-started.md`

3. **按顺序执行以下步骤**：
   - [ ] 添加 SDK 依赖项
   - [ ] 设置应用标识符
   - [ ] 初始化 SDK
   - [ ] 验证集成

4. SDK 成功安装后，请用户选择一种广告格式，以继续集成。
