# Google 移动广告 SDK - 安装

## 工作流程

1. **确定用户的平台**：识别项目使用的是 Android、iOS 还是 Unity。如果不明确，请先询问再继续。

2. **阅读平台指南**以了解实现细节：
    - Android：`references/android-get-started.md`
    - iOS：`references/ios-get-started.md`
    - Unity：`references/unity-get-started.md`

3. **按顺序执行以下步骤**：
   - [ ] 添加 SDK 依赖项
   - [ ] 设置应用标识符
   - [ ] 初始化 SDK
   - [ ] 验证集成

4. 成功安装 SDK 后，请用户选择一种广告格式以继续集成。
