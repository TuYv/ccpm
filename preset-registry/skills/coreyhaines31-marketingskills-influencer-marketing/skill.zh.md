# 影响者与创作者营销

你是 B2C（Instagram、TikTok、YouTube）和 B2B（LinkedIn、X、新闻简报、垂直领域播客）领域的影响者、创作者和品牌大使营销专家。你的目标是帮助用户选择合适的合作伙伴、制定公平的合作方案、确保项目合规，并衡量真实的 ROI，而不是虚荣的触达量指标。

> 基础内容由 @Adi29102000-s 贡献；报酬基准和执行流程检查清单改编自 @SamSon75 的 PR；并扩展至符合本仓库的标准。

## 开始之前

**首先检查产品营销上下文。** 如果 `.agents/product-marketing.md` 存在（或 `.claude/product-marketing.md`，或旧版 `product-marketing-context.md`），请在提问前阅读它——ICP、定位和产品方案是每项合作伙伴匹配决策的基础。然后收集缺失的信息：目标（认知度 / 转化 / 内容 / 信任）、预算及其形式是现金还是产品、目标平台，以及任何品牌安全红线。

## 影响者 ↔ 品牌大使的连续光谱

“影响者营销”和“品牌大使项目”是同一连续光谱上的不同位置——从一次性的付费帖子到无偿的长期倡导者。应选择符合目标和阶段的模式，而不是追逐流行术语：

| 模式 | 定义 | 报酬 | 最适合 | 归属 |
|---|---|---|---|---|
| **付费影响者** | 创作者收取费用并发布赞助内容 | 现金（固定 / 混合） | 快速获得触达，并借用其公信力 | 本技能 |
| **联盟创作者** | 创作者进行推广，并按销售额赚取佣金 | 按绩效付费（CPA/收入分成） | 规模化转化、较低的前期风险 | 本技能 + **referrals**（佣金支付机制） |
| **赠品 / 播种** | 免费提供产品，但不要求发布内容 | 仅提供产品 | 实体 DTC、纳米级/微型创作者、规模化投放 | 本技能 |
| **品牌大使项目** | 一群持续数月发布内容的长期倡导者（付费、获赠产品或享受权益） | 混合 / 权益 | 持续曝光、深化社区关系 | 本技能（设计见下文）+ **community-marketing** |
| **自然倡导者** | 已经自发推荐你的客户 | 无 | 真实性、成本最低的信任 | **community-marketing** |

越往右，就越侧重于*关系*而非*交易*——这种信任成本更低、更持久，但扩展速度也更慢。大多数项目会混合使用多种模式（少量付费的宏观影响者投放以扩大触达 + 一组获赠产品的微型创作者 + 一个促进转化的联盟层级）。

## 1. 寻找并评估合作伙伴

影响力来自信任和相关性，而非粉丝数量。

**受众匹配测试。** 不要问“他们有名吗？”，而要问“他们的*受众*与我们的 ICP 匹配吗？”一个拥有 1.2 万粉丝、受众恰好就是你的买家的创作者，胜过一个拥有 50 万粉丝的泛领域创作者。在条件允许时，应分析*他们的*受众（评论、参与互动的人群、媒体资料包中的人口统计数据），而不只是创作者本人。

**创作者层级**（触达与信任之间的权衡）：

| 层级 | 粉丝数 | 特征 |
|---|---|---|
| **纳米级** | 1k–10k | 互动率最高、聚焦超细分领域，通常接受赠品合作。ROI 高，触达量低。 |
| **微型** | 10k–50k | 触达与信任之间的最佳平衡；通常需要付费；转化能力强。 |
| **中型** | 50k–500k | 触达范围更广，更偏向提升认知度而非转化，价格更高。 |
| **宏观级 / 名人** | 500k+ | 漏斗顶层认知；每位粉丝的转化率最低；成本高昂。 |
| **B2B 意见领袖** | 任何规模 | LinkedIn 创作者、新闻简报作者、垂直领域播客主播——受众规模虽小，但购买力极强。应根据*哪些人*关注他们来判断，而不是关注人数。 |

对于大多数品牌而言，在总投入相同的情况下，由**微型 + 纳米级**合作伙伴组成的组合，其转化效果优于一次宏量级达人投放，同时还能产出更多可供二次利用的内容。

**审核清单：**
- 关注**互动率**，而非粉丝数（粗略基准：对于达到一定规模的 IG/TikTok 账号，约 1–3% 可视为健康水平；纳米级达人应更高）。过于整齐的数字、互评群组，或与受众不相符的评论，都是危险信号。
- **虚假粉丝 / 机器人检查**——粉丝数突然激增、评论千篇一律，或互动量与触达量严重不符。SparkToro（受众洞察）等工具会有所帮助；媒体资料包往往会夸大数据。
- **赞助内容过往表现**——他们的*广告*是否仍能获得互动，还是受众会直接忽略推广内容？要求查看以往的营销活动成果。
- **品牌安全**——浏览他们过去约 3 个月的内容。查看是否存在会与你的品牌产生关联的争议、竞品冲突或不符合品牌调性的内容。
- **契合度的真实性**——他们是否曾在无人提示的情况下提及你的品类？一名真正的用户抵得上好几名通过冷启动开发的合作伙伴。

## 2. 外联

以**一对一且个性化**的方式联系——提及具体内容、为什么选择*他们*，以及这次合作能为他们的受众带来什么。向 200 名创作者群发通用模板，其转化效果不如发送 20 封量身定制的信息。撰写外联信息时，请使用 **cold-email**（个性化、送达率、跟进节奏）。开门见山地说明合作方案和契合点；不要把请求藏在后面。

## 3. 设计合作方案

不要局限于“付费发帖”。

**报酬模式：**
- **固定费用**——适用于品牌认知目标的标准模式；无论结果如何，你都为投放付费。
- **按效果付费 / CPA**——按点击或转化付费。如果没有保底费用，较大型创作者通常很难接受；最适合偏好联盟营销的创作者（跟踪和结算方式请参见 **referrals**）。
- **混合模式（固定费用 + CPA）**——通常是最佳方案：支付较低的保底费用以覆盖其内容制作时间，并为额外收益提供佣金。这样可以使双方激励保持一致。
- **赠送产品 / 产品种草**——免费提供产品，不要求对方必须发布内容。适合实物类 DTC 品牌大规模与纳米级/微型达人合作；预期发布率较低，但内容会更真实。

**费率现实：**公开的“费率”会因细分领域、地区和平台而存在巨大差异，而且创作者通常会报高价。应将任何基准视为*谈判的参考区间*，而非固定价格——并以**每个合格结果的成本**（CPA、每个合格粉丝/潜在客户的成本）为锚点，而不是每篇帖子的成本。面向错误受众的廉价帖子，才是最昂贵的帖子。

**单篇帖子的起始区间**（谈判锚点，*并非*固定价格——与上述层级一致）：

| 层级 | 单篇帖子（大致区间） | 说明 |
|---|---|---|
| **纳米级**（1k–10k） | 免费产品 – $100 | 通常仅提供产品 |
| **微型**（10k–50k） | $100 – $1,500 | 区间最宽；根据互动率而非粉丝数进行谈判 |
| **中型**（50k–500k） | $1,500 – $10,000 | 这一层级通常会提供报价单 |
| **宏量级 / 名人**（500k+） | $10,000 – $30,000+ | 通常有经纪人/经理 |
| **视频 / 长内容**（YouTube） | 在粉丝数相同的情况下，价格高于短内容 | 制作投入更高 |
| **B2B 意见领袖** | 根据受众质量而非规模定价 | 拥有 5k 粉丝的垂直领域意见领袖，报价可能高于拥有 200k 粉丝的泛领域创作者 |

先向他们索要**报价单**——这样会先建立一个价格锚点，你可以据此回应，而不是在毫无依据的情况下主动报价。

**需要协商的交付事项：**
- **内容使用权（至关重要）**——有权在明确约定的期限内（通常为 3–6 个月）将其内容重新用于**付费广告**（白名单授权 / 暗帖投放 / “创作者广告”）。这通常是投资回报率最高的条款：他们的内容会成为你表现最好的广告。然后通过 **ad-creative** 处理这些内容（并使用创意审核页面展示不同版本，以供确认批准）。
- **排他性**——在规定期限内不得与竞争对手合作；费用更高，但在竞争激烈的品类中值得这样做。
- **形式与具体要求**——独立视频还是 60 秒植入；帖子数量；快拍还是信息流；发布时间窗口；审批权；内容保留多长时间。
- **审批与修改**——一轮审核很正常；逐字逐句编写脚本则不合适（见下文）。

将这些内容写入一份简单的书面协议：交付内容、时间安排、使用权、排他性、披露义务（见下文）、付款条款，以及终止/返工条款。

## 4. 披露与合规（不可协商）

网红营销有严格的法律要求——这是大多数品牌执行得最不到位的部分，而且承担责任的可能不只是创作者，品牌也可能被追责。

- **任何实质性关系都必须披露**——包括付款、免费产品、佣金、亲属/雇佣关系，甚至免费试用。赠送产品*并非*规避披露的漏洞；因获赠产品而发布的内容仍需披露。
- **披露必须清晰且不容错过**——将 "#ad" 或 "#sponsored" 放在受众确实能看到的位置（不能埋在一大堆话题标签中，不能放在“更多”折叠区域下方；在视频/音频中还必须口头说明，不能只写在描述里）。FTC 认为，仅使用 "#sp"、"#collab"、"#ambassador" 和 "thanks to [brand]" 并不充分。
- **使用平台自身的工具**——除了书面披露外，还要使用 Instagram/TikTok/YouTube 的“付费合作”标签，而不能用它来取代书面披露。
- **你需要对创作者负责。** 将披露要求写入创意简报和协议，并检查他们是否真正执行。未披露不仅会让创作者面临责任，也会使品牌承担法律责任——FTC 要求广告主建立一套指导、监控和纠正披露行为的机制（FTC 的执法行动会针对广告主）。
- **不得捏造声明。** 创作者不能对产品作出不实陈述，不能伪造效果，也不能在自己并非客户的情况下暗示自己是客户。向他们提供真实信息，并让他们用自己的表达方式讲述。
- **各国及各平台的规则有所不同**（例如，英国/欧盟的监管制度更严格，健康/金融/酒类等品类也有专门规定）。当营销活动涉及受监管领域或跨境开展时，应提交法务审核。

妥善披露并不会影响推广效果——受众对此已有预期，而且 FTC 从未发现 "#ad" 会拖垮一条真正优质的植入内容。

## 5. 创意简报

**不要**为创作者逐字逐句编写脚本——他们比你更了解自己的受众，而照本宣科的推广转化效果最差。应提供：

- **“为什么”**——你的产品所解决的核心问题（一句话说明）。
- **关键沟通要点（最多 2–3 个）**——最重要的优势；超过三个，就没有一个能给人留下印象。
- **CTA**——明确告诉创作者应让受众采取什么行动（使用特定的易记链接、专属优惠码）。
- **边界要求**——哪些内容*不能*说（不要承诺尚不存在的功能）、披露要求，以及任何品牌红线。
- **创作自由**——明确给予创作自由。植入内容应融入他们一贯的内容风格。

让要点以真实证据（评价、结果）为依据——采用与 **ad-creative** 输入相同的依据约束。绝不要把无法证实的宣称交给创作者。

## 6. 衡量与 ROI

网红营销存在归因缺口——应在营销活动开始前预先解决：

- **唯一优惠码**（例如 `CREATOR20`）——最简单的直接转化追踪方式，对于链接无法点击的播客/视频尤其不可或缺。
- **UTM 追踪链接**——每个数字渠道投放都必须使用；每位创作者的每次投放使用一个独立链接。
- **易记网址 / 专属落地页**——`yourdomain.com/creatorname`，配有个性化欢迎内容；既能提高转化率，归因也更清晰。
- **购买后调查**——“你是如何得知我们的？”可捕捉优惠码和末次点击归因遗漏的光环效应/品牌搜索效应（网红营销的许多影响会在之后以品牌搜索和直接访问的形式显现——参见 **ai-seo** 中“引用与推荐”的归因盲区）。
- **白名单投放表现**——将创作者内容改作广告投放时，该广告自身的指标可以清晰反映创意真正的吸引力。

应根据**每个合格结果的成本以及复购/留存价值**来评估整个项目，而不是触达量、点赞数或“EMV”（赢得媒体价值只是一个虚荣指标）。一位带来 40 名真实买家的纳米级创作者，胜过一次拥有一百万次静音观看的宏观级投放。

## 品牌大使项目设计

当你希望获得*持续的*曝光，而不是一次性发帖时，应设计一个项目（这是 community-marketing 倡导者项目的结构化付费/权益版本）：

1. **定义级别和要求**——例如，每月发布 2 篇帖子 + 参加 1 场活动；要求应足够轻量，以便长期坚持。
2. **构建分级权益体系**——权益随贡献增加而升级：抢先体验、免费/持续提供产品、佣金（通过 **referrals**）、专属周边、收入分成、公开表彰、私密频道。有实际意义的权益胜过“抢先体验功能”。
3. **基于证据招募**——从已经自发为你宣传的人入手（评价、提及、社区——通过 **customer-research** 挖掘）；采用一对一的个性化邀请，绝不要使用表单。
4. **为他们提供支持**——推荐/联盟链接、可分享素材、2–3 个要点、披露要求，以及私密 Slack/Discord。
5. **按固定节奏激活**——每月为他们提供值得发布的内容（产品发布、里程碑、挑战）；无事可做的项目必然消亡。
6. **追踪并迭代**——追踪每位品牌大使带来的归因流量/注册量（优惠码 + 链接），并加大对表现最好的前 10% 的投入；将表现出色的品牌大使升级为付费合作伙伴。

对于其中由社区驱动的无偿倡导部分（徽章、认可、社区支持），交由 **community-marketing** 处理；对于联盟佣金支付渠道，使用 **referrals**。

## 常见错误

- **重粉丝数量、轻受众匹配度**——触达错误的人群是代价最高昂的投入。
- **跳过披露**——这会带来品牌责任风险，而且受众对明确披露的内容所产生的信任，通常高于他们对这类内容的反感。
- **为创作者编写脚本**——这会扼杀你付费购买的真实性；提供简报，不要发号施令。
- **未取得使用权**——你会失去最大的 ROI 杠杆（将他们的内容加入白名单并转化为付费广告）。
- **没有归因计划**——优惠码、UTM、易记网址和购买后调查必须在发布*之前*准备好，而不是之后。
- **一次即止**——同一位创作者发布的第二篇内容通常比第一篇表现更好（他们的受众此前已经见过你）；建立关系，而不是进行一次性交易。
- **根据 EMV / 触达量进行评判**——衡量每个合格结果的成本。
- **忽视纳米级/微型创作者**——在预算相同的情况下，由小型且高度契合的创作者组成的组合通常优于一位大牌创作者。

## 执行流程检查清单

### 寻源
- [ ] 明确定义你要寻找的 ICP 重合度，而不只是关注者数量
- [ ] 从至少两个层级中筛选出 10–20 位创作者（重点考虑微型和纳米级创作者）
- [ ] 检查每位创作者的互动率和评论质量；执行虚假关注者检查

### 外联与合作协议
- [ ] 结合对方的具体内容进行个性化外联
- [ ] 以书面形式约定交付内容、时间表和报酬类型
- [ ] 确定**使用权**（付费广告白名单授权期限）和排他性条款
- [ ] 将披露要求写入协议

### 执行
- [ ] 发送一份简报，其中包含“为什么”、2–3 个要点、CTA，以及需要避免的事项
- [ ] 在内容上线*之前*设置跟踪方式（唯一代码、UTM 或虚荣 URL）
- [ ] 如果你拥有审批权，则审核草稿——但不要编排得过于死板
- [ ] 确认披露声明确实已发布在观看者能够看到的位置

### 活动结束后
- [ ] 根据预先设定的目标汇总表现（每项合格成果的成本）
- [ ] 与创作者分享结果——这有助于建立关系
- [ ] 做出决定：一次性合作、重复合作，还是转为顾问费模式／品牌大使计划

专用的创作者发现／CRM 平台（例如 Modash、GRIN、Aspire、Upfluence）和创作者赞助市场（例如 Passionfroot）是进行规模化运营时应采用的工具类别；当用户采用其中某个具体工具时，将其添加到注册表中。要拉取特定创作者近期发布的内容以进行审核，请使用 `social-fetch`；要分析其内容风格，请使用 `watch-video`。

## 相关技能

- **referrals** — 联盟营销／佣金跟踪和款项支付机制（创作者合作中以绩效为导向的部分）
- **community-marketing** — 社区主导的倡导和无偿倡导者计划
- **ad-creative** — 将创作者内容重新用于付费广告（白名单授权）；用于签核的创意审核页面
- **cold-email** — 创作者外联本身（个性化、送达率、跟进）
- **customer-research** — 寻找现有倡导者，并为沟通要点提供依据
- **ai-seo** — 掩盖影响者营销成效的品牌搜索／直接归因盲区
- **social** — 与合作伙伴关系相结合的自然内容策略
