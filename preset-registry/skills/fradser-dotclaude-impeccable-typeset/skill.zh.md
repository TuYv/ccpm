## 评估当前排版

分析当前文字排版中薄弱或显得通用的地方：

1. **字体选择**：
   - 是否使用了缺乏辨识度的默认字体？（Inter、Roboto、Arial、Open Sans、系统默认字体）
   - 字体是否符合品牌个性？（一个活泼的品牌不应使用企业风格的字体）
   - 是否使用了过多字体家族？（超过 2-3 个几乎总会造成混乱）

2. **层级**：
   - 能否一眼区分标题、正文和说明文字？
   - 字号是否过于接近？（14px、15px、16px = 层级模糊）
   - 字重对比是否足够明显？（Medium 与 Regular 的差异几乎不可见）

3. **字号与比例**：
   - 是否有一致的字体比例体系，还是字号设置很随意？
   - 正文是否满足最低可读性要求？（16px+）
   - 字号策略是否适合当前场景？（应用界面使用固定的 `rem` 比例；营销/内容页面标题使用流式 `clamp()`）

4. **可读性**：
   - 行长是否舒适？（理想范围为 45-75 个字符）
   - 行高是否适合所用字体和场景？
   - 文本与背景之间是否有足够的对比度？

5. **一致性**：
   - 相同元素是否始终采用相同的样式？
   - 字重使用是否一致？（同一角色的文本不应在一个区块使用 Bold，而在另一个区块使用 Semibold）
   - 字间距是经过有意设计的，还是所有地方都使用默认值？

**关键要求**：目标不是让文本看起来“更花哨”——而是让它更清晰、更易读，也更具设计意图。好的排版让人感觉不到它的存在；糟糕的排版则会分散注意力。

## 规划排版改进

请参阅 impeccable skill 中的[排版参考](reference/typography.md)，获取有关比例体系、字体搭配和加载策略的详细指导。

制定系统化的计划：

- **字体选择**：是否需要更换字体？什么字体适合品牌/场景？
- **字体比例体系**：建立模块化比例体系（例如 1.25 的比例），形成清晰的层级
- **字重策略**：哪些字重用于哪些角色？（正文使用 Regular、标签使用 Semibold、标题使用 Bold——或采用任何适合当前场景的方案）
- **间距**：行高、字间距以及不同文本元素之间的外边距

## 系统化改进排版

### 字体选择

如果需要更换字体：
- 选择能够体现品牌个性的字体
- 搭配具有真正对比度的字体（衬线体 + 无衬线体、几何风格 + 人文主义风格）——或者使用同一字体家族的多个字重
- 确保 Web 字体加载不会导致布局偏移（`font-display: swap`、度量匹配的后备字体）

### 建立层级

构建清晰的字体比例体系：
- **5 种字号足以覆盖大多数需求**：说明文字、次要文本、正文、副标题、标题
- **各层级之间使用一致的比例**（1.25、1.333 或 1.5）
- **组合多个维度**：通过字号 + 字重 + 颜色 + 间距建立鲜明的层级——不要只依赖字号
- **应用界面**：使用基于固定 `rem` 的字体比例体系，也可以选择在 1-2 个断点处进行调整。流式字号会削弱密集、基于容器的布局所需的空间可预测性
- **营销/内容页面**：标题和展示文本使用 `clamp(min, preferred, max)` 实现流式字号。正文字号保持固定

### 修正可读性

- 使用 `ch` 单位为文本容器设置 `max-width`（`max-width: 65ch`）
- 根据上下文调整行高：标题使用更紧凑的行高（1.1-1.2），正文使用更宽松的行高（1.5-1.7）
- 对深色背景上的浅色文本略微增加行高
- 确保正文文本至少为 16px / 1rem

### 优化细节

- 对数据表格和需要对齐的数字使用 `tabular-nums`
- 正确应用 `letter-spacing`：小型大写字母和全大写字母略微加宽，大号展示文本使用默认或较紧的字间距
- 使用语义化的令牌名称（`--text-body`、`--text-heading`），而不是基于值的名称（`--font-16`）
- 设置 `font-kerning: normal`，并在适当情况下考虑使用 OpenType 特性

### 字重一致性

- 为每种字重定义清晰的用途并始终遵循
- 不要使用超过 3-4 种字重（常规、中等、半粗、粗体已经足够）
- 仅加载实际使用的字重（每种字重都会增加页面加载开销）

**绝不要**：
- 使用超过 2-3 种字体系列
- 随意选择字号——确定一套比例并坚持使用
- 将正文文本设置为低于 16px
- 对正文文本使用装饰性字体或展示字体
- 禁用浏览器缩放（`user-scalable=no`）
- 使用 `px` 设置字号——应使用 `rem` 以尊重用户设置
- 在个性化很重要时默认使用 Inter/Roboto/Open Sans
- 搭配相似但不完全相同的字体（例如两种几何无衬线字体）

## 验证排版改进

- **层级**：你能否立即区分标题、正文和说明文字？
- **可读性**：长篇正文阅读起来是否舒适？
- **一致性**：具有相同用途的元素是否始终采用相同的样式？
- **个性**：排版是否体现了品牌特色？
- **性能**：Web 字体是否能高效加载且不会引发布局偏移？
- **无障碍性**：文本是否符合 WCAG 对比度要求？是否可以缩放至 200%？

请记住：排版是界面设计的基础——它承载了绝大多数信息。做好排版是你能够实现的最高杠杆改进。
