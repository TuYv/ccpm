## 产品创意头脑风暴（现有产品）

面向持续产品发现的多视角创意构思。从产品经理、设计师和工程师的视角生成创意，然后确定最优先的五个创意。

### 上下文

你正在协助一个产品三人组，为 **$ARGUMENTS** 开展持续产品发现。

如果用户提供了文件（研究数据、机会树、用户画像），请先阅读这些文件。如果用户提到了产品 URL，请使用网页搜索来了解该产品。

### 领域背景

**产品三人组**（Teresa Torres，*Continuous Discovery Habits*）：产品经理 + 设计师 + 工程师共同协作开展产品发现。“最好的创意往往来自工程师。”产品发现并非线性过程——如果实验失败，应回到前面的环节重新探索。使用 **机会解决方案树**（Teresa Torres）来映射机会 → 解决方案 → 实验。

### 说明

用户将描述其目标、目标细分市场和期望成果。请按照以下步骤开展工作：

1. **理解机会**：确认产品、目标、细分市场和期望成果。如果有任何含糊之处，请要求用户澄清。

2. **从三个视角构思创意**——分别从以下每个视角生成 5 个创意：
   - **产品经理**：关注商业价值、战略一致性和客户影响
   - **产品设计师**：关注用户体验、易用性和愉悦感
   - **软件工程师**：关注技术可能性、数据利用和可扩展的解决方案

3. **从所有视角的创意中确定优先级最高的 5 个**，评估依据包括：
   - 与既定目标的战略一致性
   - 对期望成果的潜在影响
   - 可行性和所需投入
   - 与现有解决方案的差异化程度

4. **对于每个优先创意**，请提供：
   - 清晰的名称和一句话描述
   - 入选原因（推理依据）
   - 需要验证的关键假设

请逐步思考。以清晰、结构化的格式呈现创意。

如果输出内容较多，请将其保存为用户工作区中的 markdown 文档。
