# 预算与竞价

1. 明确目标、转化价值、毛利率、现金约束、销售承接能力、归因不确定性、
   季节性以及平台要求的最低证据量。
2. 将支出和结果统一到可比较的时间窗口和定义下。
3. 计算盈亏平衡边界，并展示公式、输入、不确定性和敏感性情景。
4. 区分已承诺的基准投入、受控实验和预留能力。
5. 根据边际证据，而非仅依据混合平均值，比较维持、重新分配、扩大、
   缩减或实验等选项。
6. 返回一份决策要素完整的计划，包括平台/广告系列金额、时间安排、负责人、
   约束条件、成功衡量指标和回滚触发条件。

70/20/10、固定 CPA 倍数、固定预算与 CPA 比率以及固定百分比扩量等规则，
只能作为可选的启发式方法，绝不能视为普遍适用的授权依据。
