# 数据叙事

将原始数据转化为能够驱动决策、激发行动的精彩叙事。

## 何时使用此技能

- 向高管展示分析结果
- 制作季度业务回顾
- 构建面向投资人的演示文稿
- 撰写数据驱动的报告
- 向非技术受众传达洞察
- 基于数据提出建议

## 核心概念

### 1. 故事结构

```
Setup → Conflict → Resolution

Setup: Context and baseline
Conflict: The problem or opportunity
Resolution: Insights and recommendations
```

### 2. 叙事弧

```
1. Hook: Grab attention with surprising insight
2. Context: Establish the baseline
3. Rising Action: Build through data points
4. Climax: The key insight
5. Resolution: Recommendations
6. Call to Action: Next steps
```

### 3. 三大支柱

| 支柱           | 目的     | 组成要素                         |
| ------------- | -------- | -------------------------------- |
| **数据**       | 证据     | 数字、趋势、对比                 |
| **叙事**       | 意义     | 背景、因果、影响                 |
| **可视化**     | 清晰     | 图表、示意图、重点标注           |

## 最佳实践

### 建议做法

- **从“所以呢”开始** - 先亮出洞察
- **运用“三的法则”** - 三个要点、三组对比
- **展示，而非陈述** - 让数据说话
- **让内容与受众切身相关** - 关联听众的目标
- **以行动收尾** - 明确的后续步骤

### 避免做法

- **不要堆砌数据** - 果断取舍
- **不要埋没洞察** - 把关键发现放在最前面
- **不要使用行话** - 用词要与受众匹配
- **不要先讲方法论** - 先讲背景，再讲方法
- **不要忘记叙事** - 数字需要意义
