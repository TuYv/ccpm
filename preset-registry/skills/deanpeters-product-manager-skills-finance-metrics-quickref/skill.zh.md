## 目的

快速查阅任何 SaaS 财务指标，无需深入讲解。当你需要快速查询公式、检查基准或回顾决策框架时，请使用此技能。有关详细说明、计算方法和示例，请参阅相关的深度解析技能。

这不是教学工具，而是一份针对速度优化的速查表。浏览、查找、应用。

## 输入

**最适合提供：** 你需要的指标——给出名称，即可获取公式、基准和决策背景。
**同样有用：** 你的数据，以便当场套用公式。

调用时提供的任何内容——技能名称后的文本、粘贴的上下文内容，或附加的 `ARGUMENTS:` 行——都视为已经给出的答案。使用这些内容并跳过其中已涵盖的问题；不要重复询问。

**什么都没准备？也没问题。** 询问你正在处理的指标类别（收入、留存、效率、资本），然后从那里开始查阅。

**调用示例：** `Quick ref: burn multiple — formula, benchmark, and whether 1.7 is bad for Series B.`

## 核心概念

### 指标类别

指标分为四大类：

1. **收入与增长**——营收规模相关资金指标（收入、ARPU、ARPA、MRR/ARR、流失、NRR、扩张）
2. **单位经济效益**——客户层面的盈利能力（CAC、LTV、回收期、利润率）
3. **资本效率**——现金管理（消耗率、现金跑道、OpEx、净利润）
4. **效率比率**——增长与盈利能力之间的平衡（40 法则、魔数）

### 何时使用此技能

**在以下情况下使用：**
- 你需要快速查询公式或基准
- 你正在准备董事会会议或投资者电话会议
- 你正在评估某项决策，需要确认哪些指标最重要
- 你想快速识别危险信号

**在以下情况下不要使用：**

- 你是第一次学习这些指标（请从深度解析技能开始）
- 你需要示例和常见误区（相关技能中已有涵盖）

## 应用

### 全部指标参考表

| **指标** | **公式** | **衡量内容** | **良好基准** | **危险信号** |
|------------|-------------|----------------------|-------------------|--------------|
| **收入** | 扣除费用前的销售总额 | 获得的营收规模资金 | 同比增长率 >20%（因阶段而异） | 收入增长慢于成本增长 |
| **ARPU** | 总收入 / 总用户数 | 每位用户产生的收入 | 因模式而异；跟踪趋势 | ARPU 在连续各队列中持续下降 |
| **ARPA** | MRR / 活跃账户数 | 每个客户账户产生的收入 | SMB：$100-$1K；中端市场：$1K-$10K；企业：$10K+ | ARPA 高但 ARPU 低（席位变现不足） |
| **ACV** | 每份合同的年度经常性收入 | 年化合同价值 | SMB：$5K-$25K；中端市场：$25K-$100K；企业：$100K+ | ACV 下降（无意中转向低端市场） |
| **MRR/ARR** | MRR × 12 = ARR | 可预测的经常性收入 | 增长和质量都很重要；跟踪各组成部分 | 新增 MRR 下降，而流失保持稳定或增长 |
| **流失率** | 流失客户数 / 期初客户数 | 取消服务的客户百分比 | 月度 <2% 很好，<5% 尚可；年度 <10% 很好 | 流失率在连续各队列中持续上升 |
| **NRR** | (期初 ARR + 扩张 - 流失 - 收缩) / 期初 ARR × 100 | 收入留存与扩张 | >120% 优秀；100-120% 良好；90-100% 尚可 | NRR <100%（客户基础正在收缩） |
| **扩张收入** | 向上销售 + 交叉销售 + 使用量增长 | 来自现有客户的额外收入 | 占总收入的 20-30% | 扩张收入低于 MRR 的 10% |
| **速动比率** | (新增 MRR + 扩张 MRR) / (流失 MRR + 收缩) | 收入增长与损失之比 | >4 优秀；2-4 健康；<2 如同漏水的桶 | 速动比率 <2（如同漏水的桶） |
| **毛利率** | (收入 - COGS) / 收入 × 100 | 扣除直接成本后剩余的收入百分比 | SaaS：70-85% 良好；<60% 令人担忧 | 毛利率 <60% 或持续下降 |
| **CAC** | 销售与营销总支出 / 新客户数 | 获取一位客户的成本 | 因情况而异：企业客户 $10K+ 尚可；SMB <$500 | CAC 上升，而 LTV 持平 |
| **LTV** | ARPU × 毛利率 % / 流失率 | 一位客户带来的总收入 | 必须达到 CAC 的 3 倍以上；因客户细分而异 | LTV 在连续各队列中持续下降 |
| **LTV:CAC** | LTV / CAC | 单位经济效益效率 | 3:1 健康；<1:1 不可持续；>5:1 投资不足 | LTV:CAC <1.5:1 |
| **回收期** | CAC / (月度 ARPU × 毛利率 %) | 收回 CAC 所需的月数 | <12 个月很好；12-18 个月尚可；>24 个月令人担忧 | 回收期 >24 个月（现金陷阱） |
| **贡献毛利率** | (收入 - 所有可变成本) / 收入 × 100 | 扣除可变成本后的真实贡献 | 对 SaaS 而言，60-80% 良好；<40% 令人担忧 | 贡献毛利率 <40% |
| **消耗率** | 月度现金支出 - 收入 | 每月消耗的现金 | 早期阶段净消耗 <$200K 尚可管理；增长阶段 <$500K | 净消耗正在加速 |
| **现金跑道** | 现金余额 / 月度净消耗 | 资金耗尽前剩余的月数 | 12 个月以上良好；6-12 个月尚可；<6 个月为危机 | 现金跑道 <6 个月 |
| **OpEx** | S&M + R&D + G&A | 运营企业所需的成本 | 增长速度应慢于收入 | OpEx 增长快于收入 |
| **净利润** | 收入 - 所有费用 | 实际利润/亏损 | 早期为负尚可；成熟期利润率应达到 10-20%+ | 亏损在没有增长的情况下加速扩大 |
| **40 法则** | 收入增长率 % + 利润率 % | 增长与效率之间的平衡 | >40 健康；25-40 尚可；<25 令人担忧 | 40 法则 <25 |
| **魔数** | (本季度收入 - 上季度收入) × 4 / 上季度 S&M | S&M 效率 | >0.75 高效；0.5-0.75 尚可；<0.5 需要修复 GTM | 魔数 <0.5 |
| **经营杠杆** | 收入增长与 OpEx 增长之比 | 规模化效率 | 收入增长 > OpEx 增长 | OpEx 增长快于收入 |
| **总收入与净收入** | 净收入 = 总收入 - 折扣 - 退款 - 抵扣额 | 实际保留的收入 | 退款 <10%；折扣 <20% | 退款 >10%（产品问题） |
| **收入集中度** | 前 N 大客户收入 / 总收入 | 对最大客户的依赖程度 | 最大客户 <10%；前 10 大客户 <40% | 最大客户 >25%（生存风险） |
| **收入组合** | 产品/客户细分收入 / 总收入 | 业务组合构成 | 理想情况下，任何单一产品均不超过 60% | 单一产品 >80%（缺乏多元化） |
| **队列分析** | 按加入日期对客户分组；跟踪其行为 | 业务是在改善还是恶化 | 近期队列的表现与旧队列相同或更好 | 新队列表现更差 |
| **按渠道划分的 CAC 回收期** | CAC / 月度贡献（按渠道） | 各获客渠道的回收期 | 在不同渠道之间进行比较 | 某一渠道远差于其他渠道 |
| **按毛利计算的回收期** | CAC / (月度 ARPU × 毛利率 %) | 使用实际利润计算的回收期 | 通常是简单回收期的 1.5-2 倍 | 按毛利计算的回收期 >36 个月 |
| **单位经济效益** | 每单位收入 - 每单位成本 | 每个“单位”的盈利能力 | 必须具有正贡献 | 贡献毛利率为负 |
| **客户细分回收期** | CAC / 月度贡献（按客户细分） | 各客户细分的回收期 | 通过比较来分配资源 | 某一客户细分无法盈利 |
| **增量效应** | 行动带来的收入 - 基准收入 | 营销/促销的真实影响 | 使用留出测试进行衡量 | 为本来就会发生的收入增长庆功 |
| **营运资金** | 收入确认与款项收取之间的现金时间差 | 现金与收入的时间差 | 年度预付优于月度计费 | 过长的付款期限正在缩短现金跑道 |

### 快速决策框架

使用这些框架综合各项指标，为常见的产品经理决策提供依据。

#### 框架 1：我们应该开发此功能吗？

**需要考虑：**
1. **对收入的影响？** 是直接影响（定价、附加功能）还是间接影响（留存率、转化率）？
2. **对利润率的影响？** COGS 是多少？是否会摊薄利润率？
3. **ROI？** 收入影响 / 开发成本

**满足以下条件时开发：**
- 第一年 ROI >3x（直接变现），或者
- LTV 影响 >10x 开发成本（留存），或者
- 战略价值高于短期 ROI

**满足以下条件时不要开发：**
- 即使采用乐观的使用率预估，贡献利润率仍为负
- 回收期超过平均客户生命周期

**需要检查的指标：** 收入、毛利率、LTV、贡献利润率

---

#### 框架 2：我们应该扩大此获客渠道吗？

**需要考虑：**
1. **单位经济效益？** CAC、LTV、LTV:CAC 比率
2. **现金效率？** 回收期
3. **客户质量？** 同期群留存率、各渠道的 NRR
4. **可扩展性？** Magic Number、可触达规模

**满足以下条件时扩大：**
- LTV:CAC >3:1，并且
- 回收期 <18 个月，并且
- 客户质量达到或超过其他渠道，并且
- Magic Number >0.75

**满足以下条件时不要扩大：**
- LTV:CAC <1.5:1，并且
- 没有明确的改善路径

**需要检查的指标：** CAC、LTV、LTV:CAC、回收期、NRR、Magic Number

---

#### 框架 3：我们应该调整定价吗？

**需要考虑：**
1. **对 ARPU/ARPA 的影响？** 每位客户带来的收入是否会增加？
2. **对转化率的影响？** 会促进还是阻碍从试用到付费的转化？
3. **对流失率的影响？** 会带来流失风险，还是降低流失率？
4. **对 NRR 的影响？** 会促进扩展，还是造成收缩？

**满足以下条件时实施：**
- 考虑流失风险后，净收入影响为正
- 可先在某个细分客户群中测试，再全面推出

**满足以下条件时不要调整：**
- 流失风险高，且无法通过扩展收入抵消
- 无法在正式实施前验证假设

**需要检查的指标：** ARPU、ARPA、流失率、NRR、CAC 回收期

---

#### 框架 4：业务是否健康？

**按阶段检查：**

**早期阶段（ARR 低于 $10M）：**
- 同比增长率 >50%
- LTV:CAC >3:1
- 毛利率 >70%
- 现金可维持运营时间 >12 个月

**增长阶段（ARR 为 $10M-$50M）：**
- 同比增长率 >40%
- NRR >100%
- Rule of 40 >40
- Magic Number >0.75

**规模化阶段（ARR 为 $50M+）：**
- 同比增长率 >25%
- NRR >110%
- Rule of 40 >40
- 利润率 >10%

**需要检查的指标：** 收入增长率、NRR、LTV:CAC、Rule of 40、Magic Number、毛利率

### 各类别的危险信号

#### 收入与增长危险信号
| **危险信号** | **含义** | **行动** |
|--------------|-------------------|------------|
| 流失率逐同期群上升 | 产品与市场的契合度正在下降 | 停止扩大获客规模；优先改善留存 |
| NRR <100% | 现有客户群正在收缩 | 在扩大规模前改善扩展收入或降低流失率 |
| 收入流失率 > 客户流失率 | 正在失去大客户 | 调查高价值客户离开的原因 |
| Quick Ratio <2 | 漏桶效应（增长仅勉强超过损失） | 在扩大获客规模前改善留存 |
| 扩展收入 < MRR 的 10% | 缺乏追加销售/交叉销售引擎 | 建立扩展路径 |
| 前 10 大客户的收入占比 >50% | 存在威胁生存的依赖风险 | 实现客户群多元化 |

#### 单位经济效益危险信号
| **危险信号** | **含义** | **应对措施** |
|--------------|-------------------|------------|
| LTV:CAC <1.5:1 | 以亏损为代价购买收入 | 在扩大规模前降低 CAC 或提高 LTV |
| 回收期 >24 个月 | 现金陷阱（资金回收周期过长） | 协商年度预付款，或降低 CAC |
| 毛利率 <60% | 每一美元收入带来的利润较低 | 提高价格或降低 COGS |
| CAC 上升而 LTV 持平 | 单位经济效益恶化 | 优化转化率或缩短销售周期 |
| 贡献毛利率 <40% | 扣除可变成本后无利可图 | 削减可变成本或提高价格 |

#### 资本效率危险信号
| **危险信号** | **含义** | **应对措施** |
|--------------|-------------------|------------|
| 资金可维持时间 <6 个月 | 生存危机 | 立即融资或削减资金消耗 |
| 净资金消耗加速，但收入未增长 | 资金消耗更快，却没有产生相应成果 | 削减成本或加紧提升收入 |
| OpEx 增长快于收入 | 负经营杠杆 | 冻结招聘；优化支出 |
| 40 法则 <25 | 消耗现金却没有增长 | 改善增长，或削减开支以实现盈利 |
| 魔力数字 <0.5 | 销售与营销引擎失效 | 在扩大支出规模前修复 GTM 效率 |

### 何时使用哪项指标

**确定功能优先级：**
- 收入影响 → 收入、ARPU、扩展收入
- 利润率影响 → 毛利率、贡献毛利率
- ROI → 对 LTV 的影响、开发成本

**评估渠道：**
- 获客成本 → CAC、各渠道 CAC
- 客户价值 → LTV、各渠道 NRR
- 回收期 → 回收期、各渠道 CAC 回收期
- 可扩展性 → 魔力数字

**定价决策：**
- 变现 → ARPU、ARPA、ACV
- 影响 → 流失率、NRR、扩展收入
- 效率 → CAC 回收期（定价变更是否会对其产生影响？）

**业务健康状况：**
- 增长 → 收入增长、MRR/ARR 增长
- 留存 → 流失率、NRR、速动比率
- 经济效益 → LTV:CAC、回收期、毛利率
- 效率 → 40 法则、魔力数字、经营杠杆
- 生存能力 → 资金消耗率、资金可维持时间

**董事会/投资者报告：**
- 关键指标：ARR、收入增长率、NRR、LTV:CAC、40 法则、魔力数字、资金消耗率、资金可维持时间
- 特定阶段：早期阶段强调增长 + 单位经济效益；增长阶段强调 40 法则 + 魔力数字；规模化阶段强调盈利能力 + 效率

## 示例

### 示例 1：功能投资合理性检查

你正在决定是否构建一项高级导出功能。

1. 使用框架 1（我们是否应该构建此功能？）
2. 获取基准指标：ARPU、毛利率、LTV、贡献毛利率
3. 对乐观、基准和下行情景下的采用率进行建模
4. 如果在下行情景中贡献毛利率转为负值，则否决该功能

简要输出：
- 基准情景 ROI：3.8x
- 对贡献毛利率的影响：+4 个百分点
- 决策：立即构建，并在发布 90 天后检查流失率和扩展收入

### 示例 2：渠道扩展决策

付费社交渠道带来了大量注册用户，但留存表现较弱。

1. 使用框架 2（我们是否应该扩大此获客渠道？）
2. 检查各渠道的 CAC、LTV:CAC、回收期和 NRR
3. 与表现最佳的渠道比较，而不是与公司平均水平比较

快速输出：
- LTV:CAC：1.6:1
- 回收期：26 个月
- NRR：88%
- 决策：不要扩大规模；限制支出并开展有针对性的优化测试

## 常见误区

- 使用公司整体混合平均值，而不是按同期群或渠道划分的指标
- 在速动比率较弱且留存率持续恶化时扩大获客规模
- 认为高 LTV:CAC 已足够，而不检查回收期及其对现金跑道的影响
- 仅根据 ARPU 提升就提高价格，而不对客户流失和收入收缩进行建模
- 在公司阶段或商业模式不匹配的情况下比较基准数据
- 跟踪大量指标，却没有明确的决策问题
