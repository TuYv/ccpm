# 付费媒体优化

默认使用 `--draft`。

1. 加载最新的标准化快照、先前决策、监控结果、实验状态、转化延迟、经济性数据和平台能力清单。
2. 明确决策依据和因果证据；不要孤立地优化某个指标。
3. 比较不做更改、开展实验和执行变更等选项，包括其对学习、政策、跟踪、库存和机会成本的影响。
4. 输出按优先级排序的建议，并注明置信度和成功衡量指标。
5. 仅通过主变更关卡，将已批准的建议转换为变更计划。
6. 仅当确切操作已启用且远程状态仍与草案的前置条件一致时，才执行变更、验证、审计并保留回滚方案。

绝不能仅凭固定的 CPA 倍数、预算比例、基准或新颖性声明，就授权更改账户。

## 破坏性操作边界

拒绝永久删除广告系列、广告组、广告、受众、转化或其他账户对象。永久删除不属于受支持的变更契约范围，且无法通过确认使其变得安全。应提供可逆的替代方案：将对象保持为暂停状态、在支持的情况下归档、应用标签、导出备份，以及设定保留期限或后续复查日期。不要创建或执行删除计划。

搜索词操作需要搜索词报告、业务相关性证据和过度屏蔽审查。如果缺少这些材料，请要求提供缺失的证据，并且不要虚构或举例说明具体的否定关键词。
