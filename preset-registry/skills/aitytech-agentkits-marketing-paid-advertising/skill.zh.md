# 付费广告

跨平台的付费媒体策略与优化，实现可盈利的客户获取。

## 语言与质量标准

**关键要求**：使用与用户相同的语言回复。如果用户使用越南语，则用越南语回复；如果使用西班牙语，则用西班牙语回复。

**标准**：提高 Token 效率，为简洁可牺牲语法，最后列出尚未解决的问题。

---

## 何时使用此 Skill

以下情况应运用付费广告专业知识：
- 规划付费广告活动策略
- 优化广告表现和 ROAS
- 跨平台管理预算
- 设置跟踪与归因
- 撰写广告文案和创意简报
- 排查广告活动表现不佳的问题

## 核心概念

### 按目标划分的广告活动目标

| 目标 | 适用场景 | 主要 KPI | 平台功能 |
|-----------|----------|-------------|-------------------|
| 认知 | 建立品牌 | CPM、覆盖人数 | 品牌认知、视频观看 |
| 流量 | 推动网站访问 | CPC、CTR | 流量广告活动 |
| 互动 | 提升社交互动 | CPE、互动率 | 互动广告活动 |
| 潜在客户 | 获取联系人 | CPL、潜在客户质量 | 潜在客户表单、转化 |
| 转化 | 推动销售 | ROAS、CPA | 购买、注册事件 |
| 应用安装 | 移动端获客 | CPI、安装率 | 应用广告活动 |

### 基于漏斗的定向策略

**TOFU（认知）——冷受众**
- 宽泛兴趣定向
- 类似受众（1-3%）
- 视频观看者（3 秒以上）
- 内容：教育性、娱乐性
- 出价：CPM 或 ThruPlay

**MOFU（考虑）——温受众**
- 网站访问者（7-30 天）
- 匹配电子邮件列表的受众
- 在社交平台上互动过的受众
- 内容：案例研究、对比
- 出价：落地页浏览量

**BOFU（决策）——热受众**
- 高意向访问者（定价页、演示页）
- 购物车放弃者（1-7 天）
- 试用用户、演示申请者
- 内容：优惠、紧迫感、客户评价
- 出价：转化、ROAS

### 核心指标与基准

| 指标 | 公式 | 良好范围 | 低于标准时的措施 |
|--------|---------|------------|-----------------|
| CTR | 点击次数 / 展示次数 | 1-3% | 改进创意素材/定向 |
| CPC | 花费 / 点击次数 | <$1-5（视情况而定） | 提高质量得分 |
| CPL | 花费 / 潜在客户数 | <$20-100 | 优化落地页 |
| CPA | 花费 / 转化次数 | < LTV 的 1/3 | 全漏斗审查 |
| ROAS | 收入 / 广告花费 | 3:1+ | 提高 AOV 或 CVR |
| CVR | 转化次数 / 点击次数 | 2-5% | 优化落地页 |

### 预算分配框架

**成熟项目的 70-20-10 法则**：
- 70% 分配给经过验证且可盈利的广告活动
- 20% 分配给优化测试
- 10% 分配给新渠道/受众实验

**初创/测试阶段**：
- 在获得数据之前，平均分配给各渠道
- 每项测试的最低可行花费（$500-1000）
- 每项测试至少持续 2 周

## 最佳实践

### 卓越的广告活动设置
1. **像素/跟踪优先**：没有正确设置跟踪时绝不启动广告活动
2. **排除列表**：排除已转化用户、竞争对手和不相关受众
3. **命名约定**：使用一致且可搜索的广告活动名称
4. **UTM 规范**：在分析工具中跟踪所有广告活动

### 卓越的创意素材
1. **在 3 秒内设置钩子**：立即吸引注意力
2. **移动优先**：面向移动设备进行设计，并适配桌面设备
3. **测试不同版本**：每个广告组至少使用 3-5 个创意素材
4. **定期更新**：应对创意疲劳

### 卓越的优化
1. **让数据充分积累**：在进行重大更改前获得 50 次以上转化
2. **一次只更改一个变量**：明确哪些因素正在发挥作用
3. **每周审查节奏**：定期调整，但不要每天更改
4. **细分效果**：按受众和版位进行细分

## 应避免的反模式

| 反模式 | 错误原因 | 应改为 |
|--------------|----------------|-----------------|
| 未设置跟踪便启动 | 无法衡量成效 | 始终先设置像素 |
| 定向范围过宽 | 浪费花费 | 从窄范围开始，再逐步扩大 |
| 仅使用一个创意素材 | 无法学习，且容易产生疲劳 | 测试 3-5 个不同版本 |
| 每日更改出价 | 干扰算法 | 每周优化 |
| 忽视落地页 | 将落地页问题归咎于广告 | 优化整个漏斗 |
