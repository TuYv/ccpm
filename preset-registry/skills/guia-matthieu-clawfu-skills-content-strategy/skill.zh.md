# 内容战略——打造能够带来购买的受众群体

> 运用 Joe Pulizzi 的史诗级内容营销方法论，创建一个能够吸引受众、促进互动并实现转化的内容引擎

## 何时使用此技能

- **从零开始建立内容营销计划**，或改造现有计划
- **为你的品牌、产品或服务培养受众群体**
- **创建内容使命宣言**，使团队目标一致
- **制定编辑日历**和内容计划
- **战略性地选择内容类型和渠道**
- **衡量内容投资回报率**并向管理层证明其价值
- **摆脱营销活动思维**，实现可持续的内容运营

## 此技能的作用

此技能可帮助你打造真正有意义的内容营销——让人们在内容消失后会想念它。你不再用广告打扰人们，而是用价值吸引他们。

你将学会：

1. **明确你的内容细分领域**——在某个具体领域做到最好
2. **创建内容使命**——围绕清晰的目标统一所有工作
3. **培养你的受众群体**——让人们从访客转变为超级粉丝
4. **战略性地规划内容**——将内容映射到买家旅程
5. **持续执行**——内容取得成功的首要因素
6. **衡量真正重要的指标**——向管理层证明投资回报率

最终成果：一个能够建立信任、获取潜在客户并推动收入增长的内容引擎。

## 说明

### 史诗级内容的六大原则

每一份内容都应依据以下原则进行评估：

```
┌─────────────────────────────────────────────────────────────┐
│              THE 6 PRINCIPLES OF EPIC CONTENT               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. FILL A NEED       Useful in itself, answers questions   │
│  2. BE CONSISTENT     Same quality, same schedule, always   │
│  3. BE HUMAN          Your voice, your personality          │
│  4. HAVE A POV        Take sides, express opinions          │
│  5. AVOID SALES SPEAK Less about you = more sharing         │
│  6. BE BEST OF BREED  The best on your topic, period        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**终极检验**：如果你的内容消失了，受众会想念它吗？

### 第 1 步：定义你的内容细分领域

你的细分领域越聚焦，就越容易成为该领域的首选资源。

**不好的细分领域示例**：
- “营销”（过于宽泛）
- “小型企业建议”（过于宽泛）
- “科技新闻”（过于宽泛）

**好的细分领域示例**：
- “面向 Shopify 商店的电子邮件营销”
- “面向 SaaS 初创公司的定价策略”
- “带小型犬进行探险旅行”

**寻找你的细分领域**：

| 问题 | 你的答案 |
|----------|-------------|
| 哪个主题能让你创作 100 多篇内容？ | |
| 你的专业知识在哪些方面与受众的痛点相交？ | |
| 你的行业中哪些需求尚未得到充分满足？ | |
| 哪些领域是竞争对手尚未创作出优质内容的？ | |
| 哪个主题能让你兴致勃勃地持续创作多年？ | |

**细分领域检验**：你能切实成为该主题的第一信息来源吗？

### 第 2 步：创建你的内容使命宣言

**XYZ 方法**（Andy Crestodina）：

> “我们公司是 **[Audience X]** 获取 **[Content Y]**，从而实现 **[Benefit Z]** 的地方。”

**示例**：

| 企业 | 使命宣言 |
|----------|-------------------|
| B2B SaaS | “我们公司是初创公司创始人获取可落地的增长策略，从而在避免过度消耗的同时扩大业务规模的地方。” |
| 金融服务 | “我们公司是年轻职场人士获取实用理财建议，从而在 40 岁前积累财富的地方。” |
| 电子商务 | “我们公司是家庭厨师获取经过验证的食谱和烹饪技巧，从而做出餐厅品质菜肴的地方。” |

**使命宣言工作表**：

```markdown
## Content Mission Statement

### Audience (X)
Who are we creating content for?
- Primary persona:
- Their biggest challenge:
- What they're trying to achieve:

### Content (Y)
What type of content will we create?
- Format (blog, video, podcast, newsletter):
- Tone (educational, entertaining, inspiring):
- Depth (beginner, intermediate, expert):

### Benefit (Z)
What will they get from our content?
- Tangible outcome:
- Emotional benefit:
- Transformation:

### Final Mission Statement
"[Company] is where [Audience] finds [Content] for [Benefit]."
```

### 第 3 步：规划内容支柱

内容支柱是支撑你的使命的 3-5 个主要主题。

**框架**：

```
                 CONTENT MISSION
                       |
       ┌───────────────┼───────────────┐
       |               |               |
   PILLAR 1        PILLAR 2        PILLAR 3
       |               |               |
   ┌───┴───┐       ┌───┴───┐       ┌───┴───┐
Topics  Topics  Topics  Topics  Topics  Topics
```

**示例：SaaS 营销公司**

| 支柱 | 涵盖的主题 |
|--------|----------------|
| **增长策略** | SEO、付费广告、内容营销、电子邮件 |
| **产品策略** | 定价、定位、发布、路线图 |
| **团队建设** | 招聘、文化、远程工作、领导力 |

**内容支柱规划问题**：
1. 哪 3-5 个类别可以涵盖受众 80% 的问题？
2. 你是否在每个支柱领域都具备专业知识（或能接触到相关专家）？
3. 你能否每年为每个支柱创作 20 篇以上的内容？
4. 每个支柱是否都与你的产品/服务相关联？

### 第 4 步：将内容映射到买家旅程

不同的内容服务于不同的阶段：

| 阶段 | 买家状态 | 内容目标 | 内容类型 |
|-------|-------------|--------------|---------------|
| **认知** | “我遇到了一个问题” | 教育、吸引 | 博客文章、社交媒体、播客、视频 |
| **考虑** | “我有哪些选择？” | 培育、差异化 | 指南、网络研讨会、对比内容 |
| **决策** | “这适合我吗？” | 转化、证明价值 | 案例研究、演示、试用、评价 |
| **留存** | “我做出了正确的选择吗？” | 取悦、拓展 | 教程、社区、专属内容 |

### 第 5 步：创建编辑日历

持续性是内容成功的首要因素。编辑日历能够确保你按计划交付内容。

**最小可行日历**：

| 要素 | 说明 |
|---------|-------------|
| **发布日期** | 内容上线的时间 |
| **内容标题** | 暂定标题 |
| **内容支柱** | 它所支持的支柱 |
| **格式** | 博客、视频、播客等 |
| **目标用户画像** | 内容面向的对象 |
| **买家阶段** | 认知、考虑、决策 |
| **作者/负责人** | 负责人员 |
| **状态** | 构思、草稿、审核、已排期、已发布 |

**发布频率建议**：

| 渠道 | 最低频率 | 理想频率 |
|---------|-------------------|-----------------|
| 博客 | 每周 1 次 | 每周 2-4 次 |
| 新闻简报 | 每周 1 次 | 每周 1-2 次 |
| 播客 | 每周 1 次 | 每周 1 次 |
| YouTube | 每周 1 次 | 每周 2 次 |
| LinkedIn | 每周 3 次 | 每天 |

**警告**：不要承诺超出你持续执行能力的工作量。持续性 > 频率。

### 第 6 步：构建订阅者层级

推动你的受众沿着金字塔逐级向上：

```
                    SUPERFANS
                   /         \
                  /  Advocates \
                 /   Share your  \
                /    content      \
               /___________________\
                   SUBSCRIBERS
                  /             \
                 / Email list,   \
                /  direct access  \
               /___________________\
                    FOLLOWERS
                   /           \
                  / Social media \
                 /  low engagement\
                /__________________\
                 CASUAL VISITORS
                /                 \
               / One-time readers  \
              /_____________________|
```

**推动人们向上晋级**：

| 层级 | 晋级策略 |
|-------|------------------|
| 访客 → 关注者 | 引导关注社交媒体的 CTA、易于分享的内容 |
| 关注者 → 订阅者 | 潜在客户诱饵、独家内容、新闻简报价值 |
| 订阅者 → 超级粉丝 | 社区、认可、内部访问权限、卓越价值 |

**关键指标**：每月跟踪各层级之间的转化率。

---

### 第 7 步：衡量真正重要的指标

**三因素评分法**（Jessica Bergmann，Salesforce）：
1. 你是否吸引了正确的受众？
2. 你是否让他们持续参与？
3. 你是否推动他们采取了下一步行动？

**高管层关心什么**：

| 问题 | 如何衡量 |
|----------|----------------|
| 内容是否在推动销售？ | 销售提升分析、归因收入 |
| 内容是否在节省成本？ | 客服工单减少量、自助服务使用量 |
| 内容是否有助于提高留存率？ | 内容消费者的 NPS 分数、续订率 |
| 内容是否在壮大我们的社区？ | 订阅者增长、参与度趋势 |

**内容指标框架**：

| 层级 | 指标 | 目的 |
|-------|---------|---------|
| **消费** | 页面浏览量、下载量、收听量 | 人们能找到它吗？ |
| **参与** | 页面停留时间、滚动深度、评论 | 他们在消费这些内容吗？ |
| **分享** | 社交分享、转发、推荐 | 他们在传播这些内容吗？ |
| **潜在客户生成** | 邮箱注册、表单填写 | 他们在转化吗？ |
| **销售** | 受影响的销售管道、归因收入 | 它是否在推动业务？ |

## 示例

### 示例 1：B2B SaaS 内容策略

**公司**：面向代理机构的项目管理软件

**内容使命**：
> “AgencyFlow 是创意代理机构所有者获取运营洞见、开展利润更高的项目的地方。”

**内容支柱**：
1. 项目管理最佳实践
2. 代理机构盈利能力与定价
3. 团队与资源管理
4. 客户沟通

**编辑日历（每月）**：
- 8 篇博客文章（每个支柱 2 篇）
- 4 期新闻简报
- 2 个案例研究
- 1 场网络研讨会
- 12 篇 LinkedIn 帖子

**衡量指标**：
- 主要指标：邮箱订阅者（目标：每月 500 人）
- 次要指标：由内容带来的演示申请（目标：每月 50 个）
- 第三级指标：内容潜在客户从 MQL 到 SQL 的转化率

---

### 示例 2：电子商务内容策略

**公司**：高端炊具品牌

**内容使命**：
> “ChefGear 是家庭厨师获取经过验证的烹饪技巧、在自家厨房制作餐厅品质菜肴的地方。”

**内容支柱**：
1. 烹饪技巧与技能
2. 食材深度解析
3. 食谱开发
4. 厨房设备指南

**渠道策略**：
- YouTube（主要渠道）：每周 2 个视频
- 博客：每周 3 篇文章（以 SEO 为重点）
- Instagram：每日帖子 + 快拍
- 电子邮件：每周食谱通讯

**衡量指标**：
- 主要指标：YouTube 订阅者和电子邮件列表增长
- 次要指标：自然流量和食谱页面转化
- 第三级指标：内容归因购买产生的收入

## Skill 边界

### 此 Skill 擅长的方面
- 构建音频制作工作流
- 提供技术指导
- 创建质量检查清单
- 提出创意方法建议

### 此 Skill 无法做到的事情
- 取代音频工程专业知识
- 代替用户做出主观的创意决策
- 直接访问或编辑音频文件
- 保证商业成功
