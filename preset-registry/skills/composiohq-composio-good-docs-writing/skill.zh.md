# 优秀文档写作

按照 Modal 的方式撰写文档：直接、友好、自信，并且毫不妥协地注重实用。用一句话解释_为什么_，然后展示可运行的代码。把读者视为想要交付成果的有能力的开发者，而不是需要听课的学生。

阅读 `references/style-guide.md` 以了解完整的规则集（语气、结构、术语、标点、代码示例、格式），并在起草时应用每一条规则。

在打开参考文件之前，你最需要关注以下规则：

- 使用“你”称呼读者，绝不要使用“用户”或“人们”。
- 第一句话就说明概念或好处。不要铺垫。
- 在靠近开头的位置放置一个最小可运行示例，然后解释刚刚发生了什么。
- 删除所有长破折号。改用句号、逗号、冒号或括号。
- 删掉含糊的程度修饰词（“无缝地”“强大的”“健壮的”“尖端的”）。通过实际展示来体现某件事很容易，而不是直接说它很容易。
- 为每个代码标识符、命令、参数、路径和文件名添加反引号。

如果要按照这些规则审查现有文稿，而不是起草新文稿，请使用 `good-docs-audit`。
