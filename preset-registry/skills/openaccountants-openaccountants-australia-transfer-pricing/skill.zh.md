## 第 2 节——文档要求

### 2.1 一般文档（所有纳税人）

| 项目 | 详情 |
|---|---|
| 是否要求？ | 是——所有存在国际关联方交易的纳税人均须保存能够证明符合独立交易条件的记录 |
| 时间要求 | 同期资料——在提交所得税申报表之前编制 |
| 与处罚的关系 | 如果没有同期文档，则无法确立“合理可争辩的立场”（RAP） |

### 2.2 三层文档（重大跨国实体）

适用于合并年度全球收入 ≥ AUD 10 亿的集团内实体：

| 文档 | 详情 |
|---|---|
| 主体文档 | 采用 OECD 附件 I 格式；以电子方式提交 |
| 本地文档 | 澳大利亚特定格式（交易规模较小时可采用简表） |
| 国别报告 | 采用 OECD 附件 III 格式 |
| 提交截止日期 | 所得年度结束后 12 个月内 |
| 提交方式 | 以电子方式向 ATO 提交 |

### 2.3 国际交易附表（IDS）

| 项目 | 详情 |
|---|---|
| 是否要求？ | 是，适用于所有存在重大国际关联方交易的纳税人 |
| 提交 | 每年随公司所得税申报表一并提交 |
| 内容 | 关联方交易、所用方法及文档状态的摘要 |

### 2.4 简式本地文档

适用于达到 AUD 10 亿门槛，但国际关联方交易风险较低或金额较小的实体。

## 第 3 节——独立交易原则

### 3.1 定义

第 815-B 分部：如果实体之间的国际交易条件不同于独立交易条件，且某一实体获得了“转让定价利益”，则应调整应税所得，以反映独立交易条件。

### 3.2 可接受的方法

| 方法 | 是否接受 |
|---|---|
| 可比非受控价格法（CUP） | 是 |
| 再销售价格法（RPM） | 是 |
| 成本加成法（CPM） | 是 |
| 交易净利润法（TNMM） | 是 |
| 利润分割法（PSM） | 是 |
| 其他可靠方法 | 是（方法选择具有灵活性） |

### 3.3 首选方法

不存在法定的方法层级。ATO 遵循 OECD 的“最适当方法”原则。在存在可靠可比对象的情况下，优先采用 CUP。

### 3.4 自我评估

澳大利亚实行自我评估制度——纳税人必须在未事先获得 ATO 批准的情况下，自行确定并适用独立交易条件。

## 第 5 节——截止日期

| 项目 | 截止日期 |
|---|---|
| 转让定价文档准备 | 提交所得税申报表之前 |
| IDS 申报 | 随所得税申报表一并提交（因实体类型而异；大型实体通常为 1 月 15 日） |
| 主体文档/本地文档/国别报告 | 所得年度结束后 12 个月 |
| 所得税申报表（公司） | 通常应在次年 1 月 15 日前提交（适用于 6 月 30 日年末），可申请延期 |

## 第 6 节——处罚

### 6.1 转让定价税款少缴处罚

| 情形 | 处罚比例 |
|---|---|
| 已确立合理可争辩立场（RAP） | 不予处罚 |
| 无 RAP，且不存在主要避税目的 | 少缴税款的 25% |
| 无 RAP，且存在主要避税目的 | 少缴税款的 50% |
| 重复行为加重处罚 | 额外加收 20% |
| SGE 倍增处罚 | 对 SGEs 的处罚加倍 |

### 6.2 文档的影响

如果未在提交申报表之前准备同期转让定价文档，纳税人将被**依法认定为不具备**合理可争辩立场。

### 6.3 未按时提交（SGEs）

| 违规行为 | 处罚 |
|---|---|
| 未提交本地文档、主体文档或国别报告 | 每次违规最高罚款 AUD 825,000 |
| 少缴税款利息费用 | 适用于未足额缴纳的税款 |

## 第 7 节——预约定价安排（APA）

| 项目 | 详情 |
|---|---|
| 是否提供 | 是（已有成熟完善的制度） |
| 类型 | 单边、双边、多边 |
| 适用指引 | TR 95/23；实务合规指南 PCG 2019/1 |
| 申请 | 向 ATO 提交；先提交意向书，然后提交正式申请 |
| 期限 | 通常前瞻适用 3-5 年；可追溯适用 |
| 费用 | 无正式收费 |
| 处理时间 | 12-24 个月（双边安排可能需要更长时间） |
| 年度合规报告 | 必须提交 |
| 关键假设 | APA 受关键假设约束；不合规可能导致其被撤销 |

## 第 8 节——安全港

| 领域 | 详情 |
|---|---|
| 低价值集团内部服务 | 接受加成方法（按照 OECD 简化方法采用 5% 成本加成） |
| 低额入境/出境贷款 | 提供利率安全港（PCG 指引） |
| 小型纳税人（营业额 < AUD 50m） | 低风险交易可适用简化文档要求 |
| 关联方交易有限的分销商 | 基于重要性的简化措施 |
| 管理/技术服务 | 基于门槛的简化措施 |

ATO 发布《实务合规指南》，说明各种交易类型的风险区域。
