## 第 2 节 -- 分类规则

### 2.1 租金收入

所有租金总收入均属于应税收入。在个人所得税申报表的第 21 项（租金）中申报。

| 收入类型 | 处理方式 |
|---|---|
| 从租户处收取的租金 | 应税 -- 已收取或应收取的全部金额 |
| 被没收的押金（因损坏而留存） | 在留存年度计入应税收入 |
| 保险赔款（租金损失） | 应税 |
| 租户偿付的款项（超额水电费） | 应税 |
| 额外租赁费 / 租赁权利金 | 应税 |

### 2.2 负扣税安排

如果扣除总额超过租金总收入，出租净亏损可抵减其他应税收入（工资、经营收入）。对于现有或新购房产，负扣税安排均无金额上限（依据截至 2025 年的法律）。

### 2.3 可立即扣除的费用

| 费用 | 税务处理 | 备注 |
|---|---|---|
| 投资贷款利息 | 可扣除 | 必须追溯贷款用途，证明其用于出租物业 |
| 市政费 | 可扣除 | 如部分用于私人用途，则须按比例分摊 |
| 水费 / 相关收费 | 可扣除 | |
| 业主委员会 / 分契物业费用 | 可扣除 | 包括行政基金和偿债基金缴款 |
| 土地税 | 可扣除 | |
| 物业管理费 | 可扣除 | 中介佣金、招租费用 |
| 保险（房东险、建筑险、屋内财物险） | 可扣除 | |
| 招租广告费 | 可扣除 | |
| 害虫防治费 | 可扣除 | |
| 园艺 / 草坪修剪费（如向租户提供） | 可扣除 | |
| 税务代理费（出租物业明细部分） | 可扣除 | |
| 前往物业的差旅费（自 2017 年 7 月 1 日起取消） | 不可扣除 | 除非经营出租物业业务 |

### 2.4 维修与改良（TR 97/23）

| 特征 | 维修（立即扣除） | 改良（资本化） |
|---|---|---|
| 恢复至原始状态 | 是 | 否 |
| 使用基本相同的材料进行更换 | 是 | 否——质量更好或性质不同 |
| 购置时进行的初始维修 | 不可扣除（资本性支出） | 资本性支出——计入成本基础 |
| 更换整个结构（例如完整屋顶） | 资本性支出（整体更换） | 资本性支出 |
| 示例：修补开裂的瓷砖 | 维修 | -- |
| 示例：将所有瓷砖更换为石材 | -- | 改良 |
| 示例：使用相同型号更换损坏的水龙头 | 维修 | -- |
| 示例：全面翻新厨房 | -- | 改良 |

### 2.5 第 40 部分——设备与器材折旧

适用于物业内可拆卸或机械类资产。

| 资产 | 有效寿命（ATO） | 折旧方法 |
|---|---|---|
| 热水系统 | 12 年 | 余额递减法或直线法 |
| 地毯 | 8 年 | 任一种 |
| 百叶窗 / 窗帘 | 8 年 | 任一种 |
| 烤箱 / 炉灶 | 12 年 | 任一种 |
| 空调（分体式系统） | 10 年 | 任一种 |
| 洗碗机 | 8 年 | 任一种 |
| 烟雾报警器 | 6 年 | 任一种 |
| 吊扇 | 10 年 | 任一种 |

**余额递减法折旧率：** 200% ÷ 有效寿命
**直线法折旧率：** 100% ÷ 有效寿命

**限制（自 2017 年 7 月 1 日起）：** 对于住宅出租物业，只有首位所有者（或最初安装全新资产的实体）才能申报第 40 部分扣除。后续所有者不得对现有资产申报设备与器材折旧——对于先前使用过的物品，其承继的可折旧价值为零（除非适用例外情况，例如由新所有者进行翻新）。

### 2.6 第 43 部分——资本工程扣除

适用于结构性部分（建筑物本身及固定改良设施）。

| 建造日期 | 税率 | 备注 |
|---|---|---|
| 1985 年 7 月 18 日之前 | 0% | 不可扣除 |
| 1985 年 7 月 18 日至 1987 年 9 月 15 日 | 4% | 住宅 / 非住宅 |
| 1987 年 9 月 15 日之后（住宅） | 2.5% | 分 40 年摊销 |
| 1987 年 9 月 15 日之后（短期旅客住宿） | 4% | 特定住宿设施 |

**计算基础：** 原始建造成本（从工料测量师报告或建筑商记录中获取），而非物业的购买价格。

**尚未扣除的建筑成本**会在出售时转移给新业主——新业主可继续按剩余尚未扣除金额的 2.5% 进行扣除。

### 2.7 利息的可扣除性

贷款必须与产生租金收入存在明确关联。主要规则如下：

| 情形 | 是否可扣除？ |
|---|---|
| 用于购买出租物业的贷款 | 是——利息可全额扣除 |
| 用于翻新出租物业的贷款 | 是——利息可全额扣除 |
| 再融资贷款（用途相同，金额相同或更低） | 是 |
| 重新提取贷款用于个人用途 | 否——需按比例分摊 |
| 信用额度（混合用途） | 必须追踪每笔提款 |
| 物业空置期间的贷款利息（可供出租） | 是 |
| 建造期间的利息 | 从物业可供出租之日起可扣除（或资本化计入成本基础） |

### 2.8 处置时的 CGT

| 要素 | 处理方式 |
|---|---|
| 成本基础 | 购买价格 + 印花税 + 法律费用 + 资本性改良支出 - 已申报的 Div 43 扣除额 |
| 资本所得 | 出售价格 - 中介佣金 - 出售时的法律费用 |
| 净资本利得 | 所得 - 成本基础 |
| 50% CGT 折扣 | 持有满 12 个月或以上时可享受（仅限个人/信托） |
| 主要住所豁免（部分） | 如果该物业在部分持有期间曾作为主要住所，则可享受 |
| 6 年离住所规则 | 如果未将其他住所申报为主要住所，则离开后最长 6 年仍可视为主要住所 |
| 非居民 | 不享受 50% 折扣（自 2012 年 5 月 8 日起，适用于该日期之后产生的利得） |

### 2.9 非居民租金预扣税

| 规则 | 详情 |
|---|---|
| 适用于 | 获得澳大利亚租金收入的非居民房东 |
| 税率 | 付款方（租户/中介）必须按照 ATO 的指示预扣相应金额 |
| FRCGW（外国居民资本利得预扣税） | 如果物业价值 ≥ $750,000，则按出售价格的 12.5% 预扣（由买方预扣） |
| 完税证明 | 居民卖方需取得该证明，以避免在交割时被预扣 FRCGW |

| PERSONAL USE period expenses | 按比例分摊 | 仅扣除用于出租部分的费用 |

## 第 4 节 -- 计算方法

### 第 1 步：租金总收入
汇总该财政年度内所有应税租金收入。

### 第 2 步：即时扣除
汇总所有允许扣除的费用（利息、政府收费、保险、管理费、维修费、物业管理费等）。

### 第 3 步：折旧（Div 40 + Div 43）
加上资本工程扣除额（建筑成本的 2.5%）和设备折旧额（依据 ATO 有效使用年限表）。

### 第 4 步：租金净收入／亏损
总收入 − 扣除额 − 折旧额 = 租金净收入（如果采用负扣税，则为亏损）。

### 第 5 步：在纳税申报表中申报
正数：计入应税收入，并按边际税率纳税。
负数：按等额方式抵扣其他应税收入（工资、经营收入）。

## 第 6 节 -- 边界情况

### 6.1 房产空置

只有在房产确实可供出租（已发布出租广告，且未限制可出租时间）的情况下，空置期间的费用才可扣除。如果房产未投放市场（例如预留作个人用途或度假用途），则该期间的费用不得扣除。

### 6.2 部分年度出租／部分私人使用

所有费用均按时间比例分摊（出租或可供出租的天数 ÷ 365）。如果房产全年均可供出租，即使期间空置，利息仍可全额扣除。

### 6.3 度假住宅

如果房产以低于市场的价格出租、仅限于度假期间出租，或以优惠价格出租给亲属，则扣除额仅限于所收取的收入（不得进行负扣税）。ATO 会严格审查度假住宅出租情况。

### 6.4 分割与开发

如果出租房产被分割，当纳税人具有营利意图时，出售分割后地块所获得的利润可能属于普通收入（而非 CGT）。应上报给专家处理。

### 6.5 遗产

出租房产通过遗产进行转移时：在房产转让给受益人之前，法定遗产代理人（LPR）应在遗产纳税申报表中申报租金收入。CGT 将递延至受益人处置该房产时。

## 第 7 节——禁止事项

- 绝不得将前往住宅出租房产的差旅费用申报为扣除项（自 2017 年 7 月 1 日起，不再适用于非经营性房东）
- 绝不得为住宅房产的后续所有者申报 Div 40 设备折旧（2017 年之后的规则），除非该资产由该所有者新安装
- 在没有建筑成本证据（工料测量师报告或原始建筑商记录）的情况下，绝不得申报 Div 43
- 绝不得扣除贷款本金还款
- 对于与实际私人使用期间相关的费用，未经分摊，绝不得扣除
- 绝不得为非居民个人申报 CGT 50% 折扣
- 处置房产时，绝不得从成本基础中遗漏之前的 Div 43 扣除额（该扣除额会降低成本基础）
- 绝不得将税务计算结果表述为确定数值——始终将其标注为估算值
