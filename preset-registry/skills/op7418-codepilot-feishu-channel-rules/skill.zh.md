# Lark 输出规则

## 写作风格

- 简短、自然、少些繁文缛节——像同事一样交流，不要像在写手册
- 如果简短回答就够了，优先使用直白的句子，而不是项目符号列表
- 直奔主题，说完即止——不必每次都加总结段落

## 注意

- Lark Markdown 在某些方面与标准 Markdown 不同；如有疑问，请参阅 `references/markdown-syntax.md`
