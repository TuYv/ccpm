## 评估当前布局

分析当前空间设计的薄弱之处：

1. **间距**：
   - 间距是一致的还是随意的？（随机的内边距/外边距值）
   - 所有间距是否都相同？（所有位置使用相同的内边距 = 缺乏节奏）
   - 相关元素是否紧密分组，而各组之间留有充足空间？

2. **视觉层级**：
   - 进行眯眼测试：将你的眼睛（比喻意义上）模糊起来——你是否仍能识别最重要的元素、第二重要的元素以及清晰的分组？
   - 是否有效地建立了层级？（仅靠空间和字重就可能足够——但当前方式是否奏效？）
   - 留白是否能引导视线关注重要内容？

3. **网格与结构**：
   - 是否存在清晰的底层结构，还是布局给人随机拼凑的感觉？
   - 是否到处都使用相同的卡片网格？（图标 + 标题 + 文本，无休止地重复）
   - 所有内容是否都居中对齐？（左对齐配合非对称布局通常更有设计感，但这并非绝对规则）

4. **节奏与变化**：
   - 布局是否具有视觉节奏？（紧凑与宽松的间距交替出现）
   - 每个区块的结构是否都完全相同？（单调的重复）
   - 是否有经过刻意设计的惊喜或强调时刻？

5. **密度**：
   - 布局是否过于拥挤？（缺乏足够的呼吸空间）
   - 布局是否过于稀疏？（留白过多且没有明确目的）
   - 密度是否符合内容类型？（数据密集型 UI 需要更紧凑的间距；营销页面则需要更多留白）

**关键要求**：即使颜色和字体没有问题，布局问题也往往是界面让人感觉“不对劲”的根本原因。空间是一种设计材料——应有意识地使用它。

## 规划布局改进

查阅 impeccable skill 中的[空间设计参考](reference/spatial-design.md)，获取关于网格、节奏和容器查询的详细指导。

制定系统化计划：

- **间距系统**：使用一致的比例体系——无论是框架的内置比例（例如 Tailwind）、基于 rem 的令牌，还是自定义系统。具体数值不如一致性重要。
- **层级策略**：如何通过空间传达重要性？
- **布局方式**：哪种结构适合当前内容？一维布局使用 Flex，二维布局使用 Grid，复杂页面布局使用命名区域。
- **节奏**：哪些位置的间距应该紧凑，哪些位置应该宽松？

## 系统化地改进布局

### 建立间距系统

- 使用一致的间距比例——框架比例（Tailwind 等）、基于 rem 的令牌或自定义比例均可。重要的是所有值都来自一个明确的集合，而不是任意数字。
- 如果使用自定义属性，请按语义命名令牌：使用 `--space-xs` 到 `--space-xl`，而不是 `--spacing-8`
- 使用 `gap` 设置同级元素之间的间距，而不是使用外边距——这样可以避免处理外边距折叠的变通方案
- 使用 `clamp()` 实现流式间距，使布局在更大的屏幕上拥有更充足的呼吸空间

### 营造视觉节奏

- 对相关元素进行**紧密分组**（同级元素之间间距为 8-12px）
- 在不同区块之间进行**宽松分隔**（间距为 48-96px）
- 区块内部使用**有变化的间距**——并非每一行都需要相同的间距
- 采用**非对称构图**——在适当情况下，打破可预测的内容居中模式

### 选择合适的布局工具

- **使用 Flexbox 处理一维布局**：项目行、导航栏、按钮组、卡片内容以及大多数组件内部布局。对于大多数布局任务，Flexbox 更简单，也更合适。
- **使用 Grid 处理二维布局**：页面级结构、仪表盘、数据密集型界面，以及任何需要协同控制行和列的场景。
- 当使用带有 `flex-wrap` 的 Flexbox 更简单、更灵活时，**不要默认使用 Grid**。
- 使用 `repeat(auto-fit, minmax(280px, 1fr))` 创建无需断点的响应式网格。
- 对于复杂的页面布局，使用命名网格区域（`grid-template-areas`）——在断点处重新定义。

### 打破卡片网格的单调感

- 不要默认对所有内容使用卡片网格——间距和对齐本身就能自然形成视觉分组
- 仅当内容确实彼此独立且可操作时才使用卡片——绝不要在卡片内嵌套卡片
- 改变卡片尺寸、让卡片跨列，或混合使用卡片与非卡片内容，以打破重复感

### 强化视觉层级

- 使用尽可能少的维度来建立清晰的层级。仅靠空间就可能足够——元素周围充足的留白能够吸引视线。一些最精致的设计仅通过空间和字重就能形成节奏。只有当更简单的方式不足以实现效果时，才添加颜色或尺寸对比。
- 注意阅读动线——在 LTR 语言中，视线通常会自然地从左上方扫向右下方，但主要操作的位置取决于具体情境（例如，对话框中位于右下方，导航中位于顶部）。
- 通过邻近与分隔建立清晰的内容分组。

### 管理深度与层级

- 创建语义化的 z-index 层级体系（下拉菜单 → 吸顶元素 → 模态框背景层 → 模态框 → 提示消息 → 工具提示）
- 构建一致的阴影层级（sm → md → lg → xl）——阴影应当保持微妙
- 使用层级高度来强化层次，而不是将其作为装饰

### 视觉校正

- 如果图标尽管在几何上居中，但视觉上看起来偏离中心，可以对其进行微调——但前提是你确信它确实看起来不正确。不要凭猜测进行调整。

**绝不要**：
- 使用间距尺度之外的任意间距值
- 让所有间距都相等——变化能够建立层级
- 把所有内容都包裹在卡片中——并非所有内容都需要容器
- 在卡片内嵌套卡片——应使用间距和分隔线来建立内部层级
- 到处使用完全相同的卡片网格（图标 + 标题 + 文本，反复重复）
- 将所有内容都居中——左对齐和非对称布局更具设计感
- 默认将主视觉指标布局（大号数字、小号标签、统计数据、渐变）用作模板。如果展示的是真实用户数据，突出显示某项指标是可行的——但它应展示实际数据，而不是装饰性数字。
- 当 Flexbox 更简单时默认使用 CSS Grid——针对具体任务选择最简单的工具
- 使用任意的 z-index 值（999、9999）——应构建语义化的层级体系

## 验证布局改进

- **眯眼测试**：在视线模糊的情况下，你能否辨识主要内容、次要内容及内容分组？
- **节奏**：页面中紧凑与宽松的间距是否形成了令人舒适的节奏？
- **层级**：能否在 2 秒内明显看出最重要的内容？
- **留白**：布局是否舒适，既不拥挤，也不浪费空间？
- **一致性**：间距系统是否得到统一应用？
- **响应式**：布局能否在不同屏幕尺寸下自然适配？

请记住：空间是最未被充分利用的设计工具。拥有恰当节奏和层级的布局，即使内容简单，也能呈现出精致且经过用心设计的效果。
