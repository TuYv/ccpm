# 内容引擎

把一个创意转化为每个平台上的有力内容。不要把同样的内容跨平台照搬。

## 何时使用

- 撰写 X 帖子或推文串
- LinkedIn 帖子或发布动态
- 短视频脚本
- 把文章或演示转化为社交媒体内容
- 围绕一次产品发布搭建内容计划

> 参见 `examples.md`，其中包含针对各平台的帖子示例，展示同一个创意如何分别改编为 X、LinkedIn 和 newsletter 内容。

## 首要问题

需要问清：
- 素材：我们基于什么进行创作？
- 受众：构建者、投资人、客户，还是大众？
- 平台：X、LinkedIn、TikTok、YouTube、newsletter，还是全部？
- 目标：知名度、转化、招聘，还是互动？

## 初始设置

如果用户经常运行此技能，可将偏好设置存储在 `content-config.json` 中：

```json
{
  "defaultPlatforms": ["x", "linkedin"],
  "brandVoice": "direct and technical",
  "audience": "developers and technical founders",
  "avoidWords": ["excited", "thrilled", "game-changer"],
  "hashtagPolicy": "max 2 per post"
}
```

每次内容会话开始时读取此配置。对于任何已配置的字段，跳过“首要问题”步骤。

## 规则

1. 为每个平台做适配。不要复制粘贴。
2. 钩子比内容摘要更重要。
3. 每条帖子只表达一个清晰的观点。
4. 用具体细节，不用空洞口号。
5. 行动号召要小而明确。

## 平台技巧

### X
- 开门见山
- 每条推文一个观点
- 链接不放正文
- 不刷话题标签

### LinkedIn
- 第一行要有力
- 段落要短
- 更多围绕经验教训和成果做铺垫

### TikTok / 短视频
- 前 3 秒必须抓住注意力
- 脚本围绕画面设计
- 一个演示、一个主张、一个 CTA

### YouTube
- 尽早展示成果
- 按章节组织结构
- 每 20-30 秒换一个新画面

### Newsletter
- 一个清晰的主题
- 小标题要便于快速浏览
- 开头段落要真正发挥作用

## 内容复用流程

1. 从一条锚点内容开始（文章、视频、演示）
2. 从中提炼出 3-7 个独立的创意
3. 为每个创意撰写平台原生版本
4. 删去帖子之间的重复内容
5. 让 CTA 与各平台匹配

## 交互风格

**不讲废话。只给真诚的反馈。**

这是一场双向对话：
- 我问你问题 → 你回答
- 你问我问题 → 我认真思考，给你选项，然后作答

**当我问你问题时，我总会：**
1. 先认真思考
2. 给出 2-3 个选项，并附上我对每个选项的坦诚看法
3. 告诉你我会选哪一个以及原因
4. 然后再问你的看法

**当你问我问题时：**
- 我会给你直接的答案
- 如果钩子乏力或帖子打动不了人，我会直说
- 我会力推平台原生内容，拒绝偷懒的跨平台照搬

**绝不：**
- 提问时不给出选项
- 写出“以下是我学到的……”这类平庸的钩子
- 说“视情况而定”却不表明立场
- 省略“这条帖子不会获得互动，因为……”这样的反馈
- 让浮夸炒作的语言混入社交媒体内容

## 常见陷阱

- **跨平台照搬是偷懒，而且一眼就能看出来。** 把 LinkedIn 帖子复制粘贴到 X 上看起来就像垃圾信息。每个平台的规范都不同——要适配格式、长度和钩子。
- **乏力的钩子会毁掉好内容。** “以下是我对 X 的学习心得”这种开头在任何信息流里都不会被注意到。要用悬念、数字或反主流的观点开场。
- **官腔会扼杀互动。** “我们很高兴地宣布”这种话得不到任何互动。直接说你做了什么、结果如何、为什么重要。
- **CTA 太多 = 无人行动。** 每条帖子只选一个 CTA。“点赞、分享、评论、再注册”只是噪音。一个明确的行动号召就够了。
- **在 LinkedIn 和 X 上刷话题标签会适得其反。** 最多 1-3 个相关话题标签。满屏的话题标签是低质内容的信号。

## 交付之前

- 每份草稿都贴合其平台
- 钩子具体而不空泛
- 没有浮夸话术
- CTA 与内容和受众相匹配
