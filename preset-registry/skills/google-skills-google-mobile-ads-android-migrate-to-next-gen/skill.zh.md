# Google 移动广告 SDK 的 AI 迁移代理说明

## 迁移工作流

使用此检查清单跟踪迁移进度：

*   **配置 Gradle**：
    -   [ ] 将 `com.google.android.gms:play-services-ads` 替换为
        `com.google.android.libraries.ads.mobile.sdk:ads-mobile-sdk` 的最新稳定版本。如果无法直接访问 Maven，请运行以下命令获取最新版本。`latest` 标签中返回的版本即为 GMA 新一代 SDK 的最新版本：

        ```bash
        curl -sS https://dl.google.com/dl/android/maven2/com/google/android/libraries/ads/mobile/sdk/ads-mobile-sdk/maven-metadata.xml | sed -n 's/.*<latest>\(.*\)<\/latest>.*/\1/p'
        ```

    -   [ ] 更新 `minSdk`（24+）和 `compileSdk`（34+）。
    -   [ ] 在应用级构建文件中，从所有依赖项中全局排除 `play-services-ads` 和 `play-services-ads-lite`，以避免重复符号错误。
    -   [ ] 同步 Gradle，然后再继续下一步。
*   **逐文件迁移**：
    -   [ ] 按照 API 映射和方法映射表重构代码库，将导入、类名和方法签名迁移到 GMA 新一代 SDK。
*   **验证并构建**：
    -   [ ] 运行 `gradle build -x test`，确认能够成功完成干净构建。解决所有与 GMA SDK 相关的编译错误。

## 核心迁移规则

*   **应用 ID 的使用**：对于 `InitializationConfig` 中的 `applicationId`，**始终**使用 `AndroidManifest.xml` 中 `com.google.android.gms.ads.APPLICATION_ID` 元数据标签的值。
    *   *约束*：保留清单中的 `<meta-data>` 标签；使用 User Messaging Platform SDK 的发布商仍然需要该标签。
*   **初始化顺序**：
    1.  在后台线程中调用 `MobileAds.initialize()`。
    2.  确保在调用任何其他 SDK 方法**之前**调用 `initialize()`。
    3.  如果使用 `RequestConfiguration`，请通过 `InitializationConfig.Builder.setRequestConfiguration()` 将其包含在配置中。**不要**在初始化之前调用 `MobileAds.setRequestConfiguration()`。
*   **UI 线程处理**：**强制要求**：GMA 新一代 SDK 中的回调会在后台线程上调用。在 GMA SDK 回调中，**所有与 UI 相关的操作**（例如 Toast、View 更新、Fragment 事务）**必须**封装在 `runOnUiThread {}` 或 `Dispatchers.Main.launch {}` 中。跳过此步骤将导致应用崩溃。
*   **中介**：实现 `com.google.android.gms.ads.mediation.Adapter` 的类必须继续使用 `com.google.android.gms.ads`。

## 各广告格式的具体要求

### 横幅广告

*   使用 `com.google.android.libraries.ads.mobile.sdk.banner.AdView` 加载 GMA 新一代 SDK 横幅广告。
*   以下 API 用于检查横幅广告是否可折叠：
    `adView.getBannerAd().isCollapsible()`。

### 原生广告

*   **NativeAdLoader**：`NativeAdLoader` 是抽象类，无法实例化。它以静态方式使用（例如 `NativeAdLoader.load(...)`）。
*   以下 API 现在通过 `NativeAdRequest.Builder` 设置：
    *   `.setCustomFormatIds(customFormatIds: List<String>)`
    *   `.disableImageDownloading()`
    *   `.setMediaAspectRatio(mediaAspectRatio: NativeMediaAspectRatio)`
    *   `.setAdChoicesPlacement(adChoicesPlacement: AdChoicesPlacement)`
    *   `.setVideoOptions(videoOptions: VideoOptions)`
*   **移除**：删除所有“将此广告静音”逻辑；GMA 新一代 SDK 不支持此功能。
*   **MediaView**：`NativeAd` 不再具有直接的 `mediaView` 变量；请使用 `registerNativeAd(nativeAd, mediaView)` 将广告与视图关联。

### 广告预加载

*   除非映射表中另有说明，否则 GMA Next-Gen SDK 中的广告预加载方法与旧版 SDK
    保持相同的 API 签名和参数。
