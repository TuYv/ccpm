此技能有助于为给定的单词或短语生成同义词和替代表达。它会提供符合语境的替代表达，以丰富词汇并提高写作的多样性。

用户会提供需要同义词建议的单词、短语或句子。他们可能会指定所需的语境、语气或正式程度。

## 同义词生成指南

生成同义词时，请考虑：

- **语境**：该词所使用的具体领域或情境
- **语气**：正式、非正式、中性、学术、会话等
- **细微差别**：相似词语在含义上的细微差异
- **语域**：适合目标受众的正式程度

## 输出格式

对于每个输入的单词或短语，提供：

1. **直接同义词**：含义几乎相同的词语
2. **相关替代表达**：含义相似但内涵略有不同的词语
3. **语境示例**：在有帮助时提供简短的用法示例

## 最佳实践

- 优先选择常用同义词，而不是生僻的替代表达
- 说明含义或用法上的细微差异
- 在相关时考虑地区差异
- 标明正式程度（正式/非正式/中性）
- 提供多个选项，让用户有所选择

## 示例

**输入**：“happy”

**同义词**：

- **直接同义词**：joyful、cheerful、delighted、pleased、content
- **非正式**：thrilled、stoked、over the moon
- **正式**：elated、gratified、blissful
- **细微差别**：
  - _content_ - 平和的满足感
  - _ecstatic_ - 强烈且难以抑制的幸福感
  - _cheerful_ - 在外在表现上流露出幸福感
