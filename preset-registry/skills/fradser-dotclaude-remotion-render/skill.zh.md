## 通用渲染策略

使用以下命令渲染视频：

```
npx remotion render
```

完整选项列表：https://www.remotion.dev/docs/cli/render.md

使用以下命令渲染静态图像：

```
npx remotion still
```

完整选项列表：https://www.remotion.dev/docs/cli/still.md

## 透明视频

有关如何渲染带透明度的视频，请参阅[透明视频](./transparent-videos.md)。
