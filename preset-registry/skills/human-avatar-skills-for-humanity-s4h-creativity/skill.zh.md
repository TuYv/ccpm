# 创造力

将创造性思维应用于任何挑战。诊断所需的创造性工作类型，并运行合适的单项工具，或按顺序使用多个工具进行全面探索。

## 哪种工具适合

| 你需要…… | 工具 |
|---|---|
| 质疑问题本身的框定方式是否正确 | assumption-excavator |
| 摆脱反复回到的主导想法 | lateral-thinking |
| 在做出任何选择之前了解所有选项 | alternatives / concept-fan |
| 公正地评估某个具体想法，避免仓促判断 | plus-minus-interesting |
| 从多个视角全面思考某件事 | six-hats |
| 从其他人的实际立场出发思考 | other-perspectives |
| 在不过早评判的情况下进行探索 | water-logic |
| 用随机冲击打破思维定式 | random-entry |
| 将荒诞的前提用作跳板 | provocation |
| 在做决定之前考虑所有因素 | consider-factors |
| 进行全面的多方法会话 | 运行下方的完整流程 |

## 路由决策

**框定检查：**继续之前，确认具体的挑战或问题。用一句话说明你识别出的内容——实际的创造性挑战及其关键参数——然后使用 `AskUserQuestion`：
- **问题：**“我的理解是：[用一句话框定具体挑战]。对吗？”
- **标题：**“框定”
- **选项：**
  - **是——继续**——框定正确
  - **调整**——有一个要素不准确；用户会先纠正它，然后再继续
  - **重新框定**——实际情况与当前理解不同；先纳入修正内容，再继续

- **问题的框定本身可能有误** → assumption-excavator（在其他任何操作之前运行）
- **困在一个方向中，不断回到同一个想法** → lateral-thinking
- **需要在选择之前了解完整的选项空间** → alternatives 或 concept-fan
- **有一个具体想法需要评估** → plus-minus-interesting
- **需要完整的多视角分析** → six-hats
- **决定会影响其他人** → other-perspectives
- **处于早期探索阶段，过早评判是最大阻碍** → water-logic
- **完全陷入僵局，需要外部刺激** → random-entry
- **需要刻意冲击思维，进入不可能的领域** → provocation
- **即将采取行动，希望确保没有遗漏任何事项** → consider-factors
- **挑战重大，希望应用所有方法** → 运行完整的头脑风暴流程

## 确认方向

诊断出适合的工具后，使用 `AskUserQuestion` 工具确认方向。动态构造问题，并在其中包含你的诊断：

- **问题：**“我的判断是：**[诊断出的工具]**——[用一句话说明它为何适用]。你希望如何继续？”
- **标题：**“方向”
- **选项：**
  - **是，运行该工具**——使用已提供的上下文立即执行诊断出的技能
  - **显示所有选项**——列出此类别中的每项技能，并分别提供一句话说明
  - **快速版本**——如果当前情况存在更轻量的替代方案，则运行该方案
  - **重新诊断**——重新审视情况描述，得出不同的判断

根据他们的选择继续。

## 假设挖掘器

*揭示并质疑隐藏的假设。*

列出当前问题框架中隐含的每一项假设——包括对什么是可能的、想要什么、什么是固定不变的，以及涉及哪些人的假设。逐一质疑：如果这项假设不成立会怎样？哪些假设是承重假设（如果没有它们，问题就不复存在），哪些只是附带假设？找出一旦错误便会最大程度改变解决方法的那项假设。

**输出：** 完整的假设清单，按质疑难度分类，并给出最能改变问题的一种重新定义方式。

---

## 横向思维

*摆脱主导模式，产生真正崭新的方向。*

指出主导想法——那个不断浮现的方向。有意识地将其搁置：在本练习的剩余部分不再考虑它。在腾出的思考空间中，生成 5 个以上完全不涉及主导想法的方向。运用移动式思维：不要评估，只管推进。生成之后再判断：这些新方向中的哪一个，或哪种组合，值得认真关注？

**输出：** 指明并搁置主导想法。给出 5 个以上真正不同的方向。选出 1-2 个值得进一步发展的方向。

---

## 替代方案（APC）

*在评估之前，有意识地生成多个选项。*

应用替代方案、可能性、选择：设定一个数量目标——在评估任何方案之前，先找出当前方法的至少 5 个替代方案。阻止评估进入生成阶段。生成完毕后，再进行比较。第一个想法几乎从来都不是最好的，但如果过早开始评估，它就会排挤掉更好的替代方案。

**输出：** 不加评判地生成 5 个以上替代方案，然后进行简要的比较评估。

---

## 概念扇

*在不同抽象层级上拓展解决方案空间。*

定义当前正在考虑的直接解决方案。后退一个层级：它服务于什么概念？然后生成多种服务于该概念的方法。再后退一个层级：这个概念服务于什么更广泛的目的？生成多个可以服务于该目的的概念。这会形成一个选项扇面，从具体策略一直延伸到战略替代方案。

**输出：** 三个层级——直接解决方案、所服务的概念和底层目的——每个层级均包含多个选项。

## 优点/缺点/有趣之处（PMI）

*在接受或拒绝一个想法之前，对其进行公正评估。*

对该想法应用优点/缺点/有趣之处分析：(1) 优点——它真正好在哪里，包括不明显的优点？(2) 缺点——它真正存在什么问题，包括不明显的负面因素？(3) 有趣之处——无论好坏，哪些方面值得注意，又引出了哪些问题？PMI 是仓促判断的解药。

**输出：** PMI 表格。最终评估：将有趣之处纳入考量后，优点是否胜过缺点？

## 六顶思考帽

*从六个不同角度进行结构化的平行思考。*

依次应用每一顶思考帽：(1) 白帽——只关注事实和数据，(2) 红帽——情感和直觉反应，(3) 黑帽——风险、问题和批判性分析，(4) 黄帽——乐观态度和实际益处，(5) 绿帽——创造性的替代方案和新的可能性，(6) 蓝帽——过程，以及需要进行哪些思考。每一顶思考帽都应保持纯粹——不要混合。

**输出：** 六部分分析，每顶帽子对应一部分。最终观点：当同时考虑所有帽子的视角时，完整图景呈现了什么？

## 他人视角（OPS）

*真正站在他人的立场上思考。*

识别受这一情况影响或参与其中的关键人物。对每个人分别思考：他们的实际目标是什么？在他们看来，问题是什么？他们担心什么？从他们的立场看，怎样才算好的结果？OPS 是结构化的共情——不是同情，而是真正从他人的约束和目标出发进行推理。

**输出：** 逐人分析。综合：从所有这些立场出发思考，揭示出了哪些你从自身立场出发时遗漏的内容？

## 水逻辑

*在不过早评判的情况下进行探索。*

进入流动模式：顺着想法延伸的方向思考，不要追问“这是否正确？”水逻辑不作判断，而是绘制图景。从当前情况出发并追问：这会导向什么？它会自然流向哪里？它与什么相连？先构建完整的领域图景，再决定什么最重要。岩石逻辑问“这是真的吗？”；水逻辑问“这会走向哪里？”

**输出：** 在进行任何评估之前，绘制情况的流向图——包括联系、方向和可能性。

---

## 随机切入

*使用不相关的刺激打破思维定式。*

选择一个随机单词或物体（也可以使用他人提供的内容）。将它应用于问题：这个词让你想到什么？它与当前挑战有什么关系？强行建立联系，即使这些联系很荒谬——荒谬的联系正是重点。随机性可以绕过熟悉思维形成的固定轨道。

**输出：** 使用的随机词、由此产生的强制联系，以及值得继续探索的 1-2 个联系。

---

## 挑衅（Po）

*将一个不可能或荒谬的陈述作为思考跳板。*

提出一个刻意的挑衅——某个明显错误或不可能的命题：“Po：[不可能的前提]。”不要评估这个挑衅。相反，思考：如果这是真的，世界会是什么样子？我们会怎么做？接着思考：其中哪些想法可以在现实世界中奏效？挑衅是脚手架，而不是目的地。

**输出：** 提出的挑衅、它所激发的想法，以及由此引出的现实可行想法。

---

## 考虑所有因素（CAF）

*在采取行动之前梳理所有相关因素。*

列出可能影响结果的每一个因素：利益相关者、风险、资源、时机、依赖关系、二阶效应。CAF 是一份起飞前检查清单——它不进行评估，只负责盘点。列出之后，思考：哪些因素是你刚才差点忽略的？哪些因素比最初看起来更重要？

**输出：** 完整的因素清单。最有可能被忽略的因素。最能改变行动方式的因素。

---

## 完整头脑风暴流程

*针对复杂挑战组织多方法协同会话。*

面对重大挑战时，按顺序使用这些工具：(1) 假设挖掘器，用于清理问题框架；(2) 横向思维，用于摆脱主导性想法；(3) 概念扇或替代方案，用于扩展选项空间；(4) 六顶思考帽或 PMI，用于评估最佳方向；(5) 考虑因素，用于发现遗漏之处。在不同工具之间，明确说明它们之间的联系——每个工具都建立在前一个工具的成果之上。

最后进行综合：综合来看，这些工具揭示了哪些单一工具无法独立呈现的内容？最重要的方向是什么？具体的下一步是什么？
