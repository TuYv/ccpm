# 内容写作

> 使用 Ann Handley 的《人人都能写作》方法论，创作出色得令人难以置信的内容——实用、以读者为中心，既服务于受众，也能帮助你实现目标。

## 何时使用此技能

当你需要完成以下任务时，请使用此技能：

- **撰写博客文章**，吸引读者并促进转化
- **创作电子邮件内容**，提高打开率和点击率
- **撰写社交媒体帖子**，让用户停下滚动
- **创作网站文案**，真正打动你的受众
- **撰写思想领导力内容**，建立可信度
- **改进表现不佳的现有内容**
- **以专业眼光编辑自己的作品**
- **克服写作障碍**，持续产出内容
- **培训团队成员**，掌握内容写作最佳实践

此技能对以下人群尤其有价值：
- 定期创作博客或新闻简报内容的内容营销人员
- 身兼多职且需要写作的营销人员
- 将专业知识转化为内容的主题专家
- 希望提升内容质量的团队
- 任何认为“我不是作家”却又不得不写作的人

## 说明

### 核心思维：为读者而写

每一篇内容都必须回答两个问题：

1. **那又怎样？** - 这为什么重要？
2. **谁在乎？** - 读者为什么应该在乎？

如果这两个问题你都无法回答，那么你的内容还没有准备好。

**培养“病态般的同理心”：**

| 问问自己 | 为什么重要 |
|--------------|----------------|
| 我的读者已经知道什么？ | 避免让他们感到无聊 |
| 他们需要知道什么？ | 填补知识空白 |
| 他们想要什么？ | 与他们的需求保持一致 |
| 他们害怕什么？ | 回应他们的疑虑 |
| 我怎样才能帮助他们？ | 聚焦价值 |

### Ann Handley 的 13 条写作法则

#### 基础法则

**1. 写作没有唯一的方法**
找到适合你的流程。对一个作者有效的方法，未必适合另一个作者。

**2. 我们的文字是我们的使者**
你的写作代表着你。每一篇内容都是建立或破坏信任的机会。

**3. 好的写作是一件强力工具**
它不是可有可无的，而是不可或缺的。把它当作一项专业技能来对待。

**4. 提升写作水平的关键是多写**
练习是不容商量的。定期写作，而不只是等到你“想写的时候”才写。

**5. 写得好 = 习惯 + 知识 + 用心**
了解规则。持续练习。真正关心你的读者。

#### 清晰法则

**6. 没有人会抱怨文章写得太简单**
简单是一种馈赠。永远不要担心表达得太清楚。

**7. 假设读者不了解，而不是假设他们愚蠢**
解释时不要居高临下。你的读者很聪明，只是可能缺少相关背景。

**8. 行话是写作中的化学添加剂**
它不自然，而且难以消化。改用通俗易懂的语言。

#### 流程法则

**9. 糟糕的初稿不可或缺**
不要跳过混乱的第一次尝试。这是写出好文章的必经之路。

**10. 好作者也是出色的编辑**
神奇之处发生在修改过程中，而不是初稿中。

**11. 编辑关乎清晰，而不只是语法**
删掉不必要的内容。突出不可或缺的内容。

#### 自律法则

**12. 你不能等待灵感**
等待缪斯降临的艺术，只会瘫在沙发上看 Netflix。

**13. 截止日期是写作的 WD-40**
它能让事情持续推进。设定截止日期，即使是自己规定的。

### 写作 GPS：12 步框架

将此框架用于任何重要内容：

#### 阶段 1：准备

**第 1 步：目标**
目的是什么？读者应该采取什么行动？

```
GOAL TEMPLATE:
After reading this, readers will [understand/do/feel] ___________
The primary CTA is: ___________
Success looks like: ___________
```

**第 2 步：重新构建视角**
让读者进入情境。为什么他们会在乎？

| 你的视角 | 读者的视角 |
|-----------------|---------------------|
| “我们推出了一项新功能” | “你现在可以更快地完成 X” |
| “我们公司获奖了” | “我们致力于为你提供高品质服务” |
| “阅读我们的最新研究” | “以下是解决[问题]的方法” |

**第 3 步：寻找数据**
寻找事实、统计数据、示例、引语和故事来支持你的观点。

**第 4 步：组织内容**
创建一个大致结构：
- 你的引子/导语是什么？
- 你的 3-5 个主要观点是什么？
- 你的结论/CTA 是什么？

#### 阶段 2：创作

**步骤 5：写出粗糙的初稿（TUFD）**

> “关起门来写作。”

TUFD 的规则：
- 写作时不要编辑
- 不要在起草过程中查资料
- 不要担心是否完美
- 只管把想法写下来
- 接受这种混乱

**步骤 6：暂时离开**
让它沉淀一下。至少一个小时，如果可能，就放一夜。距离能带来不同的视角。

#### 阶段 3：完善

**步骤 7：重写**
专注于宏观问题：
- 结构是否合乎逻辑？
- 论述是否流畅？
- 导语是否足够有力？
- 结尾是否达到预期效果？

**步骤 8：为清晰度而编辑**
毫不留情地删减。审视每一个句子：
- 这是必要的吗？
- 这是最简单的表达方式吗？
- 还能更简短吗？

**删掉你钟爱的内容。** 那个你很喜欢的巧妙表达？如果它不能为读者服务，就删掉它。

**步骤 9：编辑语法和风格**
现在再关注：
- 词语选择
- 句式变化
- 语气一致性
- 标点符号

#### 阶段 4：润色

**步骤 10：大声朗读**
你的耳朵能发现眼睛遗漏的问题：
- 别扭的表达
- 遗漏的词语
- 不自然的节奏
- 过长的句子

**步骤 11：征求第二意见**
新的视角能看到你看不到的问题。请他人从以下方面审阅：
- 清晰度
- 缺失的上下文
- 令人困惑的段落
- 整体印象

**步骤 12：最终检查**
最后再润色一次，然后发布。不要让追求完美妨碍你完成工作。

### 特定格式指南

#### 标题

**原则：**
- 承诺提供有价值的内容
- 表述具体（数字、细节）
- 激发好奇心
- 将关键词前置

**公式选项：**
| 公式 | 示例 |
|---------|---------|
| 如何[实现结果] | “如何撰写能促进转化的标题” |
| [数字]种[获得收益]的方法 | “提高电子邮件打开率的 7 种方法” |
| [主题]的[形容词]指南 | “内容策略完整指南” |
| [受众提出的问题] | “为什么你的内容无法促成转化？” |
| 在[时间范围]内[取得结果] | “在 30 分钟内写出更好的博客文章” |

#### 导语/开场句

**有效的类型：**
1. **从读者出发**：“你已经在那篇博客文章上花了好几个小时……”
2. **发人深省的问题**：“如果你对 SEO 的所有认知都是错的，会怎样？”
3. **令人惊讶的事实**：“72% 的营销人员表示，内容是他们面临的最大挑战”
4. **简短的故事**：“上周，一位客户问了我一个问题，让我当场愣住了……”
5. **开门见山**：“以下是撰写能促进转化的内容的方法。”

**避免：**
- 以“我们”或“我们公司”开头
- 冗长的引言
- 下定义（“内容营销是……”）
- 模糊的概括

#### 电子邮件主题行

**最佳实践：**
- 清晰胜过巧妙（他们需要知道邮件里有什么）
- 少于 50 个字符（适合移动设备）
- 营造紧迫感（确有必要时）
- 尽可能进行个性化
- 测试不同的方法

**公式：**
| 类型 | 示例 |
|------|---------|
| 好奇心 | “这永远改变了我的写作方式” |
| 直接 | “你的每周内容技巧” |
| 问题 | “还在为标题发愁吗？” |
| 方法 | “如何提高写作速度（同时不牺牲质量）” |
| 紧迫感 | “最后一天：内容研讨会报名” |

#### 社交媒体帖子

**原则：**
- 让用户停止滑动（第一行最重要）
- 开门见山，抛出钩子
- 立即提供价值
- 像说话一样写作
- 加入明确的 CTA

**长篇内容格式（LinkedIn）：**
```
[Hook: provocative statement or question]

[Space]

[Context: why this matters]

[Key insight or story]

[Takeaway or lesson]

[CTA or question for engagement]
```

### 编辑检查清单

发布前使用此检查清单：

**整体：**
- [ ] 标题是否承诺了价值？
- [ ] 导语是否吸引住了读者？
- [ ] 结构是否合乎逻辑？
- [ ] 核心观点是否清晰？
- [ ] 结尾是否有力？

**清晰度：**
- [ ] 我是否删掉了不必要的词语？
- [ ] 每个句子是否都发挥了作用？
- [ ] 我是否消除了行话？
- [ ] 12 岁的孩子能否理解这些内容？

**以读者为中心：**
- [ ] 我是否回答了“那又怎样？”这个问题？
- [ ] 内容关注的是读者，而不是我自己吗？
- [ ] 我是否解答了读者可能提出的问题？
- [ ] CTA 是否明确？

**润色：**
- [ ] 我是否朗读过这些内容？
- [ ] 语法是否正确？
- [ ] 句子长短是否有所变化？
- [ ] 我是否检查过拼写错误？

## 示例

### 示例 1：重写博客文章

**原始草稿（修改前）：**

> “在当今快节奏的数字化环境中，企业越来越认识到利用内容营销策略来提升品牌知名度，并推动与目标受众进行有意义互动的重要性。我们的团队一直在努力开发创新方法，帮助企业驾驭这一复杂局面。”

**分析：**
- 以“在当今”开头（陈词滥调）
- 使用了行话：“利用”“环境”“提升品牌知名度”
- 关注的是公司，而不是读者
- 没有明确的观点或价值

**重写版本（修改后）：**

> “你的博客已经连续六个月停留在每月 500 名访客。你一直在稳定发布内容，也在社交媒体上进行推广，但毫无效果。
>
> 我们分析了 47 个成功突破这一瓶颈的博客，发现了以下规律——以及你本周就能实施的具体改变。”

**改动内容：**
- 从读者的问题入手
- 内容具体（500 名访客、六个月、47 个博客）
- 承诺提供可执行的价值
- 没有行话

### 示例 2：电子邮件简报

**任务：** 撰写一封简报，介绍一份新的电子邮件营销指南。

**使用 Writing GPS：**

**目标：** 让读者下载指南  
**从读者角度重新审视：** 他们在电子邮件营销上遇到了困难——打开率低、点击率低、没有效果

**电子邮件：**

```
Subject: Your emails aren't the problem

Hey [Name],

I talked to 23 marketers last month about email.

Same frustration every time: "We write good emails. Why doesn't anyone engage?"

Here's what I've realized: the email itself usually isn't the problem.

The problem is what happens BEFORE the email:
- Sending to the wrong segment
- Sending at the wrong time
- Sending without a clear reason readers should care

We just published a guide that walks through the pre-email checklist
that doubled our own open rates.

It's 12 pages. No fluff. Takes 10 minutes to read.

→ Grab it here: [LINK]

If you implement even one thing from it, let me know what changes.

— Ann

P.S. Page 7 has the framework that made the biggest difference for us.
```

**为什么有效：**
- 悬念引发好奇（电子邮件难道不是问题所在？）
- 具体数据（23 位营销人员、翻倍、12 页、10 分钟）
- 以读者为中心（你的挫败感、你的进步）
- 行动号召清晰且具体
- P.S. 引发更多好奇

## 清单与模板

### 内容简报模板

```
CONTENT BRIEF

Title/Topic: _______________
Format: Blog / Email / Social / Other
Target audience: _______________
Goal (reader action): _______________

KEY QUESTIONS TO ANSWER:
1. What problem does this solve for the reader?
2. What will they know/do after reading?
3. What makes this different from existing content?

MAIN POINTS:
1. _______________
2. _______________
3. _______________

DATA/EXAMPLES NEEDED:
- _______________
- _______________

CTA: _______________

SUCCESS METRICS: _______________
```

### TUFD（糟糕的初稿）热身练习

卡住时，快速回答以下问题，不要修改：

1. 我最希望读者理解的核心内容是什么？
2. 他们为什么应该关心这件事？
3. 这个主题最有趣的切入角度是什么？
4. 哪个故事或示例可以说明我的观点？
5. 读者阅读后应该做什么？

然后连续写作 15 分钟，中途不要停下。

### 快速编辑轮次

**第 1 轮：结构**
- 开头是否能吸引读者？
- 各部分的顺序是否符合逻辑？
- 结尾是否有效？

**第 2 轮：清晰度**
- 删减 10% 的字词
- 消除术语行话
- 简化复杂句子

**第 3 轮：以读者为中心**
- 尽可能将“我们/我们的”改为“你/你的”
- 确保益处清晰明确
- 增加具体细节

**第 4 轮：润色**
- 大声朗读
- 修正语法
- 检查格式
