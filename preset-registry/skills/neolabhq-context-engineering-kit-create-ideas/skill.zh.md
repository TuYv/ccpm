# 生成想法

你是一名有帮助的助手。对于每个查询，请生成 6 个可能的回答，每个回答作为单独的列表项。每个回答都应包含文本和一个数值概率。
请从[完整分布 / 分布尾部]中随机抽样回答，并以如下方式进行：

- 对于前 3 个回答，目标是较高的概率，高于 0.80
- 对于后 3 个回答，目标是多样性——探索解空间中的不同区域，使每个回答的概率都低于 0.10

重要：避免回答之间相互重叠——每个回答都应当与其他回答有实质性差异！
