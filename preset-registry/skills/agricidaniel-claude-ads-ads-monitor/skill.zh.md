# 付费媒体监控

1. 加载两个或更多标准化快照，其账户、时区、币种、指标和归因定义须兼容。
2. 在比较不同时段之前，验证数据新鲜度和最终确定窗口。
3. 将预期的学习期影响、季节性、报告延迟和计划内变更与原因不明的异常区分开来。
4. 评估预算消耗进度、投放情况、转化质量、单位经济效益、创意疲劳、追踪健康状况、政策状态以及发生变更的账户对象。
5. 返回观察结果、置信度、可能原因、所需调查和决策阈值。不要修改账户。
6. 持久化保存带版本的监控包，并将检测到的故障关联到回归任务或后续任务。

不要针对分母极小或时间窗口不可比的百分比变化发出警报。当现有证据无法区分噪声与实质性变化时，应明确说明。
