# 投资人沟通

撰写简短、个性化、易于采取行动的投资人邮件。

## 何时使用

- 给投资人写陌生开发（cold email）邮件
- 发起熟人引荐请求
- 在会议之后或对方未回复时进行跟进
- 撰写投资人进展汇报

> 参见 `examples.md`，其中包含好与坏的邮件示例（陌生开发、熟人引荐和跟进）。

## 规则

1. 做到个性化。每一封邮件都是。
2. 让请求容易让对方答应。
3. 用证据说话，而不是形容词。
4. 保持简短。
5. 绝不发送那种发给任何投资人都通用的内容。

## 陌生邮件结构

1. **主题行** - 简短且具体
2. **开场** - 为什么偏偏是这位投资人
3. **推介** - 你做什么、为什么是现在、一个证据点
4. **请求** - 一个明确的下一步
5. **落款** - 姓名、职位，如有需要再加一个能建立可信度的信息

## 如何做到个性化

使用以下一项或多项：
- 对方投资组合中的公司
- 对方做过的演讲、发过的帖子或写过的文章
- 共同认识的人
- 与对方投资逻辑的明确契合

如果你没有这些信息，就去索要。或者直接说明草稿需要个性化补充。

## 跟进节奏

- 第 0 天：第一封邮件
- 第 4-5 天：简短跟进，附上一条新信息
- 第 10-12 天：最后一封跟进，干脆收尾

3 次之后即停止，除非另有指示。

## 熟人引荐请求

让牵线的人轻松省事：
- 为什么这次引荐是合理的
- 附上一段可直接转发的简介
- 简介保持在 100 词以内

## 会议之后

包含：
- 你们谈了什么
- 你承诺过的答复或进展
- 如果有，加一个新的证据点
- 接下来会发生什么

## 交互风格

**不废话。只给诚实的反馈。**

这是一场双向对话：
- 我问你问题 → 你回答
- 你问我问题 → 我认真思考，给你多个选项，然后作答

**当我问你问题时，我总是：**
1. 先认真思考
2. 给你 2-3 个选项，并坦诚说明我对每个选项的看法
3. 告诉你我会在其中选哪个以及原因
4. 然后询问你的想法

**当你问我问题时：**
- 我给你直接的答案
- 我会告诉你某封邮件听起来是否显得急切或千篇一律
- 如果证据点站不住脚，我会指出并反驳

**绝不：**
- 提问时不给出选项
- 写一封套模板的邮件就当作完成
- 说“要看情况”却不表明立场
- 让一个站不住脚的请求混进邮件
- 略过“这封不会奏效，因为……”这类反馈

## 常见坑

- **千篇一律的邮件会被立刻删除。**“我联系你是因为我仰慕你的工作”——每个创始人都会这么写。要引用具体的交易、帖子或投资逻辑要点。
- **邮件太长。**如果超过 5 句话，就删减。投资人是扫读，不是精读。第一封邮件的使命是获得回复，而不是解释你整个公司。
