# 经济学

将经济学推理应用于决策、组织和系统。诊断需要哪种分析，并将问题交给合适的工具。经济学不仅关乎金钱——它还关乎激励如何塑造行为、选择如何排除其他可能性，以及为什么理性的个体行动者如此频繁地产生集体非理性的结果。

## 哪个工具适用

| 你需要…… | 工具 |
|---|---|
| 梳理做出这一选择实际上会放弃什么 | opportunity-cost |
| 了解谁受益、谁付出代价，以及由此会产生哪些行为 | incentive-mapping |
| 识别由决策之外的各方承担的成本或获得的收益 | externalities |
| 应用下一单位的逻辑——沉没成本、平均量与边际量之分 | margin |
| 诊断为什么理性的个体不断产生糟糕的集体结果 | coordination |

## 路由决策

**框架确认：** 在路由之前确认当前情境。用一句话说明你识别出的内容——核心经济问题以及其中的利害关系——然后使用 `AskUserQuestion`：
- **问题：** “我对这一情况的理解是：[用一句话概括经济情境和核心问题]。对吗？”
- **标题：** “框架”
- **选项：**
  - **是——继续** — 框架正确
  - **调整** — 有一个要素不准确；用户会在你继续之前予以纠正
  - **重新构建框架** — 实际情况与你的理解不同；继续之前先纳入用户的纠正

- **正在评估一项选择，并希望了解包括所放弃选项在内的全部成本** → opportunity-cost
- **试图理解或改变人们的行为——谁因为什么而得到回报** → incentive-mapping
- **决策或政策会影响未参与决策的各方** → externalities
- **决策涉及做多少：增加、减少、扩大、削减——或涉及沉没成本推理** → margin
- **即使合作会让所有人受益，一个群体仍不断合作失败** → coordination
- **不明确** → incentive-mapping；几乎每个经济学问题最终都会变成关于激励的问题

## 机会成本

*每个选择都会排除其他可能性——梳理你放弃了什么，而不仅仅是你获得了什么。*

阿尔弗雷德·马歇尔的基础性洞见是：任何选择的真正成本并非花掉的金钱，而是所放弃的次优选项。大多数分析只计算花费了什么；机会成本分析则坚持追问，这些资源原本还可以用来做什么。这样做可以揭示那些看似免费之决策中的隐藏成本，显明在相互竞争的事物之间进行选择时真正的权衡，并将“我们应该这样做吗？”重新表述为“这是对现有资源的最佳利用吗？”其输出是一幅完整的成本图景，其中包括未选择路径的价值。

**输出：** 明确的机会成本图谱——最佳可用替代方案、每个替代方案的价值、所选路径的真实成本，以及在放弃的价值变得清晰可见后，该选择是否仍然成立的建议。

## 激励映射

*梳理谁受益、谁买单，以及激励结构实际促成了哪些行为。*

激励是人类行为的操作系统。关键不在于人们被告知要做什么，也不在于他们打算做什么——而在于该结构会奖励他们做什么。识别系统中的每一个参与方。对每一方而言：做 X 能获得什么？会失去什么？激励结构会促使他们采取哪些行动，而这些行动在哪些方面偏离了系统对他们的要求？与不良意图相比，错位的激励更能可靠地预测不当行为。

**输出：** 按参与方绘制的激励图谱——当前结构下的收益、成本和预测行为——以及识别出的激励错位和重新设计方案。

## 外部性

*识别并非由行为主体承担的成本和获得的收益——以及如何将其内部化。*

A.C. Pigou 的核心洞见是：当决策者不承担决策带来的全部成本（或无法获得其全部收益）时，他们会系统性地过度从事有害活动，或不足地从事有益活动。负外部性（污染、拥堵、噪声）会被过度产生；正外部性（疫苗接种、教育、开源软件）会被不足地产生。该分析会梳理所有受影响方，量化外部影响，并确定最适合将其内部化的机制——税收、补贴、产权、监管或社会规范。

**输出：** 外部性图谱——谁受到影响、影响有多大、影响方向如何——以及按可行性排序的内部化机制。

## 边际

*应用边际思维：相关的决策对象是下一个单位，而不是平均值或沉没成本。*

经济学中最经久不衰的洞见是：决策应在边际上做出。问题从来不是“总体而言，这是一项好的投资吗？”——而是“我们是否应该再多做一个单位？”边际成本与边际收益的比较决定了应当扩大、维持还是缩减。沉没成本——已经投入且无法收回的资源——在经济学意义上与未来决策无关，然而它们却主导着大多数人的推理。此技能会剔除沉没成本推理，正确地重新表述问题，并将边际逻辑应用于当前决策。

**输出：** 边际分析——决策边际上的相关成本与收益、沉没成本的识别与隔离，以及基于正确的前瞻性比较提出的建议。

## 协调

*诊断集体行动失灵、公共品问题，以及为何个体理性行为会导致集体非理性。*

Elinor Ostrom 的毕生研究表明：公地悲剧并非不可避免。但它确实很常见——而且其成因是结构性的，而非道德性的。当某项行动的收益分散（由多人共享），而成本集中（由个人承担）时，理性行为者对集体利益的贡献就会不足。当背离合作的收益归个人所有，而成本由群体共同承担时，理性行为者就会过度使用公地资源。此技能会梳理协调失灵的结构——公共品、公共池塘资源、保证博弈、搭便车问题——并识别能够解决该问题的制度安排（产权、社会规范、监管、社区监督）。

**输出：** 协调失灵诊断——问题的结构、个体理性为何会造成集体损害，以及最有可能解决这一问题的制度机制。
