### 1.2 暴力形态（《法令》11.340/2006第7条）

| 形式 | 定义 | 示例 |
|-------|-----------|----------|
| **身体** (I) | 损害身体完整性或健康 | 拍打、拳打、推搡、灼伤、窒息 |
| **心理** (II) | 精神伤害、自尊受损、控制 | 羞辱、威胁、隔离、gaslighting、操控 |
| **性** (III) | 强迫或胁迫对方目睹/维持/参与性行为的行为 | 婚内强奸、阻止使用避孕工具、强迫流产 |
| **财产** (IV) | 扣押、抢夺、毁坏财物/工作工具 | 扣留证件、毁坏手机、控制资金 |
| **道德** (V) | 诽谤、毁损名誉或侮辱 | 公开指控通奸、公开曝光隐私、辱骂 |

### 1.4 流程化接待 — 家庭暴力受害者

```
VITIMA em situacao de violencia
│
├─→ EMERGENCIA (risco imediato de vida)
│   └─→ Ligar 190 (PM) ou 180 (Central da Mulher)
│       └─→ Flagrante + afastamento imediato do agressor
│           └─→ Delegacia (B.O.) + DEAM se disponivel
│               └─→ Medida protetiva em ate 48h (Art. 12-C)
│
├─→ URGENCIA (violencia recorrente)
│   └─→ Delegacia (B.O.) ou DEAM
│       └─→ Solicitar medidas protetivas
│           └─→ Juiz decide em ate 48h (inaudita altera pars)
│               └─→ Monitoramento eletronico se necessario
│
├─→ ORIENTACAO (quer saber direitos)
│   └─→ CRAM (Centro de Referencia da Mulher)
│       └─→ Defensoria Publica / OAB / advogado particular
│           └─→ Avaliacao do caso + estrategia juridica
│
└─→ SINAL VERMELHO (Lei 14.188/2021)
    └─→ Desenhar X vermelho na mao
        └─→ Mostrar em farmacia/hospital participante
            └─→ Estabelecimento aciona autoridades
```

### 5.4 狡诈作为加重因素

狡诈可表现为：
- **一般加重情节**（CP第61条II项“c”款）——犯罪在陷害、埋伏、**借助伪装**或其他使受害人辩护困难的方式下实施
- **杀人加重情节**（CP第121条第2款IV项）——在背叛、埋伏、**隐匿**或其他使受害人辩护困难的手段下实施
- **抢劫案加重事由**（CP第171条第1款）——对老年人实施

### 6.1 三段制（第68条《刑法典》）

```
FASE 1: Pena-base (Art. 59 CP — circunstancias judiciais)
  → Culpabilidade, antecedentes, conduta social, personalidade,
    motivos, circunstancias, consequencias, comportamento vitima
  → Resultado: entre o minimo e maximo legal

FASE 2: Circunstancias agravantes e atenuantes
  → Agravantes (Arts. 61-62) e Atenuantes (Arts. 65-66)
  → NAO pode ultrapassar os limites legais (Sumula 231 STJ)

FASE 3: Causas de aumento e diminuicao
  → Majorantes e minorantes (partes especial e geral)
  → PODE ultrapassar os limites legais
```

## 模块10 — 刑事案件完整分析工作流

在接到刑事案件分析时，始终遵循以下 10 个步骤：

## 第1步——事实定性

- 罪名类型（具体是什么罪？）
- 法律依据（是《刑法典》或特别法哪一条？）
- 分类：故意/过失、未遂/既遂、一般/特别/恶性犯罪

## 第2步——主体

- 行为人（谁实施了？）
- 受害人（谁遭受了？）
- 双方关系（家庭、职业、陌生人）
- 受害人脆弱性

## 第3步——犯罪事实与责任人

- 物证（鉴定书、报案书、照片、医疗记录）
- 责任人证据（证人、监控、供述、电子数据）
- 是否有足够线索支持起诉？

## 第4步——加重与减轻情形

- 适用的加重/减轻情节
- 加重与减轻原因
- 罪名竞合（实质竞合、形式竞合、连续犯罪）

## 第5步——预估量刑

- 量刑基准（第一阶段）
- 加重/减轻（第二阶段）
- 增幅/减幅（第三阶段）
- 预计初始执行制度

## 第6步——程序问题

- 管辖权（刑事庭、陪审团、刑事上诉庭、家庭暴力法院）
- 起诉性质（附条件公诉、非附条件公诉、自诉）
- 是否存在当场/预防/临时拘捕？
- 可适用的保全措施

## 第7步——可用论点

- 对辩方：哪些论点可行？
- 对控方：哪些论点最有力？
- 相关判例

## 第8步——风险与情景

- 乐观情景（宣告无罪、降级）
- 基准情景（有罪但附减轻情节）
- 悲观情景（按法定最高刑判处）

## 第9步——建议策略

- 和解（若可适用 ANPP —— 第28-A条《刑事诉讼法》）
- 庭审辩护
- 与检察机关谈判
- 可提起的上诉

| 不当保护性措施 | 撤销 + 必要时申请人身保护令 | Art. 19, par. 3 Lei 11.340 |

### 14.3 玛丽亚·达·贝克法下的诬告

**危险情况**：当涉嫌受害人伪造侵害情节以获取利益（抚养权、房产、赡养费）时。

**注意点：**
- 在家庭暴力案件中，受害人陈述具有特殊权重（隐匿性犯罪）
- 指称虚假需具备**充分证据**（仅否认不足以成立）
- 片面主张可能导致再次受害
- 一旦虚假成立：Art. 339 CP（诬告罪）—2至8年有期徒刑

**可证明虚假的证据包括：**
- IML 鉴定报告为阴性 / 与陈述不符
- 矛盾性信息（WhatsApp、SMS）
- 安防监控
- 现场证人
- 经证实的不在场证明（定位、卡片、监控）
- 双方财产纠纷既往历史

### 15.1 刑罚执行中的利益

| 利益 | 时间条件 | 主观条件 |
|-----------|-------------------|-------------------|
| **进阶（一般）** | 16%（初犯） / 20%（累犯） | 良好表现 |
| **进阶（暴力犯罪）** | 25%（初犯） / 30%（累犯） | 良好表现 |
| **进阶（重罪，无死亡）** | 40% / 50% / 60% | 良好表现 |
| **进阶（重罪，含死亡）** | 50% / 60% / 70% | 良好表现 |
| **假释** | 1/3（初犯） / 1/2（累犯） | 良好表现 + 赔偿损失 |
| **假释（重罪）** | 2/3 + 非特定累犯 | 良好表现 |
| **暂时外出** | 1/6（半开放） | 良好表现 |
| **外部劳动** | 1/6（半开放） | 适格性、纪律 |
| **抵扣** | 3天劳动=1天刑期 | 劳动或学习 |
| **特赦** | 总统谕令 | 按年度谕令 |

### 15.2 扣减与减刑

- **扣刑**（Art. 42 CP）：羁押及强制住院时间从最终刑期中扣减
- **劳动减刑**（Art. 126 LEP）：3天劳动 = 1天刑期
- **学习减刑**（Art. 126, par. 1, I LEP）：12小时学习 = 1天刑期
- **阅读减刑**（Recomendacao 44/2013 CNJ）：1本书/30天 = 4天刑期（每年最多12天）
