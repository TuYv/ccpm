# 社交媒体

跨平台的社交媒体策略、内容创作和社区建设。

## 语言与质量标准

**关键要求**：使用与用户相同的语言回复。如果用户使用越南语，则用越南语回复；如果使用西班牙语，则用西班牙语回复。

**标准**：提高 Token 效率，为简洁性牺牲语法，在末尾列出尚未解决的问题。

---

## 何时使用此技能

在以下情况下运用社交媒体专业知识：
- 制定社交内容策略
- 开发平台专属内容
- 针对平台算法进行优化
- 提升互动并建设社区
- 规划社交媒体内容日历
- 分析社交媒体表现

## 核心概念

### 有来源支撑的 X 输入

当营销活动依赖当前的 X 帖子、公开账号历史记录或互动背景时，
在推荐吸引点、切入角度或效果优化策略之前，先索取来源材料。如果
用户提供了 Xquik REST API 或 MCP 输出，请将返回的帖子文本、URL、作者、
时间戳、媒体引用和公开指标用作依据。将缺失字段视为未知，
绝不虚构互动数据或帖子历史记录。

**四大内容支柱**：
| 支柱 | 目的 | 比例 | 示例 |
|--------|---------|-------|----------|

| 推广性 | 推动行动和营收 | 10% | 优惠、产品、行动号召 |

### 平台算法因素

**LinkedIn 算法**：
- 停留时间（阅读所花费的时间）
- 评论 > 分享 > 反应
- 第一小时的互动至关重要
- 优先推荐原生内容
- 正文中不要放外部链接（放在评论中）

**Instagram 算法**：
- 关系（私信、评论、Story 回复）
- 兴趣（基于过去的行为）
- 时效性（优先推荐最近的帖子）
- 大力推广 Reels
- Story 互动很重要

**TikTok 算法**：
- 观看时长 / 完播率
- 分享 > 评论 > 点赞
- 视频信息（说明文字、话题标签）
- 设备和账号设置
- 热门音乐可提升触达

**Twitter/X 算法**：
- 互动速度（前 30 分钟）
- 回复和对话
- 优先推荐媒体内容（图片、视频）
- 使用帖子串呈现深度内容
- 账号权威性很重要

### 互动策略

**主动互动**：
- 在 1 小时内回复评论
- 在帖子中提问
- 使用投票和互动功能
- 标记相关账号
- 参与细分领域内的对话

**社区建设**：
- 创建专属群组
- 展示用户生成的内容
- 举办直播活动
- 发起挑战/竞赛
- 重点介绍社区成员

### 内容格式优化

**轮播帖最佳实践**：
- 在第 1 张幻灯片设置吸引点（问题/疑问）
- 在第 2-8 张幻灯片中提供价值
- 在最后一张幻灯片中加入 CTA
- 保持设计一致
- 提供值得收藏的信息

**视频最佳实践**：
- 在前 3 秒设置吸引点
- 始终添加字幕（80% 的用户会静音观看）
- 针对移动设备使用竖屏格式
- 在大多数平台上控制在 60 秒以内
- 设置有力的结尾/CTA

**文字帖最佳实践**：
- 使用有力的第一行（吸引点）
- 使用留白提高可读性
- 使用项目符号和格式排版
- 只设置一个 CTA
- 有策略地放置话题标签

## 最佳实践

### 卓越内容
1. **平台原生**：针对各平台调整格式
2. **一致性**：保持规律的发布计划
3. **价值优先**：先给予，再索取
4. **真实性**：真实的声音，真实的故事

### 卓越互动
1. **快速回应**：速度体现你的重视
2. **保持人性化**：个性胜过完美
3. **鼓励对话**：主动提问，而不只是单向传播
4. **赞扬社区**：展示 UGC 并给予认可

### 卓越增长
1. **协作**：与细分领域内的其他人合作
2. **趋势**：在相关时参与热门趋势
3. **交叉推广**：利用其他渠道
4. **付费推广**：扩大表现最佳的自然内容的影响力

## 应避免的反模式

| 反模式 | 错误原因 | 应改为 |
|--------------|----------------|-----------------|
| 在所有平台发布相同内容 | 各平台存在差异 | 针对各平台进行调整 |
| 发布后不再互动 | 会扼杀互动 | 在评论区参与互动 |
| 全是推广内容 | 没人会为了看广告而关注 | 90% 价值内容，10% 推广内容 |
| 忽视分析数据 | 重复无效的做法 | 分析并迭代 |
| 购买粉丝 | 虚假互动，会损害触达率 | 自然增长 |

## 指标与基准

| 指标 | 良好 | 优秀 | 计算方式 |
|--------|------|-----------|-----------|
| 互动率 | 1-3% | 3%+ |（互动数 / 粉丝数）× 100 |
| 粉丝增长率 | 每月 2-5% | 每月 5%+ | 每月净增粉丝数 / 粉丝总数 |
| 分享率 | 1-2% | 2%+ | 分享数 / 触达人数 |
| 收藏率 | 2-5% | 5%+ | 收藏数 / 触达人数 |
