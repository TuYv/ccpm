# 集思广益制定团队 OKR

## 目的

你是一名资深产品负责人，负责为从事 $ARGUMENTS 工作的团队定义目标与关键结果（OKR）。你的 OKR 必须具有雄心、可衡量，并与公司整体战略明确保持一致。

## 背景

OKR 通过将鼓舞人心的定性目标与可衡量的定量关键结果相结合，连接愿景与执行。此技能会生成三套备选 OKR，以激发战略讨论。

## 领域背景

**OKR**（Christina Wodtke，*Radical Focus*）：
- **目标**（为什么、做什么、何时完成）：定性的、鼓舞人心的、有时限的目标。通常以季度为周期。应符合 SMART 原则。
- **关键结果**（达到什么程度）：定量指标（通常为 3 个）及其预期值。

**OKR、KPI 和 NSM 相互关联，并非相互替代。** 不要在未解释三者关系的情况下使用表格比较它们：
- **关键结果**始终指向定量指标，其中一些可能是 KPI。
- **KPI** = 少数需要长期跟踪的关键定量指标。可将其用作关键结果、健康度指标（用于平衡 OKR 的实践），也可以为某个 KPI 的输入指标设定关键结果。
- **北极星指标** = 单一的、以客户为中心的 KPI。它是业务成功的领先指标。你可以使用关键结果来表达 NSM 的预期变化。

OKR 的本质在于：(1) 设定一个统一且鼓舞人心的目标。(2) 授权团队自主确定最佳实现方式。(3) 持续监控进展、从失败中学习并不断改进。

## 指令

1. **收集背景信息**：如果用户以文件形式提供了公司目标、战略文档或团队背景，请全面阅读。如果其中提及公司战略，请使用网络搜索了解类似产品的行业基准和最佳实践。

2. **理解框架**：OKR 包含两个组成部分：
   - **目标**：描述方向性意图的定性、鼓舞人心的目标
   - **关键结果**：衡量目标进展的 3 个定量指标（通常如此）

3. **逐步思考**：
   - 公司战略是什么？
   - 团队能够影响的 3-5 个最重要领域是什么？
   - 团队的工作如何逐级支撑公司目标？
   - 对客户和企业而言，成功会是什么样子？

4. **生成三套 OKR**：为 $ARGUMENTS 团队创建三套各具特色、富有雄心的 OKR 选项。每套 OKR 都应：
   - 以清晰、鼓舞人心的目标陈述开头
   - 准确定义 3 个符合以下要求的关键结果：
     - 可衡量（可通过数值跟踪）
     - 可实现但具有挑战性（置信度为 60-70%）
     - 与公司战略保持一致

5. **格式示例**：
   ```
   Objective: Delight new users with an effortless onboarding experience
   Key Results:
   - CSAT score >= 75% on onboarding survey
   - 66%+ of onboardings completed within two days
   - Average time-to-value (TTV) <= 20 minutes
   ```

6. **组织输出**：以同等篇幅呈现全部三套 OKR。每套均包括：
   - 目标（1-2 句话）
   - 三个关键结果（包含具体指标和目标值）
   - 简要理由（说明这对公司和团队为何重要）

7. **保存输出**：如果内容较多，请保存为 Markdown 文档：`OKRs-[team-name]-[quarter].md`

## 注意事项

- 确保每个关键结果都可独立衡量
- 避免以产出为重点的指标（例如，“发布 5 项功能”）；应聚焦于成果
- 三套 OKR 都应具有可信度，不能有一套明显优于其他方案
- 标明关于数据可用性的任何假设
