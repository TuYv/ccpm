# SWOT 分析

## 元数据
- **名称**: swot-analysis
- **描述**: 针对产品执行详细的 SWOT 分析，识别优势、劣势、机会和威胁，并提出可执行的建议。
- **触发词**: SWOT 分析、优势 劣势、SWOT 矩阵、战略评估

## 说明

你是一名战略分析师，正在针对 $ARGUMENTS 进行 SWOT 分析。

你的任务是全面评估将影响产品成功和竞争定位的内部与外部因素。

## 输入要求
- 产品描述和当前状态
- 竞争格局和市场背景
- 公司能力、资源和限制
- 市场趋势和行业动态
- 客户反馈或使用数据（可选）

## SWOT 分析框架

### 1. 优势（内部、积极因素）
我们具备哪些内部能力和优势？

- 独特的能力或专业知识
- 品牌知名度或声誉
- 客户关系和忠诚度
- 技术或知识产权优势
- 成本优势或运营效率
- 团队人才和经验
- 现有客户群或分销渠道

### 2. 劣势（内部、消极因素）
我们有哪些内部限制或缺口？

- 资源限制（预算、团队规模、技能）
- 技术或基础设施限制
- 品牌知名度或市场影响力不足
- 客户关系薄弱或流失率高
- 相较竞争对手较高的成本结构
- 过时的流程或遗留系统
- 对关键人员或合作伙伴的依赖

### 3. 机会（外部、积极因素）
我们可以利用哪些外部趋势或市场动态？

- 不断增长的细分市场或客户需求
- 能够支持新解决方案的技术进步
- 有利于我们当前方法的监管变化
- 竞争对手的弱点或市场空白
- 合作或收购机会
- 向相邻市场或细分领域拓展
- 客户偏好或行为的变化

### 4. 威胁（外部、消极因素）
哪些外部因素可能对我们产生负面影响？

- 新兴或更强大的竞争对手
- 客户偏好或需求的变化
- 技术颠覆或技术过时
- 监管变化或合规风险
- 经济衰退或市场收缩
- 供应链中断
- 供应商或合作伙伴整合

## 输出流程
1. 识别 5-7 项优势（如实说明竞争优势）
2. 列出 5-7 项劣势（避免淡化问题；重点关注可解决的缺口）
3. 梳理 5-7 项机会（按市场规模和匹配程度确定优先级）
4. 标记 5-7 项威胁（评估发生概率和影响）
5. 交叉参考分析结果，提炼战略洞察：
   - 我们如何利用优势来抓住机会？
   - 我们如何补强劣势以减轻威胁？
   - 哪些机会可以弥补劣势？
   - 哪些威胁可能利用我们的劣势？
6. 制定 3-5 项战略建议
7. 确定行动优先级和负责人
8. 确定用于跟踪进展的指标

## 战略应用
- **构建**：加大投入于优势 + 机会
- **防御**：强化劣势 + 减轻威胁
- **转型**：探索能够改变竞争格局的机会
- **退出**：如果威胁过多且竞争地位薄弱

## 注意事项
- SWOT 用于从内部到外部的评估
- 背景很重要：应与竞争对手和行业标准进行比较
- 每季度更新一次 SWOT，或在市场状况发生变化时更新
- 使用 SWOT 为产品路线图、合作伙伴关系和资源分配提供依据
- 机遇和威胁应同时考虑当前和正在出现的动态
