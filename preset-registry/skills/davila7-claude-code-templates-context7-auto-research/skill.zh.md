# context7-auto-research

## 概述
通过 Context7 API 自动获取适用于 Claude Code 的最新库和框架文档

## 适用场景
- 当你需要获取库和框架的最新文档时
- 当你询问 React、Next.js、Prisma 或任何其他热门库时

## 安装
```bash
npx skills add -g BenedictKing/context7-auto-research
```

## 分步指南
1. 使用上述命令安装该 Skill
2. 配置 API 密钥（可选，详情请参阅 GitHub 仓库）
3. 在 Claude Code 对话中自然使用

## 示例
示例请参阅 [GitHub 仓库](https://github.com/BenedictKing/context7-auto-research)。

## 最佳实践
- 通过环境变量配置 API 密钥，以获得更高的速率限制
- 使用该 Skill 的自动触发功能，实现无缝集成
