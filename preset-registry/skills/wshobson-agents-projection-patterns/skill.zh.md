# 投影模式

构建事件溯源系统的投影与读模型的综合指南。

## 何时使用此技能

- 构建 CQRS 读模型
- 从事件创建物化视图
- 优化查询性能
- 实现实时仪表盘
- 从事件构建搜索索引
- 聚合跨流数据

## 核心概念

### 1. 投影架构

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ Event Store │────►│ Projector   │────►│ Read Model  │
│             │     │             │     │ (Database)  │
│ ┌─────────┐ │     │ ┌─────────┐ │     │ ┌─────────┐ │
│ │ Events  │ │     │ │ Handler │ │     │ │ Tables  │ │
│ └─────────┘ │     │ │ Logic   │ │     │ │ Views   │ │
│             │     │ └─────────┘ │     │ │ Cache   │ │
└─────────────┘     └─────────────┘     └─────────────┘
```

### 2. 投影类型

| 类型           | 描述                 | 使用场景               |
| -------------- | -------------------- | ---------------------- |
| **实时**       | 通过订阅实时处理     | 当前状态查询           |
| **追赶**       | 处理历史事件         | 重建读模型             |
| **持久**       | 存储检查点           | 重启后恢复             |
| **内联**       | 与写入处于同一事务   | 强一致性               |

## 最佳实践

### 推荐做法

- **让投影幂等** - 可安全重放
- **使用事务** - 用于多表更新
- **存储检查点** - 故障后可恢复
- **监控延迟** - 对投影延迟发出告警
- **为重建做好规划** - 设计时考虑可重构

### 禁忌做法

- **不要耦合投影** - 每个投影相互独立
- **不要跳过错误处理** - 记录日志并在失败时告警
- **不要忽略顺序** - 事件必须按顺序处理
- **不要过度规范化** - 针对查询模式进行反规范化
