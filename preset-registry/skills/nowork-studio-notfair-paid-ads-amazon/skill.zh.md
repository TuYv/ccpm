# Amazon Ads 规划

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。此插件未声明第一方 NotFair Amazon Ads MCP 变更接口；请使用经过验证的连接器或提供的报告，并交付一份可供审核的运营简报。

## 从单位经济效益开始

记录产品/ASIN、市场、币种、贡献毛利率、价格、库存约束和目标 ACoS。ACoS 等于广告支出除以归因广告收入；只有结合利润率和用户的战略目标，才能判断其表现是好是坏。在评估效果之前，应将广告产品与所有计量到的交叉销售区分开来。

提出范围最小的学习计划：产品范围、广告活动意图、自动发现或手动关键词/ASIN 假设、预算、否定/排除规则和复盘周期。将搜索词发现视为设置定向否定词或提升至受控定向投放的依据，而不是过早取消广泛发现的理由。

## 审核与移交

针对完整且可比的周期，报告广告支出、归因销售额、ACoS、ROAS（如有帮助）、订单量、转化率、搜索词质量和库存风险。说明报告延迟和归因来源。在经过验证的连接器或获得授权的 Amazon Ads 运营人员确认确切结果之前，将变更标记为 `ready_for_review`。
