# 待完成工作画布

待完成工作（JTBD）画布完整呈现了客户为何“雇用”产品来推动自己生活进展。JTBD 基于 Clayton Christensen 的框架，不局限于功能和人口统计特征，而是深入理解驱动客户行为的底层动机——功能性、情感性和社会性动机。

## 使用时机

- 在构建产品前深入研究客户动机时
- 围绕客户进展重新构建产品定位时
- 当现有用户画像过于表面化或仅停留在人口统计层面时
- 在竞品分析期间识别客户为何转换产品时
- 设计能够引发共鸣的营销信息时
- 让团队对客户究竟是谁以及他们需要什么达成一致时

## 不要使用的情况

- 你需要一个以人为中心的产物（目标、行为、引语）来支持设计或营销工作 -> 使用 `foundation-persona`；画布描述的是工作，用户画像描述的是人
- 你还没有任何客户研究 -> 先使用 `discover-interview-synthesis` 综合访谈；画布中的洞察必须能够追溯到研究，而不是源于假设
- 你正在界定当前要解决的某个具体问题 -> 使用 `define-problem-statement`
- 你需要将机会映射到可衡量的结果，以便进行优先级排序 -> 使用 `define-opportunity-tree`

## 说明

当被要求创建 JTBD 画布时，请遵循以下步骤：

1. **确定工作执行者**
   明确是谁在执行这项工作。不要局限于人口统计特征，还要捕捉他们所处的情境。同一个人在不同情况下可能会有不同的工作。

2. **描述具体情境**
   描述这项工作在何时、何地出现。工作通常由特定情境触发。理解背景有助于预测客户何时会寻求解决方案。

3. **撰写工作陈述**
   使用以下格式：“当[情境]时，我想要[动机]，这样我就能[期望结果]。”工作陈述概括了客户希望实现的核心进展。

4. **定义功能性工作**
   客户需要完成的实际任务是什么？这是工作中有形且可衡量的部分。具体说明什么才算“完成”。

5. **捕捉情感性工作**
   客户希望在执行这项工作期间以及完成后有什么感受？情感性工作往往比功能性工作更能驱动决策。同时纳入期望获得的感受，以及希望避免的感受。

6. **确定社会性工作**
   客户希望如何被他人看待？社会性工作与地位、身份和关系有关。并非所有工作都有很强的社会性维度。

7. **梳理竞争性解决方案**
   客户目前正在“雇用”什么来完成这项工作？包括直接竞争对手、间接替代方案，以及不消费（什么都不做）。了解当前解决方案有助于揭示你需要与哪些对象竞争。

8. **定义选择标准**
   客户选择某个解决方案而不是另一个的原因是什么？哪些是“必备项”，哪些是“锦上添花”？这将为定位和优先级排序提供依据。

## 输出格式

使用 `references/TEMPLATE.md` 中的模板来组织输出。一份完整的画布应填写模板中的每个部分：工作概览；工作执行者；情境；工作陈述；功能性工作；情感性工作；社会性工作；替代方案；雇佣标准；洞察与启示；支持性引述；以及后续研究问题。

## 质量检查清单

定稿前，请确认：

- [ ] 工作陈述遵循“When... I want... so I can...”格式
- [ ] 情境具体明确（不只是“任何时候”）
- [ ] 功能性工作描述了切实可见的结果
- [ ] 情感性工作包含客户希望拥有的感受
- [ ] 替代方案包括不明显的替代选择
- [ ] 洞察基于研究，而非假设
