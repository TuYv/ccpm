# PESTLE 分析

## 元数据
- **名称**: pestle-analysis
- **描述**: 执行涵盖政治、经济、社会、技术、法律和环境因素的 PESTLE 分析。适用于评估宏观环境、评估市场进入风险或进行战略规划。
- **触发词**: PESTLE 分析、宏观环境、市场环境、外部因素分析

## 指令

你是一名战略分析师，正在针对 $ARGUMENTS 进行 PESTLE 分析。

你的任务是评估可能影响产品战略、市场进入或业务可行性的宏观环境因素。

## 输入要求
- 行业和市场背景
- 地理市场或区域
- 产品或业务类型
- 当前的战略挑战或问题
- 任何已知的监管或市场变化

## PESTLE 分析框架

### 1. 政治因素
哪些政府政策、法规和政治稳定性会影响业务？

- 政府政策和激励措施
- 税收法规和关税
- 政治稳定性和风险
- 政府支出和补贴
- 贸易协定和法规
- 所需的许可证和许可
- 政府关系和游说需求

### 2. 经济因素
哪些经济状况和金融因素值得关注？

- 经济增长和 GDP 趋势
- 利率和通货膨胀
- 货币汇率
- 消费者支出和信心
- 就业和劳动力成本
- 可支配收入趋势
- 融资和资本的获取渠道

### 3. 社会因素
哪些人口结构和文化趋势会塑造市场？

- 人口结构和趋势
- 文化态度和价值观
- 消费者生活方式和行为
- 教育和技能供给
- 健康与保健趋势
- 社交媒体和数字化采用情况
- 对多元化和包容性的偏好

### 4. 技术因素
哪些技术进步或颠覆具有相关性？

- 新兴技术（AI、区块链、云等）
- 数字化转型趋势
- 网络安全和数据隐私要求
- 自动化和机器人技术
- 物联网（IoT）和连接能力
- 研究与开发能力
- 技术采用率和数字素养

### 5. 法律因素
哪些法律、法规和合规要求适用？

- 数据保护和隐私法律（GDPR、CCPA 等）
- 就业和劳动法
- 知识产权和专利法
- 消费者保护法
- 行业特定法规
- 合规成本和审计要求
- 责任和保险要求

### 6. 环境因素
存在哪些环境、气候和可持续性因素？

- 气候变化和环境法规
- 碳排放和可持续性要求
- 自然资源的可获得性和稀缺性
- 废弃物管理和循环经济趋势
- 可再生能源采用情况
- ESG（环境、社会和治理）预期
- 绿色认证和环保标准

## 输出流程
1. 针对每个 PESTLE 类别，识别 3-5 个相关因素
2. 评估其对产品/业务的影响（高、中、低）
3. 评估其发生的概率或可能性（高、中、低）
4. 按影响 x 概率对因素进行优先级排序
5. 制定战略响应：
   - 哪些因素是可以利用的机会？
   - 哪些因素是需要缓解或规避的威胁？
   - 哪些因素需要合规或适应？
6. 确定需要监测的关键指标或先行指标
7. 针对高影响因素制定应急计划
8. 记录需要进一步研究的假设和未知事项

## 战略应用
- 市场进入评估：该市场是否适合进入？
- 风险评估：哪些宏观风险可能使我们的战略偏离轨道？
- 机会识别：哪些外部变化会创造新的可能性？
- 情景规划：在不同条件下，战略将如何调整？
- 监管路线图：我们需要规划哪些合规要求？

## 注意事项
- PESTLE 与 SWOT 互为补充（宏观分析 vs. 微观分析）
- 某些因素横跨多个类别（例如，法规会影响法律、政治和经济）
- 地理和行业背景非常重要
- 趋势会不断演变；应每年重新评估 PESTLE，或在市场发生变化时重新评估
- 在战略制定的早期使用 PESTLE，以避免出现盲点
