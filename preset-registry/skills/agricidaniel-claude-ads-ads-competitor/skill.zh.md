# 竞品广告情报

1. 确认指定的竞争对手、市场、地域、客户、目标和待作决策。
2. 使用官方透明度资料库、公开广告、操作方提供的竞价数据以及其他符合条款要求的数据源。
3. 记录采集日期、平台、广告位、可观察到的创意/信息、落地页目标地址和来源 URL。
4. 将直接观察与对受众、支出、效果或策略的推断区分开；绝不将估算结果表述为账户事实。
5. 对具有持久性的主题、形式、优惠、漏斗路径和市场空白进行归类，同时不复制受保护的创意或文本。
6. 返回有证据支持的机会、风险、实验建议和来源记录。

遵守平台条款、robots 和访问控制要求，以及版权、商标和隐私规定。不得绕过身份验证或抓取私有账户界面。
