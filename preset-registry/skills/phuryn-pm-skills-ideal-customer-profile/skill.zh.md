# 理想客户画像

## 概述
根据研究和调查数据识别你的理想客户画像（ICP）。此技能综合客户研究，定义最有可能从你的产品中获得价值、持续留存并扩大使用范围的客户。

## 使用时机
- 根据产品市场契合度调查数据定义 ICP
- 瞄准高价值客户细分群体
- 分析客户成功和扩展使用模式
- 确定销售和营销工作的优先级
- 评估新客户机会的匹配度
- 优化目标市场定义

## ICP 框架组成部分

### 人口统计特征
从企业特征和个人特征角度来看，他们是谁？
- 公司规模（员工人数、收入）
- 行业或垂直领域
- 地理位置
- 职位和部门
- 担任该职位的年限
- 教育背景和个人经历
- 组织结构和汇报关系

### 行为
他们如何工作和做决策？
- 他们如何发现和评估解决方案
- 购买流程和决策时间线
- 技术素养和产品采用速度
- 协作方式（个人决策还是委员会决策）
- 变革管理和采用方式
- 更换工具的频率
- 社区参与度和同行影响

### 待完成的任务（JTBD）
他们想要完成什么？
- 他们试图实现的主要任务/目标
- 支持主要任务的次要任务
- 情感任务（他们希望获得的感受）
- 社交任务（地位和他人认知）
- 他们希望避免或消除的任务
- 每项任务的频率和重要性
- 完成任务的成功指标

### 需求和痛点
你的产品解决了哪些问题？
- 他们遇到的具体痛点
- 当前的变通方案及其局限性
- 对生产力或结果的影响
- 问题带来的成本或时间负担
- 情绪上的挫败程度
- 解决问题的障碍
- 可用于解决问题的预算
- 相互竞争的优先事项

## 工作原理

### 第 1 步：收集客户数据
收集有关实际客户和潜在客户的研究资料：
- 产品市场契合度调查回复
- 客户访谈记录
- 试用用户或免费增值用户的行为数据
- 客户反馈和支持工单
- 客户流失分析和客户生命周期数据
- 销售赢单/输单分析
- 竞争对手客户分析

### 第 2 步：按价值进行细分
识别客户群组及其价值：
- LTV（客户终身价值）最高的客户
- 实现价值所需时间最短的客户
- 流失率最低的客户
- 扩展使用/追加销售金额最高的客户
- 最热情/参与度最高的客户
- 最适合进行客户推荐/案例研究的客户
- 与产品愿景最契合的客户

### 第 3 步：建立人口统计特征画像
提取企业特征模式：
- 常见的公司规模（员工人数、收入）
- 行业垂直领域和子垂直领域
- 地理位置集中区域
- 典型的部门和汇报结构
- 预算持有人及可用预算
- 公司发展阶段（初创期、成长期、企业级）
- 公司文化指标

### 第 4 步：识别行为
梳理决策和采用模式：
- 他们如何发现你的产品（渠道）
- 评估流程和时间线
- 决策中的关键利益相关者
- 销售流程中的障碍
- 产品采用速度和使用广度
- 团队在入门过程中的参与程度
- 功能使用频率
- 支持和服务需求

### 第 5 步：定义 JTBD
阐明他们试图完成什么：
- 主要工作/目标（功能性工作）
- 情感层面（他们希望获得怎样的感受）
- 社交层面（对团队和利益相关者的影响）
- 成功指标（他们如何衡量成功）
- 背景与约束（何时、何地、与谁一起）
- 相互竞争的工作与优先事项
- 各项工作的优先级排序

### 第 6 步：记录痛点与需求
综合具体的问题领域：
- 当前状态（现状与挫败点）
- 期望的未来状态（理想状态）
- 差距大小及影响量化
- 问题的情感层面
- 阻碍解决方案的资源限制
- 疑虑或犹豫
- 对解决方案的成功标准

## 输入格式
使用 $ARGUMENTS 传入：
- 研究数据（调查、访谈、记录稿）
- 客户成功/指标数据
- 产品使用分析数据
- 销售活动及赢单/丢单数据
- 现有客户数据库
- 竞争情报

## 输出
一份全面的 ICP 定义，包括：
- 企业特征画像（公司规模、行业、所在地）
- 行为画像（购买模式、采用方式）
- 完整的 JTBD 映射（功能性、情感性、社交性工作）
- 排名前 5–7 的痛点及具体需求
- 量化的影响指标（问题成本、解决方案价值）
- 决策流程及关键利益相关者
- 典型客户旅程与时间线
- 对市场进入策略及信息传达的影响
- 排除标准（哪些对象并不适合）
- ICP 中的高价值细分市场（最理想客户中的理想客户）

## 框架
基于 Clayton Christensen 提出的待完成任务（Jobs to Be Done）理论和客户画像方法论。结合行为数据与动机洞察，定义可执行的客户画像。

## 提示
- 综合使用定量数据和定性数据
- 访谈 10 位以上高价值客户，以识别共性模式
- 寻找非显而易见的人口统计模式（异常值可能具有很高价值）
- 同时定义理想 ICP 和可接受的次级细分市场
- 随着收集到更多客户数据，每季度重新审视 ICP
- 使用 ICP 评估所有新的销售机会
- 在整个组织内共享 ICP（市场营销、销售、产品）
- 请记住：ICP 应用于推动聚焦，而不是排除所有其他对象
