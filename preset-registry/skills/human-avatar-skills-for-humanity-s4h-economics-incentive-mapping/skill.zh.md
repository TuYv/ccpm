# 经济学：激励映射

查理·芒格的格言是：“告诉我激励机制，我就能告诉你结果。”预测行为最可靠的依据，不是人们打算做什么、声称会做什么或被要求做什么，而是制度结构会因为什么行为而奖励他们。人们根据激励采取行动时，并非不理性或不道德；他们只是在理性地适应自己所处的环境。如果行为出现问题，问题通常出在激励结构，而不是人本身。

激励映射是一种系统化方法：识别行为会影响结果的每个相关方，确定当前安排下各方会获得什么、失去什么，预测这些激励会导致哪些行为，并将预测行为与期望行为进行比较。预测行为与期望行为之间的差距就是错配，而错配几乎总是组织、政策和市场失灵的根源。

这一框架以经典价格理论为基础，但其最具影响力的现代应用是在委托—代理分析中：当做出决策的人（代理人）与承担后果的人（委托人）面临不同的激励时，会发生什么？卡尼曼关于损失厌恶的研究又增加了一个层面——人们对潜在损失的反应强于对等额收益的反应，因此，仅依赖收益的激励机制，在系统性上弱于同时激活损失厌恶的机制。

## 你的流程

**第 1 步：梳理相关方**
识别系统中行为会影响结果的每个相关方。这包括：决策者、执行者、受益者、成本承担者，以及受到影响但没有正式角色的第三方。不要将名单局限于显而易见的参与者——最重要的激励往往属于与主要行动相隔一层的相关方。

**框架确认：** 在继续之前，确认系统和相关方。用一句话说明你识别出的内容，然后使用 `AskUserQuestion`：
- **问题：** “我的理解是：[一句话框架——正在分析的系统，以及行为会产生影响的相关方]。这样理解对吗？”
- **标题：** “框架”
- **选项：**
  - **是——继续** ——框架正确
  - **调整** ——有一个要素不准确；用户会在你继续之前予以纠正
  - **重新界定** ——实际情况与当前理解不同；继续之前纳入用户的纠正

**第 2 步：梳理各方的激励**
对于每个相关方，回答：采取期望行动会让他们获得什么？他们会失去什么？如果他们*不*采取期望行动，或者采取其他行动，会获得什么？既要记录正式激励（薪资、奖金、晋升、处罚、罚款、合同条款），也要记录非正式激励（声誉、地位、关系、对担责的恐惧、习惯）。

**第 3 步：预测行为**
根据第 2 步中梳理出的激励，预测每个相关方实际上会做什么，而不考虑他们被请求或被要求做什么。当正式要求与个人激励发生冲突时，理性行动者通常会遵循激励，而不是要求。明确指出这些冲突。注意损失厌恶会在哪些地方强化激励（损失威胁产生的反应强于等额奖励）。

**第 4 步：识别错位**
将预测行为（第 3 步）与期望行为（系统需要各方采取的行为）进行比较。对于每个差距，都要追问：问题是否在于正确的行为没有得到奖励？错误的行为反而得到了奖励？激励虽然存在，但力度太小？还是激励信号出现得太晚或不够明确？准确指出具体的激励错位。

**第 5 步：设计重新对齐方案**
针对每个激励错位，至少提出两种重新设计方案。这些方案可能包括：改变付费方或受益方、改变激励信号出现的时机、引入新的后果（正面或负面）、提高激励的透明度，或重构各方之间的关系。评估每个方案：它能否在不造成其他新错位的情况下实现激励对齐？

## 说明

委托—代理问题是最常见的激励错位形式：采取行动的人（代理人）与承担后果的人（委托人）具有不同的利益诉求。它广泛存在于雇佣、承包、专业服务、政治和金融中介等领域。其解决方案已经得到充分研究，包括：监督、绩效薪酬、声誉机制、统一时间跨度，以及利益共担机制。

激励图谱并不是假设人们贪婪或精于算计，而是承认所有人都会对其所处的环境作出反应，而环境的设计有优劣之分。得出“激励结构会推动人们走向 X”这一结论，并不意味着人们本身不好；它意味着该结构需要重新设计。

当你想要正式设计一个能够使激励保持一致的系统时，可与 `/s4h-game-theory-mechanism-design` 搭配使用——机制设计是重新设计的严谨版本。当激励问题嵌入更大的反馈动态中时，可与 `/s4h-systems-feedback-mapping` 搭配使用。当这种不一致正在引发明显冲突时，`/s4h-social-incentive-analysis` 可处理其中的政治和关系维度。

## 接下来做什么

交付此输出后，使用 `AskUserQuestion` 提供下一步选项：

- **问题：**“激励关系已梳理完毕。接下来做什么？”
- **标题：**“下一步”
- **选项：**
  - `/s4h-game-theory-mechanism-design` — 正式设计一个将正确激励内置于规则之中的系统
  - `/s4h-economics-externalities` — 某些成本或收益正由此图谱之外的相关方承担或获得
  - `/s4h-economics-coordination` — 这种不一致正在导致集体行动失败，而不只是个体层面的失灵
  - **完成** — 收尾并综合梳理目前为止的内容
