# 品牌建设

品牌战略、品牌识别与品牌定位，旨在打造差异化的市场形象。

## 语言与质量标准

**关键要求**：使用与用户相同的语言回复。如果用户使用越南语，则用越南语回复；如果用户使用西班牙语，则用西班牙语回复。

**标准**：提高 Token 效率，可牺牲语法以求简洁，在末尾列出尚未解决的问题。

---

## 何时使用此技能

在以下情况中运用品牌专业知识：
- 制定或更新品牌战略
- 创建品牌指南与标准
- 定义品牌声音与语调
- 构建品牌定位与信息传达框架
- 为多产品公司设计品牌架构
- 确保品牌在各渠道保持一致

## 核心概念

### 品牌基础要素

| 要素 | 定义 | 示例 |
|---------|------------|---------|
| 品牌宗旨 | 除盈利之外的存在意义 | “激发并滋养人文精神”（Starbucks） |
| 品牌愿景 | 未来的发展方向 | “让每张办公桌上都有一台计算机”（Microsoft，20 世纪 80 年代） |
| 品牌使命 | 如何实现愿景 | “整合全球信息”（Google） |
| 品牌价值观 | 品牌所坚持的原则 | 创新、诚信、客户至上 |
| 品牌个性 | 人格化特征 | 自信、活泼、值得信赖 |
| 品牌声音 | 品牌的沟通方式 | 对话式、专业、温暖 |
| 品牌承诺 | 客户可以期待获得什么 | “15 分钟可为你节省 15%”（GEICO） |

### 定位框架

**定位陈述模板**：
> 对于[目标受众]中有[需求/机会]的人而言，[产品名称]是一种[品类]，能够[核心利益]。与[竞争对手]不同，我们[独特差异点]，因为[可信理由]。

**强有力定位的要素**：
1. **目标受众**：具体明确，而非“所有人”
2. **参照框架**：你所参与竞争的品类
3. **差异点**：为何你既与众不同又更加出色
4. **可信理由**：证明依据与资质

### 品牌架构模式

**单一品牌架构**
- 所有产品统一使用一个主品牌
- 子品牌归于主品牌旗下
- 示例：Google（Maps、Drive、Cloud 等）
- 最适合：B2B、依赖信任、产品相互关联的业务

**多品牌架构**
- 各品牌相互独立，母公司居于幕后
- 每个品牌都有独特定位
- 示例：P&G（Tide、Pampers、Gillette）
- 最适合：品类多样、受众不同的业务

**背书品牌架构**
- 子品牌获得母品牌背书
- 在一定程度上保持独立，同时提升可信度
- 示例：Marriott（Courtyard by Marriott）
- 最适合：拓展至相邻品类

**混合品牌架构**
- 根据战略适配性混合使用多种模式
- 示例：Apple（Apple、Beats by Dr. Dre）

### 品牌声音光谱

| 维度 | 光谱 | 选择依据 |
|-----------|----------|-----------------|
| 正式 ←→ 随意 | 专业与友好 | 受众期望、行业规范 |
| 严肃 ←→ 活泼 | 权威与有趣 | 产品品类、品牌个性 |
| 技术化 ←→ 简单 | 专业与易懂 | 受众专业水平、产品复杂度 |
| 谦逊 ←→ 自信 | 低调与大胆 | 品牌成熟度、市场地位 |

### 品牌资产构成

1. **品牌知名度**：品牌识别与回忆
2. **品牌联想**：人们对你的看法和感受
3. **感知质量**：对卓越品质的预期
4. **品牌忠诚度**：重复购买行为与主动推荐

## 最佳实践

### 卓越战略
1. **研究先行**：基于客户洞察而非主观假设进行定位
2. **实现有意义的差异化**：既要与众不同，又要与目标受众相关
3. **占据一个关键词**：因一件事而为人所知（沃尔沃 = 安全）
4. **长期保持一致**：品牌建设需要数年，而非数月

### 卓越指南
1. **实用示例**：不仅要说明，还要展示
2. **正确/错误示例**：明确界限
3. **针对具体情境**：为不同渠道和场景制定指南
4. **动态文档**：随着品牌发展持续更新

### 卓越品牌声音
1. **塑造个性，而非制定规则**：定义品牌个性，而不只是罗列词汇
2. **情境灵活性**：保持相同的品牌声音，根据情境采用不同语气
3. **培训示例**：提供现实应用示例
4. **词汇库**：我们使用的词汇 / 我们避免的词汇

## 应避免的反模式

| 反模式 | 错误原因 | 正确做法 |
|--------------|----------------|-----------------|
| 模仿竞争对手 | 导致同质化 | 寻找独特定位 |
| 面向所有人进行定位 | 无法吸引任何人 | 聚焦特定受众 |
| 频繁改变品牌 | 损害品牌资产 | 逐步演进，而非彻底放弃 |
| 品牌声音缺乏个性 | 听起来千篇一律 | 定义人性化特质 |
| 指南缺少示例 | 难以应用 | 展示实际应用方式 |
