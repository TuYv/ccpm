# 运动法则（总纲）

在编排任何动画之前，请先阅读本文档。它决定了每个场景衔接处要发生什么，以及每个场景应如何呈现；具体技术技能负责实现这些规则。这些规则优先于通用的／上游运动指导。它所防止的问题是：各场景彼此孤立地制作——视线的动势在每次剪切时都会中断，而场景在进入和退出之间只会原地晃动。

## 路线图

| 决策（本技能）                                     | 实现技能                                                                                          |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 衔接转场的选择 + 参数 + 代码                       | `cut-the-curve` §1–5（目录）                                                                      |
| 文本／元素进入的级联效果                           | `cut-the-curve` §6（瀑布式进入）                                                                  |
| 场景内编组重新定位（无剪切）                       | `cut-the-curve` §7（微移曲线）                                                                    |
| 光标引导的操作／场景启动／变形触发                 | `oversized-cursor`                                                                                |
| 衔接渲染机制／白闪防护                             | `seam-craft`                                                                                      |
| 产品发布／解说／字幕工作                           | 在上游技能之上叠加 `text-beat-economics`、`brand-faithful`、`captions-overlay`                    |

制作顺序：**矢量台账（`ledger.json`）→ 根据台账为主衔接处盖章标记
（`scripts/seam-stamp.mjs --ledger ledger.json --write index.html`）→ 每个阶段的持续运动
路线 → 载体与动因 → 构建合成 → 验证（`scripts/seam-gate.mjs`）。**
仅手工制作 A 级变形／匹配剪切；经盖章标记的衔接天然可以通过门禁检查。

# 第 1 部分——衔接法则

## 矢量法则

> 场景 A 如何退出，决定了场景 B 如何进入：轴线相同、方向相同、速度匹配，
> 并且在两侧运动进行到一半时剪切。

1. **轴线**——x 始终对应 x，y 始终对应 y，Z 始终对应 Z。绝不能跨剪切切换轴线。
2. **方向**——绝不能镜像反转。对于 Z 轴，方向 = 缩放变化的正负号：放大 =
   推进（摄影机向前），缩小 = 拉远（摄影机向后）。一个后退的退出动作如果接上
   从小到大的进入动作，就形成了镜像矢量——这是最常见的违规，因为
   从小到大是元素进入的默认方式。
3. **速度**——通过镜像缓动，使进入的初始速度 ≈ 退出的最终速度（退出使用
   `power4.in` + 进入使用 `power4.out`，距离和持续时间相同；进入侧从假想路径
   ≥50% 的位置开始衔接）。具体机制见 `cut-the-curve`。
4. **相位**——剪切点必须落在两侧运动进行到一半的位置。在剪切前减速至静止，
   或在剪切后从静止开始，都会形成节奏断点。

## 主流向

每部影片都选择一个主导方向（默认规范：向左）。每个常规衔接都使用这个方向。
其他矢量属于保留资源——一旦使用，就必须有所表达：

| 向量                      | 含义                                                            |
| ------------------------- | --------------------------------------------------------------- |
| 当前方向（向左）          | “下一拍”——中性地向前推进                                        |
| 向上                      | 提升——结论或揭示上升到此前内容之上                              |
| Z 轴向前（穿透式缩放）    | 更深入地推进同一思路                                            |
| Z 轴向后（反向缩放）      | 抵达——更重大的内容落定                                          |
| 尺度爆发（向外炸开）      | 离开一个世界——某个表面从摄像机旁呼啸而过                        |

- 绝不要让连续的接缝朝相反方向运行——来回摆动看起来像是错误。
- 改变方向需要有可见的原因（点击 / 弹跳 / 撞击），或发生在章节边界。

## 向量台账

在编写任何主时间线之前先写好它——作为项目根目录下的 **`ledger.json`**
（模式：`references/seam-gate.md`）。每个接缝一行：切换时间、退出和进入向量
（轴 + 带符号的方向；Z 轴行还需包含缩放符号）、选择器、技术手段。退出和
进入必须匹配；如果某一行不匹配，应修正方案，而不是缓动。验证器会在任何
运行时采样之前静态检查各行的一致性。

## 载体

眼睛追随的是对象，而不是抽象概念。最有力的接缝会在切换前后，以匹配的位置和
速度交接一个具体载体：路径中途的光标、缩小/停靠到下一布局中的容器、飞入精确
位置的标记、瀑布式切换中的词组。如果没有自然载体，就由场景主角来承担
（部分移动 + 提前淡出，进入时已在飞行途中）。绝不要使用交叉淡化——它根本没有载体。

## 因果运动

将运动串联起来，使每个动作都明显由上一个动作触发：点击 → 挤压 → 释放
弹簧 → 飞行 → 撞击 → 回弹 → 揭示。

- 效果应在触发它的那一帧开始——位于同一时间线位置，绝不能“稍后”开始。
- 反应幅度应与隐含质量相称：大元素回弹较慢，小元素快速弹回。
- 作用力赋予了改变方向的正当理由；无缘无故的反转就是来回摆动。

## 接缝门禁（构建门禁——运行验证器，退出码为 0，否则接缝就不算完成）

```bash
node <SKILL_DIR>/scripts/seam-stamp.mjs --ledger ledger.json --write index.html  # generate
node <SKILL_DIR>/scripts/seam-gate.mjs  verify --ledger ledger.json --project .  # verify
```

该脚本（用法 + 台账模式：`references/seam-gate.md`）会对每个接缝执行数值验证：
台账行一致性、退出侧在切换时仍处于运动中、进入侧已在飞行途中（绝不从静止开始）、
测得方向 = 台账方向、进入/退出速度匹配（警告）、**零重叠**（每一帧只有一侧可见——
该切换不是叠化）、**Z 轴符号**规则（两侧的 d(scale)/dt 符号相同；还会扫描进入
场景自身的入场动画，以检查是否存在符号冲突），以及包含祖先元素缩放在内的载体
矩形连续性。编写台账时，使用 `seam-gate.mjs probe --t <cut>` 查找每个接缝真正的
载体选择器。

脚本无法检查的规则——仍由你负责：

1. **编辑会重新打开接缝。** 对场景开头/结尾约 1 秒所做的任何更改（包括
   为适配新 VO 而重新调整时序）都会使该边界的审计失效——请重新运行验证器。
2. **音频就是时钟。** 根据 VO 的真实单词时间戳重新调整场景时序；绝不要为了
   塞进时间段而加快朗读。重新生成 VO 会重新打开其接缝。
3. **片段门控陷阱**（导致零重叠 FAIL 的常见原因）：如果片段的
   `data-start` 早于其入场补间动画，它会以初始不透明度取消隐藏——请将
   初始 `autoAlpha: 0`，并将 `data-start` 设为切换时间，绝不能更早。

# 第 2 部分——表演（场景持续演绎）

## 不要空闲摇摆

禁止将空闲正弦循环（呼吸、漂浮、飘移、光晕脉动）用作持续运动——它们会
给人“视频正在等待”的感觉。一个场景完成入场后还剩数秒，是规划上的错误：
应增加叙事，而不是摇摆。入场与退场之间的每个阶段都必须归属于以下路线之一
（在计划中注明路线名称）：

| 路线                   | 含义                                                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **分阶段揭示**         | 暂不展示内容；在旁白节拍处兑现——画面持续增加信息（有 ≥2 个内容组时的默认选择）                                        |
| **有意图的镜头运动**   | 规划好的缩放+平移路径：以广角建立场景 → 移动 → 抵达主体                                                                 |
| **有序的 UI 活动**     | 产品随时间推移产生行为：进度推进、高亮逐步切换、计数递增                                                               |
| **动画序列**           | 元素通过动作演绎一个节拍：卡片归入一叠、项目被拖动、结果逐步组装                                                       |
| **光标引导的操作**     | 超大光标引导视线移向触发点；其 CLICK 点燃下一个节拍（`oversized-cursor`）                                               |

测试：在任意一秒暂停——都必须有某个有意义的动作正在进行（一次揭示正在落定、
镜头正在移动、UI 正在执行旁白所描述的操作）。

## 高潮前的静止

在主要动作与其结果之间安排一次 **0.3–0.75 秒的停顿**——这是戏剧性的逗号。
如果场景从动作直接跳到结果，就会失去这种效果。

## 时序意图

- 单次入场 ≤ 约 800ms；更长的铺垫应使用多元素错落动画，而不是让单个元素缓慢运动。
- 退场时长约为入场的 75%。例外：切断曲线会反转这一比例（入场约为退场的 127%）。
- 错落动画总时长 ≤ 500ms；有 8 个以上元素时，应缩短每项的延迟，或只让前几个元素错落出现。
- 禁用的缓动：`bounce.out` / `elastic.out`。入场过冲使用 `back.out(1.4–1.7)` 没有问题。
- 相似元素应共用同一种缓动+时长意图——绝不要为每个元素使用独有的组合。

## 转场词汇

每部影片只使用 2–3 种场景间转场，并重复使用；默认边界为
**沿当前场景方向切断曲线**。手写的共享元素变形
（`intent: morph`）不计入此预算。

## 反模式

| 不要这样做                                                               | 应该这样做                                           |
| ------------------------------------------------------------------------ | ---------------------------------------------------- |
| 孤立地设计每个场景的入场                                                 | 先编写矢量账本                                       |
| 在场景之间使用交叉淡化                                                   | 沿当前运动方向切断曲线                               |
| 退场完成，之后场景才发生变化                                             | 在运动中途切换，前后两侧都保持运动                   |
| 切换后从静止状态开始入场                                                 | 从假想路径上已完成 ≥50% 的位置入场                   |
| 反向缩放退场 → 从小变大入场（或推进 → 超大尺寸回缩）                    | 匹配缩放速度的正负号（接缝门 7）                     |
| 在 Z 轴接缝交接下，新场景仍使用自己的弹出式开场动画                     | 保持其开场画面的构图，或匹配运动正负号               |
| 用无意义的摇晃／呼吸／漂浮来填充时间                                    | 指定一条持续运动路线；或添加叙事                     |
| 无缘无故地改变方向                                                       | 消耗一个作用力，或维持当前方向                       |
| 将保留矢量用于制造变化                                                   | 默认沿用当前矢量；将保留矢量用于表达意义             |
| 结果反应比原因晚几帧发生                                                 | 在同一帧触发                                         |
| 动作直接跳到结果                                                         | 在高潮前安排静止时刻（0.3–0.75 秒）                  |
