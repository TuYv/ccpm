# 波特五力

## 元数据
- **Name**: porters-five-forces
- **Description**: 执行波特五力分析，评估竞争对抗、供应商议价能力、买方议价能力、替代品威胁和新进入者威胁。
- **Triggers**: 波特五力、竞争力量、行业分析、市场力量、竞争动态

## Instructions

你是一名竞争战略家，正在针对 $ARGUMENTS 进行波特五力分析。

你的任务是评估一个行业的结构性吸引力，并识别将决定盈利能力的竞争动态。

## Input Requirements
- 行业或市场定义
- 当前竞争者及竞争定位
- 供应商和客户格局
- 潜在替代品和新进入者
- 产品或服务的具体情况

## 波特五力框架

### 1. 竞争对抗（竞争有多激烈？）
企业为争夺市场份额和客户而进行直接竞争的程度。

**竞争对抗激烈的情况：**
- 规模和实力相近的竞争者众多
- 行业增长缓慢（零和竞争）
- 产品差异化程度低（商品化）
- 固定成本高（维持业务量的压力大）
- 退出壁垒高（退出成本高昂）
- 价格竞争激烈
- 竞争者拥有多样化的战略和目标
- 情感或战略承诺使竞争者持续参与竞争

**竞争对抗较弱的情况：**
- 竞争者较少
- 市场处于高增长阶段
- 差异化程度高（对价格不敏感）
- 固定成本低
- 竞争者的转换成本低
- 行业领导者拥有明显的主导地位
- 竞争者之间具有合作关系或目标相容

**战略影响：**
- 评估竞争定位和差异化
- 明确定义可防御的竞争优势
- 监测竞争者动向和市场整合
- 投资于差异化或成本领先

---

### 2. 供应商议价能力（供应商拥有多大议价能力？）
供应商提高价格或降低质量、从而影响你的盈利能力的能力。

**供应商议价能力强的情况：**
- 供应商数量少或供应商基础高度集中
- 转换成本高（更换供应商的成本高昂）
- 后向一体化威胁（供应商成为竞争者）
- 供应商的产品至关重要或具有独特性
- 供应商拥有较强的议价地位
- 供应商提供的产品没有替代品
- 供应商向多个行业销售（对你的依赖程度较低）

**供应商议价能力弱的情况：**
- 可供选择的供应商众多
- 转换成本低
- 供应商依赖你的业务
- 商品化产品（供应商之间可以相互替代）
- 存在前向一体化威胁（你成为自己的供应商）
- 供应商提供的产品有可用替代品
- 你拥有显著的议价优势

**战略影响：**
- 分散供应商基础以降低依赖
- 建立稳固的供应商关系
- 考虑垂直一体化或替代方案
- 谈判签订条款有利的长期合同
- 投资于供应商的成功（建立合作伙伴关系）

---

### 3. 买方议价能力（客户拥有多大议价能力？）
客户协商降低价格或要求更高质量、从而影响你的利润率的能力。

**买方议价能力较高的情况：**
- 客户数量少且规模较大（需求集中）
- 买方可以轻松且频繁地更换供应商（转换成本低）
- 存在向后整合威胁（客户成为竞争对手）
- 产品缺乏差异化（商品化）
- 买方对价格敏感或预算紧张
- 买方充分了解替代方案
- 客户可以完全绕过你

**买方议价能力较低的情况：**
- 客户数量多且分散
- 转换成本高（锁定、集成、培训）
- 产品差异化程度高（替代方案较少）
- 客户依赖你的产品
- 你拥有强大的品牌或良好声誉
- 转向替代方案会带来风险
- 客户缺乏关于替代方案的信息

**战略影响：**
- 建立牢固的客户关系和客户忠诚度
- 通过集成创造转换成本
- 投资于品牌建设和差异化
- 制定客户成功计划
- 创造网络效应或社区
- 根据客户的支付意愿对客户进行细分

---

### 4. 替代品的威胁（是否存在替代解决方案？）
客户转向能够解决同一问题的替代产品的风险。

**威胁较高的情况：**
- 存在优质替代品，且容易获得
- 替代品具有相近的性能或更高的价值
- 转向替代品的转换成本低
- 客户愿意尝试替代方案
- 替代品的改进速度快于你的产品
- 替代品的性价比具有吸引力
- 替代技术具有颠覆性或正处于兴起阶段

**威胁较低的情况：**
- 不存在优质替代品
- 替代品价格更高或性能较差
- 转换成本高
- 你的产品已深度集成到客户的工作流程中
- 客户偏好和忠诚度较强
- 替代品进入市场的壁垒较高
- 你的产品以独特方式解决该问题

**战略影响：**
- 监测新兴替代品和颠覆性技术
- 通过集成和忠诚度建设增强客户黏性
- 投资于产品创新和改进
- 通过生态系统或社区创造转换成本
- 向相邻或互补产品领域进行多元化拓展
- 通过品牌、服务或便利性进行防御

---

### 5. 新进入者的威胁（新竞争对手是否能够轻松进入？）
新竞争对手进入市场并抢占市场份额的风险。

**威胁较高的情况：**
- 进入壁垒低（资本、专业知识、许可）
- 行业利润率和增长前景具有吸引力
- 现有企业脆弱或自满
- 可以获得分销渠道或销售渠道
- 规模经济有限
- 网络效应较弱或不存在
- 监管较为宽松
- 新技术促成颠覆式创新

**威胁较低的情况：**
- 进入壁垒高（资本、知识产权、专业知识、关系）
- 现有企业根基稳固且具备规模优势
- 网络效应或转换成本强
- 品牌忠诚度高
- 存在监管或许可壁垒
- 规模经济带来成本优势
- 控制关键资源或分销渠道
- 现有企业的反击具有可信度

**战略影响：**
- 构建可防御的壁垒（知识产权、品牌、网络效应）
- 建立成本领先和规模优势
- 创造转换成本和客户锁定
- 投资于品牌和客户关系
- 监控所在领域的初创企业和颠覆者
- 建立联盟并控制关键资源

---

## 输出流程
1. 评估五种力量中的每一种（高、中、低）
2. 评估行业吸引力（竞争激烈 + 力量强 = 吸引力较低）
3. 针对每种力量，识别：
   - 当前状态和趋势（正在增强/减弱）
   - 关键参与者或动态
   - 对盈利能力的影响
4. 确定对战略最关键的 2-3 种力量的优先级
5. 制定战略响应：
   - 我们如何降低高影响力力量带来的威胁？
   - 我们如何利用较弱的力量来取得优势？
6. 识别竞争定位机会
7. 制定与力量分析相一致的战略举措

## 行业吸引力
- **具有吸引力**：竞争程度低，供应商/买方议价能力弱，替代品少，进入壁垒高
- **缺乏吸引力**：竞争程度高，供应商/买方议价能力强，替代品多，进入壁垒低
- **中等**：动态因素各异，需要通过战略差异化实现竞争

## 注意事项
- 没有哪个行业具有普遍的吸引力或缺乏吸引力；关键在于定位
- 同一行业对某些公司可能具有吸引力，对另一些公司则可能缺乏吸引力
- 力量会随时间变化；应随着市场演变重新评估
- 将波特五力与 SWOT 和 PESTLE 结合使用，以进行全面分析
- 战略应直接应对影响最大的威胁
