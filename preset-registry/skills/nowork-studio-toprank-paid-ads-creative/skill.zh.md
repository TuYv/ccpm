# 付费广告创意

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。根据具体情况，将平台执行工作交由 `/notfair:google-ads-copy`、`/notfair:google-ads-assets`、`/notfair:meta-ads-creative`、`/notfair:paid-ads-x` 或 `/notfair:paid-ads-linkedin` 处理。

## 基于明确的证据开展工作

从经过验证的来源入手：表现优异的广告、搜索词、客户研究、已获批准的落地页声明、销售通话、经授权使用的评论，或有文档记录的优惠方案。确保每项承诺与其目标落地页相匹配。不得捏造客户证言、评分、价格、效果、供应情况、所有权或产品证明。

## 制作创意方案集

交付三张彼此不同的 `ready_for_review` 概念卡。每张卡片包含：

- 概念 ID 和假设：受众 × 动机 × 角度 × 格式 × 一个变量；
- 证据来源和声明台账，不受支持的声明标记为 `needs_substantiation`；
- 钩子、核心信息、CTA、目标页面和版位适配；
- 视觉/制作简报，包括所需权利或缺失素材；
- 成功指标、护栏指标、归因窗口、观察窗口和失败条件。

不要制作同一创意的表面变体。每次只测试一个策略变量：钩子、证明、格式、角度、受众或目标页面。在建议更新创意之前，先结合完整观察窗口内的频次、链接 CTR、CPM 和投放情境诊断创意疲劳。

## 发布边界

发布前，从经过验证的来源核实当前的平台规范和政策。简报或生成的图像并不能证明某项声明符合规定，也不能证明平台已接受该素材。对于没有经过验证的 NotFair 变更操作入口的平台，应输出可供运营人员直接执行的简报和清晰的交接说明，而不是承诺上传。
