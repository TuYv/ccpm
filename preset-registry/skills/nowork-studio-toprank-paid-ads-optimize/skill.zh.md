# 付费广告优化

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。在更改任何内容之前先进行审查。

## 先诊断，再削减

核实转化信号、周期完整性、支出规模、归因模型以及近期的账户变更。有支出但没有记录到转化，可能表示跟踪出现故障或数据尚未成熟；在信号和数据量足以支持干预之前，应将其视为一种假设。在归咎于定向之前，先检查落地页或运营方面的故障。

将瓶颈归类为查询/受众质量、创意疲劳、投放/排名、预算限制、落地页不匹配、跟踪或经济效益。使用专门的 Google、Meta、X 或 LinkedIn skill 进行实时诊断。对于其他平台，仅分析已提供或经核实的数据。

## 对可逆操作进行排序

优先采用以下顺序：排除不相关的查询、广告位或受众；暂停范围最窄的亏损单元；以审慎的幅度调整预算或出价；然后再考虑结构性变更。进行预算重新分配时，应展示当前分配方案和拟议分配方案；除非用户批准增加预算，否则总预算应保持不变；同时还应说明可观察验证的假设。

不要仅凭几次点击就判定某个单元表现不佳。应根据指定的目标 CPA、转化延迟和渠道角色设定适当的阈值。保留对上层漏斗和辅助转化的考量，而不是仅依据末次点击 CPA 来评判所有广告活动。

## 审批与后续跟进

列出每项具体变更，包括其范围、当前值、拟议值、涉及的货币金额、理由和复查日期。获得批准后，只能通过经验证的平台 skill 或连接器执行操作，回读执行结果，并记录此次干预的预期效果和护栏。应在声明的观察期结束后重新审查，而不是笼统地承诺持续监控。
