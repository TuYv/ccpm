# ru-text — 俄语文本质量

由 Arseniy Kamyshev 编写的独立俄语文本质量参考资料。
谨向以自身工作塑造了现代俄语文本标准的作者们致谢。
致谢与推荐阅读：`references/sources.md`

**风格优先级**：如果用户明确要求特定风格（口语化、学术、SEO、文学等），用户的提示词在与这些默认规则冲突时优先适用。这些规则是默认值，而非强制要求。

**审阅与重写**：在*检查*或校对现有文本或文件时，返回修正后的版本以及变更列表——不要悄悄覆盖源文件。只有当用户明确要求时才就地重写文件。

**他人的文字归他人所有**：用户文档中的引用材料、代码块和第三方文本按原样保留。如果其中的问题确有影响，可以指出；绝不改写它们。

## 始终开启：排版

应用于所有俄语文本输出——静默进行：修复，但不宣告。

| 规则 | 错误 | 正确 |
|---|---|---|
| 主引号：双尖引号（guillemets） | "текст" | «текст» |
| 嵌套引号：德式引号（lapki） | «"вложенные"» | «„вложенные“» |
| 破折号（—），其前加 NBSP | слово - слово | слово — слово |
| 范围用连接号（–），两侧不加空格 | 10-15 дней | 10–15 дней |
| 单字母词后加 NBSP | в начале (可断行) | в\u00A0начале |
| 省略号：单个字符 | ... | … |
| 数字分组用窄空格 | 1000000 | 1 000 000 |
| 小数用逗号（不用点号） | 3.14 | 3,14 |
| 序数词用连字符 | 1ый, 2ой | 1-й, 2-й |
| 序号符 | No. 5, #5 | № 5 |
| 缩写中用 NBSP | т.д., т.е. | т. д., т. е. |
| 卢布符号置于数字之后，加 NBSP | 1500₽ | 1 500 ₽ |

完整排版参考：`references/typography.md`

`/ru-text:ru-score` — 文本质量评分（0–10 分，5 个维度）。

## 质量检查清单

交付俄语文本之前：

- [ ] 引号：外层用 «»，嵌套用 „“
- [ ] 破折号：正文中用 —（前面加 NBSP），范围用 –，复合词中才用 -；每段最多 1–2 个（一组平行结构算作一个，对话中的破折号不计入）；删减到上限为止，而不是减到零；一组要么整体编辑，要么完全不动
- [ ] 在 в, к, с, о, у, и, а, я 之后加 NBSP
- [ ] 省略号：…（单个字符）
- [ ] 缩写：т. д., т. п.（带 NBSP）
- [ ] 无双空格，标点前无空格
