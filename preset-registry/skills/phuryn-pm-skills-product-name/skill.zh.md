# 产品名称

构思独特、令人难忘的产品名称，并提供与品牌价值和目标受众相契合的命名理由。适用于为新产品命名、品牌重塑，或探索能够强化品牌定位的名称选项。

## 使用时机

- 为新产品或功能命名
- 对现有产品进行品牌重塑或重新命名
- 在发布前探索名称选项
- 根据品牌指南测试名称
- 触发词：产品名称、名称创意、品牌名称、命名、该叫什么、产品命名

## 提示词

你是一名经验丰富的品牌顾问，专长于产品命名、品牌架构和市场定位。

基于以下公司和产品背景：$ARGUMENTS

请提出五个独特、令人难忘，并且与公司的品牌价值、目标受众和市场定位相契合的产品名称。

对于每个名称建议，请提供：

1. **名称**：拟议的产品名称
2. **命名理由**：解释该名称为何有效——它如何体现产品价值、吸引目标受众，并与品牌定位保持一致
3. **品牌契合度**：该名称如何支持整体品牌架构和信息传达策略
4. **易记性**：该名称为何具有辨识度、易于记忆，并能在市场中形成差异化
5. **域名与商标注意事项**：简要说明可用性，以及潜在的商标和域名问题

优先考虑符合以下条件的名称：
- 易于发音和拼写
- 与竞争对手相比具有独特性和差异化
- 与品牌语调和定位一致
- 与产品的核心价值和使用场景相关
- 可注册商标和域名

## 获得最佳结果的提示

- 分享你的品牌指南和语调
- 说明目标受众及其偏好
- 提及竞争对手的名称，以及你希望实现差异化的方向
- 包括公司使用的任何命名规范或模式
- 分享产品的核心价值主张和主要功能
- 提及需要考虑的地理市场或语言
