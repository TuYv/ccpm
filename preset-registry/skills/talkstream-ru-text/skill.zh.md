# ru-text — 俄语文本质量

由阿尔谢尼·卡梅舍夫（Arseniy Kamyshev）编写的独立俄语文本质量参考。
谨向那些以著作塑造了现代俄语文本标准的作者们致谢。
致谢名单与推荐阅读：`references/sources.md`

**风格优先级**：如果用户明确要求某种特定风格（口语化、学术、SEO、文学性等），则在冲突之处，用户的提示词将覆盖这些默认规则。这些规则是默认约定，而非强制要求。

**审校与改写的区别**：在*检查*或校对现有文本或文件时，应返回修正后的版本并附上修改清单——不要悄悄覆盖源文件。只有当用户明确提出要求时，才就地改写文件。

## 始终启用：排版规则

对所有俄语文本输出，无一例外地应用以下规则。

| 规则 | 错误 | 正确 |
|---|---|---|
| 主引号：双尖括号引号 | "текст" | «текст» |
| 嵌套引号：„小爪子"引号 | «"вложенные"» | «„вложенные"» |
| 破折号（em dash）两侧留空格 | слово - слово | слово — слово |
| 范围用连接号（en dash），不加空格 | 10-15 дней | 10–15 дней |
| 单字母前置词后用不换行空格 | в начале（可能被断行） | в\u00A0начале |
| 省略号：单个字符 | ... | … |
| 数字分组用窄空格分隔 | 1000000 | 1 000 000 |
| 小数用逗号（不用点号） | 3.14 | 3,14 |
| 序数词加连字符 | 1ый, 2ой | 1-й, 2-й |
| 编号符号 | No. 5, #5 | № 5 |
| 缩写中用不换行空格 | т.д., т.е. | т. д., т. е. |
| 卢布符号置于数字之后 | 1500 руб | 1 500 ₽ |

完整排版参考：`references/typography.md`

## 高频禁用词（删除或替换）

| 禁用词 | 替换为 |
|---|---|
| является | —（破折号）或调整句式 |
| осуществлять | делать, проводить |
| в настоящее время | сейчас |
| данный | этот |
| определённый | （点明具体事物） |
| произвести оплату | оплатить |
| высококачественный | （点明具体品质） |
| был осуществлён | （主动语态 + 施动者） |
| на сегодняшний день | сегодня |
| в целях | чтобы |

## 质量检查清单

交付俄语文本之前：

- [ ] 引号：主引号使用 «»，嵌套引号使用 „“
- [ ] 破折号：正文用 —，范围用 –，连字符 - 仅用于复合词；每段最多 1–2 个
- [ ] в、к、с、о、у、и、а 之后加不换行空格
- [ ] 省略号：…（单个字符）
- [ ] 缩写：т. д.、т. п.（带不换行空格）
- [ ] 无双空格，标点前无空格
