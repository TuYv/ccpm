# data-forms

这是一套形式库，而非一种风格。它提炼自 Lenny's Newsletter 的数据插图
（2025-2026 年调查特刊）——这些图表之所以有效，不是因为配色，而是因为
形式选择和编码规范。两者都可以迁移到任何视觉语言中。

对于视觉层，请沿用目标环境已有的方案：在产品内界面中使用产品的品牌
令牌，使用内置的 `dataviz` skill 构建配色并确保可访问性，在个人网站中使用你自己的风格。
这个 skill 决定的是*数据采用什么形状*——也就是颜色之上的那一层。

## 比形式更重要的六个决定

**1. 在选择形式之前，先写出结论。**
补完整这句话：“这张图的重点是 ___。”如果你做不到，那你拥有的是一张表格，
而不是图表，任何形式都救不了它。这句话将成为标题。标题只有两种合规
模式：

- *论断*，用于比较和分析——“倦怠正在激增，而乐观情绪正在消退”
- *逐字引用问题*，当图表展示的是答案分布时——“你有多担心
  裁员？”

绝不能使用字段名。“按公司规模划分的倦怠情况”只是一个电子表格标签页。

**2. 标出每一个数值。**读者绝不应该根据坐标轴估算数值。数字应紧邻
对应的标记。这正是你有资格执行第 3 条的原因。

**3. 删除坐标轴。**只保留基线——不要 y 轴、网格线或刻度。例外情况是：
时间序列图和斜率图，因为其中的*形状*就是要传达的信息，需要参考
网格。在其他所有情况下，坐标轴都只是你忘了移除的脚手架。

**4. 能直接标注时，就不要使用图例。**类别名称应放在对应标记上或旁边。只有当
一个图例服务于多个面板（小多图），或编码了一个与位置正交的维度（效价、群体归属）
时，使用图例才合理。

**5. 突出两个，其余弱化。**在包含九个类别的比较中，只有标题点名的一个或两个
对象应得到强调；其他对象都应退居次要位置。图表应论证标题，而不是
展示表格。如果突出显示的对象实际上并非离群值，那么图表刚刚反驳了你的标题——
修改标题，而不是数据。

**6. 在图内展示注意事项。** 小样本量、误差范围、未回应、「由于可多选，百分比总和超过 100」——把这些放在图表中，而不是脚注里。对不显著的条形使用虚线轮廓，并加上括号标注「差异在误差范围内」，比一张干净的图表配上一条无人阅读的免责声明更可信。

还有一项限制：**最多只能有一个注释。** 指出读者原本可能忽略的内容。没有也可以。两个就显得杂乱。

## 编码经验法则

- **颜色要么传达含义，要么就不该出现。** 如果标签已经能够区分各条形，就不要再用颜色区分。只为标题所强调的对象保留高饱和度颜色。
- **顺序色阶 = 数值大小或排名。发散色阶 = 正负值。分类色阶 = 类别身份。** 混用这些编码方式，是图表误导读者最常见的原因。
- **矩阵中的每列使用独立色阶。** 在形式 10 中，每个指标都应有自己的色阶和方向，否则「深色 = 高」会与「深色 = 差」相冲突。
- **中性项应使用无填充轮廓，而不是灰色。** 灰色会被理解为缺失数据。
- **没有坐标轴时，可以使用冗余编码**——词云可以同时使用字号和颜色表示频率；这并不浪费。
- **顺序承载含义。** 除非类别本身具有固有顺序（时间、分桶、李克特量表），否则应按数值排序。在一组小多图的每个面板中保持相同顺序。
- **条形始终从零开始。** 如果零对该指标没有意义，那么你需要的是点图（形式 17），而不是条形图。
- **仅在主题与人有关时使用拟人化表达。** 人形华夫图、表情符号锚点、用户画像插图——这些元素用于情绪和人数时物有所值，用于延迟和收入时则显得廉价。

## 工作流程

1. 用一句话说明核心结论。
2. 对数据所呈现的关系进行分类（分布 / 排名 / 比较 / 趋势 / 相关性 / 构成 / 定性），并从选择表中选取合适形式。
3. 阅读 `references/forms.md` 中对应形式的条目——尤其是其失效模式。如果你的数据触发了该失效模式，请采用其中列出的替代形式。
4. 应用六项决策和编码规则。
5. 使用目标环境所采用的工具构建图表。
6. **渲染图表并查看图像。** 不要看 DOM，也不要看规范——看实际像素。运行检查清单。修复发现的问题，然后重新渲染。

## 发布前检查清单

查看渲染后的图像并逐项作答。任何一项回答「否」都意味着需要修复，而不是仅作记录。

- [ ] 标题陈述了一项发现，或提出了原始问题——而不是字段名
- [ ] 每个标记都显示其数值，并且在 50% 缩放比例下清晰可读
- [ ] 不存在可由直接标签替代的图例
- [ ] 重点落在标题所强调的对象上；其他一切均弱化处理
- [ ] 最长标签不会与其标记碰撞、换行至标记下方或溢出标记
- [ ] 条形从零开始；没有截断的刻度
- [ ] ≤1 个注释
- [ ] 眯眼测试：缩放至 25% 时，答案的整体形态仍清晰可辨
- [ ] 注意事项（n、误差范围、多选）在图内可见
- [ ] `references/forms.md` 中该形式自身的失效模式并不适用
