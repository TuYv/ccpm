# 投资人材料

构建一致、可信且经得起推敲的投资人材料。

## 何时启用

- 创建或修改融资演示文稿
- 撰写投资备忘录或单页材料
- 构建财务模型、里程碑计划或资金用途表
- 回答加速器或孵化器的申请问题
- 围绕单一事实来源统一多份融资文件

## 黄金法则

所有投资人材料必须相互一致。

在撰写之前，创建或确认单一事实来源：
- 业务进展指标
- 定价和收入假设
- 融资规模和融资工具
- 资金用途
- 团队简介和职务
- 里程碑和时间表

如果出现相互冲突的数据，请停止并先解决冲突，然后再起草材料。

## 核心工作流程

1. 盘点权威事实
2. 识别缺失的假设
3. 选择材料类型
4. 以明确的逻辑起草材料
5. 对照单一事实来源交叉核验每一个数字

## 材料指南

### 融资演示文稿
推荐结构：
1. 公司 + 切入点
2. 问题
3. 解决方案
4. 产品 / 演示
5. 市场
6. 商业模式
7. 业务进展
8. 团队
9. 竞争 / 差异化
10. 融资诉求
11. 资金用途 / 里程碑
12. 附录

如果用户需要原生 Web 演示文稿，请将此技能与 `frontend-slides` 搭配使用。

### 单页材料 / 备忘录
- 用一句简洁的话说明公司是做什么的
- 说明为什么是现在
- 尽早展示业务进展和佐证要点
- 明确说明融资诉求
- 确保各项主张易于验证

### 财务模型
包括：
- 明确的假设
- 在有用时提供悲观 / 基准 / 乐观情景
- 清晰的逐层收入逻辑
- 与里程碑挂钩的支出
- 当决策取决于假设时进行敏感性分析

### 加速器申请
- 准确回答所提出的问题
- 优先突出业务进展、洞察和团队优势
- 避免夸大其词
- 确保内部指标与演示文稿和模型保持一致

## 应避免的危险信号

- 无法验证的主张
- 缺乏假设支撑的模糊市场规模估算
- 不一致的团队角色或职务
- 无法准确汇总的收入计算
- 在假设不稳固时表现出过度的确定性

## 质量门槛

交付前：
- 每个数字都与当前的单一事实来源一致
- 资金用途和各收入层级均能正确汇总
- 假设清晰可见，而非隐而不显
- 叙事清晰，不使用炒作性语言
- 最终材料能够在合伙人会议上经得起质询
