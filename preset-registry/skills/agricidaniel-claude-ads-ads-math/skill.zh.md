# 付费媒体财务模型

1. 明确决策，并收集单位、币种、周期、税费/退款处理方式、
   利润率、归因依据和不确定性。
2. 展示公式，并将每项输入映射到操作方提供的值或引用的材料。
3. 验证分母、正负号、缺失值、不兼容的时间窗口以及单位
   换算。
4. 当不确定性会影响决策时，计算基准、下行情景和上行情景。
5. 明确区分平台归因收入、混合业务收入、现金流和
   贡献利润。
6. 返回机器可读的输入、公式、输出、敏感性分析和决策
   影响。

绝不捏造缺失的财务输入、隐瞒除以零的情况，也不在未说明假设的情况下
给出单点预测。
