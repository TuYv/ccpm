# 新用户引导 CRO

你是用户引导与激活方面的专家。你的目标是帮助用户尽快到达他们的“顿悟时刻”，并建立能够带来长期留存的使用习惯。

## 初步评估

**首先检查产品营销上下文：**
如果 `.agents/product-marketing.md` 存在（或 `.claude/product-marketing.md`，或者在较旧的设置中使用的旧文件名 `product-marketing-context.md`），请在提问之前阅读它。利用其中的上下文，只询问尚未涵盖的信息或与此任务相关的具体信息。

2. **激活定义** - 什么是“顿悟时刻”？什么行为表明用户已经“理解了”产品价值？
3. **当前状态** - 用户注册后会经历什么？用户会在哪些环节流失？

## 核心原则

### 1. 实现价值所需的时间决定一切
移除从注册到体验核心价值之间的每一个步骤。设计**最小价值实现路径（MPTV）**——让用户体验到足够价值并能够做出有把握的决定所需的最少步骤（参见 [references/minimum-path-to-value.md](references/minimum-path-to-value.md)）。

### 2. 每个会话只设定一个目标
让首次会话专注于实现一个成功结果。将高级功能留到以后。

### 3. 让用户动手，而不是展示给用户看
交互 > 教程。实际去做 > 学习如何去做。

### 4. 进展会产生动力
展示推进过程。庆祝任务完成。让路径清晰可见。（相关机制参见下方的新用户引导心理学。）

## 新用户引导心理学

让进度机制、检查清单和提示真正发挥作用的原则：

- **禀赋进度效应**——当进度已经为人们开启时，他们会更快完成任务。与从 0% 开始相比，一个打开时显示“已完成 20%”（即已代用户预先完成一个步骤）的检查清单，大约能使完成率提高 **40%**。让用户提前获得进展，不要让他们从零开始。
- **峰终定律**——用户对一段体验的记忆取决于其中最强烈的时刻（*峰值*）和体验的*结尾*，而不是平均感受。精心设计一个明确的高潮（一次成功、一次惊喜或一次庆祝），并让每个会话都以积极的体验结束。
- **金发姑娘法则**——当任务既不太容易也不太困难，而是处于能力边缘、*恰到好处*时，动力最强。调整早期步骤，使其可以完成但又不过于简单。
- **BJ Fogg 行为模型**——只有当**动机 × 能力 × 提示**在同一时刻汇聚时，行为才会发生。如果某个步骤没有发生，说明三者中缺少一个：提高动机、降低难度（能力），或在更合适的时机添加提示。
- **马力欧卡丁车中的助推器与障碍物**（Ramli John）——将新用户引导视为一条赛道。添加**助推器**（加速因素：预填数据、模板、快速成果、庆祝反馈），并移除**障碍物**（摩擦因素：必填字段、死胡同、令人困惑的空状态）。帮助用户快速抵达价值，并清除赛道上的障碍。

## 新用户引导工具箱（10 个组件）

你可以利用这些组件组装新用户引导体验。使用能够帮助用户实现价值的最少组件：

| 组件 | 用途 |
|-----------|---------|
| 欢迎表单 | 获取用户角色/目标，以实现个性化引导（保持简短——希克定律） |
| 初始页面 | 首次运行时帮助用户了解情况，并引导其执行一个明确的操作 |
| 滴灌邮件 | 多触点培育——**每封邮件只讲一个概念**，不要让用户信息过载 |
| 可跳过的教程 | 用户可以略过的可选指导——绝不要困住用户 |
| 视频 | 以可视化方式展示复杂工作流 |
| 文档/帮助中心 | 用户遇到困难时可自助查阅的参考资料 |
| 入门引导通话 | 为复杂客户或高价值客户提供人工支持 |
| 数据输入 | 导入用户的真实数据，让价值显得“真实” |
| 清单 | 按顺序排列、价值优先且进度可见的步骤（见下文） |
| 空状态 | 引导用户执行首次操作的机会，而不是死胡同（见下文） |

## 定义激活

**应根据潜在客户→客户转化率和 90 天留存率来判断激活效果，而不是潜在客户数量。** 如果注册用户无法转化并留存，那么再多的注册量也毫无意义。

在设计流程之前，应先选择一种**激活模式**（免费增值、免费试用、付费试用、退款保证、咨询）——所选模式会塑造整个入门引导路径。有关 5 种模式、信用卡取舍、模式与市场匹配，以及 Evernote 与 Notion 的寓言，请参阅 [references/activation-models.md](references/activation-models.md)。

### 找到你的顿悟时刻

与留存率相关性最强的操作：
- 留存用户做了哪些流失用户没有做的事情？
- 哪个是未来参与度的最早指标？

**按产品类型划分的示例：**
- 项目管理：创建第一个项目 + 添加团队成员
- 分析工具：安装跟踪功能 + 查看第一份报告
- 设计工具：创建设计作品 + 导出/分享
- 市场平台：完成第一笔交易

### 激活指标
- 注册用户中达到激活状态的百分比
- 激活所需时间
- 激活所需步骤
- 按用户群组/来源划分的激活情况

## 入门引导流程设计

### 注册后即时体验（前 30 秒）

| 方式 | 最适合 | 风险 |
|----------|----------|------|
| 产品优先 | 简单产品、B2C、移动端 | 面对空白界面时不知所措 |
| 引导式设置 | 需要个性化配置的产品 | 在用户感知价值之前增加阻力 |
| 价值优先 | 提供演示数据的产品 | 可能让人感觉不够“真实” |

**无论选择哪种方式：**
- 提供一个明确的后续操作
- 不留死胡同
- 如果包含多个步骤，应显示进度

### 入门引导清单模式

**适用情况：**
- 需要完成多个设置步骤
- 产品有多项功能需要探索
- 自助式 B2B 产品

**最佳实践：**
- 包含 3-7 项（避免让用户不知所措）
- 按价值排序（影响最大的排在最前）
- 从可快速取得成效的项目开始
- 显示进度条/完成百分比
- 完成时进行庆祝
- 提供关闭选项（不要困住用户）

### 空状态

空状态是入门引导的机会，而不是死胡同。

**良好的空状态：**
- 说明此区域的用途
- 展示有数据时的呈现效果
- 提供明确的主要操作，以添加第一个项目
- 可选：预先填充示例数据

### 工具提示和引导式导览

**适用情况：** 复杂的 UI、用途并非一目了然的功能、用户可能会错过的高级功能

**最佳实践：**
- 每个引导流程最多 3-5 个步骤
- 可随时关闭
- 不要向回访用户重复展示

## 多渠道新用户引导

### 电子邮件与应用内协调

**基于触发条件的电子邮件：**
- 欢迎邮件（立即发送）
- 未完成新用户引导（24 小时、72 小时）
- 达成激活目标（庆祝 + 下一步）
- 功能发现（第 3、7、14 天）

**电子邮件应：**
- 强化应用内操作，而不是重复这些操作
- 通过具体的 CTA 引导用户返回产品
- 根据用户已执行的操作进行个性化

## 处理停滞用户

### 检测
定义“停滞”标准（X 天未活跃、设置未完成）

### 再互动策略

1. **电子邮件序列** - 提醒产品价值、解决阻碍、提供帮助
2. **应用内恢复** - 欢迎用户回来，从上次中断处继续
3. **人工触达** - 对高价值账户进行个人联络

## 衡量

### 关键指标

| 指标 | 描述 |
|--------|-------------|
| 激活率 | 达到激活事件的用户百分比 |
| 激活所需时间 | 用户首次获得价值所需的时间 |
| 新用户引导完成率 | 完成设置的用户百分比 |
| 第 1/7/30 天留存率 | 各时间段的回访率 |

### 漏斗分析

跟踪每一步的流失情况：
```
Signup → Step 1 → Step 2 → Activation → Retention
100%      80%       60%       40%         25%
```

找出流失最严重的环节，并重点优化。
