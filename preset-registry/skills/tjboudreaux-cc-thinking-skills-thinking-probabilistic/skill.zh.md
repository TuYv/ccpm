# 概率思维

**核心规则：** 用数字和区间来表达信念，而不是凭感觉。以基准率为锚点，用明确的似然性进行更新，并通过因子分解为未知量界定边界——绝不制造虚假精度。

## 何时使用

- 真实值不确定的时间线、工作量或结果预测。
- 为变更、迁移、部署或发布评估风险规模。
- 任何你即将自信地说出一个实际上无法得知的具体数字的时刻。
- 新证据到来，而先前的估计应当随之调整时。

## 何时不使用

- 该量可测量或可查证——那就去测量或查证。
- 决策在整个合理区间内都不变——跳过估计，直接行动。
- 不存在真实的参照类、你只能凭空编造基准率——把它标记为猜测，而不是校准过的预测。
- 你只需要一个二元门槛判断，且已握有决定性的观察结果——不要用多余的形式来充数。

## 流程

1. **定义可检验的断言：** 结果 + 时间范围 + 单位。优先使用可证伪的陈述，而非模糊语言（“可能”）。
2. **锁定先验并加以挑战：** 给出参照类基准率，以及至少一条可信的备选路径/假设及其比率。除非你写下偏离的具体理由，否则应把先验向基准率拉近。然后陈述“你选定的先验或区间是错的”这一立场的最强基于证据的论述，说明它支持哪个估计，若该反例站得住脚就据此修订。把模糊措辞转换为数字（例如“可能”≈ 65–80%）。
3. **表达区间而非点值：** 至少给出一个置信区间（首选 50% 和 80%）。默认自己是过度自信的；当外部视角的依据薄弱时，加宽区间。
4. **证据到来时按 先验 → 似然 → 后验 更新：**
   - 先验几率 = p / (1 − p)。
   - 似然比 LR = P(E|H) / P(E|¬H)。LR > 1 支持 H；LR = 1 是噪声；LR < 1 削弱 H。
   - 后验几率 = 先验几率 × LR（即使 LR < 1 也要相乘）；p = odds / (1 + odds)。
   - 按与 1 的距离划分强度档：弱 ~1.5–3×，中 3–10×，强 10–100×，决定性 100×+。
   - 昨天的后验就是今天处理下一条证据时的先验。对于罕见事件，要从基准率出发——生动的阳性结果仍会把大部分概率质量留在误报上。
5. **用费米法为无法测量的量界定边界**（仅当你需要一个无法测量/查证的数量级时）：
   - 分解：Quantity = Factor₁ × Factor₂ × …（或各分量之和）。
   - 给每个因子界定一个范围；用一位有效数字的几何均值来确定数量级。
   - 相乘；报告“~X，误差在 3–5× 以内”；做合理性检查：10× 的误差是否会改变决策；若某个因子其实可以查到，就用查证结果替换它。
   - 当数值很容易测量、决策需要比 ~3–5× 更高的精度、或每个因子纯属臆造时，跳过费米估算。
6. **给出可供检验的最终估计：** 断言、区间/置信区间、关键不确定性，以及能证明它错误的观察结果。当决策在剩余区间内保持稳定，或下一次更新需要你目前没有的新证据时，就停下来。

## 输出

1. **断言** — 带时间范围的可证伪陈述。
2. **先验** — 基准率、备选路径、调整理由、最强反例，以及由此得到的先验概率。
3. **区间** — 置信区间（而不是孤立的点值）。
4. **更新** — 每条证据一行：先验、LR（或明确的启发式 Δ）、后验。
5. **费米边界**（如使用）— 因子乘积及“~X，误差在 N× 以内”。
6. **决策含义** — 若真实值落在区间低端或高端，会有什么变化。

## 验证

- **证伪/停止：** 如果你举不出基准率、备选假设或有力的反例，就把该估计标记为猜测而非校准结果。如果决策在整个区间内都不变，就停止估计。如果新证据到来而数字没有变动（或变动没有 LR/Δ 支撑），就重新计算。
- **过度使用防范：** 不要把可核查的事实包装成概率，不要臆造参照类，也不要对可测量的量做费米分解。不要对一个有 5× 不确定性的乘积报告三位有效数字。对于罕见事件，在没有基准率先验的情况下，拒绝从一个生动的命中直接跳到近乎确定。
