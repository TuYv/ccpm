用于有效执行营销工作的核心营销概念、心理学和框架。

在以下情况下应用营销基础知识：

- 设计客户获取策略

## 核心概念

### 营销漏斗（TOFU/MOFU/BOFU）

**漏斗顶部（TOFU）— 认知**
- 阶段：意识到问题 → 意识到解决方案
- 内容：教育内容、思想领导力、娱乐内容
- 指标：覆盖人数、展示次数、流量、品牌认知度
- 渠道：SEO、社交媒体、付费认知广告、公关

**漏斗中部（MOFU）— 考虑**
- 阶段：意识到解决方案 → 意识到产品
- 内容：对比指南、案例研究、网络研讨会
- 指标：互动、潜在客户、MQLs、电子邮件注册
- 渠道：内容营销、电子邮件、再营销

**漏斗底部（BOFU）— 决策**
- 阶段：意识到产品 → 高度了解
- 内容：演示、试用、客户评价、定价
- 指标：SQLs、销售机会、转化率
- 渠道：直接销售、演示、免费试用

**购买后 — 留存**
- 阶段：客户 → 品牌拥护者
- 内容：新用户引导、教程、社区
- 指标：NPS、留存率、扩展销售、推荐
- 渠道：客户成功、电子邮件、社区

### 客户旅程地图

| 阶段 | 问题 | 触点 | 情绪 |
|-------|----------|-------------|----------|
| 认知 | 他们如何发现你？ | 广告、内容、推荐 | 好奇、怀疑 |
| 调研 | 他们寻找哪些信息？ | 网站、评论、社交媒体 | 感兴趣、谨慎 |
| 考虑 | 他们会比较哪些选项？ | 竞争对手、功能 | 评估、焦虑 |
| 决策 | 什么会促使他们购买？ | 演示、试用、优惠 | 自信、兴奋 |
| 体验 | 购买后会发生什么？ | 新用户引导、支持 | 期待、获得认可 |
| 拥护 | 什么会促使他们推荐？ | 成果、愉悦体验 | 满意、自豪 |

### 价值主张设计

**待完成任务框架**：
- **功能性任务**：需要完成的任务（节省时间、降低成本）
- **社会性任务**：他们希望别人如何看待自己（显得聪明、受到尊重）
- **情感性任务**：他们希望获得何种感受（自信、安全、如释重负）

**价值主张画布**：
| 客户画像 | 价值地图 |
|------------------|-----------|
| 任务 | 产品与服务 |
| 痛点 | 痛点缓解方案 |
| 收益 | 收益创造方案 |

### 定位框架

**强大定位的要素**：
1. **目标受众**：特定细分群体，而非“所有人”
2. **参照系**：你参与竞争的品类
3. **差异化要点**：为何与众不同且更加优秀
4. **可信理由**：证明依据和资质

**定位陈述模板**：
> 对于[目标受众]而言，他们有[需求/机会]，[产品名称]是一款能够[核心利益]的[产品类别]。与[竞争对手]不同，我们凭借[可信理由]实现了[独特差异化优势]。

### 营销心理学原则

| 原则 | 定义 | 应用 |
|-----------|------------|-------------|
| 互惠 | 人们会回报他人的帮助 | 免费价值 → 付费 |
| 社会认同 | 从众心理 | 客户评价、数据 |
| 稀缺性 | 害怕错过 | 限时/限量 |
| 权威性 | 信任专家 | 资质、背书 |
| 一致性 | 履行承诺 | 小的肯定 → 大的肯定 |
| 喜爱 | 从我们喜欢的人那里购买 | 个性、亲和力 |

### 营销指标框架

| 类别 | 指标 | 健康范围 |
|----------|---------|---------------|
| 获客 | CAC、CPL、CPC | CAC < 1/3 LTV |
| 激活 | 试用转付费、完成引导流程 | 20-40% |
| 留存 | 流失率、NRR | 月流失率 <5% |
| 收入 | LTV、ARPU、扩展收入 | LTV:CAC > 3:1 |
| 推荐 | 推荐率、NPS | NPS > 50 |

## 最佳实践

### 卓越策略
1. **客户优先**：从受众研究入手，而非产品功能
2. **先测试再扩展**：在进行重大投入前验证营销信息
3. **全漏斗思维**：覆盖所有阶段，而不仅仅是获客
4. **差异化**：明确说明为什么选择你，而不是竞争对手

### 卓越执行
1. **一致性**：所有渠道传达相同的核心信息
2. **清晰性**：每项内容只传达一个核心观点
3. **证据支撑**：用证据支持主张
4. **行动号召**：在每次互动中提供清晰的下一步行动

### 卓越衡量
1. **先行指标**：追踪早期信号，而不仅仅是最终结果
2. **归因**：了解是什么在推动结果
3. **细分**：按受众细分，以获取洞察
4. **迭代**：持续测试、学习和改进

## 应避免的反模式

| 反模式 | 错误原因 | 替代做法 |
|--------------|----------------|-----------------|
| 以功能为先的营销信息 | 客户想要的是结果 | 以利益为先 |
| 面向所有人 | 无法引起任何人的共鸣 | 锁定特定受众 |
| 忽视竞争 | 导致定位不清晰 | 明确差异化 |
| 只获客、不留存 | 漏桶效应 | 平衡全漏斗 |
| 靠猜测而非测试 | 浪费资源 | 验证假设 |
