# 经济学：边际思维

经济学中最重要的词是*边际*。不是平均。不是总量。不是我们已经花费了什么。真正相关的问题始终是：在*下一个单位*上会发生什么？我们是否应该再招聘一名工程师？再生产一批产品？再增加一项功能？再开展一次营销活动？答案取决于边际成本（下一个单位的成本）与边际收益（下一个单位产生的收益）之间的比较。当边际收益超过边际成本时，就多做一些。当边际收益不再超过边际成本时，就停止。

这听起来显而易见。实践中，组织几乎无一例外地无法应用这一原则。它们在应该使用边际成本时使用平均成本。它们把过去的支出当作继续投入的理由，尽管这些支出在经济上已无关紧要。它们问“我们当初是否应该这样做？”，而不是“我们是否应该继续做更多？”阿尔弗雷德·马歇尔将边际分析置于新古典经济学的核心，正是因为前边际思维——评估总量或平均值，而非增量——会系统性地产生错误决策。

沉没成本谬误是边际思维中代价最高昂的失败。已经投入的资源无法收回——它们是不可逆的。因此，它们不能也不应该影响未来的决策。然而，卡尼曼的研究证实，人们会高度看重沉没成本：已经遭受的损失所带来的痛苦，会促使人们继续投资于失败的项目，其程度远远超过前瞻性分析所能证明的合理范围。此技能的核心做法是从分析中剔除沉没成本，并完全以前瞻性的边际视角重新表述决策。

## 你的流程

**步骤 1：确定边际**
明确决策究竟涉及什么。它是：(a) 是否再多做一个单位的某件事，(b) 要生产、执行或雇用多少个单位，(c) 是否继续现有项目或承诺，还是 (d) 如何在相互竞争的用途之间分配资源？答案决定了“边际”在当前情境中的含义。

**框架检查：** 在继续之前，确认决策和相关边际。用一句话说明你所确定的内容，然后使用 `AskUserQuestion`：
- **问题：** “我的理解是：[用一句话描述框架——当前决策以及正在从边际角度考虑的单位]。对吗？”
- **标题：** “框架”
- **选项：**
  - **是——继续**——框架正确
  - **调整**——其中一个要素有误；用户会在你继续之前予以纠正
  - **重新界定**——实际情况与当前理解不同；继续之前先纳入修正内容

**步骤 2：识别并隔离沉没成本**
在进行任何前瞻性分析之前，识别所有已经投入且无法收回的成本：已经支出的资本、已经投入的时间、已经签署的合同、已经作出的决策。明确将这些标记为沉没成本。它们是真实的——它们确实发生过——但在经济上与未来决策无关。明确说明：“这些成本已经发生。它们无法收回。它们不会出现在前瞻性分析中。”

如果用户执着于沉没成本（将过去的投资作为继续投入的理由），请直接指出：这是沉没成本谬误。问题不在于过去的投资是否明智。问题在于下一个投资单位是否会产生回报。

**步骤 3：计算边际成本**
*下一个单位*的成本是多少？边际成本包括所有会随下一个单位而变化的成本——可变成本、额外劳动力、材料、时间——但不包括不因该决策而变化的固定成本（无论如何，这些成本都已经在承担）。注意：边际成本通常不同于平均成本。对于许多活动，边际成本最初低于平均成本（规模经济），但最终会随着产能约束的出现而上升。

**步骤 4：估算边际收益**
下一个单位会产生什么？可能包括：收入、影响、风险降低、选择权、信息价值。请明确说明所使用的单位和增量。如果边际收益存在不确定性，请使用期望值（按概率加权）。如果边际收益是定性的，请使用明确的量表。

**步骤 5：进行边际比较**
比较相关单位的边际收益与边际成本。规则如下：
- 如果边际收益 > 边际成本 → 增加投入
- 如果边际收益 < 边际成本 → 减少投入（或停止）
- 如果边际收益 = 边际成本 → 已达到最优点

如果决策涉及数量，请针对不同单位重复进行比较：两条曲线在哪里相交？在什么产出水平下，边际成本开始超过边际收益？

**步骤 6：应用停止规则**
制定明确的停止规则：在什么条件下应扩大、维持或削减这项活动？什么信号表明边际成本已经超过边际收益？这项前瞻性规则就是交付成果——它不仅用于指导当前决策，也用于指导未来决策。

## 说明

本技能纠正的最常见错误，是将平均成本当作边际成本。“我们的单位平均成本是 £X，因此应该维持当前产量”这一说法可能正确，也可能错误，具体取决于边际成本所处的水平——而且两者经常存在偏差，尤其是在固定成本较高的企业中。一家开发固定成本高、边际分发成本接近于零的软件公司，应该根据边际成本（接近于零）而不是平均成本（较高）来定价。

第二常见的错误是：用沉没成本论证是否继续投入。“我们已经投入了 £5m，现在不能停”并不是经济学论据，而是心理层面的论据。正确的问题始终是：“下一英镑的投资能产生什么？”如果答案是“产生的价值不足一英镑”，那就停止。

当相关比较是在做这件事与做其他事情之间（机会成本），而不是在做这件事与少做一些这件事之间（边际分析）时，边际思维应与 `/s4h-economics-opportunity-cost` 搭配使用。它们针对的是不同的决策结构。对于是否继续一项可能从一开始就构思有误的承诺这一类决策，应与 `/s4h-decision-premortem-analysis` 搭配使用。
