# SEO 精通

实现可持续自然增长的搜索引擎优化策略与战术。

## 语言与质量标准

**关键要求**：使用与用户相同的语言回复。如果用户使用越南语，则使用越南语回复。如果用户使用西班牙语，则使用西班牙语回复。

**标准**：提高 Token 效率，为简洁性牺牲语法，在末尾列出未解决的问题。

---

## 何时使用此技能

在以下情况中应用 SEO 专业知识：
- 优化内容以提高搜索排名

- 执行技术 SEO 审计
- 制定链接获取策略
- 分析搜索表现
- 制定自然增长内容策略

## 核心概念

### 搜索意图类型

| 意图 | 用户目标 | 内容类型 | 示例 |
|--------|-----------|--------------|----------|
| 信息型 | 学习某些内容 | 操作教程、指南、定义 | "如何撰写电子邮件文案" |
| 导航型 | 查找特定网站 | 品牌页面 | "HubSpot 登录" |
| 商业型 | 购买前进行研究 | 对比、评测 | "最佳电子邮件营销工具" |
| 交易型 | 完成购买 | 产品页面、定价页面 | "购买 mailchimp 订阅" |

### 关键词研究框架

**需要评估的关键词指标**：
| 指标 | 含义 | 良好范围 |
|--------|--------------|------------|
| 搜索量 | 每月搜索次数 | 大多数情况下为 100-10,000 |
| 关键词难度 | 竞争程度 | 新网站为 0-30 |
| CPC | 商业意图 | 越高 = 价值越高 |
| SERP 特性 | 搜索结果第 1 页上的内容 | 越少 = 越容易 |

**关键词类型**：
- **核心词**：1-2 个单词，搜索量高，竞争非常激烈
- **中等长度关键词**：2-3 个单词，搜索量中等，具有竞争性
- **长尾关键词**：4 个以上单词，搜索量低，竞争较小

### 页面 SEO 元素

**标题标签**（50-60 个字符）：
- 主要关键词靠近开头
- 有吸引力，能够促使用户点击
- 每个页面使用唯一标题
- 在空间允许的情况下包含品牌名称

**元描述**（150-160 个字符）：
- 自然地包含主要关键词
- 包含行动号召
- 突出独特价值主张
- 匹配搜索意图

**标题结构**：
```
H1: Main Page Title (one per page, contains keyword)
  H2: Major Section (keyword variations)
    H3: Subsection (semantic terms)
      H4: Supporting detail
```

**内容优化检查清单**：
- [ ] 关键词出现在前 100 个单词中
- [ ] 自然的关键词密度（1-2%）
- [ ] 在全文中使用语义变体
- [ ] 添加指向相关内容的内部链接（每篇文章 3-5 个）
- [ ] 添加指向权威来源的外部链接（1-2 个）
- [ ] 图片替代文本中包含关键词
- [ ] 使用简短且具有描述性的 URL

### 技术 SEO 要点

**核心网页指标**：
| 指标 | 目标 | 衡量内容 |
|--------|--------|------------------|
| LCP（最大内容绘制） | <2.5s | 加载性能 |
| FID（首次输入延迟） | <100ms | 交互性 |
| CLS（累积布局偏移） | <0.1 | 视觉稳定性 |

**可抓取性检查清单**：
- [ ] 已提交 XML 站点地图
- [ ] robots.txt 简洁规范
- [ ] 没有失效链接（4xx 错误）
- [ ] 正确设置重定向（永久重定向使用 301）
- [ ] 采用移动设备友好型设计
- [ ] 已启用 HTTPS

**可索引性检查清单**：
- [ ] 重复页面设置 Canonical 标签
- [ ] 不存在意外的 noindex
- [ ] 为国际化内容设置 Hreflang
- [ ] 正确处理分页

### 链接建设策略

| 策略 | 工作量 | 影响 | 最适合 |
|----------|--------|--------|----------|
| 客座发文 | 高 | 中 | 新网站、建立权威性 |
| 失效链接建设 | 中 | 中 | 快速见效 |
| 资源页面 | 中 | 中 | 综合性内容 |
| 数字公关 | 高 | 高 | 品牌 + 链接 |
| 原创研究 | 非常高 | 非常高 | 思想领导力 |
| HARO | 低 | 不定 | 易于获取的机会 |

### 内容集群

**支柱-集群模型**：
```
Pillar Page (comprehensive, 3000+ words)
├── Cluster 1 (specific subtopic, links to pillar)
├── Cluster 2 (specific subtopic, links to pillar)
├── Cluster 3 (specific subtopic, links to pillar)
└── Cluster N (specific subtopic, links to pillar)
```

**优势**：
- 建立主题权威性
- 改善内部链接
- 覆盖长尾变体
- 提供更好的用户导航

## 最佳实践

### 卓越的关键词研究
1. **意图匹配**：使内容与搜索意图保持一致
2. **现实目标**：从难度可控的目标开始
3. **集群思维**：将相关关键词分组
4. **商业平衡**：兼顾信息型与交易型关键词

### 卓越的内容
1. **10 倍内容**：明确优于搜索结果第一页的内容
2. **全面覆盖**：回答所有相关问题
3. **定期更新**：通过刷新内容释放新鲜度信号
4. **丰富的多媒体**：图片、视频、交互式元素

### 卓越的技术
1. **速度优先**：速度快的网站排名更高
2. **移动优先**：Google 会索引移动版本
3. **清晰的架构**：符合逻辑的 URL 和网站结构
4. **结构化数据**：使用 Schema 标记生成富媒体搜索结果

## 应避免的反模式

| 反模式 | 错误原因 | 应改为 |
|--------------|----------------|-----------------|
| 关键词堆砌 | 损害排名和用户体验 | 保持自然密度 |
| 购买链接 | 存在被处罚的风险 | 通过优质内容赢得链接 |
| 重复内容 | 导致关键词蚕食 | 设置 Canonical 或合并内容 |
| 忽视搜索意图 | 产生不良的互动信号 | 精确匹配意图 |
| 只追求搜索量 | 忽视转化 | 平衡搜索量与意图 |
