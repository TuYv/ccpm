# 孟加拉国财务报表与报告 — Skill v1.0

> **仅供一般参考。** 本技能是用于 AI 辅助工作流的一般税务/会计参考资料。其内容尚未针对任何特定个人的事实、文件、选择、截止日期、居民身份、申报状态或当地程序进行审查。未经相关司法管辖区的合格专业人士审核，请勿依赖本技能进行申报、缴税、修正申报或采取税务立场。

## 第 1 节 — 快速参考

| 字段 | 值 |
|---|---|
| 独资经营者 / 自由职业者 | 无法定财务报表 — 保留账目并提交 **NBR e-Return**（参见 bd-bookkeeping） |
| 合伙企业 | 用于支持申报的账目 |
| 公司（私人/公众有限公司） | 根据 **BFRS**（孟加拉国财务报告准则，采用 IFRS / IFRS for SMEs）编制财务报表，由 ICAB 成员事务所审计，并向 **RJSC** 提交 |
| 审计 | 公司须接受法定审计；财务报表及审计报告须提交给 RJSC 和 NBR |
| 主管机构 | NBR（税务）；RJSC（公司事务）；ICAB（审计行业） |

## 第 2 节 — 谁编制什么（第 1 级）
- **独资经营者 / 自由职业者：****无需**编制法定财务报表。其义务是提交 **NBR e-Return**，并以简单账目（收入、支出、银行账目、资产登记簿）作为支持。这是对大多数自由职业者而言的关键要点。
- **合伙企业：**维护用于支持其申报的账目；无需向 RJSC 提交财务报表。
- **公司：**根据 **BFRS**（所采用的 IFRS，或适用于较小型公司的 IFRS for SMEs）编制财务报表，由 ICAB 成员事务所进行**审计**，并向 **RJSC** 提交（同时将经审计账目附于所得税申报表）。

## 第 3 节 — 示例
一名独立 IT 自由职业者（独资经营）：**无需**编制法定财务报表 — 提交 NBR e-Return，并保留支持性账目。如果其注册成立一家私人有限公司，则须开始编制 BFRS 报表、接受法定审计并向 RJSC 提交文件。

## 第 10 节 — 禁止事项
- 绝不要告诉独资经营者/自由职业者必须提交法定财务报表（他们提交的是 e-Return）。
- 绝不要假定小型公司适用完整 IFRS — IFRS for SMEs / 基于规模的准则可能适用。
- 未核实《公司法》/ RJSC 规则前，绝不要陈述审计/申报门槛。
