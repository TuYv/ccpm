此技能旨在指导创建独特、达到生产级质量的前端界面，避免千篇一律的“AI 垃圾”美学。应实现真正可运行的代码，并对美学细节和创意选择给予极致关注。

用户会提供前端需求：需要构建的组件、页面、应用程序或界面。他们可能还会提供有关用途、受众或技术约束的背景信息。

## 设计思考

在编码之前，先理解背景，并坚定地选择一个大胆的美学方向：
- **用途**：这个界面解决什么问题？谁会使用它？
- **基调**：选择一种极致风格：极简主义、极繁主义式混乱、复古未来主义、有机/自然、奢华/精致、俏皮/玩具感、编辑设计/杂志风、粗野主义/原始感、装饰艺术/几何风、柔和/粉彩、工业/实用主义等。可供选择的风格非常多。以这些风格为灵感，但要创造出真正忠于既定美学方向的设计。
- **约束**：技术要求（框架、性能、无障碍访问）。
- **差异化**：是什么让它令人过目不忘？人们会记住的那一个特点是什么？

**关键要求**：选择明确的概念方向，并精准地将其贯彻到底。大胆的极繁主义和精致的极简主义都能奏效——关键在于设计的意图，而非视觉强度。

然后实现可运行的代码（HTML/CSS/JS、React、Vue 等），并确保其：
- 达到生产级质量且功能完整
- 在视觉上引人注目、令人难忘
- 风格统一，并具有明确的美学主张
- 每个细节都经过精心打磨

## 前端美学指南

重点关注：
- **字体排印**：选择美观、独特且有趣的字体。避免使用 Arial 和 Inter 等通用字体；应选择能提升前端美感、出人意料且富有个性的字体。将独特的展示字体与精致的正文字体搭配使用。
- **色彩与主题**：坚定地采用统一的美学风格。使用 CSS 变量来保持一致性。以主导色搭配鲜明强调色，效果优于保守且平均分布的配色方案。
- **动效**：使用动画来实现视觉效果和微交互。对于 HTML，优先采用纯 CSS 解决方案。在 React 中，如果 Motion 库可用，则使用该库。专注于具有高影响力的关键时刻：一次编排精良、带有错落显现效果（animation-delay）的页面加载动画，比零散的微交互更令人愉悦。使用滚动触发效果和令人惊喜的悬停状态。
- **空间构图**：采用出人意料的布局。不对称。重叠。对角线流动。打破网格的元素。大量留白，或受控的高密度排布。
- **背景与视觉细节**：营造氛围和层次感，而不是默认使用纯色背景。添加符合整体美学风格的情境化效果和纹理。运用渐变网格、噪点纹理、几何图案、分层透明效果、戏剧化阴影、装饰性边框、自定义光标和颗粒叠加层等创意形式。

绝不要使用千篇一律的 AI 生成式美学，例如被过度使用的字体系列（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（尤其是白色背景上的紫色渐变）、可预测的布局和组件模式，以及缺乏特定情境个性的模板化设计。

进行富有创意的诠释，做出真正契合具体情境且出人意料的选择。任何设计都不应雷同。在浅色与深色主题、不同字体和不同美学风格之间灵活变化。绝不要在多次生成中趋同于常见选择（例如 `Space Grotesk`）。

**重要提示**：实现复杂度应与美学愿景相匹配。极繁主义设计需要精心编写的复杂代码，以及丰富的动画和特效。极简或精致的设计则需要克制、精准，并对间距、字体排印和细微细节给予充分关注。优雅源于对愿景的出色执行。
