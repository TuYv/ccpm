# AgentFolio

**角色**: 自主代理发现指南

当你想要在生态系统中**发现、比较并研究自主 AI 代理**时，使用此技能。
AgentFolio 是一个经过筛选的目录，位于 https://agentfolio.io，用于追踪代理框架、产品和工具。

这个技能可以帮助你：

- 在从头构建之前找到已有代理。
- 绘制代理框架和托管产品的生态地图。
- 收集智能体能力的具体示例和基准。

## 能力

- 按用例发现自主 AI 代理、框架和工具。
- 按能力、目标用户和集成入口比较代理。
- 识别市场空白或为新技能/工作流寻找灵感。
- 为你自己的设计收集示例化的代理行为和 UX 模式。
- 跟踪代理架构和部署中的新兴趋势。

## How to Use AgentFolio

1. **打开目录**
   - 在浏览器中访问 `https://agentfolio.io`。
   - 可选地按分类筛选（例如 Dev Tools、Ops、Marketing、Productivity）。

2. **按目标搜索**
   - 从你要解决的问题开始：  
     - “customer support agents”  
     - “autonomous coding agents”  
     - “research / analysis agents”
   - 使用与您领域或工作流匹配的关键词，在 AgentFolio 搜索栏中检索。

3. **评估候选项**
   - 对每个有趣的代理，记录：
     - **核心承诺**（它自动化的目标结果）。
     - **输入/输出形态**（API、UI、数据源）。
     - **自治模型**（单次触发、多步骤、使用工具、human-in-the-loop）。
     - **部署模型**（SaaS、self-hosted、browser、IDE 等）。

4. **提炼洞察**
   - 使用发现结果：
     - 决定是集成现有代理还是自行构建。
     - 借鉴成功的 UX 与安全模式。
     - 将你自己的代理技能和工作流与生态系统进行对照定位。

## 示例工作流

### 1) 构建新代理前的全局扫描

- 定义问题：“autonomous test failure triage for CI pipelines”。
- 使用 AgentFolio 搜索：
  - “testing agent”、“CI agent”、“DevOps assistant”、“incident triage”。
- 针对每个相关代理：
  - 记录支持的平台（GitHub、GitLab、Jenkins 等）。
  - 收集它们如何阐明自治性和安全边界。
  - 若你计划采纳而非自行构建，请记录定价/授权约束。

### 2) 新技能的竞品与灵感研究

- 如果你计划新增技能（例如 observability agent、security agent）：
  - 使用 AgentFolio 查找相似的代理和特性。
  - 提取 3–5 个你想模仿或避免的具体模式。
  - 将这些模式转化为你自己技能的清晰需求。

### 3) 供应商筛选

- 在多个代理供应商之间做选择时：
  - 使用 AgentFolio 条目作为中立目录。
  - 制作对比表（列：capabilities、integrations、pricing、trust & security）。
  - 使用该表推动更正式的评估或概念验证。

## 示例提示

在 AI 编码代理中使用此技能时可用以下提示：

- “使用 AgentFolio 查找 3 个专注于代码审查的自主 AI 代理。对每个代理总结其核心价值主张、支持的语言，以及它们如何融入开发者工作流。”
- “扫描 AgentFolio，查找能够帮助客户支持分流的代理。列出最佳选项、它们的目标客户规模（SMB vs. enterprise）以及任何值得关注的 UX 模式。”
- “在我们自己构建研究助手之前，先用 AgentFolio 梳理现有的 research / analysis 代理，并突出我们可以填补的空白。”

## 何时使用
当你需要**发现或比较自主 AI 代理**而不是在真空中构建时，适用此技能：

- 在新建代理或工作流项目启动之初。
- 在评估要集成的供应商或工具时。
- 当你想从现有代理产品中获取灵感或最佳实践时。

## 限制
- 仅在任务明确符合上述范围时使用此技能。
- 不要将输出视为替代特定环境验证、测试或专家审查的替代方案。
- 如果缺少必要输入、权限、安全边界或成功标准，应停止并请求澄清。
