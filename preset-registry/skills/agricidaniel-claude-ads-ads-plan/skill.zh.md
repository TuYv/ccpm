# 付费媒体计划

1. 将设置档案、业务经济性、证据、当前账户状态和相关行业模板作为可选输入进行读取。
2. 定义目标、客户、优惠、转化、价值、约束条件、地理区域、受监管类别、时间范围和成功标准。
3. 基于第一性原理评估渠道角色和排除项；无需使用所有受支持的平台。对于十二平台契约之外的渠道，请加载 `ads/references/additional-platforms.md` 并返回研究线索，除非已具备有关其当前购买方式、资格要求、衡量方法和创意素材的证据。
4. 明确广告活动架构、受众策略、创意系统、预算与投放节奏、衡量方案、实验、政策控制和运营节奏。
5. 分阶段安排启动、学习、优化和规模化之前的先决条件。
6. 为每项行动指定负责人、时间安排、依赖项、护栏、证据、成功衡量指标，以及回滚或退出条件。
7. 返回规范 JSON，并呈现所请求的人工可读计划。

计划仅作为建议。只有通过启动或优化变更门控后，计划才会成为账户变更。
