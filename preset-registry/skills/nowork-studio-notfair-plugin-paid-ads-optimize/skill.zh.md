# 付费广告优化

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。在更改任何内容之前先进行审查。

## 先诊断，再削减

核实转化信号、统计周期完整性、花费量、归因模型以及近期账户变更。有花费但没有记录到转化，可能意味着跟踪失效或数据尚未成熟；在信号和数据量足以支持干预之前，应将其视为一种假设。在归咎于定向之前，先检查落地页或运营环节是否存在故障。

将瓶颈归类为搜索词/受众质量、创意疲劳、投放/排名、预算限制、落地页不匹配、跟踪或经济效益问题。使用专门的 Google、Meta、X 或 LinkedIn Skill 进行实时诊断。对于其他平台，只分析已提供或经核实的数据。

## 按可逆性对操作排序

优先遵循以下顺序：排除不相关的搜索词、版位或受众；暂停范围最窄的亏损单元；以审慎的幅度调整预算或出价；然后再考虑结构性变更。对于预算重新分配，应展示当前分配方案和拟议分配方案；除非用户批准增加预算，否则总预算应保持不变；同时还要说明可观测、可验证的假设。

不要仅凭少量点击就断定某项表现不佳。应根据指定的目标 CPA、转化延迟和渠道角色设定适当的阈值。保留对漏斗上层和辅助转化的考量，而不是仅依据最终点击 CPA 评判所有广告活动。

## 审批与跟进

列出每一项具体变更，并说明其作用范围、当前值、拟议值、涉及的货币金额、理由和复核日期。获得批准后，只能通过已验证的平台 Skill 或连接器执行操作，回读执行结果，并记录此次干预的预期效果和保护性约束。在预先声明的观察期结束后重新评估，而不是笼统地承诺持续监控。
