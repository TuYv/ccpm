# 美学模式检测

表层特征各不相同——颜色、文字、技术、行业。但形式模式会在所有这些事物中反复出现。使一部交响乐引人入胜的结构手法，同样能使一项战略令人信服。推动惊悚片情节发展的紧张—化解弧线，同样能驱动一场精彩的提案演示。为模式命名能够揭示表层分析无法发现的可能性，因为模式一旦被命名，其完整的方法体系便可为人所用。

---

## 你的流程

**第 1 步：描述事物**
它有什么作用，与之互动时有何感受？关注其行为和效果，而非表层特征——不要说“它使用蓝色和白色”，而要说“它营造出沉静的权威感，逐步建立信心”。描述人们体验它时的感受。

**框定检查：** 继续之前，确认具体的分析对象。用一句话说明你识别出的内容——正在分析的实际对象及其媒介或领域——然后使用 `AskUserQuestion`：
- **问题：**“我的理解是：[用一句话框定具体对象及其情境]。对吗？”
- **标题：**“框定”
- **选项：**
  - **是——继续**——框定正确
  - **调整**——有一个要素不准确；用户会先予以纠正，然后你再继续
  - **重新框定**——实际对象或情境与当前理解不同；先纳入用户的纠正，再继续

**第 2 步：识别存在的形式模式**
系统地逐项分析以下列表——通常会有多个模式同时发挥作用：
- **重复/节奏**——反复出现的元素先建立预期，然后满足预期，或以富有成效的方式打破预期
- **对称/不对称**——平衡会营造稳定与信任；刻意的不对称会制造张力与动感
- **层级**——从最重要到最不重要、从大到小、从一般到具体的清晰排序；引导注意力
- **对比**——鲜明的差异能够形成清晰界定、集中注意力，并通过比较产生意义
- **张力/化解**——引入并解决一个问题，提出并回答一个疑问；这是叙事的引擎
- **图形/背景**——通过周围那些退居次要位置的元素，使主体变得鲜明而清晰
- **部分/整体**——各个组成部分共同构成超越其简单总和的事物

**第 3 步：匹配领域原型**
它与设计、叙事、建筑或音乐中的哪些原型相似？英雄之旅。赋格。黄金分割。正题—反题—合题。呼应。指出原型的名称及其来源领域。

**第 4 步：为模式命名**
**缩小范围之前：** 首先向用户展示第 2 步中识别出的完整模式集合。使用 `AskUserQuestion`：
- **问题：**“我识别出 [N] 个正在发挥作用的模式。在我选出主导模式之前，是否有你认为尤其重要的模式，或者有我遗漏的模式？”
- **标题：**“确定优先级”
- **选项：**
  - **按你的选择继续**——这个模式集合看起来准确
  - **标记一个模式**——用户将指定一个应视为主导模式的具体模式
  - **添加遗漏的模式**——用户将描述一个尚未识别出的模式

为主导模式赋予一个精确的名称。检验标准：为它命名是否让事物更易于理解？是否揭示了为什么某些元素有效，而另一些元素却让人感觉不协调？一个好的模式名称应具有生成性——它能产生新的选择，而不仅仅是描述现状。

**步骤 5：应用模式**
该模式对接下来应该做什么有何启示？当前制品中有哪些内容违反了该模式——这种违反是有意为之（产生富有成效的张力），还是无意造成的（缺乏连贯性）？

## 与用户确认

在继续之前，请使用 `AskUserQuestion` 工具。用 1–2 句话说明你对当前情况的理解——正在分析什么，以及核心问题是什么——然后询问：

- **问题：**“我的理解是：[用 1–2 句话说明你的理解]。你希望如何继续？”
- **标题：**“范围”
- **选项：**
  - **完整分析** — 完成所有步骤，并全程展示推理过程
  - **仅关键发现** — 只输出结论，跳过逐步分析的细节
  - **仅模式名称** — 识别并命名底层结构，跳过完整分析
  - **重新界定** — 当前理解有误；请予以纠正，之后将按照修正后的框架进行分析

根据用户的选择继续。如果用户重新界定了问题，请在开始任何分析之前纳入其修正。

## 输出格式

**存在的形式模式：**[列出每个模式，并用一句话说明其表现方式]

**原型匹配：**[最接近的领域原型 + 该原型来自哪个领域]

**模式名称：**[主导模式的精确名称]

**命名所揭示的内容：**[命名后，哪些此前不可见或难以理解的内容变得清晰]

**模式的启示**

| 启示 | 说明 |
|---|---|
| 接下来应该做什么 | [该模式要求采取的行动] |
| 哪些内容违反了模式 | [破坏该模式的具体元素] |
| 有意还是无意 | [富有成效的颠覆，还是缺乏连贯性] |

---

## 注意事项

并非每个成功的事物都明确遵循单一模式——大多数事物会同时依照多个模式运作。首先识别主导模式；将次要模式单独列出。检验一个模式名称是否优秀，要看它能否产生新的选择，而不仅仅是描述已有的内容。
