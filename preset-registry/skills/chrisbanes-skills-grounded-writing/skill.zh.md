# 有据可依的写作

## 核心原则

在文字中复现 Chris 的推理方式，而不是堆砌一系列语言习惯。以对话式语气写出清晰、由证据支撑的内容，然后删除任何听起来像是虚构、泛泛而谈或刻意模仿「Chris 风格」的部分。

## 流程

1. 确认文本以 Chris 的身份撰写，且长度超过一个段落。不要将这种风格用于简短回复、引用的源文本或为他人撰写的内容。
2. 在起草或修订前阅读[风格档案](references/voice-profile.md)。
3. 明确受众、目的、要求的格式、提供的事实以及 Chris 的真实立场。保留所要求交付物的形式，不要把每项交付物都变成博客文章。
4. 在写作前解决缺失的信息：
   - 当任务需要研究时，查找能够通过公开渠道获得的事实。
   - 如果缺失的个人观点或经历会实质性地改变文章，请询问 Chris，并停止起草相关部分。
   - 如果缺口很小，使用醒目的占位符，或如实说明不确定性。绝不虚构第一人称陈述、结果、偏好或记忆。
5. 从风格档案中选择语域。默认使用近期较为克制的风格；只有当教程或深入的技术演练能从中受益时，才使用更活泼、更具解释性的语域。
6. 先组织推理，再润色句子。优先从具体问题或观察切入，解释其机制，以证据或示例提供支持，承认重要的限制，说明实际影响，并以剩余要点中最清晰的一点收尾。交付物不需要的阶段可以省略。
7. 除非请求另有说明，否则使用用户的默认语言和地区惯例。保持段落主题集中，长短句结合，只在有事实依据时使用第一人称，并确保每个标题都有存在的必要。
8. 分别从风格和真实性两个方面各编辑一次。删除泛泛的背景铺陈、营销语言、重复的结论、装饰性的口头禅以及缺乏依据的确定性表述。

## 完成门槛

只有在以下各项全部满足时才能完成：

- 结果仍符合要求的格式和目的。
- 每项个人陈述和实质性事实都已由用户提供、经过核实、附有限定条件，或明确标记为缺失。
- 论述足够具体，无需宣传性填充内容也能让人理解。
- 限制条件应改变读者的理解，而不是仅仅充当免责声明。
- 拼写和语法遵循用户默认语言及地区惯例。
- 结尾一次落定，不再概括全文。
- 文章朗读起来自然，不会堆砌借用的措辞、反问、插话或表情符号。

如果某项检查未通过，请修订草稿。如果失败是因为未知的个人立场，请询问 Chris，而不是含糊地填补这一缺口。

## RED/GREEN 智能体场景

1. RED 将提供的发布说明改写成精致的营销文案。GREEN 从这项工作的具体缘由切入，解释发生了哪些变化，给出测量结果及其局限，并以实际价值收尾。
2. 新颖案例：一篇技术教程需要更亲切的语域。GREEN 偶尔使用问题或插话来引导读者，同时让解释和代码始终占据主导。
3. 反例：只有一句话的议题回复已经直接且清晰。GREEN 不调用此技能，也不扩写该回复。
