# Suede 营销创意优先级排序器

Suede 将广泛的策略库转化为一个有边界的候选清单，并根据用户的受众、阶段、证据、能力、成本和风险进行评分。目标不是将策略库中的策略标记为“已验证”；而是确定在特定情境下，哪些少数策略值得验证，以及哪些策略应当推迟或拒绝。

## 如何使用此 Skill

如果 `.agents/product-marketing.md` 存在，请先阅读；只询问其中未涵盖的内容；路径回退方式请参见 `suede-product-marketing`。

当被要求提供营销创意时：
1. 持续询问下方的任务特定问题，直到产品、受众、阶段、预算、负责人能力以及已经尝试过的事情都有记录。不要基于假设进行评分。
2. 从下方的分类索引中提取候选项（完整描述见 `references/ideas-by-category.md`）。评分候选项不超过 8 个。
3. 使用下方的评分标准为每个候选项评分，并应用其决策规则。
4. 按照输出格式返回候选清单，其中包括规定的拒绝项。

## 评分标准

在六个维度上为每个候选项分别评定 0–3 分。0 表示“没有任何证据支持或反对”，而不是“可能没问题”。

| 维度 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **受众** | 没有证据表明 ICP 能在此处触达 | 从类别来看合理，但未经验证 | 已观察到 ICP 出现在此渠道 | 用户能够指出具体的社区、查询或账号 |
| **阶段** | 前置条件不存在 | 缺少一个前置条件 | 前置条件满足，但尚未测试 | 前置条件满足，且类似行动已经奏效 |
| **证据** | 支持依据是“它很流行” | 只有第三方案例研究 | 来自相邻渠道的、有日期的第一方信号 | 针对该受众的、有日期的第一方结果 |
| **能力** | 没有负责人 | 已指定负责人，但没有投入时长 | 有负责人和投入时长，但会挤占其他事项 | 有负责人和投入时长，且不会挤占任何既定承诺 |
| **成本** | 总成本未知 | 超出已批准的限定金额 | 在预算范围内，但会消耗其中的大部分 | 在预算范围内，且有充足余量 |
| **风险** | 无法定义停止条件 | 只有付出代价后才能逆转，且检查门槛尚未确认 | 可以逆转，且已确定检查门槛 | 可以逆转、停止成本低，且不存在法律、平台或品牌风险 |

**决策规则**——按顺序应用，以第一个匹配项为准：

1. 任一维度得分为 0 → **跳过**或**有条件**，本周期绝不测试。注明得分为 0 的维度。
2. 总分 ≥ 14/18，且**证据** ≥ 2，且**容量** ≥ 2 → **已批准测试**。说明测试内容、成功指标、评审日期和停止条件。
3. 总分 ≥ 10，且只有一个明确的阻碍因素 → **有条件**。说明确切的解锁条件以及谁可以清除该阻碍。
4. 总分 ≥ 10，但本窗口期没有容量 → **延后**。说明评审日期。
5. 总分 < 10，或**风险** ≤ 1 → **跳过**。说明导致不符合条件的维度。

用户已经在执行的策略属于**当前执行中**——对其评分，但不要将其作为新想法提出。这五种状态与 `suede-marketing-plan` 第 12 节使用的状态集合相同，因此候选短名单可以直接纳入计划，无需重新标注。

**上限。** 最多为 8 个候选项评分；最多展示 5 个；同时最多有 3 个候选项处于**已批准测试**状态。如果有超过 3 个候选项满足规则 2，则按**容量**，然后按**成本**排序，其余移至**延后**——限制因素是容量，而不是热情。

**必须给出拒绝项。** 每份候选短名单都必须至少列出一个**不推荐**的策略，且必须取自已有记录而非凭空编造：可以是用户在特定任务问题 3 或 4 中提到的内容（已经尝试过的策略，或他们欣赏的竞争对手策略），也可以是仍有某个维度不达标的最高分候选项。不要构造用户从未提出过的稻草人。如果用户什么都没提到，且所有评分候选项都达标，请明确说明这一点，而不是捏造一个拒绝项。

## 输出格式

提出想法时，请为每个想法提供：

- **想法名称**：一行描述
- **状态**：已批准测试 / 有条件 / 延后 / 跳过，并附上六个维度的得分和总分
- **为何适合**：说明与其处境的关联，并引用为**证据**维度评分所依据的证据
- **如何开始**：前 2-3 个实施步骤
- **预期结果**：成功指标、评审日期和停止条件
- **所需资源**：所需时间、预算和技能

每份候选短名单结尾都必须包含所要求的拒绝项，格式如下：

**不推荐：**[策略]——因 [当前证据或证据缺失] 而无法通过[维度]。

## 特定任务问题

1. 你目前处于哪个阶段，主要增长目标是什么？
2. 你的营销预算和团队规模是多少？
3. 你已经尝试过哪些方法，哪些有效或无效？
4. 你欣赏哪些竞争对手的策略？

---

## 边界

- 没有当前证据和明确评分时，不要声称某个策略适合、已被证明有效或会带来收入增长。
- 未经授权，不要发起活动、发布内容、花费资金、联系潜在客户或创建账户。
- 不要把头脑风暴出的想法当作计划、预测、承诺或已完成的实验。
- 在缺少必要背景信息时，不要擅自决定预算、风险承受度、品牌声明或渠道优先级。

## 路由

- 使用 `suede-marketing-plan` 将选定的想法转化为按顺序排列的路线图。
- 使用 `suede-marketing-loops` 处理已批准的循环工作流。
- 使用 `suede-programmatic-seo`、`suede-competitors` 或 `suede-emails` 执行渠道相关工作。
- 使用 `suede-free-tools` 处理以工程为营销手段的工作，使用 `suede-referrals` 处理推荐机制。
- 当候选短名单在两个合理方向之间难分伯仲，且评分无法区分二者时，使用 `suede-marketing-council`。
- 使用 `suede-marketing-psychology` 说明转化策略背后的行为机制，并将其表述为可测试的假设。
