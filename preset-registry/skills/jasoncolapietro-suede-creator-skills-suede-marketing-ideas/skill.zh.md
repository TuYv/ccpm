# Suede 营销创意优先级排序器

Suede 将宽泛的策略库转化为一个有限的候选短名单，并根据用户的受众、阶段、证据、能力、成本和风险进行评分。目标不是将策略库中的战术标记为“已验证”；而是识别在当前具体情境下哪些少数战术值得验证，以及哪些应当推迟或拒绝。

## 如何使用此 Skill

如果 `.agents/product-marketing.md` 存在，请先阅读它，并且仅询问其中未涵盖的内容；有关路径回退，请参阅 `suede-product-marketing`。

当被要求提供营销创意时：
1. 提出下方的任务特定问题，直到产品、受众、阶段、预算、负责人能力以及已尝试内容均有记录。不要基于假设进行评分。
2. 从下方的类别索引中选取候选项（完整描述见 `references/ideas-by-category.md`）。评分候选项不得超过 8 个。
3. 使用下方的评分量表为每个候选项评分，并应用其决策规则。
4. 按输出格式返回候选短名单，包括必需的拒绝项。

## 评分量表

在全部六个维度上为每个候选项评分，范围为 0–3。0 表示“没有任何方向上的证据”，而不是“可能没问题”。

| 维度 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **受众** | 没有证据表明 ICP 可在此触达 | 按类别来看合理，但未经验证 | 在此渠道观察到 ICP | 用户能够指出具体的社区、查询词或账户 |
| **阶段** | 前提条件缺失 | 缺少一项前提条件 | 前提条件已满足，尚未测试 | 前提条件已满足，且类似做法已经奏效 |
| **证据** | 支持依据只是“它很受欢迎” | 仅有第三方案例研究 | 来自相邻渠道的有日期的一手信号 | 针对此受众的有日期的一手结果 |
| **能力** | 没有负责人 | 已指定负责人，但没有工时 | 负责人 + 工时，会挤占其他事项 | 负责人 + 工时，不会挤占已有承诺 |
| **成本** | 总成本未知 | 超出已批准的限定金额 | 在预算内，但会消耗大部分预算 | 在预算内且仍有余量 |
| **风险** | 无法定义停止条件 | 仅能以成本为代价撤回，关卡尚未检查 | 可撤回，已识别关卡 | 可撤回、停止成本低，且无法律/平台/品牌风险 |

**决策规则** — 按顺序应用，首个匹配项优先：

1. 任一维度得分为 0 → **Skip** 或 **Conditional**，本周期绝不进行测试。指出得分为 0 的维度。
2. 总分 ≥ 14/18 **且** Evidence ≥ 2 **且** Capacity ≥ 2 → **Approved test**。说明测试内容、成功指标、复核日期和停止条件。
3. 总分 ≥ 10 且存在一个明确的阻碍因素 → **Conditional**。说明确切的解锁条件以及谁可以清除该阻碍。
4. 总分 ≥ 10 且本窗口期没有执行能力 → **Deferred**。说明复核日期。
5. 总分 < 10，或 Risk ≤ 1 → **Skip**。说明导致淘汰的维度。

用户已经在执行的策略属于 **Current** — 对其进行评分，但不要将其作为新想法提出。这五种状态与 `suede-marketing-plan` 第 12 节使用的状态集合相同，因此候选清单无需重新标注即可纳入计划。

**上限。** 最多为 8 个候选项评分；最多展示 5 个；同时最多有 3 个候选项处于 Approved test 状态。如果有超过 3 个候选项符合规则 2，则按 Capacity、再按 Cost 排名，其余移至 Deferred — 约束因素是执行能力，而不是热情。

**必须列出不推荐项。** 每份候选清单都必须至少指出一个*不推荐*的策略，且该策略必须来自现有记录，而不是凭空编造：可以是用户在特定任务问题 3 或 4 中提到的内容（已经尝试过的策略，或用户欣赏的竞争对手策略），也可以是仍有某个维度不达标的最高分候选项。如果用户没有提到任何策略，且所有评分候选项都达标，请明确说明这一点，而不要人为制造一个不推荐项。

## 输出格式

提出建议时，为每个建议提供：

- **想法名称**：一句话描述
- **状态**：Approved test / Conditional / Deferred / Skip，并列出六个维度的得分和总分
- **为什么适合**：说明其与用户情况的关联，并引用用于 Evidence 维度评分的证据
- **如何开始**：前 2-3 个实施步骤
- **预期结果**：成功指标、复核日期和停止条件
- **所需资源**：所需时间、预算和技能

每份候选清单都必须以以下格式列出不推荐项：

**不推荐：** [策略] — 因为基于[当前证据，或缺乏证据]而未通过[维度]。

## 特定任务问题

1. 你目前处于什么阶段，主要增长目标是什么？
2. 你的营销预算和团队规模是多少？
3. 你已经尝试过哪些方法，哪些有效或无效？
4. 你欣赏哪些竞争对手的策略？

## 边界

- 没有当前证据和明确评分时，不得声称某项策略适合、已被验证，或将带来收入增长。
- 未经授权，不得启动活动、发布内容、花费资金、联系潜在客户或创建账号。
- 不得将头脑风暴中的想法视为计划、预测、承诺或已完成的实验。
- 在缺少必要背景信息时，不得自行决定预算、风险承受度、品牌声明或渠道优先级。

## 路由

- 使用 `suede-marketing-plan` 将选定的想法转化为按顺序执行的路线图。
- 使用 `suede-marketing-loops` 处理已批准的周期性工作流。
- 使用 `suede-programmatic-seo`、`suede-competitors` 或 `suede-emails` 执行渠道工作。
- 使用 `suede-free-tools` 处理工程化营销，使用 `suede-referrals` 处理推荐机制。
- 当候选清单在两个合理方向之间难分高下，且评分无法拉开差距时，使用 `suede-marketing-council`。
- 使用 `suede-marketing-psychology` 分析转化策略背后的行为机制，并将其表述为可测试的假设。
