# 增长循环

## 概述
识别并设计能够创造可持续增长势能的增长循环（飞轮）。此技能评估五种经过验证的增长循环机制，以减少对付费获客的依赖，并构建产品驱动增长。

## 适用场景
- 为产品设计增长机制
- 构建可持续的病毒式增长或推荐增长势能
- 减少对付费获客的依赖
- 分析竞争对手的增长策略
- 针对产品驱动增长优化产品

## 5 种增长循环类型

### 1. 病毒式循环
用户创建的产品内容会被分享到外部平台，从而将新用户带回产品。
- **机制**：用户在产品内创建内容 → 分享到社交/外部平台 → 新用户发现并注册
- **示例**：以链接形式分享的 Figma 设计、通过电子邮件分享的 Loom 视频
- **优势**：如果内容本身具有很强的分享性，就能实现指数级用户获取
- **挑战**：需要高度易于分享的产出，以及强烈的分享动机

### 2. 使用循环
用户在产品内创建内容或价值，然后进行分享，从而邀请新用户或推动用户重新参与。
- **机制**：用户创建 → 分享创作内容 → 他人消费内容 → 成为活跃用户
- **示例**：Twitter 帖子串、Medium 文章、公开分享的 Notion 模板
- **优势**：增长与产品使用和网络效应直接相关
- **挑战**：需要将内容创建的阻力降到极低

### 3. 协作循环
用户邀请同事在产品内共同创建或协作，从而扩大组织内部的用户群体。
- **机制**：用户创建 → 邀请同事协作 → 同事发现产品价值
- **示例**：Google Docs 邀请、Figma 团队项目、Slack 频道
- **优势**：能够深入组织内部，并具有较高的留存率
- **挑战**：最适用于协作型/团队型产品

### 4. 用户生成循环
用户通过其他用户的创作发现新内容或新功能，然后创建并分享自己的内容。
- **机制**：用户发现内容 → 创建类似内容 → 分享创作内容 → 其他人发现
- **示例**：TikTok、Pinterest、YouTube 上推动创作者参与的趋势
- **优势**：能够形成内容飞轮和网络效应
- **挑战**：需要一定规模的高质量内容才能持续运转

### 5. 推荐循环
用户邀请其他潜在用户，以换取奖励、激励或社交认可。
- **机制**：用户发起推荐 → 被推荐用户加入 → 推荐者获得奖励 → 分享更多推荐
- **示例**：Dropbox 推荐奖励、Uber 乘客推荐、PayPal 注册奖励
- **优势**：直接激励获客；投资回报率易于衡量
- **挑战**：需要提供有价值的激励，同时不能侵蚀单位经济效益

## 运作方式

### 第 1 步：定义产品价值
明确用户获得的核心价值：
- 用户在你的产品中采取的主要操作
- 每次用户操作所创造的价值
- 存在的网络效应（如有）
- 体验中的阻力点

### 第 2 步：评估增长循环匹配度
评估哪些增长循环与您的产品相匹配：
- 产品类型（协作型、内容型、工具型等）
- 目标用户行为和分享习惯
- 已存在的网络效应
- 现有用户群体和参与度

### 第 3 步：设计循环机制
创建具体的循环实现方案：
- 发起分享或邀请的触发因素
- 参与激励（内在激励或外在激励）
- 分享机制的便捷程度
- 从邀请到激活的转化率
- 每位用户重复循环的频率

### 第 4 步：计算循环系数
估算增长速度：
- 每位用户每个周期发出的邀请/分享次数
- 邀请转化为新用户的转化率
- 每个周期带来的净新增用户数
- 每次循环迭代所需的时间

### 第 5 步：构建循环
优先实现杠杆效应最高的循环：
- 从最适合您产品的自然循环开始
- 优化消息传达和摩擦点
- 衡量循环指标和转化率
- 让成果随着时间不断复利增长

## 输入格式
使用 $ARGUMENTS 传入：
- 产品描述和主要用户行为
- 目标用户的人口统计特征和行为
- 现有的分享/协作功能
- 当前增长渠道和指标
- 约束条件或机会

## 输出
一份增长循环分析，包括：
- 针对您产品的全部 5 种循环类型的排名评估
- 推荐的主要增长循环及其实施计划
- 随时间逐步叠加的次要循环
- 关键指标和衡量框架
- 30-60-90 天实施路线图
- 潜在循环系数和增长预测

## 框架
基于 Ognjen Bošković 的增长循环研究。重点是通过内置的、原生于产品的分享和协作机制，复合式地获取用户。

## 提示
- 先从一个循环开始，在增加复杂性之前先将其打磨成熟
- 病毒式循环的复合增长速度最快，但构建需要时间
- 协作循环能带来最强的留存率和 LTV
- 在优化阶段每周衡量循环的健康度
- 达到规模化运营后，结合多个循环以产生乘数效应
