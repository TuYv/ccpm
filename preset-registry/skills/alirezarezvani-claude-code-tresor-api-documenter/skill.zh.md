# API 文档生成技能

从代码中自动生成 API 文档。

## 何时激活

- ✅ 添加/修改了 API 端点
- ✅ 用户提及 API 文档、OpenAPI 或 Swagger
- ✅ 路由文件发生更改
- ✅ 控制器文件被修改
- ✅ 需要文档

## 生成内容

### OpenAPI 3.0 规范
- 端点描述
- 请求/响应模式
- 身份验证要求
- 示例有效载荷
- 错误响应

### 支持的格式
- OpenAPI 3.0 (JSON/YAML)
- Swagger 2.0
- API Blueprint
- RAML

## 示例

### Express.js 端点

```javascript
// You write:
/**
 * Get user by ID
 * @param {string} id - User ID
 * @returns {User} User object
 */
app.get('/api/users/:id', async (req, res) => {
  const user = await User.findById(req.params.id);
  res.json(user);
});

// I auto-generate OpenAPI spec:
paths:
  /api/users/{id}:
    get:
      summary: Get user by ID
      parameters:
        - name: id
          in: path
          required: true
          description: User ID
          schema:
            type: string
      responses:
        '200':
          description: User found
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/User'
              example:
                id: "123"
                name: "John Doe"
                email: "john@example.com"
        '404':
          description: User not found
```

### FastAPI 端点

```python
# You write:
@app.get("/users/{user_id}")
def get_user(user_id: int) -> User:
    """Get user by ID"""
    return db.query(User).filter(User.id == user_id).first()

// I auto-generate:
paths:
  /users/{user_id}:
    get:
      summary: Get user by ID
      parameters:
        - name: user_id
          in: path
          required: true
          schema:
            type: integer
      responses:
        '200':
          description: Successful response
          content:
            application/json:
              schema:
                $ref: '#/components/schemas/User'
```

### 完整的 OpenAPI 文档

```yaml
openapi: 3.0.0
info:
  title: User API
  version: 1.0.0
  description: API for user management

servers:
  - url: https://api.example.com/v1

paths:
  /api/users:
    get:
      summary: List all users
      responses:
        '200':
          description: Users array
          content:
            application/json:
              schema:
                type: array
                items:
                  $ref: '#/components/schemas/User'

components:
  schemas:
    User:
      type: object
      properties:
        id:
          type: string
        name:
          type: string
        email:
          type: string
          format: email
```

## 文档增强

### 缺失的信息

```javascript
// Your code:
app.post('/api/users', (req, res) => {
  User.create(req.body);
});

// I suggest additions:
/**
 * Create new user
 * @param {Object} req.body - User data
 * @param {string} req.body.name - User name (required)
 * @param {string} req.body.email - User email (required)
 * @returns {User} Created user
 * @throws {400} Invalid input
 * @throws {409} Email already exists
 */
```

## 与 @docs-writer 的关系

**我（Skill）：** 根据代码自动生成 API 规范
**@docs-writer（子代理）：** 编写全面的用户指南和教程

### 工作流程
1. 我生成 OpenAPI 规范
2. 你需要用户指南 → 调用 **@docs-writer** 子代理
3. 子代理创建完整的文档站点

## 集成

### 与 Swagger UI 集成

```javascript
// app.js
const swaggerUi = require('swagger-ui-express');
const spec = require('./openapi.json'); // Generated by skill

app.use('/api-docs', swaggerUi.serve, swaggerUi.setup(spec));
```

### 与 Postman 集成

导出生成的 OpenAPI 规范：
```bash
# Import into Postman for API testing
File → Import → openapi.json
```
