# 澳大利亚 GST 申报表编制技能（BAS）v2.0

> **仅供一般参考。** 本技能是用于 AI 辅助工作流的一般税务/会计参考资料。其内容尚未针对任何特定个人的事实情况、文件、选择、截止日期、居民身份、申报状态或当地程序进行审核。在未经相关司法管辖区合格专业人士审核的情况下，请勿依赖本技能进行申报、缴款、修正申报或采取税务立场。

**主要 BAS 标签（最常用的标签）：**

| 标签 | 含义 |
|---|---|
| G1 | 销售总额（应税销售按不含 GST 金额计算；包括 GST 免税销售和进项税征税型免税销售） |
| G2 | 出口销售（GST 免税，第 38-E 部） |
| G3 | 其他 GST 免税销售（食品、医疗、教育 -- 第 38-A 至 38-D、38-F+ 部） |
| G4 | 进项税征税型免税销售（金融供应、住宅租金 -- 第 40 部） |
| G5 | G2 + G3 + G4（计算得出） |
| G6 | G1 减去 G5（计算得出 -- 应税销售总额，即销项 GST 的计税基础） |
| G7 | 销售调整（坏账、价格变动 -- 第 19 部） |
| G10 | 资本性采购（厂房、设备、车辆 -- 含 GST） |
| G11 | 非资本性采购（运营费用、存货 -- 含 GST） |
| G12 | G10 + G11（计算得出） |
| G13 | 用于产生进项税征税型免税销售的采购（不得抵扣） |
| G14 | 价格中不含 GST 的采购（购自未注册主体、GST 免税项目、工资） |
| G15 | 估算的私人用途采购（不得抵扣） |
| G16 | G13 + G14 + G15（计算得出） |
| G17 | G12 减去 G16（计算得出 -- 可抵扣采购总额） |
| G18 | 采购调整（第 19 部、第 129 部） |
| 1A | 销售产生的 GST（销项 GST） |
| 1B | 采购产生的 GST（进项税抵扣） |

**简化版 BAS（营业额 < $10M，自 2017 年 7 月 1 日起为默认方式）：** 仅申报 G1、1A、1B。无需申报 G2-G18。

**完整 BAS：** 根据适用情况，报告所有 G 标签，以及 1A、1B 和 PAYG/FBT 标签。

**GST 计算公式：**

```
GST = GST-inclusive price x 1/11
GST = GST-exclusive price x 10%
GST-inclusive = GST-exclusive x 1.1
GST-exclusive = GST-inclusive / 1.1
```

**保守默认值——澳大利亚特定：**

| 模糊情况 | 默认处理 |
|---|---|
| 销售的 GST 状态未知 | 按 10% 应税处理 |
| 采购的 GST 状态未知 | 不申报进项税抵扣 |
| 业务用途比例未知（车辆、电话、家庭办公室） | 抵扣比例为 0% |
| 不确定食品属于基本食品还是加工食品 | 按 10% 应税处理（加工食品） |
| 交易对手的注册状态未知 | 视为未注册（价格中不含 GST，G14） |
| SaaS 计费实体所在地未知 | 视为非居民，适用反向征税 |
| 保险类型未知（一般保险或人寿保险） | 按进项税处理（不可抵扣） |
| 房产类型未知（商业房产或住宅房产） | 按住宅房产处理（进项税，不可抵扣） |
| 不确定交易是否在范围内 | 视为在范围内 |
| 现金取款用途 | 视为业主提款，排除 |

## 第 2 节——必需输入和拒绝处理目录

### 必需输入

**最低可行要求**——提供该期间的银行对账单，格式可以是 CSV、PDF 或粘贴的文本。必须涵盖完整的 BAS 期间。接受任何澳大利亚商业银行的对账单：CBA、Westpac、ANZ、NAB、Macquarie、Bendigo、Suncorp、Bank of Queensland、Up Bank、ING、Revolut AU、Wise 或任何其他银行。

**建议提供**——该期间的销售发票（尤其是出口和 GST-free 供应）、任何超过 AUD $500 的进项税抵扣申请所对应的采购发票、客户以书面形式提供的 ABN（11 位数字）、上一期间的 BAS。

**理想情况**——完整的会计软件导出文件（Xero、MYOB、QuickBooks）、税务发票登记册、包含任何结转抵免额的上一期间 BAS。

**缺少最低要求时的拒绝政策——SOFT WARN。** 如果完全没有银行对账单，则必须停止。如果只有银行对账单而没有发票，则继续处理，但应在审核人员简报中记录：“本 BAS 仅根据银行对账单编制。审核人员必须在提交前核实，超过 AUD $500 的进项税抵扣申请均有有效税务发票支持，并且所有 GST-free 和反向征税分类均与供应商发票一致。”

### 澳大利亚特定的拒绝处理目录

如果触发任何条件，则停止，逐字输出拒绝消息，并结束对话。拒绝是一项安全机制。

**R-AU-1——复杂的部分免税。** *触发条件：* 客户同时进行应税/GST-free 供应和进项税供应，并且进项税供应的比例并非微不足道（已超过金融采购阈值）。*消息：* “您同时进行应税供应和进项税供应。您的进项税抵扣必须依据 Division 11 (s 11-30) 进行分摊，这要求确定每项采购的可抵扣用途比例。如果没有经注册税务代理确认并记录在案的分摊方法，则无法完成此项工作。请升级处理。”

**R-AU-2 -- GST 集团。** *触发条件：* 客户属于第 48 分部规定的 GST 集团，或询问集团注册事宜。*提示信息：* “第 48 分部规定的 GST 集团需要在集团范围内进行合并，并由代表成员提交一份统一的 BAS。集团内部供应不予考虑。这超出了本技能的范围。请咨询注册税务代理。”

**R-AU-3 -- 差额计税法。** *触发条件：* 客户根据第 75 分部使用差额计税法出售房产。*提示信息：* “第 75 分部规定的差额计税交易需要按差额（售价减去取得成本）计算 GST，并根据最初取得房产的情况确认是否符合资格。这过于依赖具体事实，超出了本技能的处理能力。请咨询注册税务代理。”

**R-AU-4 -- 持续经营业务。** *触发条件：* 客户根据 s 38-325 以持续经营业务形式出售或购买企业。*提示信息：* “根据 s 38-325 进行的持续经营业务供应，需要核实是否满足全部三个条件（属于持续经营业务、双方均已注册、达成书面协议）。错误分类会导致需要按全部售价缴纳 10% 的 GST，或错失 GST 免税资格。请在继续操作前咨询注册税务代理，以确认是否符合资格。”

**R-AU-5 -- 复杂金融供应（金融机构）。** *触发条件：* 客户是金融机构（银行、保险公司、养老基金），其主要供应属于进项税供应，或客户询问减免进项税抵免（RITC）。*提示信息：* “主要提供进项税供应的金融机构需要进行专业分摊、RITC 计算（75%/55%）以及金融购置门槛测试。这超出了本技能的范围。请咨询专门从事金融服务 GST 的注册税务代理。”

### 3.7 SaaS（来自非居民供应商的反向征税）

## 第 5 节——第 1 层分类规则

每条规则均说明法律依据及其对应的 BAS 标签。如果数据明确无歧义，则直接应用，无须提示。

### 5.1 应税供应（10%）

**法律依据：**《GST 法》第 9-5 条（应税供应的定义）、第 9-70 条（税率）。

由已注册 GST 的实体在经营企业过程中提供、且与澳大利亚有关的任何供应，默认税率均为 10%，除非该供应属于 GST 免税（第 38 分部）或进项税（第 40 分部）供应。澳大利亚实行单一的 10% 税率——没有优惠税率，也没有多档税率。

满足以下所有条件时，供应即为应税供应（第 9-5 条）：
1. 有偿提供；
2. 在经营企业的过程中或为促进企业经营而提供；
3. 与间接税区（澳大利亚）有关；
4. 供应方已注册或必须注册 GST；并且
5. 既非 GST 免税供应，也非进项税供应。

销售：G1（以及派生的 G6）。采购：G10（资本性）或 G11（非资本性）。销售产生的 GST：1A。采购的 GST 抵免：1B。

常见应税供应：专业服务（法律、会计、咨询）、商业租赁、建筑施工、电信、一般保险保费、软件许可证、机动车销售、餐厅/咖啡馆餐食、澳大利亚境内运输、办公用品、设备采购。

### 5.2 GST 免税供应（0%，保留抵免权）

**法律依据：**《GST 法》第 38 分部。

GST 免税供应适用 0% GST，但供应方仍保留对相关成本全额申请进项税抵免的权利。这与欧盟的零税率供应概念相对应。

销售：G1，以及 G2（出口）或 G3（其他 GST 免税供应）。在简化版 BAS 中，仅计入 G1。

### 5.3 进项税供应（不征收 GST，不享有抵免）

**法律依据：**《GST 法案》第 40 分部。

进项税供应不收取 GST，供应方也不能就相关成本取得进项税抵免。这与欧盟免税且不可抵免供应的概念类似。

销售：G4（进项税销售）。与进项税供应相关的采购：G13（不可抵免）。

**关键区别：**免 GST 与进项税供应并不相同。免 GST 供应方保留进项税抵免权；进项税供应方则不享有该权利。混淆二者会导致完全相反的结果。

| 类别 | 条款 | 主要项目 |
|---|---|---|
| 金融供应 | 40-5 | 利息、贷款费用、货币兑换差价、信用卡费用（发卡方）、股份交易、担保费用、人寿保险、养老金基金管理 |
| 住宅租赁 | 40-35 | 出租现有住宅物业。商业物业租赁应税。 |
| 出售现有住宅物业 | 40-65 | 以前曾作为住宅出售，且并非新建或经过大规模翻修 |
| 人寿保险 | 40-5 | 一般保险应税 |

**住宅与商业物业——界限：**

| 供应 | 处理方式 |
|---|---|
| 住宅租赁（现有物业） | 进项税供应 |
| 出售现有住宅物业 | 进项税供应 |
| 出售新建住宅物业 | 按 10% 征税（建成或大规模翻修后的首次出售） |
| 商业物业租赁（办公室、零售场所、仓库） | 按 10% 征税 |
| 短期住宿（酒店、Airbnb <3个月） | 按 10% 征税（属于商业而非住宅）[如有歧义则为 T2] |

### 5.4 范围外交易（不在 BAS 中申报）

| 交易 | 原因 |
|---|---|
| 工资、薪金、养老金缴款 | 不属于供应——属于雇佣关系 |
| 股息 | 不属于供应——属于股权回报 |
| 偿还贷款本金 | 不属于供应——属于资本偿还 |
| 向 ATO 缴纳 GST/所得税 | 属于税款缴纳，而非供应 |
| 个人的私人交易 | 并非在经营企业过程中发生 |
| 所有者提款/转账 | 属于内部交易，而非供应 |
| 礼品/捐赠（无对价） | 无对价 = 不属于供应 |

### 5.5 反向征税（第 84 分部）

**澳大利亚与欧盟的关键区别：**在澳大利亚，针对向已注册接收方提供的境外供应，只有当相关购入不能全额抵免时，才适用反向征税。如果接收方无论如何都能申领 100% 的进项税抵免，则不适用反向征税——因为不存在税收流失。

适用反向征税时：
- 销项 GST（自行计税）：计入 1A
- 进项税抵免（如有）：计入 1B
- 不在 G1（销售总额）中申报
- 两端均在 BAS 中体现

**“Netflix 税”（第 83-5 分部，自 2017 年 7 月 1 日起）：**如果非居民数字供应商的澳大利亚营业额超过 $75,000，则必须进行 GST 注册，并对 B2C 供应收取 10% 的 GST。对于接收方提供 ABN 的 B2B 供应，供应商不收取 GST。

### 5.6 进项税抵免权（第 11 分部）

如果满足以下所有条件，已注册实体有权获得进项税抵免（s 11-5）：
1. 购入用于可抵免目的（与应税供应或免 GST 供应相关）；
2. 该供应属于应税供应（价格中包含 GST）；
3. 实体提供对价；
4. 实体已注册 GST；并且
5. 实体持有有效的税务发票（或可在 4 年内取得）。

**不得抵扣的进项税额：** 与进项税供应相关的购置（s 11-15）、私人/家庭用途的购置（s 11-15）、免征 FBT 的娱乐支出（s 69-5）、不可扣除的罚款/处罚（s 69-5），均不得抵扣进项税额。

**汽车限额：** 汽车的进项税额抵扣上限为汽车限额 / 11。2024-25 年度：$69,674 / 11 = 最高抵扣额约为 $6,334。汽车并非完全不得抵扣（与马耳他不同）。

### 5.7 税务发票（Division 29）

| 要求 | 供应金额 < $1,000 | 供应金额 >= $1,000 |
|---|---|---|
| 标明“税务发票” | 是 | 是 |
| 供应商身份信息（名称、ABN） | 是 | 是 |
| 开具日期 | 是 | 是 |
| 简要说明 | 是 | 是 |
| GST 金额（或“价格包含 GST”） | 是 | 是 |
| 接收方身份信息（名称、ABN） | 否 | 是 |

**未提供 ABN 时的预扣税：** 如果供应商未提供 ABN，付款方必须预扣 47%（最高边际税率 + Medicare levy）。在 BAS 的 W3 标签中申报。供应金额 < $75（不含 GST）的情况除外。

## 第 6 节——第 2 层目录

针对每种歧义类型：模式、银行对账单为何不足以判断、保守的默认处理、向客户提出的问题。

### 6.1 车辆费用（燃油——商务还是私人用途？）

*模式：* BP、Shell、Caltex、Ampol、7-Eleven fuel、Viva Energy。*为何不足以判断：* 商务用途占比未知。与马耳他不同，澳大利亚并不完全禁止抵扣汽车相关的 GST——但必须排除私人用途部分。*默认处理：* 抵扣 0%。*问题：* “这些燃油是否用于商务车辆？商务用途与私人用途各占多少比例？您是否保留行车日志？”

### 6.2 居家办公（公用事业费用——70c/hr 还是实际成本？）

*模式：* 住宅地址上的 Origin Energy、AGL、Telstra；家庭互联网。*为何不足以判断：* 如果客户在家工作，一部分家庭支出可能可以申报扣除。ATO 允许使用固定费率法（自 2022 年 7 月 1 日起为每小时 67 澳分）或按比例分摊的实际成本法。对于 GST，实际成本法要求拆分应税部分。*默认处理：* 抵扣 0%（无法确定商务用途占比）。*问题：* “您是否在家工作？每周工作多少小时？这是专用于商务的线路/服务，还是与个人用途共用？”

### 6.3 食品采购（Woolworths——免 GST 的基本食品还是加工食品？）

*模式：* Woolworths、Coles、IGA、Aldi、任何超市。*为何不足以判断：* 一张超市收据可能同时包含免 GST 的基本食品，以及应税的加工食品、糖果、软饮料和非食品类商品。仅凭收据总额无法确定如何拆分。*默认处理：* 不申报抵扣（视为价格中不含 GST，G14）。*问题：* “您能否提供收据？我需要将免 GST 的食品与应税商品拆分，以申报正确的抵扣额。”

### 6.4 现金取款

*模式：* ATM、cash withdrawal、CBA cash、Westpac cash。*为何不足以判断：* 无法确定现金的实际用途。*默认处理：* 作为业主提款予以排除。*问题：* “这些现金用于什么用途？如果用于商务支出，您是否有收据？”

### 6.5 保险（有些应税，有些属于进项税供应——具体是哪种保单？）

*模式：* insurance premium、policy payment、Suncorp、QBE、AMP。*为何不足以判断：* 一般保险（商务、机动车、财产）按 10% 征税，并可抵扣 GST。人寿保险和私人健康保险属于进项税供应（不可抵扣）。银行对账单上的说明很少会注明保单类型。*默认处理：* 按进项税供应处理，不予抵扣（保守处理）。*问题：* “这是一般保险（商务/财产/车辆）、人寿保险，还是健康保险？一般保险包含 GST；人寿保险和健康保险不包含 GST。”

### 6.6 个人/业务混合订阅

*模式：* Netflix、Spotify、Apple、Amazon Prime、健身房会员。*为何信息不足：* 如果订阅部分用于个人、部分用于业务，则只有业务使用部分可以抵扣。大多数流媒体/娱乐订阅纯属个人用途。*默认处理：* 作为私人用途排除。*问题：* “这项费用是业务支出还是个人支出？如果是混合用途，业务使用比例是多少？”

### 6.7 Airbnb 收入（短期住宿——住宅还是商业？）

*模式：* Airbnb 付款、Stayz 付款、短期租赁收入。*为何信息不足：* 短期住宿（通常不超过 3 个月）被视为商业住宿，按 10% 征税。长期住宅租赁（超过 3 个月）属于进项税销售。银行对账单只显示 Airbnb 付款金额。此外，如果 Airbnb 总营业额低于 $75,000，房东可能无须注册 GST。*默认处理：* [T2] 标记供复核人员审查。*问题：* “这是短期租赁吗（每位住客的租期不超过 3 个月）？您的 Airbnb 年收入总额是多少？您是否已针对这项活动注册 GST？”

## 第 7 节——Excel 工作底稿模板（澳大利亚专用）

### 工作表 "Transactions"

列：
- A：日期
- B：交易对手（按银行对账单所示）
- C：类型（DEBIT/CREDIT）
- D：描述
- E：总金额（AUD，来自银行对账单——蓝色字体，硬编码）
- F：净额（公式：如果应税，= E / 1.1；如果免 GST 或已排除，= E）
- G：GST 金额（公式：如果应税，= E / 11；如果免 GST 或已排除，= 0）
- H：BAS 标签代码（G1、G2、G3、G4、G10、G11、G13、G14、G15，已排除的项目留空）
- I：是否采用默认处理？（Y/N）
- J：向客户提出的问题（文本或留空）
- K：是否排除？（文本形式的原因或留空）
- L：备注

### 工作表 "BAS Summary"（完整 BAS）

每个 BAS 标签占一行。A 列为标签，B 列为描述，C 列为通过公式计算的值。

```
Sales:
| G1  | Total sales                    | =SUMIFS(Transactions!F:F, Transactions!C:C, "CREDIT") |
| G2  | Export sales                   | =SUMIFS(Transactions!F:F, Transactions!H:H, "G2") |
| G3  | Other GST-free sales           | =SUMIFS(Transactions!F:F, Transactions!H:H, "G3") |
| G4  | Input taxed sales              | =SUMIFS(Transactions!F:F, Transactions!H:H, "G4") |
| G5  | GST-free + input taxed (derived)| =G2+G3+G4 |
| G6  | Taxable sales (derived)        | =G1-G5 |

Purchases:
| G10 | Capital purchases              | =SUMIFS(Transactions!E:E, Transactions!H:H, "G10") |
| G11 | Non-capital purchases          | =SUMIFS(Transactions!E:E, Transactions!H:H, "G11") |
| G12 | Total purchases (derived)      | =G10+G11 |
| G13 | Purchases for input taxed      | =SUMIFS(Transactions!E:E, Transactions!H:H, "G13") |
| G14 | Purchases with no GST          | =SUMIFS(Transactions!E:E, Transactions!H:H, "G14") |
| G15 | Private use purchases          | =SUMIFS(Transactions!E:E, Transactions!H:H, "G15") |
| G16 | Non-creditable (derived)       | =G13+G14+G15 |
| G17 | Creditable purchases (derived) | =G12-G16 |

Tax:
| 1A  | GST on sales                   | =G6/11 |
| 1B  | GST on purchases               | =G17/11 |

Net:
| GST payable / (refundable)      | =1A-1B |
```

### 工作表“Simpler BAS”

对于较简单的 BAS 客户（营业额 < $10M），仅需三个字段：

```
| G1  | Total sales    | =SUMIFS(Transactions!F:F, Transactions!C:C, "CREDIT") |
| 1A  | GST on sales   | =SUM of GST from taxable sales transactions |
| 1B  | GST on purchases | =SUM of GST from creditable purchase transactions |
| Net | GST payable / (refundable) | =1A-1B |
```

### 颜色和格式约定

银行对账单中的硬编码值（Transactions 的 E 列）使用蓝色字体。公式使用黑色字体。跨工作表引用使用绿色字体。Default? = "Y" 的任何行均使用黄色背景。

## 第 8 节——澳大利亚银行对账单阅读指南

**CSV 格式约定。** CBA NetBank 导出文件使用逗号分隔符，日期格式为 DD/MM/YYYY。列通常包括：Date、Amount、Description、Balance。Westpac 的导出格式类似。ANZ 使用 Date、Transaction Details、Debit、Credit、Balance。NAB 与之类似。Revolut 和 Wise 使用 ISO 日期格式。处理前务必确认列映射。

**CBA NetBank 特有事项。** Description 字段通常包含：商户名称、银行卡号后几位、地点。直接扣款带有 "DIRECT DEBIT" 前缀。转账显示 "TRANSFER TO" 或 "TRANSFER FROM"。Pay Anyone 显示收款人姓名。BPAY 显示账单机构名称和参考编号。

**内部转账和排除项。** 客户在 CBA、Westpac 等银行的自有账户之间进行的转账。标记为 "TRANSFER TO [account name]"、"INTERNAL TRANSFER"、"OWN ACCOUNT"。始终排除。

**业主提款。** 个体经营者不能向自己支付工资。任何转入其个人账户的款项均属于提款。从企业账户转入个人账户的款项：从 BAS 中排除。

**退款和冲销。** 通过 "REFUND"、"REVERSAL"、"CHARGEBACK"、"CREDIT ADJUSTMENT" 识别。按照原始交易的相同 BAS 标签记为负数。更正在退款入账的期间内进行。

**外币交易。** 按交易日期的汇率换算为 AUD。使用 RBA 指示性汇率或银行对账单上显示的汇率。在 Transactions 工作表的 L 列中注明所用汇率。

**BSB 和账号。** BSB（6 位数字，格式为 XX-XXXX）用于标识银行和分行。它与 GST 分类没有直接关系，但有助于识别交易对手方的银行。

**对账单上的 ABN。** 某些企业银行对账单会显示客户的 ABN。请验证其是否与 GST 注册信息中的 ABN 一致。

**含义不明的描述。** 包含商户终端代码的银行卡消费；仅包含账单机构代码的 BPAY 付款。如果无法根据描述识别交易对手方，请询问客户。不要对无法识别的交易进行分类。

**PAYG 和 FBT 项目。** 向 ATO 支付的 BAS 款项可能包括 PAYG 预扣税（W2）、PAYG 分期付款（T7）和 FBT 分期付款（F1）。这些属于税款，而非供应。将其排除在 GST 分类之外，但应记录下来以完成 BAS（标签 W1-W5、T1-T9、F1-F3）。

## 第 9 节——客户引导备用流程（仅在推断失败时使用）

首先根据数据推断客户档案。仅询问数据无法回答的问题。

### 9.1 实体类型和经营名称
*推断规则：* 个体经营者的名称与账户持有人一致；公司名称以“Pty Ltd”或“Ltd”结尾。*备选问题：*“您是个体经营者、合伙企业、公司（Pty Ltd），还是信托？”

### 9.2 GST 注册状态
*推断规则：* 如果对方要求办理 BAS，则表示其已注册。如果营业额明显低于 $75,000，则可能是自愿注册。*备选问题：*“您是否已注册 GST？如果是，从什么日期开始注册？”

### 9.3 ABN
*推断规则：* 可能出现在银行对账单的页眉或发票上。搜索交易描述。*备选问题：*“您的 ABN 是什么？（11 位数字）”

### 9.4 申报期间和方式
*推断规则：* 对账单的日期范围可表明对应的季度。*备选问题：*“这是哪个 BAS 期间？Q1（7 月至 9 月）、Q2（10 月至 12 月）、Q3（1 月至 3 月）还是 Q4（4 月至 6 月）？按月还是按季度申报？”

### 9.5 简化 BAS 或完整 BAS
*推断规则：* 如果营业额低于 $10M（个体经营者很可能如此），则默认采用简化 BAS。*备选问题：*“您采用的是简化 BAS（仅 G1、1A、1B），还是申报完整的 BAS 项目？”

### 9.6 会计核算基础
*推断规则：* 无法仅根据银行对账单推断。*备选问题：*“您的 GST 采用收付实现制还是权责发生制？”

### 9.7 行业和业务领域
*推断规则：* 根据交易对手构成和销售描述进行判断。IT、咨询、技工服务、零售和餐饮住宿业可从交易模式中识别。*备选问题：*“请用一句话说明该企业从事什么业务。”

### 9.8 进项税供应
*推断规则：* 存在住宅租金收入、贷款利息收入或金融服务收入。*备选问题：*“您是否从住宅物业、金融服务或股票交易中获得任何收入？”*如果回答是，且金额并非微不足道：可能会触发 R-AU-1 或 R-AU-5。*

### 9.9 员工
*推断规则：* PAYG 预扣税款、养老金保障缴款、WorkCover。*备选问题：*“您是否有员工？如果有，共有多少人？”

### 9.10 出口
*推断规则：* 外币贷记交易、海外交易对手名称。*备选问题：*“您是否向澳大利亚境外的客户销售商品或服务？”

### 处罚

**未按时申报（FTL）：** 对小型实体（营业额低于 $1M），每逾期 28 天处以 1 个罚款单位，最多计算 5 个期间。罚款单位：$330（2024-25，每年指数化调整）。

**一般利息费用（GIC）：** 90 天银行承兑汇票利率加每年 7%。按日计算并复利计息。可在税前扣除。

**少缴税款处罚：** 未尽合理注意义务：25%。鲁莽行为：50%。故意无视规定：75%。在审计前主动披露可减免 20%。

### 与欧盟 VAT 的比较（适用于熟悉欧盟制度的从业者）

| 特征 | 澳大利亚 GST | 欧盟 VAT |
|---|---|---|
| 税率数量 | 1（10%） | 每个成员国 2-4 种 |
| 反向征税触发条件（B2B 跨境交易） | 仅在无法全额抵免时 | 始终适用（第 196 条） |
| 欧盟内部交易制度 | 不适用 | 零税率供应 + 取得 |
| 招待费用抵免 | 遵循 FBT（如已缴纳 FBT，则可抵免） | 通常直接禁止 |
| 机动车抵免 | 允许，但以汽车限额为上限 | 通常禁止（例如马耳他第 10 附表） |
| 金融供应抵免 | 某些服务可按 75%/55% 申领 RITC | 无同等制度 |

### 已知缺口

1. 第 3 节中的供应商模式库涵盖了澳大利亚最常见的交易对手方，但并未覆盖所有本地中小企业或区域性品牌。应在新模式出现时予以补充。
2. 实例基于一家假设的悉尼 IT 咨询公司。它们并未专门涵盖酒店餐饮、零售、建筑或农业行业。
3. GST 免税食品表涵盖了最常见的项目，但《GST 法》附表 1 的规定十分详细——应标记边缘案例（例如特定烘焙食品、健康食品）[T2]。
4. 车辆限额和 LCT 门槛采用 2024-25 年度数值。由于这些数值会进行指数化调整，因此应每年核实。
5. 反向征税部分针对常见情形进行了简化（接收方可全额抵扣，因此不适用反向征税）。对于只能部分抵扣的接收方，需要进行更详细的处理。
6. 文中提到了葡萄酒均衡税和豪华汽车税，但未提供完整实例——这些属于专业领域。
7. 红旗阈值（单笔交易 AUD $5,000、税额差异 $500、绝对金额 $10,000）是针对典型澳大利亚自雇客户设定的保守起始值——尚未经过实证校准。
