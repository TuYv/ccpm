# 文案写作框架

## 概述

使用本技能将泛泛的信息转化为具体、有说服力的文案。让整个工作锚定在一位读者、一个期望行动、可信的证明，以及下一句话上。

## 快速工作流

1. 确认受众、报价、期望行动、渠道、漏斗阶段、品牌语气、证明方面的约束，以及被禁止的宣传表述。如果细节缺失但任务仍可推进，请简要说明所做假设。
2. 确定主要任务：
   - 钩子/标题：锁定一位读者，开启一个好奇心循环，并使用具体的画面或身份指向。
   - 长文案：使用 AIDA 与故事手法；让顾客成为英雄，让产品成为向导。
   - 广告或视频脚本：以打破常规模式开场，在点出产品之前先建立信念，然后让 CTA 显得水到渠成。
   - 文案诊断：诊断注意力、具体性、证明、欲望、异议疑虑以及 CTA 摩擦。
   - 仿写练习：从同一媒介的优秀范例中建立可重复的范例研习流程。
3. 分轮次起草：先让它具体，再让它可信，最后做删减。
4. 将无法证实的表述标记为 `needs proof`，而不是编造数据、客户证言、背书或科学依据。

## 必备检查项

- 让第一行文案使读者愿意读第二行。
- 让标题筛选进或排除掉特定受众。
- 加入证明、具体演示，或明确的证明占位符。
- 制造张力与变化；不要只是罗列事件。
- 在 CTA 之前处理可能出现的异议疑虑。
- 保持句子简洁且富有变化；尽量每句只表达一个要点。
- 只有在张力、证明或欲望仍在累积时，才让文案保持长度。
- 匹配品牌对幽默、锋芒与直白所允许的尺度。

## 输出形式

对于创作类请求，提供按切入角度分组的多个变体。对于诊断类请求，优先给出杠杆效应最大的修改项，再给出修改后的版本。对于策略类请求，展示所选框架及其契合受众、渠道和漏斗阶段的原因。
