可以使用 Remotion 构建应用。  
你可以创建一个简单的表单并将其连接到渲染流程，也可以构建一个复杂的视频编辑器。

## 选择模板或框架

我们提供了多个 SaaS 模板，可供克隆或用作参考。
有关选择模板或框架的帮助，请参阅[选择框架](framework.md)。 

## `<Player>`

此组件用于在 React 应用中嵌入 Remotion 预览。有关 Player 的更多信息，请参阅 [Player](player.md)。

## 渲染

可以选择客户端渲染或服务端渲染。有关如何选择渲染方式以及 Lambda、Vercel、Node.js 和 Cloudflare 选项的建议，请参阅[渲染](rendering.md)。

有关如何将 Remotion 与 Vue 配合使用，请参阅 https://www.remotion.dev/docs/vue.md。

## Angular

有关如何将 Remotion 与 Angular 配合使用，请参阅 https://www.remotion.dev/docs/angular.md。

## Svelte
