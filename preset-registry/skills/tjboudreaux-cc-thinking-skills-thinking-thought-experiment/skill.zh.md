# 思想实验

当实证验证无法企及时，运行一个严谨的反事实推演：单一隔离变更、固定条件、逐步推演机制，以及对推论设定硬边界。

## 何时使用

- 你需要了解系统在故障、规模或策略下的行为，而这些情况无法以低成本触发或测量（区域宕机、100 倍负载、单向架构）。
- 决策代价高昂或不可逆，而一次头脑推演可以在提交前暴露断点。
- 边缘情况的搭建成本过高，但机制链条仍能揭示缺失的控制措施。

## 何时不使用

- 存在低成本的真实测试（负载测试、特性开关、查询、快速试验）→ 运行测试；不要用想象替代。
- 对抗性安全攻击路径工作 → 使用红队结构，而非自由形式的场景推演。
- 你已了解机制，只需在已知事实下做出决策 → 直接决策；不要戏剧化。
- 没有单一隔离变量的、模糊的“要是所有情况都……”式头脑风暴 → 收紧范围或停止。

## 步骤

1. **陈述问题与隔离范围。** 明确指出唯一一个主变量或反事实变更。将其他所有条件冻结为对照世界。拒绝多变量的“以及还有”式场景。
2. **固定初始条件。** 具体说明系统状态、负载、配置、参与者，以及哪些内容*未*被改变。写出的值要足够具体，使另一个智能体能够复现该设置。
3. **逐步推演机制。** 从 t0 起，仅使用已知的组件与策略，记录接下来是什么失败、排队、重试或做出适应——以及为什么。不允许“然后一切都崩溃了”这种含糊其辞的说法；每一步都需要因果关联。
4. **提取不变量与断点。** 记录仍然成立的性质（不变量），以及系统违反某项需求（容量、正确性、安全性、用户体验）的第一步。标记那些一旦为假便使整条链条失效的假设。
5. **限定推论范围。** 仅将洞察映射到由该链条所支撑的行动或检查（限制、防护、监控、重新设计）。将超出隔离范围的投机性跳跃标记为越界。
6. **给出一个具有判别力的真实检查，然后停止。** 针对最薄弱的环节，给出能够证实或证伪它的最低成本观察或实验。在完成一条推论有界的受控链条后即停止；如果某个环节现在就能低成本测试，则转而执行该测试，而非继续想象。

## 输出

输出一份思想实验记录：

- `question`：正在测试的行为或决策
- `isolated_variable`：相对对照世界的单一变更
- `initial_conditions`：冻结的状态与未变更项
- `consequence_chain`：按顺序排列的机制步骤
- `invariants`：仍然成立的性质
- `break_points`：首次需求失效与关键假设
- `implication_bound`：仅由链条支撑的行动/检查
- `discriminating_check`：用于证实或证伪薄弱环节的最低成本真实观察

## 验证

- **隔离检查：** 存在不止一个自由变量且未声明对照 → 无效；重置。
- **机制检查：** 任何步骤若无法与已知组件/策略建立因果关联 → 重写或删除。
- **推论边界：** 未被链条蕴含的建议不在范围之内。
- **实证优先：** 若在分析中途出现了可行的真实测试，停止思想实验并直接测试。
- **过度使用防范：** 不要将此技能用于你能够复现的常规调试，也不要将其作为红队威胁建模的替代品。
- **停止：** 单一隔离的反事实 → 完整链条 → 有边界的推论 + 判别性检查；避免场景蔓延。
