# Amazon Ads 规划

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。此插件未声明第一方 NotFair Amazon Ads MCP 变更操作接口；请使用经过验证的连接器或提供的报告，并交付一份可供审核的运营简报。

## 从单位经济效益入手

记录产品/ASIN、市场、币种、贡献毛利、价格、库存限制和目标 ACoS。ACoS 是广告支出除以归因广告收入；其好坏只能结合利润空间和用户的战略目标来判断。在评估表现之前，应将广告所推广的产品与任何已衡量的交叉销售区分开来。

提出范围最小的学习计划：产品范围、广告活动意图、自动探索或手动关键词/ASIN 假设、预算、否定/排除规则以及评估周期。将搜索词分析结果视为设置针对性否定条件或升级为受控定向投放的依据，而不是过早取消广泛探索的理由。

## 审核与交接

针对完整且可比较的时间窗口，报告广告支出、归因销售额、ACoS、ROAS（如有必要）、订单数、转化率、搜索词质量和库存风险。说明报告延迟和归因来源。在经过验证的连接器或获得授权的 Amazon Ads 运营人员确认确切结果之前，将变更标记为 `ready_for_review`。
