# AgentFolio

**角色**: 自主代理发现指南

当你希望在不同生态系统中**发现、比较和研究**自主 AI 代理时，请使用此技能。  
AgentFolio 是一个位于 `https://agentfolio.io` 的精选目录，跟踪代理框架、产品和工具。

该技能可帮助你：

- 在从头构建之前找到现有代理。
- 绘制代理框架和托管产品的生态全景。
- 为代理能力收集具体示例和基准。

## 能力

- 按使用场景发现自主 AI 代理、框架和工具。
- 按能力、目标用户和集成入口比较代理。
- 识别市场空白，或为新技能/工作流寻找灵感。
- 收集可用于你自己设计的示例代理行为与 UX 模式。
- 跟踪代理架构与部署中的新兴趋势。

## 如何使用 AgentFolio

1. **打开目录**
   - 在浏览器中访问 `https://agentfolio.io`。
   - 可按类别过滤（例如 Dev Tools、Ops、Marketing、Productivity）。

2. **按意图搜索**
   - 从你要解决的问题出发：  
     - “customer support agents”  
     - “autonomous coding agents”  
     - “research / analysis agents”
   - 使用 AgentFolio 的搜索栏中与你领域或工作流匹配的关键词。

3. **评估候选项**
   - 对每个感兴趣的代理进行记录：
     - **核心承诺**（它自动化实现的结果）。
     - **输入 / 输出形态**（API、UI、数据源）。
     - **自治模型**（一次性、多人步骤、工具使用、human-in-the-loop）。
     - **部署模型**（SaaS、self-hosted、browser、IDE 等）。

4. **综合洞察**
   - 使用发现结果来：
     - 决定是集成现有代理还是自行构建。
     - 借鉴成功的 UX 和安全模式。
     - 将你自己的代理技能和工作流相对于生态进行定位。

## 示例工作流

### 1) 构建新代理前的全景扫描

- 定义问题：“autonomous test failure triage for CI pipelines”。
- 使用 AgentFolio 搜索：
  - “testing agent”、“CI agent”、“DevOps assistant”、“incident triage”。
- 针对每个相关代理：
  - 记录支持的平台（GitHub、GitLab、Jenkins 等）。
  - 获取它们如何说明自治性和安全边界。
  - 如果你计划采用而不是自行构建，请记录定价/许可限制。

### 2) 新技能的竞品与灵感研究

- 如果你计划新增一个技能（例如 observability agent、security agent）：
  - 使用 AgentFolio 查找类似代理和功能。
  - 提取 3–5 个你希望借鉴或避免的具体模式。
  - 将这些模式转化为你自身技能的清晰需求。

### 3) 供应商筛选

- 在多个代理供应商之间做选择时：
  - 使用 AgentFolio 条目作为中立目录。
  - 构建对比表（列：capabilities、integrations、pricing、trust & security）。
  - 用该表驱动更正式的评估或概念验证。

## 示例提示词

在 AI 编码代理中使用此技能时，可使用这些提示词：

- “Use AgentFolio to find 3 autonomous AI agents focused on code review. For each, summarize the core value prop, supported languages, and how they integrate into developer workflows.”
- “Scan AgentFolio for agents that help with customer support triage. List the top options, their target customer size (SMB vs. enterprise), and any notable UX patterns.”
- “Before we build our own research assistant, use AgentFolio to map existing research / analysis agents and highlight gaps we could fill.”

## 何时使用
该技能适用于你需要**发现或比较自主 AI 代理**而不是盲目从零构建的场景：

- 在新的代理或工作流项目启动阶段。
- 在评估要集成的供应商或工具时。
- 当你希望从现有代理产品中获取灵感或最佳实践时。

## 局限性
- 仅在任务明确匹配上述范围时使用该技能。
- 不要将输出替代环境特定的验证、测试或专家审查。
- 如果缺少必需输入、权限、安全边界或成功标准，请停止并请求澄清。
