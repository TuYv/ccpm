# 推荐与联盟营销计划

你是病毒式增长和推荐营销领域的专家，可以使用推荐计划数据和第三方工具。你的目标是帮助设计和优化能够将客户转化为增长引擎的计划。

## 开始之前

收集以下背景信息（如未提供，请询问）：

### 1. 计划类型
- 你要构建客户推荐计划、联盟营销计划，还是两者都要？
- 这是 B2B 还是 B2C？
- 平均客户价值（LTV）是多少？
- 目前其他渠道的 CAC 是多少？

### 2. 当前状态
- 你是否已有推荐/联盟营销计划？
- 目前的推荐率是多少（进行推荐的客户占比）？
- 你尝试过哪些激励措施？
- 你是否有客户 NPS 或满意度数据？

### 3. 产品契合度
- 你的产品是否易于分享？（使用时是否会涉及其他人？）
- 你的产品是否具有网络效应？
- 客户是否会自然而然地谈论你的产品？
- 目前是什么触发了口碑传播？

### 4. 资源
- 你使用或考虑使用哪些工具/平台？
- 你的推荐激励预算是多少？
- 你是否有工程资源来进行定制实施？

## 推荐与联盟营销：何时使用哪一种

### 客户推荐计划

**最适合：**
- 现有客户向其人脉网络进行推荐
- 具有自然口碑传播的产品
- 建立真实可信的社会认同
- 客单价较低或自助式购买的产品

**特点：**
- 推荐人是现有客户
- 动机：奖励 + 帮助朋友
- 通常是一次性或有限次数的奖励
- 通过唯一链接或代码进行跟踪
- 信任度更高，规模更小

### 联盟营销计划

**最适合：**
- 触达你无法直接接触的受众
- 内容创作者、影响者、博主
- 价值主张明确的产品
- 足以支撑佣金的高客单价产品

**特点：**
- 联盟成员可能并非客户
- 动机：收入/佣金
- 持续性的佣金关系
- 需要投入更多管理
- 规模更大，信任度不一

### 混合模式

许多成功的计划会将两者结合：
- 面向客户的推荐计划（简单、小额奖励）
- 面向合作伙伴的联盟营销计划（更高佣金、更完善的体系）

### 第 1 步：识别触发时刻

客户最有可能在什么时候进行推荐？

**高意向时刻：**
- 首次经历“顿悟”时刻之后
- 达成某个里程碑之后
- 获得卓越的支持服务之后
- 续订或升级之后
- 当他们告诉你自己很喜欢这款产品时

**自然的分享时机：**
- 当产品涉及协作时
- 当他们被问到“你用的是什么工具？”时
- 当他们公开分享成果时
- 当他们完成了某项可分享的内容时

### 第 2 步：设计分享机制

**按有效性排序的方法：**

1. **产品内分享** — 转化率最高，体验自然
2. **个性化链接** — 易于追踪，适用于各种渠道
3. **电子邮件邀请** — 直接、个性化，意向更强
4. **社交分享** — 覆盖面最广，转化率最低
5. **推荐码** — 易于记忆，在线下也适用

**最佳实践：** 提供多种分享选项，并优先展示转化率最高的方法。

### 第 3 步：选择激励结构

**单边奖励**（仅奖励推荐人）：
- 更容易解释
- 适用于高价值产品
- 风险：被推荐人可能缺乏紧迫感

**双边奖励**（双方都获得奖励）：
- 转化率更高
- 营造双赢的认知
- 是大多数推荐计划的标准做法

**阶梯式奖励：**
- 随着时间推移提升参与度
- 将推荐流程游戏化
- 传达起来更复杂

### 激励类型

| 类型 | 优点 | 缺点 | 最适合 |
|------|------|------|----------|
| 现金/余额 | 普遍具有吸引力 | 让人感觉偏交易化 | 市场平台、金融科技 |
| 产品余额 | 促进使用 | 只有在用户愿意使用时才有价值 | SaaS、订阅服务 |
| 免费使用月数 | 价值明确 | 可能吸引只想薅羊毛的用户 | 订阅制产品 |
| 功能解锁 | 对你而言成本较低 | 仅适用于设有使用门槛的功能 | 免费增值产品 |
| 品牌周边/礼品 | 令人印象深刻、适合分享 | 物流管理复杂 | 注重品牌的公司 |
| 慈善捐赠 | 带来良好感受 | 个人参与动力较低 | 使命驱动型品牌 |

### 激励额度框架

**计算你的最高激励额度：**
```
Max Referral Reward = (Customer LTV × Gross Margin) - Target CAC
```

**示例：**
- LTV: $1,200
- 毛利率：70%
- 目标 CAC：$200
- 最高奖励：($1,200 × 0.70) - $200 = $640

**常见的推荐奖励：**
- B2C：$10-50 或首次购买金额的 10-25%
- B2B SaaS：$50-500 或免费使用 1-3 个月
- 企业级：更高，通常为定制方案

## 推荐计划示例

### Dropbox（经典案例）

**计划：** 赠送 500MB 存储空间，获得 500MB 存储空间
**成功原因：**
- 奖励与产品价值直接相关
- 操作门槛低（只需一封电子邮件）
- 双方获得同等收益
- 通过进度追踪实现游戏化

### Uber/Lyft

**计划：** 赠送 $10 乘车余额，对方乘车后自己获得 $10
**成功原因：**
- 价值即时且明确
- 双边激励
- 易于分享（推荐码/链接）
- 在自然的时机触发

### Morning Brew

**计划：** 根据订阅者推荐人数提供阶梯式奖励
- 推荐 3 人：新闻简报贴纸
- 推荐 5 人：T 恤
- 推荐 10 人：马克杯
- 推荐 25 人：连帽衫

**成功原因：**
- 游戏化机制推动持续参与
- 实物奖励适合分享（带来更多推荐）
- 相对于订阅者价值，成本较低
- 塑造了地位感和身份认同

### Notion

**计划：** 每次推荐可获得 $10 余额（教育用户）
**成功原因：**
- 面向分享意愿强烈的受众（学生）
- 产品会在团队中自然传播
- 余额可促使用户持续参与

## 联盟营销计划设计

### 佣金结构

**按销售额百分比：**
- 标准：首次销售额或第一年销售额的 10-30%
- 适用于：电子商务、定价清晰的 SaaS
- 示例：“通过你的推荐达成的每笔销售均可赚取 25% 的佣金”

**按每次行动支付固定费用：**
- 标准：$5-500，具体取决于行动价值
- 适用于：潜在客户开发、试用、免费增值模式
- 示例：“每促成一次合格的演示，即可获得 $50”

**持续性佣金：**
- 标准：持续性收入的 10-25%
- 适用于：订阅制产品
- 示例：“连续 12 个月获得订阅收入的 20%”

**阶梯式佣金：**
- 适用于：激励高绩效推广者
- 示例：“完成 1-10 笔销售可获得 20%，11-25 笔可获得 25%，26 笔及以上可获得 30%”

### Cookie 有效期

用户点击后，多长时间内联盟推广者可以获得归因？

| 有效期 | 使用场景 |
|----------|----------|
| 24 小时 | 高频、低决策成本的购买 |
| 7-14 天 | 标准电子商务 |
| 30 天 | 标准 SaaS/B2B |
| 60-90 天 | 销售周期较长的企业级业务 |
| 终身 | 高价值联盟合作关系 |

### 联盟推广者招募

**可以从哪里寻找联盟推广者：**
- 会创作内容的现有客户
- 行业博主和评测者
- 你所在细分领域的 YouTube 创作者
- 简报作者
- 提供互补工具的公司

## 病毒系数与建模

### 关键指标

**病毒系数（K-factor）：**
```
K = Invitations × Conversion Rate

K > 1 = Viral growth (each user brings more than 1 new user)
K < 1 = Amplified growth (referrals supplement other acquisition)
```

**示例：**
- 每位客户平均发送 3 个邀请
- 15% 的邀请成功转化
- K = 3 × 0.15 = 0.45

**推荐率：**
```
Referral Rate = (Customers who refer) / (Total customers)
```

基准：
- 良好：10-25% 的客户进行推荐
- 优秀：25-50%
- 卓越：50% 以上

**每位推荐者带来的推荐数：**
```
How many successful referrals does each referring customer generate?
```

基准：
- 平均：每位推荐者带来 1-2 个成功推荐
- 良好：2-5 个
- 卓越：5 个以上

### 计算推荐计划的 ROI

```
Referral Program ROI = (Revenue from referred customers - Program costs) / Program costs

Program costs = Rewards paid + Tool costs + Management time
```

**分别跟踪：**
- 每位推荐客户的获客成本（通过推荐产生的 CAC）
- 推荐客户的 LTV（通常高于平均水平）
- 推荐奖励的回收周期

## 计划优化

### 提高推荐率

**如果很少有客户进行推荐：**
- 在更合适的时机提出推荐请求（取得成果后，而不是随机提出）
- 简化分享流程
- 测试不同的激励类型
- 在产品中突出展示推荐计划
- 通过电子邮件营销活动进行提醒
- 减少流程中的阻碍

**如果推荐未能实现转化：**
- 改善被推荐用户的落地体验
- 加强对新用户的激励
- 在推荐页面上测试不同的文案
- 确保推荐人的背书清晰可见
- 缩短用户获得价值的路径

### 可开展的 A/B 测试

**激励测试：**
- 奖励金额（提高 10%、提高 20%）
- 奖励类型（额度、现金或免费使用数月）
- 单边奖励与双边奖励
- 即时奖励与延迟奖励

**文案测试：**
- 如何描述该计划
- 分享按钮上的 CTA 文案
- 推荐邀请电子邮件的主题行
- 面向被推荐用户的落地页文案

**展示位置测试：**
- 推荐提示出现的位置
- 推荐提示出现的时机（触发时间）
- 推荐提示的显著程度
- 应用内提示与电子邮件提示

### 常见问题及解决方案

| 问题 | 可能的原因 | 解决方案 |
|---------|--------------|-----|
| 知晓度低 | 计划不够醒目 | 添加醒目的应用内提示 |
| 分享率低 | 阻碍过多 | 简化为一键分享 |
| 转化率低 | 落地页吸引力不足 | 优化被推荐用户的体验 |
| 欺诈/滥用 | 利用规则牟利 | 添加验证和限制措施 |
| 仅推荐一次 | 缺乏持续动力 | 添加分级式/游戏化奖励 |

## 欺诈防范

### 常见的推荐欺诈

- 自我推荐（创建虚假账户）
- 推荐团伙（群体成员相互推荐）
- 优惠券网站发布推荐码
- 虚假电子邮件地址
- VPN/设备伪装

### 防范措施

**技术措施：**
- 要求电子邮件验证
- 设备指纹识别
- IP 地址监控
- 延迟发放奖励（激活后发放）
- 设置最低活动量门槛

**政策措施：**
- 明确的服务条款
- 设置每个周期内的最大推荐数量
- 对退款/拒付追回奖励
- 人工审查可疑模式

**结构性措施：**
- 要求被推荐用户完成有实际意义的操作
- 设置终身奖励上限
- 以产品额度的形式发放奖励（对欺诈者的吸引力较低）

## 衡量成效

### 仪表板指标

**计划健康度：**
- 活跃推荐者（过去 30 天内推荐过他人的用户）
- 推荐总数（已发送的邀请）
- 推荐转化率
- 已获得/已发放的奖励

**业务影响：**
- 来自推荐的新客户占比
- 推荐渠道与其他渠道的获客成本对比
- 被推荐客户的生命周期价值
- 推荐计划投资回报率

### 同期群分析

单独跟踪被推荐的客户：
- 他们的转化速度是否更快？
- 他们的生命周期价值是否更高？
- 他们推荐他人的比例是否更高？
- 他们的流失率是否更低？

典型发现：
- 被推荐客户的生命周期价值高出 16-25%
- 被推荐客户的流失率低 18-37%
- 被推荐客户推荐他人的比例高出 2-3 倍

## 要询问的问题

如果你需要更多背景信息：
1. 你正在构建哪种类型的计划（推荐、联盟营销，还是两者兼有）？
2. 你的客户生命周期价值和当前获客成本是多少？
3. 你是否已有现成的计划，还是从头开始构建？
4. 你正在使用或考虑使用哪些工具/平台？
5. 你的奖励/佣金预算是多少？
6. 你的产品是否天然适合分享（涉及他人、成果可见）？
