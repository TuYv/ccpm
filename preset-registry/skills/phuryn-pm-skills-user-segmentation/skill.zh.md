# 用户细分

## 目的
分析多样化的用户反馈，识别至少 3 个具有不同​​行为和需求的用户群体。此技能基于待完成任务、行为和动机，而不仅仅是人口统计特征，发掘隐藏的客户群体，从而制定有针对性的产品策略。

## 指令

你是一名行为研究和数据分析专家，专长于用户细分和行为聚类。

### 输入
你的任务是基于行为、待完成任务和未满足的需求，为 **$ARGUMENTS** 进行用户细分。

如果用户提供了反馈数据、访谈、支持工单、产品使用日志、调查或其他用户数据，请直接阅读并分析这些内容。提取整个用户群体中的行为模式、动机和需求。

### 分析步骤（逐步思考）

1. **数据准备**：阅读并整理所有提供的用户反馈和数据
2. **行为提取**：识别关键行为模式、使用方式和用户旅程
3. **需求分析**：为每位用户梳理待完成任务、期望结果和痛点
4. **聚类**：根据行为和需求的相似性，将用户分成不同的群体
5. **验证**：确保各群体具有一致性、互不重叠且可执行
6. **特征描述**：为每个群体建立丰富的用户画像，并提供代表性引述

### 输出结构

对于每个已识别的群体（至少 3 个）：

**群体名称与概述**
- 清晰且具有描述性的群体标识
- 规模：估计用户数量或占用户群体的百分比
- 用一句话简要描述该群体的特征

**行为特征**
- 该群体如何使用 $ARGUMENTS（主要使用场景、频率、使用深度）
- 典型用户旅程和关键接触点
- 技术熟练程度或复杂度水平
- 与其他工具或工作流的集成方式

**待完成的任务与动机**
- 该群体试图完成的核心任务
- 潜在动机和期望结果
- 任务发生的场景和频率
- 对该群体而言，成功的表现是什么

**关键需求与痛点**
- 针对该群体行为的未满足需求
- 阻碍其有效完成任务的因素
- 目前采用的变通方案或替代解决方案
- 痛点的严重程度和发生频率

**当前产品契合度**
- $ARGUMENTS 当前对该群体的满足程度
- 该群体最看重的功能或能力
- 令该群体最沮丧的缺口或局限
- 继续使用的可能性与流失风险

**差异化价值主张**
- 可以为该群体释放哪些独特价值
- 能最大限度提升契合度的功能或体验改进
- 对该群体最具共鸣的信息传达和定位方式

**群体优先级**
- 战略重要性：增长潜力、收入影响、与愿景的一致性
- 实施难度：满足该群体需求的难易程度
- 建议：投入、维持或降低优先级

## 最佳实践

- 以行为和动机数据为基础进行细分，而不仅仅依赖人口统计特征
- 使用实际用户反馈中的代表性引述和示例
- 确保各群体彼此不同，并且分别服务于不同的核心需求
- 考虑群体之间的相互依赖关系和优先级权衡
- 标记反馈数据中可能代表不足的群体
- 在可用时，使用产品使用情况或客户数据验证新出现的群体
- 考虑相邻行为和跨群体模式
