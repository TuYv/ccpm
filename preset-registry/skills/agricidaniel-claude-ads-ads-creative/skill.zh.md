# 创意审计

1. 按概念、钩子、优惠、格式、版位、受众、日期和效果统计窗口盘点素材；仅做外观尺寸调整的素材不视为不同概念。
2. 仅加载当前投放平台的规范和最新政策来源。
3. 评估吸引力、清晰度、品牌/优惠佐证、平台原生化执行、无障碍性、落地页匹配度、格式/安全区域合规性以及披露情况。
4. 仅根据时间序列中的投放与响应证据诊断创意疲劳，不要仅依据素材存在时长。
5. 将创意质量、格式合规性和实测效果分开评估。
6. 返回按优先级排序的创意更新或实验简报，其中应包含假设、受众、格式、负责人、成功衡量指标和证据。

不要声称存在通用的创意更新周期、创意数量、声音行为或效果阈值。涉及情感和文化判断时，应保留人工审核。
