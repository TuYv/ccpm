# 认知：注意力

注意力是最稀缺的认知资源——而且与记忆力或推理能力不同，它无法通过训练变得不受限制。我们只能分配、保护和捍卫它。大多数专注力问题并非性格缺陷，而是设计缺陷。环境、工作流程或沟通系统的结构会系统性地分散注意力，使人无法持续投入到最重要的事情上。

注意力经济这一框架源自威廉·詹姆斯关于自主注意与非自主注意的奠基性研究，它将专注力视为一种受供求关系影响的资源。吸引注意力的因素并非随机：显著性（明亮、响亮、移动的事物）、新奇性（新出现或出乎意料的事物）、情绪冲击力（威胁、社会信号、强烈情感）以及个人相关性，都会稳定地压倒有意识的专注。设计注意力环境时，要清楚它所面对的竞争因素。

关键区别在于：注意力威胁有两种形式。**攫取**——通过感官或情绪诱因不由自主地夺走注意力的事物；以及**耗竭**——即使没有任何一次中断特别剧烈，也会逐渐消耗持续专注能力的事物。两者都很重要。攫取是可见且急性的；耗竭则缓慢、累积，而且往往难以察觉，直到认知能力被消耗殆尽。

## 你的流程

**步骤 1：定义注意力情境**
明确是谁的注意力、处于什么情境、为了什么目的。个人专注（试图开展深度工作的个人）？群体注意力（团队、会议）？沟通注意力（你需要持续吸引的受众）？不同情境需要不同的诊断。

**框架核对：**继续之前，确认具体的注意力情境。用一句话说明你所识别的内容——是谁的注意力、处于什么场景，以及目标是什么——然后使用 `AskUserQuestion`：
- **Question:** “我的理解是：[用一句话概括所涉及的是谁的注意力、处于什么情境，以及你试图实现什么目标]。对吗？”
- **Header:** “情境框架”
- **Options:**
  - **是——继续**——情境框架正确
  - **调整**——有一个要素不准确；用户将在你继续之前予以更正
  - **重新界定**——实际情况与你的理解不同；继续之前先纳入更正内容

**步骤 2：梳理注意力需求**
列出在此情境中当前争夺注意力的所有事物。将其分为：
- **合理需求：**确实需要注意力，并且有正当理由占用时间的事物
- **攫取威胁：**不由自主地劫持注意力的因素——通知、打断、环境噪声、社会信号
- **耗竭来源：**持续造成轻度认知消耗的因素——隐隐的担忧、尚未解决的决策、引发背景焦虑的低优先级任务、决策疲劳

**步骤 3：评估当前分配情况**
注意力实际投向了哪里，而它本应投向哪里？估算每个类别所消耗的认知带宽比例。找出实际分配与理想分配之间的差距。

**缩小范围之前：**在着手提出解决方案之前，使用 `AskUserQuestion` 确认需求图谱：
- **Question:** “我已将 [N] 项注意力需求归入合理需求、攫取威胁和耗竭来源三类。在确定防御措施的优先级之前，是否有我遗漏的来源，或者是否有你认为特别重要的来源？”
- **Header:** “需求图谱”
- **Options:**
  - **继续**——图谱看起来完整
  - **添加一项需求**——用户将指出要纳入的具体来源
  - **更正类别**——用户将重新归类某项内容

**步骤 4：诊断核心问题**
主要的失败模式是什么？选择最占主导地位的一项：
- **环境设计失败：** 物理或数字环境的结构使干扰最大化
- **边界失效：** 合理需求没有受到排期保护；所有事情都在实时争夺注意力
- **损耗螺旋：** 低水平的认知负荷不断累积，以至于持续集中注意力变得不可能
- **捕获脆弱性：** 特定的高显著性威胁（通知、社交媒体、电子邮件）正在绕过有意识的意图

**步骤 5：设计防御措施**
针对识别出的每项威胁，制定具体的结构性干预措施。防御措施分为四种类型：
- **消除：** 彻底移除该需求（取消订阅、关闭、删除）
- **批处理：** 在指定时间窗口内处理该需求，而不是随时响应（每天处理两次电子邮件、中午处理消息）
- **保护：** 创造使捕获威胁无法触及的结构性条件（将手机放在另一个房间、关闭通知、关门）
- **卸载：** 将未闭环事项和未解决项目记录在可信的外部系统中，以防止后台焦虑造成损耗（任务清单、决策日志）

## 说明

注意力管理并非意志力管理。建议某人“再专注一点”，在认知层面等同于建议某人“再健康一点”。真正的杠杆在于设计环境和工作流程，而不是强化决心以对抗一个充满敌意的系统。此技能应产生结构性、可执行的改变，而不是劝诫。

最接近的相邻技能是 `/s4h-cognition-cognitive-load`——它处理的是专注时段内的工作记忆容量。注意力是入口问题（你究竟能否持续投入？）；认知负荷是容量问题（一旦投入，你能否承载所需的复杂度？）。两者往往都需要同时处理。

对于传播设计场景——保持受众的注意力——请与 `/s4h-communication-audience-modeling` 配合使用。
