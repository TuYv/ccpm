# Amazon Ads 规划

阅读 `../shared/operating-contract.md` 和 `../shared/measurement-framework.md`。此插件未声明第一方 NotFair Amazon Ads MCP 变更操作接口；请使用经过验证的连接器或提供的报告，并交付一份可供审核的操作简报。

## 从单位经济效益开始

记录产品/ASIN、商城、币种、贡献毛利率、价格、库存约束和目标 ACoS。ACoS 是广告支出除以归因广告收入；其表现好坏只能结合利润率和用户的战略目标来判断。在评估效果之前，将广告产品与所有纳入衡量的交叉销售区分开来。

提出范围最小的学习计划：产品范围、广告活动意图、自动探索或手动关键词/ASIN 假设、预算、否定/排除规则以及审核周期。应将搜索词发现视为实施定向否定或将其提升为受控定向投放的依据，而不是过早移除广泛探索的理由。

## 审核与交接

针对完整且可比的时间窗口，报告广告支出、归因销售额、ACoS、ROAS（如有用）、订单量、转化率、搜索词质量和库存风险。说明报告延迟和归因来源。在经过验证的连接器或获得授权的 Amazon Ads 操作人员确认确切结果之前，将变更标记为 `ready_for_review`。
