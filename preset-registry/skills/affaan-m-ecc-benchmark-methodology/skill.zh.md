# 基准评估方法

使用此技能可将范围明确的竞争对手集合转化为**可比较、可辩护的评分**。所有竞争对手均按照相同的九个维度进行评估，采用明确的 1–5 分评分标准，然后记录在统一的档案卡中。关键在于一致性：只有当同样的证据用于任何竞争对手时都能得到同样的分数，评分才有意义。

## 何时启用

- 已有来自 competitive-platform-analysis、范围明确且分层的竞争对手集合可供评分。
- 需要对竞争对手进行可比较、有证据支撑的评分，而非凭直觉排名。
- 已确定客户的战略张力（用于界定其目标空白市场的成对坐标轴）。
- 准备生成档案卡，以便在 competitive-report-structure 中进行组装。

## 客户定位简报（须先确定）

评分前，先确定客户的定位简报。它包括：

- **战略张力** — 两个坐标轴（例如，易记忆性 × 易雇用性），其交点标志着客户的目标空白市场。维度 9 始终是客户指定的张力；分别报告两极，绝不取平均值。
- **差异化优势** — 构成客户护城河的要素。这决定了哪些维度对客户的定位论证最为重要。
- **品牌平衡** — 不同战略侧重点的预期组合。战略建议不得打破这种平衡，除非明确指出。

## 为何选择这些维度

客户的竞争优势源于**在两极之间维持特定张力**，而非服务范围的广度。各维度的权重旨在反映这一护城河。其中两个维度——张力的两极——需要**分别评分，绝不合并取平均值**，因为客户的战略问题恰恰在于竞争对手能否同时兼顾二者。

## 九个维度（含权重）

权重用于指导综合分析时的侧重点，而非计算单一的综合评分（避免产生虚假的综合指标——参见偏差控制）。总计 = 100%。

1. **定位清晰度与独特性** (18%) — 工作室的定位是否鲜明、可占据且一目了然？还是流于泛化？
2. **品牌语调 / 语言独特性** (15%) — 文案是否具有可占据的独特风格，还是可被其他代理商话术轻易替换？
3. **视觉识别与网站工艺** (15%) — 视觉系统的质量与独有性；网站能否作为工艺能力的证明。
4. **服务方案与产品包装** (12%) — 是否产品化且清晰易懂（命名明确的冲刺项目/审计服务），还是含糊不清。产品包装的成熟度。
5. **证据与可信度** (12%) — 具名客户、量化成果、案例研究深度。是否提供超越主张本身的证明。
6. **企业级服务能力 / 商业成熟度** (10%) — 是否释放出能够赢得并维系 SaaS/fintech/B2B/enterprise 项目的信号（流程、客户标识、规模、合同）。
7. **思想领导力 / 内容影响力** (8%) — 自有观点：文章、演讲、新闻简报、框架。重深度而非数量。
8. **定价透明度与合作模式** (5%) — 定价/合作方式是否清晰易懂？产品化、定制化，还是不透明。
9. **[客户的战略张力]**（5%，作为标记；**对两极分别评分并分别报告**）— 从客户的定位简报中读取张力名称和坐标轴描述。分别标绘两极；两者之间的差距正是洞察所在。客户的目标象限是最重要的单项发现：还有谁已经身处其中？

## 评分标准（1–5 分，适用于维度 1–8）

每个分数都必须以可观察的证据为依据。以下是通用描述；可根据具体维度调整细节，但各等级的含义须保持一致。

- **1 — 缺失 / 泛泛而谈。** 看不出明确立场或专业功力；与模板毫无区别。反而构成明显劣势。
- **2 — 低于水准。** 有一定意图，但表现不一致、缺乏原创性或说服力。经不起并列比较。
- **3 — 合格 / 基本门槛。** 扎实、专业，但平淡无奇。符合预期，却不具备任何一方可独占的特色。
- **4 — 强大 / 鲜明。** 明显优于同类；是真正的优势，买方会注意到并主动提及。
- **5 — 定义品类。** 行业最佳，具有独占性且难以模仿。树立了其他竞争者必须回应的标杆。

### 张力轴（维度 9）— 每项按 1–5 分评分

从客户的定位简报中读取各轴标签及其 1/3/5 分锚点。以下是记忆度 × 可信度张力的锚点示例：

- **记忆度** — 1：转瞬即忘 · 3：在特定语境中可识别 ·
  5：令人过目不忘、引发讨论，并形成鲜明的专属认知。
- **可信度** — 1：显得有风险/不专业 · 3：稳妥、合格，
  但缺乏亮点 · 5：获得企业级客户信赖，是显而易见的稳妥选择。

将竞争对手标绘在张力 2×2 矩阵中。客户的目标象限已在定位简报中指定。还有谁位于该象限，是本次基准分析中最重要的单项发现。

## 如何收集数据

针对每个竞争对手，按以下顺序分析各维度（从成本最低的信号开始）：

1. **竞争对手自己的官网** — 定位、语调、服务包装、定价姿态、具名客户、宣言/观点。截取首页及一个案例研究的屏幕截图。
2. **案例研究 / 作品** — 证据深度、量化结果、客户名称。区分*声称的*（“我们交付了 X”）与*已证实的*（有指标、已具名、可验证）。
3. **评价目录** — 交叉验证客户、项目规模、合作模式
   → 可信度与企业级服务能力（例如 Clutch.co 或相应垂直领域的同类平台）。
4. **LinkedIn** — 团队规模/模式、创始人叙事、内容发布频率 →
   思想领导力、模式。
5. **作品集 / 专业展示平台** — 专业技艺水准（使用相应垂直领域原生的展示形式：设计作品板、作品集锦、已发表样稿等）。
6. **内容渠道** — 新闻通讯/演讲/文章 → 思想领导力深度。

**每个维度需要记录的内容：** 分数、一行理由，以及支撑该分数的来源链接/屏幕截图。没有证据就不得评分。

## 偏差控制

- **不设单一综合分数。** 分别报告各维度分数和张力图。加权平均会掩盖真正重要的不对称性。
- **声称的与已证实的。** 对没有交叉佐证的自述性声明，应下调其可信度/证据分数。网站文案是营销内容，不是事实。
- **审美偏好偏差。** 评审者可能会高估与自己审美一致的工作室，并低估竞争对手的商业实力。应独立评估专业技艺和可信度；一个“乏味”的网站也可能正在赢得更大的客户。
- **新近性 / 炫目性偏差。** 获奖的展示型作品令人惊艳，但可能缺乏商业深度——在评估可信度前，应通过目录/客户信息进行验证。
- **幸存者偏差。** 那些曝光度高、擅长营销的工作室并不代表整个市场；应记录通过目录/评价发现的实力强劲但行事低调的服务商。
- **在整个集合中校准，而不是孤立评估。** 最终确定前，应并列复核所有分数——对于每个竞争对手，“4 分”必须代表相同含义。调整异常值。

## 竞品画像卡片（输出格式）

为每个已分析的竞品制作一张卡片——这是报告组装时使用的最小单元：

```
## <Competitor name>
- **Profile / Tier:** <positioning stance · specialization · size band> / <Direct | Adjacent | Aspirational>
- **One-liner:** <how they position themselves, in their words>
- **Model / size / geography:** <solo|micro|boutique> · <region> · <pricing/engagement model>
- **Notable clients / evidence:** <named, with proven/asserted tag>

### Dimension scores
| Dimension | Score (1–5) | Justification (1 line) | Source |
|---|---|---|---|
| Positioning clarity & distinctiveness | | | |
| Brand voice / verbal distinctiveness | | | |
| Visual identity & site craft | | | |
| Service offer & packaging | | | |
| Evidence & credibility | | | |
| Enterprise-readiness / commercial maturity | | | |
| Thought leadership / content presence | | | |
| Pricing transparency & engagement model | | | |

### Tension plot
- **[Axis 1 from positioning brief]:** <1–5> — <why>
- **[Axis 2 from positioning brief]:** <1–5> — <why>
- **Quadrant:** <high/high | high-1/low-2 | low-1/high-2 | low/low>

### Read for [client]
- **Strength to learn from:** <…>
- **Weakness to exploit / white-space it exposes:** <…>
- **Threat to [client]:** <…>
```

将填写完成的卡片及张力图交给 `competitive-report-structure`。

## 反模式

- **对张力轴取平均值。** 必须分别对客户战略张力的两个极点进行评分和报告。取平均值会破坏洞察——两极之间的差距才是关键发现。
- **在没有证据的情况下评分。** 每个评分都需要一行理由和一个来源链接。没有证据的评分只是观点，而非基准。
- **创建单一综合评分。** 分别报告各维度的评分。加权平均值会掩盖对定位至关重要的非对称优势。
- **直接应用通用评分标准而不进行调整。** 必须根据具体维度和竞品集合校准 1–5 分的评分标准。通用描述只是起点，而非固定标准。
- **在确定竞品集合范围之前就开始执行。** 首先使用 `competitive-platform-analysis` 生成经过分层和精简的竞品集合。对未经范围界定的列表进行评分，会把精力浪费在无关竞品上。

## 相关技能

- `competitive-platform-analysis` — 前置技能；生成供本技能评分的分层竞品集合。
- `competitive-report-structure` — 下一步；将已评分的画像卡片组装为可交付给客户的报告。
