# 文化架构师

文化取决于你做了什么，而不是你说了什么。本技能将文化构建为一套运营系统——包含可观察的行为、可衡量的健康度，以及能够从 5 人扩展到 500 人的仪式。

## 关键词

文化、公司文化、价值观、使命、愿景、文化准则、文化仪式、文化健康度、价值观到行为、创始人文化、文化债务、价值观漂绿、文化评估、文化调查、心理安全、文化规模化、敬业度、eNPS、远程文化、混合办公文化、文化冲突、雇主品牌、入职文化、绩效文化、认可

---

## 核心原则

**文化 =（你奖励什么）+（你容忍什么）+（你颂扬什么）**

如果你的价值观声称“透明”，但你却惩罚坏消息的传递者，那么你真正的价值观就是“表面形象”。文化不是愿景式的，而是描述性的。文化建设的工作，就是弥合所宣称的文化与实际文化之间的差距。

## 首先澄清

在生成内容之前，请确认以下输入。如果任何一项未知或含糊，请询问——不要假设：

- [ ] **需要哪种交付成果**（价值观 + 行为、文化准则、健康度调查、仪式日历、文化债务审计或 M&A 整合）——每种成果都有自己的模板
- [ ] **公司阶段和员工人数**——适用于 15 人团队的仪式和传递机制，到 150 人时就会失效；仪式矩阵按公司阶段划分
- [ ] **目前实际奖励、容忍和颂扬的是什么**——文化是描述性的，而不是愿景式的；如果不了解真实的现状，你产出的只会是贴在墙上的陈词滥调
- [ ] **工作模式**（现场办公、远程办公、混合办公）——这决定了适用哪些运营原则和会议规则

停止规则：只询问对输出影响最大的 2–3 个问题。如果用户说“直接起草即可”，则继续执行，并在交付成果顶部列出你的假设。

## 文化诊断决策树

```
START: "How is our culture?"
  |
  v
[Run the Values Audit]
  Ask: "What did the last person who got promoted demonstrate?"
  |
  +-- Answer matches stated values --> Values are real. Check transmission.
  |     |
  |     v
  |   [Can a 30-day employee describe the culture accurately?]
  |     +-- YES --> Culture is operational. Maintain and evolve.
  |     +-- NO  --> Transmission gap. Fix onboarding and rituals.
  |
  +-- Answer differs from stated values --> Values are performative.
        |
        v
      [Do leaders model the real (non-stated) values?]
        +-- YES --> Rewrite values to match reality, then iterate.
        +-- NO  --> Deeper problem: no coherent culture exists. Build from scratch.
```

## 框架 1：使命 / 愿景 / 价值观工作坊

### 使命（我们为何存在）

| 要素 | 检验标准 | 示例 |
|---------|------|---------|
| 使用现在时 | 它描述的是我们现在所做的事，而不是我们渴望做的事吗？ | “我们减少老年照护中本可避免的跌倒事件” |
| 具体 | 竞争对手能否提出完全相同的主张？如果可以，就过于宽泛。 | 不要使用“我们让世界变得更美好” |
| 有意义 | 如果我们消失了，是否会失去某些东西？ | 答案必须具体 |

### 愿景（成功是什么样子）

| 质量标准 | 不好 | 好 |
|---------|-----|------|
| 具体性 | “成为市场领导者” | “到 2030 年，欧洲的每家护理院都使用我们的系统” |
| 可证伪性 | “变革医疗保健行业” | “将合作机构中与跌倒相关的伤害减少 50%” |
| 时间线 | 没有日期 | 设定 5～10 年的时间跨度及里程碑 |

### 价值观（我们实际如何行事）

| 规则 | 说明 |
|------|-------------|
| 最多 3～5 条价值观 | 超过 5 条，就没有一条能让人记住 |
| 从观察中提炼 | “我们最优秀的新员工做了什么没人要求他们做的事？” |
| 每条都有行为锚点 | 足够具体，可据此作出判断 |
| 包含内在张力 | 好的价值观是有代价的（“速度”意味着“我们接受一定的风险”） |

## 框架 2：从价值观到行为的转化

这项工作能让价值观真正落地。每条价值观都需要具体的行为锚点。

| 价值观 | 模糊版本 | 行为锚点 | 如何观察到它 |
|-------|---------------|-------------------|---------------------|
| 透明 | “我们开放且诚实” | “我们会在 24 小时内分享坏消息，包括向自己的经理汇报” | 坏消息传播迅速，没有意外 |
| 担当 | “我们承担责任” | “我们不会把问题转交出去——即使跨越团队边界，也会负责到底，直至问题解决” | 没有无人负责的问题 |
| 速度 | “我们行动迅速” | “金额低于 $5K 的决策由团队在当天作出” | 决策延迟低 |
| 质量 | “我们不走捷径” | “在交付令自己不满意的成果之前，我们会叫停流程” | 团队会为了质量推迟发布 |
| 客户至上 | “客户是我们的首要任务” | “任何团队成员都可以绕过常规渠道，将客户问题上报给领导层” | 上报问题会受到肯定，而非惩罚 |

### 转化工作坊（90 分钟）

```
For each value:
  Step 1: State the value in 2-3 words
  Step 2: Ask "How would a new hire know we live this on day 30?"
  Step 3: Write 3 observable behaviors that prove this value
  Step 4: Write 3 behaviors that violate this value
  Step 5: Ask "What does this value cost us? What's the trade-off?"
  Step 6: If no trade-off exists, it's not a value -- it's a platitude

Output: Value card with behaviors, violations, and trade-offs
```

## 框架 3：创建文化准则

文化准则是一份公开文档，用于说明你们如何运作。它应当吸引合适的人，并劝退不合适的人。

### 文化准则结构

| 章节 | 目的 | 关键问题 |
|---------|---------|-------------|
| 1. 我们是谁 | 使命、背景、阶段 | “这家公司为何存在？” |
| 2. 什么样的人能在这里蓬勃发展 | 具体行为，而非形容词 | “日常工作中的成功是什么样子？” |
| 3. 什么样的人无法适应这里 | 坦诚描述不匹配的情况 | “我们何时招错过人？其中有什么规律？” |
| 4. 我们如何作出决策 | 决策权、速度要求 | “谁可以决定什么，以及多快作出决定？” |
| 5. 我们如何沟通 | 渠道、节奏、期望 | “在响应时间和透明度方面，我可以期待什么？” |
| 6. 我们如何培养人才 | 职业发展、反馈 | “我在这里的发展路径是什么？” |
| 7. 我们对领导者的期望 | 领导行为 | “管理者应该如何行事？” |

### 文化准则反模式

| 反模式 | 失败原因 | 更好的替代方案 |
|-------------|-------------|-------------------|
| “我们是一家人” | 家庭不会因绩效问题而解雇成员 | “我们是一支彼此关怀的高绩效团队” |
| 只描述正面特质 | 缺乏可信度，也无法帮助人们判断自己是否适合 | 增加“不适合在这里工作的人”章节 |
| 只描述愿景，而非现实 | 当现实与描述不符时，会引发不信任 | 先描述现状，再持续迭代 |
| 太长（> 15 页） | 没人会读 | 控制在 5-8 页，并通过链接提供详细信息 |
| 从不更新 | 随着公司规模扩大，内容会变得不再适用 | 每年审查，并在每个发展阶段更新 |

## 框架 4：文化健康度评估

每季度开展一次。采用匿名形式。最多设置 8-12 个问题。

### 核心评估维度

| 维度 | 问题示例 | 衡量内容 |
|-----------|-----------------|-----------------|
| 心理安全感 | “我可以提出担忧，而不必害怕遭受负面后果” | 对制度的信任 |
| 清晰度 | “我知道自己的工作如何与公司目标相联系” | 战略一致性 |
| 公平性 | “这里的决策始终以一致且透明的方式作出” | 对领导层的信任 |
| 成长 | “我在这里不断学习并接受挑战” | 发展机会 |
| 对领导层的信任 | “我相信领导层告诉我的信息” | 沟通可信度 |
| 认可 | “出色的工作会受到关注和肯定” | 奖励体系的健康度 |
| 归属感 | “我觉得自己属于这个团队” | 包容性的有效程度 |
| 自主性 | “我有足够的自由来发挥出最佳工作水平” | 检测微观管理问题 |

### 分数解读与应对措施

| 分数范围 | 状态 | 所需行动 | 时间要求 |
|-------------|--------|-----------------|----------|
| 80-100% | 健康 | 记录有效做法、庆祝成果并分享实践经验 | 持续保持 |
| 65-79% | 预警 | 找出具体的摩擦点，并解决最主要的 2-3 个问题 | 30 天 |
| 50-64% | 受损 | 需要领导层关注并采取针对性干预措施 | 14 天 |
| < 50% | 危机 | 需要全员参与干预，并可能需要外部协调支持 | 立即 |

### eNPS 集成

```
eNPS Question: "On a scale of 0-10, how likely are you to recommend
this company as a place to work?"

Promoters (9-10)    - Detractors (0-6)   = eNPS
-----------------------------------------
> 50  = Exceptional
30-50 = Good
10-30 = Acceptable
0-10  = Concerning
< 0   = Crisis
```

## 框架 5：不同阶段的文化仪式

仪式是文化的传递机制。适用于 10 人团队的方式，到了 100 人时就会失效。

### 仪式矩阵

| 阶段 | 团队规模 | 关键仪式 | 文化风险 |
|-------|-----------|-------------|-------------|
| 种子期 | < 15 | 每周全员会议（30 分钟）、每月复盘、默认信息透明 | 文化通过耳濡目染形成——有效但无法规模化 |
| 早期增长阶段 | 15-50 | 每季度文化调查、入职伙伴制度、认可计划、领导者开放办公时间 | 首次出现文化传递失效 |
| 规模化阶段 | 50-200 | 文化委员会（同事驱动）、基于价值观的考核、管理者培训、部门及公司全员会议 | 亚文化形成，文化偏移开始 |
| 大型组织阶段 | 200+ | 制定包含 KPI 的年度文化计划、内部 NPS、亚文化管理、并购文化整合 | 缺乏制度支撑时，文化会变得脆弱 |

### 仪式设计模板

| 要素 | 描述 |
|---------|-------------|
| 名称 | 清晰、易记的仪式名称 |
| 目的 | 这项仪式强化了哪一项价值观？ |
| 频率 | 每周、每月、每季度、每年 |
| 时长 | 所需投入的时间（越短越好） |
| 参与者 | 谁参与，谁主持 |
| 形式 | 线下、远程、混合 |
| 衡量方式 | 如何知道它是否有效？ |
| 终止标准 | 何时应停止这项仪式？ |

## 框架 6：文化债务

文化债务像技术债务一样不断累积：微小的妥协会产生复利效应。

### 文化债务清单

| 债务类型 | 示例 | 代价 | 修复难度 |
|-----------|---------|------|----------------|
| 容忍不良行为 | 业绩出色但具有毒性的明星员工 | 团队士气、人员流失 | 高（需要正面交涉） |
| 陈旧的价值观 | 创始团队制定的价值观从未更新 | 玩世不恭、投入度下降 | 中（需要举办研讨会） |
| 缺少仪式 | 没有认可机制，也没有全员大会 | 凝聚力低、孤立感强 | 低（设计并实施） |
| 执行标准不一致 | 对一些人严格要求，对另一些人则不然 | 信任受损、不公平 | 高（需要保持一致） |
| 仅靠耳濡目染传递 | 没有文化入职培训，只靠自然形成 | 新员工无法理解文化 | 中（设计入职培训） |

### 文化债务决策树

```
START: Culture debt identified
  |
  v
[Is it actively causing harm?]
  |
  +-- YES --> [Is the cost of fixing it < cost of keeping it?]
  |            |
  |            +-- YES --> Fix immediately. This week.
  |            +-- NO  --> Fix within 30 days. Plan the transition.
  |
  +-- NO  --> [Will it compound if ignored for 6 months?]
              |
              +-- YES --> Schedule fix within 90 days
              +-- NO  --> Document and monitor quarterly
```

## 远程与混合办公文化

### 远程文化运行原则

| 原则 | 实施方式 |
|-----------|---------------|
| 默认异步 | 优先书面沟通，仅在必要时开会 |
| 有意识地开展社交 | 定期安排与工作无关的社交时间（每周） |
| 充分沟通决策 | 记录决策依据，并广泛分享 |
| 平等参与 | 在混合会议中，远程参与者拥有平等的发言权 |
| 工作可见 | 定期更新进展，让工作成果无需监控也能被看见 |

### 混合会议规则

| 规则 | 理由 |
|------|-----------|
| 只要有一人远程参会，所有人都应各自单独接入 | 防止形成会议室参与者与屏幕参与者之间的对立 |
| 工作会议可选择不开摄像头 | 减少疲劳 |
| 所有会议都使用共享文档 | 促进平等参与 |
| 记录会议及其决策 | 兼顾不同时区 |
| 混合办公日不得在走廊里做决策 | 这会将远程团队成员排除在外 |

## 危险信号

- 价值观贴在墙上，但在绩效评估或决策中从未被提及
- 明星员工不受文化标准约束 -- 这会摧毁公信力
- 领导者“没时间”参加文化仪式 -- 这表明文化并非优先事项
- 新员工觉得文化“与宣传的不一样” -- 文化准则只是虚构
- 没有安全提出文化问题的机制 -- 问题会转入地下
- 文化调查结果不向团队公开 -- 这会滋生不信任
- 尽管组织已大规模扩张，仍有 5+ 年未更新价值观 -- 价值观已经过时
- 创始人不受文化规范约束 -- “照我说的做，别照我做的做”
- 违反价值观不会承担任何后果 -- 价值观只是建议，而非标准
- 文化委员会成员全都来自人力资源部门，没有同级员工参与 -- 这会变成合规工作，而非文化建设

| 当…… | 文化架构师与……协作 | 以…… |
|---------|---------------------------------|-------|
| 招聘激增 | CHRO（`chro-advisor`） | 确保文化契合度经过衡量，而非凭主观猜测 |

| 绩效问题 | CHRO | 区分文化不契合与技能不足 |

| 快速增长 | 所有高管 | 在文化被稀释之前扩展文化仪式 |
| 变革落地 | 变革管理（`change-management`） | 处理变革中的文化层面 |
| 运营系统设计 | 公司操作系统（`company-os`） | 将文化仪式融入会议节奏 |
| 创始人成长 | 创始人教练（`founder-coach`） | 评估领导风格对文化的影响 |

## 主动触发条件

- eNPS 连续 2 个以上季度下降——在演变为人员流失之前调查根本原因
- 快速招聘（单季度员工人数增长 > 30%）——文化传承面临风险
- 已宣布并购——需要立即制定文化整合计划
- 明星员工表现出有毒行为——在 1 周内处理，否则文化债务将不断累积
- 价值观已有 2 年以上未审查——安排价值观更新工作坊
- 远程团队不断壮大，但缺乏有意识的文化设计——存在孤立和文化偏移风险
- 离职面谈将“文化”列为离职原因——需要进行模式分析

## 故障排查

| 问题 | 可能原因 | 解决方案 |
|---------|-------------|------------|
| 价值观张贴在墙上，但从未在决策中被提及 | 价值观是作为愿景练习创建的，而非运营工具 | 开展从价值观到行为的研讨会；将价值观与绩效评估、招聘评分标准和认可机制关联起来 |
| 文化调查评分逐季度下降 | 上一次调查后未解决根本问题 | 按维度分析以定位下降的领域；透明地分享结果；承诺采取有明确截止日期的具体行动 |
| 明星员工不受文化标准约束 | 领导层回避问题，或担心损失产出 | 在 1 周内处理；文化债务每天都在累积；记录其对团队士气和员工流失的影响 |
| 新员工表示，文化“与宣传的不一样” | 文化准则描述的是愿景，而非现实 | 重写文化准则以描述实际情况；如实加入“哪些人不适合在这里发展”部分 |
| eNPS 下降，但领导层声称文化很强 | 领导层脱离一线体验；调查结果未被分享 | 与整个团队分享调查结果；开展越级沟通；解决最主要的 2 个负面反馈主题 |
| 远程团队成员感到被排除在文化之外 | 仪式仅为线下场景设计；混合办公日通过走廊交流做出决策 | 应用远程文化运营原则；为混合办公重新设计仪式；执行“只要有一人远程，所有人都远程参会”的会议规则 |
| 文化委员会没有产生可衡量的影响 | 委员会成员全部来自 HR，没有同级员工代表；没有决策权或预算 | 重新组建委员会，纳入同级员工代表；授予预算和决策权；设定季度文化 OKR |

## 成功标准

- 在全部 8 个评估维度上，文化健康度评分均高于 70%
- eNPS 持续连续 4 个季度高于 30（良好）
- 完成所有声明价值观从价值观到行为的转化，并具备可观察的行为锚点
- 入职 30 天的员工无需提示即可准确描述公司文化
- 每季度审查文化债务清单，且不存在超过 30 天未处理的“严重”事项
- 调查参与率高于 80%，表明员工信任反馈流程
- 不为高绩效员工提供任何文化标准例外（对“才华横溢的混蛋”零容忍）

## 范围与局限

**范围内：** 使命/愿景/价值观研讨会引导、将价值观转化为行为、文化准则制定、文化健康度评估（8 维度调查、eNPS）、按公司发展阶段设计文化仪式、文化债务识别与管理、远程/混合办公文化的运作原则、并购文化整合规划，以及竞争性价值观框架评估。

**范围外：** 人力资源政策制定（使用 hr-operations/）、薪酬与福利设计（使用 chro-advisor）、DEI 项目管理、员工关系与冲突解决、绩效管理体系设计，以及组织重组（使用 coo-advisor）。工具可以分析调查与员工敬业度数据；持续的文化监测需要与人力资源平台集成。

**局限：** 文化评估依赖于诚实的调查反馈；参与率过低（<50%）或对遭到报复的担忧会使结果失效。竞争性价值观框架提供了实用的分析图谱，但过度简化了真实组织文化的复杂性。文化变革进展缓慢（产生有意义的转变需要 12-24 个月）；工具可以衡量进展，但无法加速人的转变过程。并购文化整合评估具有预测性，而非决定性。

## 集成点

- **chro-advisor** -- 招聘与文化契合的员工、将绩效评估与价值观挂钩、分析与文化健康度相关的员工流失
- **ceo-advisor** -- 使文化战略与公司愿景保持一致；结合战略转型更新价值观
- **coo-advisor** -- 将文化仪式嵌入运营节奏；评估组织重组对文化的影响
- **change-management** -- 处理任何重大变革举措中的文化维度；将阻力模式映射到文化类型
- **founder-coach** -- 评估领导风格对文化的影响；根据公开宣示的价值观评估创始人的行为示范
- **company-os** -- 将文化仪式整合到组织运营系统的会议节奏中
