### 1.1 离婚

#### 非司法协议离婚（Lei 11.441/2007）

| 要件 | 细节 |
|-----------|---------|
| **协议一致** | 双方同意离婚及相关条款 |
| **无未成年人/无行为能力子女** | 如有此类子女，依法必须走司法程序 |
| **公开公证书** | 在公证处起草 |
| **律师** | 为必备（双方可由同一律师代理） |
| **时效** | 即时（自EC 66/2010起不再要求分居期限） |
| **平均费用** | 约R$ 1,500至R$ 4,000（公证费+律师费） |
| **财产分割** | 可在同一份公证书中一并处理 |

#### 司法离婚（Art. 731-734 CPC）

| 类型 | 说明 |
|------------|-----------|
| **协议离婚** | 双方同意；由法官确认（Art. 731 CPC） |
| **诉讼离婚** | 无协议；由法官裁决（Art. 693 CPC） |
| **管辖权** | 子女监护住所地或夫妻最后共同住所地（Art. 53, I CPC） |

#### 财产制（Art. 1.639-1.688 CC）

| 制度 | 特征 | 份额 |
|--------|---------------|--------|
| **部分共同财产制**（默认） | 婚姻存续期间取得的财产为共同财产 | 取得财产的50% |
| **共同财产制** | 一切财产均为共同财产（除Art. 1.668列明例外） | 所有财产的50% |
| **完全分离制** | 无共同财产 | 无分割份额 |
| **法定强制分离** | 由法律规定（Art. 1.641 CC） | STF判例汇编第377条：共同财产增值可分割 |
| **终局财产分割参与制** | 婚姻存续期间为分离财产制，终止时进行共同财产分配 | 资产增值的50% |

#### STF判例第377号 — 强制分离制
在强制财产分离制下，婚姻存续期间取得的财产可作分割。

**实践适用：**70岁以上婚姻（Art. 1.641, II CC）——即使系强制分离制，配偶仍有权分得婚姻期间取得财产的份额。

### 1.2 抚养费

#### 法律依据
- **Art. 1.694-1.710 CC** — 亲属、配偶及同居伴侣之间的抚养费  
- **Lei 5.478/1968** — 抚养费法（特别程序）  
- **Art. 528-533 CPC** — 抚养费执行（拘捕、查封、工资扣除）

#### 抚养费类型

| 类型 | 说明 |
|------|-----------|
| **临时抚养费** | 在抚养费诉讼中先行裁定（Art. 4 Lei 5.478） |
| **临时性强制措施** | 在紧急救济中裁定（Art. 300 CPC） |
| **确定性抚养费** | 在判决书中确定 |
| **补偿性抚养费** | 用于弥补财产不平衡（STJ — REsp 1.954.279） |
| **妊娠抚养费** | 适用于孕妇（Lei 11.804/2008） |
| **过渡性抚养费** | 前配偶在恢复自立期间的临时性抚养 |

#### 抚养费执行（Art. 528-533 CPC）

| 路径 | 程序 | 时限 |
|-----|-------------|-------|
| **民事拘留** | Art. 528, par. 3 — 1-3个月封闭性刑期 | 3期付款（STJ判例汇编第309条） |
| **查封** | 按确定金额执行 | 每期每2年时效 |
| **工资扣除** | Art. 529 CPC — 向雇主发出命令 | 不超过净收入的50% |
| **SISBAJUD** | 账户冻结 | 立即 |
| **抗议** | Art. 528, par. 1 — 债权文书抗议 | 无上限 |

#### 需求与支付能力二元框架（Art. 1.694, par. 1 CC）
- **受抚养人需求：** 生活、医疗、教育、住房成本  
- **支付人支付能力：** 收入、财产、生活水平  
- **比例原则：** 法官在两者之间平衡  

#### 认定标准（判例法）

| 情形 | 常见参数 |
|----------|----------------|
| 1名子女（CLT） | 净收入的30% |
| 2名子女（CLT） | 33%-40% |
| 3名及以上子女（CLT） | 40%-50% |
| 个体工商户/非正式劳动者 | 最低工资比例（1-3个最低工资） |
| 前配偶抚养费 | 收入的20%-33%（临时） |

### 1.3 稳定伴侣关系（Art. 1.723-1.727 CC）

| 方面 | 细节 |
|---------|---------|
| **要件** | 公开、持续、长期同居，并以组建家庭为目的 |
| **财产制度** | 共有制部分财产（除非另有约定——Art. 1.725 CC） |
| **确认方式** | 可通过司法、非司法（公证书）或死后确认 |
| **继承权** | 伴侣与后代及祖辈/父辈一同继承（Art. 1.790 CC — 已被STF在RE 878.694中认定违宪） |
| **居住权** | 有（类推适用于婚姻关系——STJ） |
| **解除** | 与离婚程序相同（Art. 7, par. 2 Lei 9.278/96） |

### 1.4 父系身份调查

| 方面 | 细节 |
|---------|---------|
| **法律依据** | Lei 8.560/1992 + Art. 1.606-1.617 CC |
| **诉讼类型** | 父系身份调查与抚养费并行 |
| **管辖权** | 未成年人住所地（Art. 53, II CPC） |
| **DNA** | 首选专家证据；但拒绝可产生推定（STJ判例汇编第301条） |
| **不受时效影响** | Art. 27 ECA — 本案由主张可免于时效限制 |
| **否认** | Art. 1.601 CC — 丈夫可提起否认亲子关系之诉 |
| **社会关系亲子性** | STF主题622 — 社会亲子身份不排除生物学亲子身份 |

### 4.1 离婚财产分割

#### 可分有财产 vs 不可分有财产（共同财产制）

| 可分（按50%份额） | 不可分（个人财产） |
|------------------------|----------------------------------|
| 婚姻存续期间购置的不动产 | 婚前财产（《民法典》第一百六十九条第 I 款） |
| 婚姻存续期间购置的车辆 | 继承和受赠财产（《民法典》第一百六十九条第 I 款） |
| 以劳动收入形成的投资 | 个人财产的代位取得财产（《民法典》第一百六十九条第 II 款） |
| 联名账户余额 | 依法设有不可分有约定的财产（《民法典》第一百六十九条第 III 款） |
| 婚姻存续期间累计的 FGTS（STJ） | 个人使用财产、书籍、职业工具（《民法典》第一百六十九条第 V 款） |
| 私人养老保险（STJ — 有分歧） | 个人劳动所得（《民法典》第一百六十九条第 VI 款）— 有争议 |

#### 资产评估

| 方法 | 适用情形 |
|--------|-------------|
| 鉴定评估（Art. 464 CPC） | 不动产、公司、 高价值财产 |
| 当事人协议 | 一致离婚—由双方确定价值 |
| 市场评估（经纪人/评估师） | 住宅不动产、机动车 |
| 资产负债表 | 社会持股、企业股权 |

### 4.2 死亡继承中的遗产清算与分割

#### 非司法遗产清算（Art. 610, par. 1 CPC + Lei 11.441/2007）

| 要件 | 说明 |
|-----------|---------|
| 所有继承人均为成年人且有行为能力 | 必要条件 |
| 对分割方案达成一致 | 所有人同意 |
| 无遗嘱 | 一般规则（例外：CNJ第35/2007号决议，Art. 12-A 允许遗嘱已生效） |
| 公证书 | 公证处出具，适用任一司法区 |
| 律师 | 必要 |
| 时限 | 自继承开始起 60 天（Art. 611 CPC）— 超期征收 ITCMD 罚金 |

#### 司法遗产清算（Art. 610-673 CPC）

| 类型 | 适用情形 |
|------------|--------|
| **简易清算**（Art. 659 CPC） | 继承人有行为能力 + 达成协议 |
| **普通清算**（Art. 664 CPC） | 财产总额不超过 1,000 个最低工资 |
| **传统遗产清算**（Art. 610 CPC） | 继承人无行为能力、存在争议、遗嘱存在 |

#### 继承顺序（Art. 1.829 CC）

| 顺序 | 继承人 | 说明 |
|-------|-----------|-----------|
| 第一顺序 | 后代 + 配偶 | 配偶与后代共同继承（《民法典》第一百八十三条） |
| 第二顺序 | 上代 + 配偶 | 配偶与父母共同继承时，配偶分得 1/3（《民法典》第一八三七条） |
| 第三顺序 | 生存配偶（单独） | 承继全部遗产 |
| 第四顺序 | 同属四亲等以内的旁系亲属 | 兄弟姊妹、侄子侄女、叔叔阿姨、表亲 |

#### 生存配偶权利

| 财产制度 | 与后代共同继承? | 法理依据 |
|----------------|--------------------------|------|
| 共同财产制 | 是，共同继承亡者的**个人财产** | 《民法典》第一百八二十九条 I |
| 全部共有制 | 否 | 《民法典》第一百八十二条 I |
| 法定分离财产制 | 否（有争议—STF Súmula 377） | 《民法典》第一百八二条 I |
| 协议分离财产制 | 是，共同继承全部财产 | STJ — REsp 1.382.170 |

#### 同居伴侣（稳定同居关系）
- **STF RE 878.694（Tema 498）**：将同居伴侣在继承意义上与配偶等同
- Art. 1.790 CC 被宣告违宪——适用 Art. 1.829 CC

|---------|---------|

### 5.1 监护权类型（Art. 1.583-1.590 Cc + Lei 13.058/2014）

| 类型 | 描述 | 法律依据 |
|------|-----------|------|
| **共有监护** | 原则——双方均行使监护权，即便无共识 | 《民法典》1.584条第2款 |
| **单独监护** | 一方行使监护，另一方享有探视权 | 《民法典》1.583条第1款 |
| **轮换监护** | 子女按周期交替居住 | 判例法（未在法条明确规定） |
| **嵌套式监护** | 子女固定居住点，父母轮流抚养 | 巴西少见 |

### 5.2 共有监护（Lei 13.058/2014）

| 方面 | 说明 |
|---------|---------|
| **一般规则** | 即便无协议，仍为**一般规则**（《民法典》1.584条第2款） |
| **例外** | 仅在一方明确表示不愿意监护或不具备条件时不适用 |
| **居住基础** | 子女有稳定居住地，但与双方共同生活 |
| **共处时间** | 平衡分配，不必严格 50/50 |
| **共同决策** | 双方共同决定健康、教育、娱乐等事项 |
| **抚养费** | 共有监护不排除抚养费义务（STJ — REsp 1.629.994） |

### 5.3 探视安排（Art. 1.589 Cc）

| 方面 | 说明 |
|---------|---------|

### 5.4 父母疏离（Lei 12.318/2010）

#### 定义（Art. 2）
由一方父母（或祖辈/监护人）为损害子女与另一方父母关系而对其心理形成进行干预。

#### 亲权疏离形式（Art. 2，paragrafo unico）

| # | 形式 |
|---|-------|
| I | 对另一方监护人的抹黑、贬损活动 |
| II | 妨碍监护权的行使 |
| III | 妨碍孩子与另一方监护人接触 |
| IV | 妨碍探望权的行使 |
| V | 隐瞒相关个人信息（学校、健康） |
| VI | 提出虚假指控以阻碍探望 |
| VII | 搬迁住所以妨碍探望 |

#### 制裁（Art. 6）

| 制裁 | 严重性 |
|--------|-----------|
| 警告 | 轻微 |
| 扩大共居制度 | 中等 |
| 罚款 | 中等 |
| 心理跟踪 | 中等 |
| 更改监护权 | 严重 |
| 暂停监护权 | 非常严重 |

## 完整案件分析流程（12 阶段）

对于任何复杂的法律案件，请按以下12个步骤执行：

## 第1步 — 法律定性

- 法律领域（对应哪个模块？）
- 主要法律依据（哪部法律、哪一条、哪一款？）
- 管辖权（是哪个法庭/法庭庭室/法院？）

## 第2步 — 参与方

- 当事人识别（原告/被告/第三方）
- 当事人关系（家庭、合同、非合同）
- 脆弱性（未成年人、老年人、消费者、处于弱势方）

## 第3步 — 相关事实

- 事件时间线
- 现有文件/需要的文件
- 可用证人和证据

## 第4步 — 法律依据

- 适用法律条款
- 相关判例（STJ、STF、TJs）
- 相关学说（在适当时）

## 第5步 — 实质分析

- 客户权利是否有充分依据？
- 是否存在可行的法律对抗？
- 现有证据的强度如何？

## 第6步 — 程序风险

- 时效中断或时效消灭
- 诉讼资格与利益
- 地域/实体管辖
- 时限的既判力（逾期丧失）

## 第7步 — 结果预估

- 乐观情景
- 基准情景（最可能）
- 悲观情景

## 第8步 — 费用估算

- 诉讼费用
- 律师费（约定和败诉相关）
- 鉴定费及附带费用
- 诉讼费减免（如符合条件——CPC第98条）

## 第9步 — 诉讼策略

- 非诉讼途径（调解、和解、仲裁）
- 司法途径（程序、请求项、紧急救济）
- 可提起的上诉方式

## 第10步 — 相关期限

- 权利时效
- 程序时限
- 上诉期限
- 判决执行期限

## 第11步 — 紧急措施

- 预防性紧急保护（CPC第300条）
- 证据性质紧急保护（CPC第311条）
- 保护性措施（如适用）
- 特定的保全措施
