## 竞争对手作战卡

创建一份简洁、适合销售人员使用的作战卡，用于应对特定竞争对手。

### 背景

你正在为 **$ARGUMENTS** 创建竞争作战卡。

使用网络搜索研究竞争对手当前的产品、定价、市场定位和近期变化。如果用户提供了文件（功能列表、赢单/输单数据、销售通话记录），请先阅读这些文件。

### 说明

1. **研究竞争对手**（使用网络搜索）：
   - 当前的产品和功能
   - 定价层级和定价模式
   - 目标市场和市场定位
   - 近期产品发布或变更
   - 已知优势和劣势
   - 客户评价和舆论倾向（G2、Capterra、Reddit）

2. **创建作战卡**，包含以下部分：

   ### 公司概览
   - 成立时间、总部、融资/收入（如为公开信息）
   - 目标市场和 ICP
   - 用一句话概括其市场定位

   ### 快速对比

   | 能力 | 我们 | 他们 | 胜者 |
   |---|---|---|---|
   | [功能领域 1] | [我们的方式] | [他们的方式] | [我们/他们/平局] |
   | [功能领域 2] | ... | ... | ... |
   | 定价 | ... | ... | ... |
   | 支持 | ... | ... | ... |

   ### 我们的优势
   - [优势 1]：[证明要点或客户引述]
   - [优势 2]：[他们缺少的具体能力]
   - [优势 3]：[更好的方式及其理由]

   ### 他们的优势
   - [他们的优势 1]：[我们的反向定位]
   - [他们的优势 2]：[我们如何弥补这一差距]

   ### 常见异议与回应

   | 潜在客户说 | 回应 |
   |---|---|
   | "竞争对手 X 有[某项功能]" | "[我们的替代方案，以及为什么对他们更好]" |
   | "他们更便宜" | "[价值阐释：总拥有成本、投资回报率、隐性成本]" |
   | "他们更成熟" | "[我们的优势：速度、创新、专注度、支持]" |

   ### 埋设引导点
   向潜在客户提出能够凸显竞争对手弱点的问题：
   - "对于您的团队而言，[我们擅长的领域]有多重要？"
   - "您是否评估过[他们缺少的具体能力]？"

   ### 赢单/输单模式
   - 我们往往在以下情况下赢单：[模式]
   - 我们往往在以下情况下输单：[模式]
   - 竞争性交易中的关键差异化因素：[决定胜负的因素]

3. **确保内容便于快速浏览**：销售人员需要在通话期间参考这份材料。使用表格、**粗体**和简短的项目符号。

保存为 markdown。格式应便于打印或分享到 Notion/Confluence。
