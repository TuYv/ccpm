# 营销活动概念与文案

1. 加载已验证的设置/品牌档案、目标、受众、优惠、证明材料、平台/版位要求、政策背景以及可选的审计发现。
2. 区分事实性声明、运营方批准的声明和创意假设。
3. 生成实质上不同的策略概念，而不是仅做表面改写。
4. 为每个概念定义洞察、承诺、证明、钩子、叙事、CTA、异议、平台适配方案、目标页面和实验假设。
5. 根据当前平台参考资料验证文案限制和政策。仅加载 `ads/references/google-creative-specs.md`、`meta-creative-specs.md`、`youtube-creative-specs.md`、`linkedin-creative-specs.md`、`tiktok-creative-specs.md` 和 `microsoft-creative-specs.md` 中当前使用的文件；对于每一项当前规范声明，都应使用注明日期的来源台账。
6. 在运行目录中返回带版本号的创意简报和文案集。

不得虚构客户证言、认证、稀缺性、价格、结果或受监管的声明。在制作或发布之前，仍须经过人工审核。
