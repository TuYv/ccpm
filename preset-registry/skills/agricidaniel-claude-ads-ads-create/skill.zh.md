# Campaign Concepts and Copy

1. 加载经过验证的设置/品牌资料、目标、受众、优惠、证明材料、平台/版位要求、政策背景，以及可选的审计结果。
2. 区分事实性声明、经运营方批准的声明和创意假设。
3. 对于 Meta 工作，根据 `skills/ads-meta/SKILL.md` 中的契约收集账户、Pixel 和转化冷启动维度。当任何维度处于冷启动或为 `unknown` 时，应在简报中说明这一点，不得复用成熟账户的创意基准或效果声明，也绝不能仅因 Pixel 是新的就判定现有创意质量不佳。
4. 生成具有实质差异的策略概念，而不是仅对措辞进行表面改写。
5. 为每个概念定义洞察、承诺、证明、钩子、叙事、CTA、异议、平台适配、落地页以及实验假设。
6. 根据当前平台参考资料验证文案限制和政策。仅加载 `ads/references/google-creative-specs.md`、`meta-creative-specs.md`、`youtube-creative-specs.md`、`linkedin-creative-specs.md`、`tiktok-creative-specs.md` 和 `microsoft-creative-specs.md` 中处于启用状态的文件；所有当前规范声明均须使用带日期的来源台账。
7. 在运行目录中返回一份带版本号的创意简报和文案套件。

不得虚构推荐语、认证、稀缺性、价格、效果或受监管声明。在进入制作或发布前，仍必须经过人工审核。
