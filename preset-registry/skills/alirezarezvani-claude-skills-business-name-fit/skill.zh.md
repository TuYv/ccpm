# 商业名称适配度

## 概述

帮助创始人选择或检查一个真实体现其来源，**并且**在其经营市场中获得良好反响的企业/品牌/产品名称。

核心价值在于发现两者之间的不匹配：一个名称在其母语中可能完全没问题，但在其他地方却可能令人困惑、觉得滑稽或产生反感。例如：
- 波斯语名称 "Anali" 在伊朗没有问题，但英语使用者听来会觉得很奇怪。
- 瑞典语单词 "framåt"（“向前”）对英语听者来说可能听起来像 "frame"。

此技能既能**提出新名称**，也能**检查用户已有的名称**。

## 第 1 步——收集必要信息

如果调用此技能时没有其他信息可供参考（例如仅输入 `/business-name-fit`，没有名称，也没有上下文），不要直接开始下面的完整提问清单。先问一个问题，并等待对方回答：

> 你是想**寻找一个新名称**，还是想**检查已有的名称**？

对方回答后，只询问对话中仍然缺失的信息。控制在几个简短问题之内。

1. **来源**——创始人的文化/语言背景，或公司的所在地（例如波斯语/伊朗、瑞典语/瑞典、普通话/中国）。
2. **目标市场**——业务将在哪些地方开展（例如国际市场/英语国家和地区、欧盟、中国、阿拉伯语国家）。目标市场可以不止一个。
3. **业务领域**——所属行业或领域，因为不同领域需要不同的调性（律师事务所和糖果品牌需要的感觉就不同）。
4. **模式**——他们是想要新的名称创意、检查已有名称，还是两者都要？（如果技能一开始就提出了“寻找新名称还是检查已有名称”的问题，这一点已经回答过了。）
5. **已有名称**——如果是检查名称，收集候选名称。
6. **期望的感觉**（可选）——现代、传统、俏皮、高端等。

## 第 2 步——执行适配度检查（技能的核心）

针对每个目标市场，对每个候选名称执行以下所有检查：

- **含义**——在目标市场的语言中，它是否有未被预期的、负面的、滑稽的或忌讳的含义？包括俚语。
- **相似词形**——它是否类似于某个会改变整体印象的现有词语（例如 framåt → "frame"）？
- **发音**——目标市场中的人能否轻松读出这个名称，还是会把它读得面目全非？
- **拼写**——听到这个名称后，他们能否正确拼写？注意容易混淆的字母组合，以及在英语中可能无法保留的来源语言变音符号（å、ø、ç 等）。
- **独特性**——按照 WIPO 的分类标准，它属于通用名称、描述性名称、欺骗性名称、暗示性名称、任意性名称，还是臆造名称？通用名称和描述性名称缺乏显著性，通常根本无法注册——要明确说明这一点，因为创始人可能基于这样的名称建立企业，却始终无法拥有该名称的权利。直接拒绝欺骗性名称。必须**分别针对每个市场**进行判断：一个词在本土市场可能明显属于描述性名称，在海外却可能属于任意性名称且具有较强显著性；反过来也一样。
- **声音**——把它大声读出来。它的声音感觉是否符合该领域？前元音（ee、i）给人的感觉轻快、迅速；后元音（o、u）给人的感觉坚实、厚重；爆破音（p、t、k、b、d、g）尖锐而有力量；柔和的擦音和鼻音（s、f、m、l、n）流畅而温和。要诚实指出，这些联想主要来自英语语言研究，并不会自动适用于其他语言。
- **调性适配**——它对于该行业和该市场来说，是否给人值得信赖且恰当的感觉？
- **来源真实性**——它是否仍然真实反映创始人的来源，还是已经被抹平为某种泛化名称？

同时也要权衡经典的评估标准：与品类的相关性、内涵、整体喜好度、易识别性、独特性以及易回忆性。

`references/naming-research.md` 收录了这些检查背后的来源和推理——当创始人询问*为什么*时，或当需要深入解释某个名称类别或语音效果时，请阅读该文件。`references/worked-examples.md` 展示了三个从头到尾的完整案例（一个名称经过修正、一个名称获批、一个名称被否决）——当你需要参考一份完成后的分析应当如何呈现时，请阅读该文件。

要诚实说明信心程度。如果不确定某个名称在某种语言中是否带有奇怪的含义或俚语含义，请直说，并建议创始人在最终确定之前请母语使用者进行核查。

## 第 3 步——如果要提出新名称

每个建议必须**同时满足三项约束**：植根于名称的来源语言、适合该行业且专业、在目标市场中没有明显问题。只满足其中两项的名称不是有效建议——放弃它，另找一个。

**3a. 先撰写命名简报——然后再生成任何名称。**
创始人（以及企业通常也是如此）往往要等到已经喜欢上某个候选名称之后，才弄清楚自己真正想从名称中得到什么，这会扭曲判断。因此要先把要求写下来，用一两行说明：企业向客户承诺什么、这一承诺需要传达什么感受，以及名称因此必须实现什么。然后选择能够承载这一含义的来源语言词汇。其逻辑示例如下：
- 儿童照护 → 温暖、安全、温柔。不是力量或速度。
- 咨询、法律、金融 → 能力、稳定、谨慎。不是可爱。
- 艺术品鉴定、认证、安全 → 真实性、精准、信任。
- 健康 → 关怀、洁净、平和。
- 科技 → 清晰、动感、向前。

优先选择一个**其字面含义本身就是价值主张**的词——对于一家鉴定公司而言，一个意为“真实”的波斯语词胜过一个仅仅优美的词。但不要直白地描述产品：应以能够*暗示*产品的名称（联想型）、使用无关但真实存在的词（任意型），或创造出来的词（创意型）为目标。与描述型名称相比，这些名称既更容易记住，也更有可能成功注册。

**3b. 从来源语言中提取原始素材。**
- 来源语言中的真实词汇、词根、姓名、地名或概念。
- 经过塑造成简短、易读形式的、有意义的文化意象（自然、价值观、神话）。
- 保留来源语言风味的轻度融合词或新造词。

**3c. 应用专业品质标准。** 如果候选名称存在以下情况，应予以否决：
- 在目标市场中听过一次后仍难以读出或拼写；
- 语气与所在领域冲突（律所使用活泼的名称，玩具品牌使用临床化的名称）；
- 需要依靠重音符号或非拉丁字符才能正确读出；
- 长度超过约三个音节，或看起来像一串随机编造的字符；
- 听起来像个人名字，而企业需要机构层面的可信度。

**3d. 根据市场的命名惯例进行合理性检查。** 名称在不同地区的分量不同——在海湾地区显得自信的名称，在北欧可能会显得夸张。确保这个名称与该行业及该市场中已经成立的企业名称放在一起时不会显得格格不入。

**3e. 将每个保留下来的候选名称都执行一遍第 2 步检查**，然后交给第 4 步进行呈现。

与其列出一长串较弱的选项，不如提供 3–5 个强有力的候选名称。

## 第 4 步 — 呈现结果

默认情况下，**每次都使用紧凑型表格**——检查现有名称和呈现新建议都应采用这种方式。整个答案应一目了然：无需滚动浏览大段文字来寻找结论。

- **检查名称**——每个名称一行（如果有多个市场，则每个名称 × 市场一行）。只设置对该名称实际有影响的检查项列——不必每次都列出全部八项。单元格中放置一个符号加 2–4 个词（例如 `❌ reads as slur (EN)`、`⚠️ crowded namespace`），绝不写完整句子。
- **建议名称**——每个候选名称一行：来源含义、目标市场解读、结论。同样遵循这一规则——单元格中使用短语，而不是段落。

表格之后，最多添加一行简短文字，列出 2–3 个最强选项。绝不要把单个最爱选项呈现得仿佛它是唯一选择。

到此为止。**不要**添加逐项检查明细、推理段落，或针对每个名称的书面结论，除非对方要求更多信息——例如“为什么”“解释一下”“告诉我更多关于 X 的信息”“详细报告”——在这种情况下，只扩展对方所要求的部分，并且仍应尽量简洁明了。

## 第 5 步 — 交接验证步骤

每次会话结束时，都要附上仍需检查的事项列表——每项一行；此技能无法确认其中任何一项：

- **商标**——在为名称投入资金之前，搜索每个目标市场的商标注册数据库（这是正式步骤，而不是事后补救）。
- **域名和账号**——确认创始人实际会使用的平台上的可用性。
- **企业注册**——确认所在国家的公司注册登记。
- **母语者直觉检查**——请每个目标市场的一名真实母语者检查最终候选名称。

只有在对方要求时，才详细展开其中任何一项。

## 反模式

- **不要只凭直觉拆分检查。** 一个名称可能通过发音检查，却无法通过形似或拼写检查（也可能反过来）——始终执行每一项检查，不要因为某一项检查看起来已经得出明确结论就停止。参见 `references/worked-examples.md` 中的场景 A。
- **不要仅凭含义就称某个名称“安全”。** 独特性（WIPO 量表）是一个独立的法律问题。一个名称在语言上可能没有问题，却仍然通用或具描述性——较弱且难以注册——反之亦然。
- **不要将英语/西方语境中的声音象征意义研究结果视为普遍规律。** 这些结论主要来自英语研究（Pogacar 等人），并不会自动适用于波斯语、阿拉伯语、普通话或任何其他目标市场——在相关时要明确说明这一点。
- **不要只呈现一个最爱选项。** 提供 3–5 个候选名称；创始人只评估一个选项，就不算是在进行评估。
- **当技能启动时没有上下文，不要跳过查找或检查问题。** 猜测来源、市场或行业，会产生不合适的建议。
- **不要让此技能的输出替代验证。** 它无法检查商标、域名或企业注册的可用性——始终以第 5 步结束。
- **默认不要写逐项检查的长篇文章。** 默认输出应为紧凑型表格（第 4 步）；只有在对方要求时才展开。
