# 社交媒体营销活动分析器

此技能可全面分析社交媒体营销活动的表现，帮助营销机构为客户提供可落地的洞察。

## 功能

- **多平台分析**：跟踪 Facebook、Instagram、Twitter、LinkedIn、TikTok 上的表现
- **互动指标**：计算互动率、覆盖人数、展示次数和点击率
- **ROI 分析**：衡量单次互动成本、单次点击成本和广告支出回报率
- **受众洞察**：分析人口统计特征、互动高峰时段和内容表现
- **趋势检测**：识别表现优异的内容类型和发布规律
- **竞争基准比较**：将表现与行业标准进行比较

## 输入要求

营销活动数据，包括：
- **平台指标**：点赞、评论、分享、收藏、点击
- **覆盖数据**：展示次数、独立覆盖人数、粉丝增长量
- **成本数据**：广告支出、营销活动预算（用于 ROI 计算）
- **内容详情**：帖子类型（图片、视频、轮播）、发布时间、话题标签
- **时间段**：分析的日期范围

接受的格式：
- 包含结构化营销活动数据的 JSON
- 从社交媒体平台导出的 CSV
- 对关键指标的文本描述

## 输出格式

结果包括：
- **表现仪表板**：关键指标及其趋势
- **互动分析**：表现最佳和最差的帖子
- **ROI 明细**：成本效益指标
- **受众洞察**：人口统计特征和行为模式
- **建议**：基于数据的优化建议
- **可视化报告**：图表和图形（Excel/PDF 格式）

## 使用方法

“分析此 Facebook 营销活动数据并计算互动指标”
“这个 Instagram 广告活动花费 $500 并获得 2,000 次点击，其 ROI 是多少？”
“比较上个月所有社交平台的表现”

## 脚本

- `calculate_metrics.py`：用于计算所有社交媒体指标的核心计算引擎
- `analyze_performance.py`：表现分析和建议生成

## 最佳实践

1. 分析前确保数据完整（缺失指标会影响准确性）
2. 在相同时间段内比较指标，以确保比较公平
3. 考虑特定平台的基准（Instagram 的互动情况与 LinkedIn 不同）
4. 分别统计自然流量指标和付费指标
5. 持续跟踪指标，以识别趋势
6. 解读结果时应结合背景因素（季节性、营销活动、事件）

## 局限性

- 需要来自社交媒体平台的准确数据
- 行业基准仅为一般性指导，会因细分领域而异
- 历史数据不能保证未来表现
- 自然覆盖人数的计算可能会因平台算法变化而有所不同
- 无法直接从平台访问数据（需要手动导出或进行 API 集成）
- 部分平台会限制数据的可用性（例如，TikTok 分析功能仅面向企业账号开放）
