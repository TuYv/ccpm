# 阿肯色州销售税和使用税技能 v2.0

> **仅供一般参考。** 本技能是用于 AI 辅助工作流的一般税务/会计参考资料。尚未针对任何特定个人的事实情况、文件、选择、截止日期、居住地、申报身份或当地程序进行审核。未经相关司法管辖区的合格专业人士审核，请勿依赖本技能进行申报、缴税、修正申报或采取税务立场。

## 第 1 节——快速参考

| 字段 | 值 |
|---|---|
| 司法管辖区 | 阿肯色州 |
| 州税率 | 6.50% |
| 食品杂货州税率 | 0.125%（优惠税率；地方税率仍按全额税率适用） |
| 最高综合税率 | ~11.625% |
| 税源归属 | 基于目的地（SST） |
| 经济关联标准 | $100,000 或 200 笔交易 |

| 门户网站 | https://atap.arkansas.gov |
| SST 成员 | 是——正式成员 |
| 技能版本 | 2.0 |

## 第 3 节——交易模式库

| 模式 | 是否应税？ | 备注 |
|---|---|---|
| 一般 TPP | 应税 6.50% | |
| 服装 | 应税 | 无免税规定 |
| 食品杂货（未经加工制作） | 0.125% 州税 + 全额地方税 | 适用优惠税率，并非免税 |
| 预制食品 | 应税 6.50% | |
| SaaS | 不应税 | 未明确征税 |
| 预制软件（下载） | 应税 | |
| 专业服务 | 不应税 | |
| 制造设备 | 免税 | |
| 处方药 | 免税 | |
| 转售 | 免税 | |

## 第 10 节——禁止事项

- 绝不能声称食品杂货免税——其适用 0.125% 的州税以及全额地方税。
- 绝不能忘记 SST 证书可被接受。
- 绝不能计算任何数值。
